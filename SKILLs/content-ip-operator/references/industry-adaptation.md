# 行业适配详细指南

> 本文件是 content-ip-operator 的§4.4行业适配的详细展开。按行业类别提供周度内容方向、弹药使用策略、转化路径的具体适配建议。

---

## 使用方法

1. 从IP档案读取"行业/赛道"字段
2. 匹配下方行业类别（无法精确匹配时，取最近似类别）
3. 按行业类别的"周度方向适配表"调整规划表中的内容方向
4. 结合IP象限和IP类型做二次微调

---

## 一、B端制造业/供应链

**典型IP**：耗材把关人（黄纯）、PCB解决方案（蒋怡微）

**行业特征**：客户是企业决策者，决策周期长，信任靠专业度+供应链实力，转化路径长。

### 周度方向适配

| 星期 | 标准方向 | 制造业适配 | 形式建议 |
|------|---------|-----------|---------|
| 周一(破圈) | 划清界限 | 行业认知误区（如"原厂维保绑架客户"） | 观点口播 |
| 周二(种草) | 给出路径 | 诊断型内容（帮客户算账：原装vs兼容成本对比） | 白板讲解/实物对比 |
| 周三(升维) | 建立信任 | 供应链实地探访/工厂跟拍 | 探访跟拍 |
| 周四(破圈) | 定义问题 | 行业热点解读（如大厂退出某市场） | 热点解读 |
| 周五(种草) | 信任建设 | 工作过程（验货/选品/出货实拍） | VLOG/场景 |

### 弹药使用策略
- 轻型：行业冷知识、验货技巧 → Phase 1
- 中型：客户踩坑案例、供应商对比 → Phase 1后段-Phase 2
- 重型：差点倒闭的经历、大客户翻盘故事 → Phase 2

### 转化路径
- 展会名片 → 加微信 → 寄样品 → 小批量试单 → 长期合作
- CTA设计：评论区扣1发产品手册 / 主页有联系方式

### 特别注意
- 制造业客户看数据。能算账的内容数据好（如"一台机器一天省4万"）
- 实物展示比口播有效。能用产品/工厂/仓库画面的不用纯口播
- 行业术语可以保留（目标客户听得懂），但要做"翻译"

## 二、B端专业服务

**典型IP**：口岸规划（邓军）、品牌咨询、法律/财税服务

**行业特征**：卖的是专业能力，客户是B端决策者，信任靠案例+方法论+行业地位。

### 周度方向适配

| 星期 | 标准方向 | 专业服务适配 | 形式建议 |
|------|---------|-------------|---------|
| 周一(破圈) | 划清界限 | 行业标准讨论（"什么是真正的XX"） | 观点口播 |
| 周二(种草) | 给出路径 | 方法论拆解（你的独门方法） | 白板讲解/案例拆解 |
| 周三(升维) | 建立信任 | 标杆客户案例复盘 | 案例讲述 |
| 周四(破圈) | 定义问题 | 行业趋势判断/政策解读 | 热点解读 |
| 周五(种草) | 信任建设 | 工作日常（见客户/做方案/开会） | VLOG |

### 弹药使用策略
- 轻型：行业趣闻、工作方法 → Phase 1
- 中型：大客户合作故事、项目复盘 → Phase 1后段-Phase 2
- 重型：职业转折点、行业危机应对 → Phase 2

### 转化路径
- 内容种草 → 咨询预约 → 方案沟通 → 签约
- CTA设计：主页预约咨询 / 评论区留需求

### 特别注意
- 专业服务忌讳"自嗨"。每条内容必须回答"这跟客户有什么关系"
- 方法论是核心资产。你的独门方法要反复讲，不要怕重复——受众是流动的
- 案例要有"过程"不只"结果"。"帮XX公司做了什么"不如"XX公司当时面临什么→我做了什么→结果是什么"

## 三、C端高客单服务

**典型IP**：港爸老肖（保险/资产配置）、衣品架构师（江总）

**行业特征**：客单价高，决策周期长，信任是核心驱动力，客户买的不是产品是"人"。

### 周度方向适配

| 星期 | 标准方向 | 高客单适配 | 形式建议 |
|------|---------|-----------|---------|
| 周一(破圈) | 划清界限 | 定义问题（"你以为XX很重要，其实XX才是关键"） | 观点口播 |
| 周二(种草) | 给出路径 | 客户故事（真实案例，有情绪有转折） | 旁白视频/场景口播 |
| 周三(升维) | 建立信任 | 深度人物故事/个人经历 | 旁白视频 |
| 周四(破圈) | 定义问题 | 行业痛点揭秘（打破信息差） | 观点口播 |
| 周五(种草) | 信任建设 | 工作日常/生活状态（展示真实的人） | VLOG |

### 弹药使用策略
- 轻型：入行故事、日常工作 → Phase 1
- 中型：客户转化故事、关键决策时刻 → Phase 1后段-Phase 2
- 重型：人生转折点、最失败的经历、最深刻的案例 → Phase 2

### 转化路径
- 内容种草 → 信任建立 → 1对1咨询 → 成交
- CTA设计：主页有联系方式 / 私信预约咨询

### 特别注意
- 高客单的核心是"信人"。50%以上的内容必须是信任型（人物故事/案例/价值观）
- 忌讳硬推产品。高客单客户反感"推销感"，内容要"让他主动想了解"
- 个人故事是最稀缺的弹药。不要一次用完，分散到12周
- 旁白视频是最佳形式——叙事感强，适合讲人物故事

## 四、C端消费品

**典型IP**：服装、美妆、食品、日用品品牌主理人

**行业特征**：客单价低，决策快，流量驱动，信任靠产品体验+口碑。

### 周度方向适配

| 星期 | 标准方向 | 消费品适配 | 形式建议 |
|------|---------|-----------|---------|
| 周一(破圈) | 划清界限 | 使用场景痛点（"你是不是也遇到过XX"） | 场景口播 |
| 周二(种草) | 给出路径 | 产品体验/使用效果展示 | 实物展示/对比 |
| 周三(升维) | 建立信任 | 用户反馈/买家秀/复购故事 | 证言型内容 |
| 周四(破圈) | 定义问题 | 品类知识/选购避坑 | 科普型内容 |
| 周五(种草) | 信任建设 | 品牌幕后/生产过程/团队日常 | VLOG |

### 弹药使用策略
- 轻型：产品冷知识、使用技巧 → Phase 1
- 中型：爆款打造故事、用户转变案例 → Phase 1后段-Phase 2
- 重型：创业低谷、差点关门的经历 → Phase 2

### 转化路径
- 内容种草 → 主页店铺/小黄车 → 下单 → 复购
- CTA设计：主页有店铺 / 视频挂车 / 评论区有链接

### 特别注意
- 消费品流量优先。破圈型可以加到60%（流量型象限）
- 产品展示比讲道理有效。能用画面展示效果的不用口播解释
- 用户证言是最强种草。真实买家反馈 > 你自己说产品好
- 直播是核心转化场。Phase 3的直播权重可以更高

## 五、知识/教育/培训

**典型IP**：行业培训师、知识博主、教育机构创始人

**行业特征**：卖的是知识/方法论，客户为"成长"付费，信任靠专业度+学员成果。

### 周度方向适配

| 星期 | 标准方向 | 知识教育适配 | 形式建议 |
|------|---------|-------------|---------|
| 周一(破圈) | 划清界限 | 认知颠覆（"你以为XX是对的，其实错了"） | 观点口播 |
| 周二(种草) | 给出路径 | 干货拆解（方法论步骤化） | 白板讲解/屏幕录制 |
| 周三(升维) | 建立信任 | 学员案例/转变故事 | 案例讲述 |
| 周四(破圈) | 定义问题 | 行业洞察/趋势判断 | 热点解读 |
| 周五(种草) | 信任建设 | 备课/教研/上课日常 | VLOG |

### 弹药使用策略
- 轻型：教学技巧、学员提问 → Phase 1
- 中型：学员转变故事、课程迭代经历 → Phase 1后段-Phase 2
- 重型：教育理念转折点、行业乱象亲历 → Phase 2

### 转化路径
- 内容种草 → 体验课/资料包 → 正价课/社群 → 复购/转介绍
- CTA设计：评论区领资料 / 主页体验课

### 特别注意
- 知识型IP最怕"空讲理论"。每条干货必须配案例或方法
- 学员成果是最强信任凭证。"学完之后他怎样了"比"课程有多好"有效100倍
- 忌讳"知识焦虑"。不要用"不学就落后"制造焦虑，用"学了能解决什么"吸引

## 六、金融/保险/法律/医疗（特殊监管行业）

**典型IP**：港爸老肖（保险）、律师、医生、财税师

**行业特征**：强监管，有行业特殊合规要求，不能承诺收益/疗效/胜诉。

### 周度方向适配

与对应B端/C端类别相同，但需叠加行业合规限制：

| 限制项 | 规则 | 替代方案 |
|--------|------|---------|
| 不得承诺收益 | 不能说"保证赚XX" | 改为"帮你做更稳健的配置" |
| 不得推荐具体产品 | 不能说"买XX产品" | 改为"这类需求的配置思路是" |
| 不得承诺疗效/胜诉 | 不能说"包治""必胜" | 改为"专业的事交给专业人" |
| 需有风险提示 | 金融内容需加"投资有风险" | 在脚本中自然融入 |

### 特别注意
- 监管行业的内容必须经过 content-quality-guard 审查
- 置顶内容需特别谨慎——置顶是永久展示，合规风险最大
- 案例分享需脱敏。不能出现客户真实姓名/金额/具体产品名
- 行业洞察类内容数据好且合规风险低，可以加大比重

## 七、无法归类时的处理

当IP档案的行业无法匹配以上6个类别时：

1. **从客户痛点推断**：客户最痛的问题是什么？这个问题更偏B端（效率/成本/专业）还是C端（体验/情感/认同）？
2. **从转化路径推断**：客户怎么成交？长周期咨询→按B端专业服务处理；短周期下单→按C端消费品处理
3. **从内容形式推断**：适合探访跟拍→偏实体行业；适合口播讲解→偏知识型
4. **降级处理**：如果实在无法归类，使用标准配比（50/35/15）+ 标准周度模板，不做行业特化。在规划表中标注"行业未归类，使用标准模板"

> **原则**：宁可不做行业特化，也不要错误归类。错误的行业适配比标准模板危害更大。
