# 法律图文笔记生成规则

> 基于300篇小红书/公众号法律类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 法律 = 法律科普、维权指南、合同避坑、劳动法常识、婚姻法知识、消费者权益、职场法律、租房法律等。

## 概述：法律图文笔记公式体系

```
封面标题(数字+法条+身份+痛点+结果) → 开头钩子(前3行定生死) → 正文干货(每段有收获)
         ↓                          ↓                          ↓
       配图逻辑(法条是证据不是装饰)  →  排版呼吸感(法条+人话翻译>长篇大论)  →  结尾CTA(给读者一个交代)
```

本文件共60个公式（6大支柱 × 10公式/支柱），全部提炼自300篇法律行业爆款笔记的真实数据。每个公式均从实际爆款中高频出现的写作模式归纳得出——不预设分类、不跨行业参考、不做"通用"与"独占"的区分。所有60个公式都从法律内容生态中自然涌现。

### 公式3：SCQA结构
```

```
- **案例（被调岗降薪怎么应对）**:
  Situation：「我在一家公司做了3年设计师，去年年底公司突然通知我'由于业务需要，你调到行政岗'。岗位变了、工资降了30%。我没有拒绝——我不知道能不能拒绝。」
  Complication：「干了两个月行政岗以后，HR又来找我，说'你不太适应行政工作，要不你主动离职吧'。这时候我才意识到——调岗降薪可能只是一个铺垫，真正的目的是逼我走而且不给任何赔偿。如果我自己提离职，一分钱赔偿都拿不到。」
  Question：「面对公司的调岗降薪，员工能不能拒绝？拒绝之后公司辞退我算不算违法解除？我能拿到什么赔偿？」
  Answer：「答案很明确——根据《劳动合同法》第35条，变更劳动合同需要双方协商一致。公司单方面调岗降薪是违法的。你应该做的：第一步，以书面形式（邮件或微信）明确表示'我不同意调岗降薪'并保留记录。第二步，继续在原岗位出勤打卡——如果你去了新岗位报到，法律上视为你同意了。第三步，如果公司以'不服从管理'为由辞退你——这就是违法解除，你可以要求2N赔偿或者要求恢复原岗位。注意：如果调岗降薪后你直接辞职——这叫'被迫解除劳动合同'，可以要求N的经济补偿，但需要以书面形式告知公司解除原因。」

### 公式4：法条拆解+人话翻译体
```
法条原文(引用) → 法条解读(大白话) → 适用场景(什么时候用) → 操作步骤(怎么用)
```
- **案例（《劳动合同法》第87条拆解）**:
  法条原文：「《劳动合同法》第87条：用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第47条规定的经济补偿标准的二倍向劳动者支付赔偿金。」
  大白话解读：「翻译一下——公司没有合法理由把你辞退了，要赔你2N。N就是你在这家公司工作的年限（每满一年算1个月工资，不满半年算半个月，半年以上不满一年算1个月）。2N就是这个数字乘以2。举个例子：你在公司干了4年，月薪1万——违法解除要赔你8万。」
  适用场景：「什么情况下能拿2N？①试用期被辞退但公司拿不出'不符合录用条件'的证据 ②公司说你'严重违反规章制度'但没有证据 ③公司单方面调岗降薪后以你不服从管理为由辞退 ④公司说你'不能胜任工作'但没有经过培训或调岗就直接辞退 ⑤你怀孕了、在医疗期、或者工伤期间被辞退。」
  操作步骤：「第一步：拿到公司给你的书面解除通知，看清楚上面写的解除理由。第二步：对照上面5种情况，判断是不是违法解除。第三步：收集证据——劳动合同、工资流水、解除通知、工作年限证明。第四步：去劳动仲裁委申请仲裁，请求事项写'请求裁定被申请人支付违法解除劳动合同赔偿金XX元（2N）'。附：仲裁是免费的，不需要请律师。」

### 公式5：案例复盘型
```
一个真实案例 → 当事人的错误 → 转折点/关键动作 → 最终结果 → 可复制的经验
```
- **案例（租房押金纠纷）**:
  案例：「一个女生租了一套公寓，一年租期到了以后退房。房东来验收的时候列了一张单子：墙上有个钉子洞扣300、地板有一块磨损扣500、抽油烟机有油渍扣200、窗帘钩掉了一个扣150——4500押金要扣掉1150块。」
  错误：「女生的第一反应是跟房东吵——'我租房的时候墙上就有钉子洞！''地板本来就是旧的！'双方各执一词。最关键的是——女生入住的时候没有拍照，退房的时候房东拍了一堆'损坏'的照片。证据上女生处于完全劣势。」
  转折点：「女生来咨询的时候我问了她一个问题：'你当时签的合同上有没有附房屋交接清单？'她翻了翻合同——没有。我又问：'房东主张的这些损坏你能证明不是你的责任吗？'她摇摇头。但是——我问了第三个问题：'钉子洞是你打的对吧？'她说是挂装饰画打的。'那地板磨损呢？''就是正常走路的。''抽油烟机的油渍呢？''正常做饭的。''窗帘钩呢？''入住的时候就掉了。'」
  结果：「关键来了——根据法律规定，租赁期间承租人对租赁物的损耗分为两类：'正常损耗'由出租人承担，'不当使用造成的损坏'由承租人承担。钉子洞属于对墙体的损坏需要赔偿（但300块明显过高），地板磨损和油烟机油渍属于正常使用损耗不需要赔偿，窗帘钩如果入住时已损坏也不需要赔偿。最终在调解下，房东只扣了50元钉子洞修补费——其余押金全部退还。」
  可复制的经验：「①入住当天拍一段完整的视频，从大门到每一个角落，重点拍已有的损坏。视频发一份给房东并让他确认——这就是你退房时的护身符。②合同上一定要附'房屋交接清单'，写明房屋现状和已有设施。③钉子洞属于损坏，挂东西之前用免钉胶或不留痕的双面胶。④退房时跟房东一起验收，全程录像。」

### 公式6：步骤拆解法
```

```
- **案例（劳动仲裁全流程）**:
  准备：「仲裁需要这些材料：①身份证原件+复印件 ②劳动合同（如果没有，工资流水、工牌、工作群聊天记录也能证明劳动关系）③公司违法解除的书面证据（解除通知书、微信/邮件截图）④工资银行流水（最近12个月，用来计算平均工资）⑤公司的工商信息（在'国家企业信用信息公示系统'上查询打印）。」
  步骤一：「写仲裁申请书。就写三件事——'申请人是谁、被申请人是谁'，'事实和理由'（什么时候入职、什么岗位、月薪多少、公司什么时候以什么理由辞退你、为什么这个理由不合法），'仲裁请求'（写清楚你要什么：违法解除赔偿金2N=XX元+未结工资XX元+未休年假折算XX元+加班费XX元=总计XX元）。不要抒情、不要骂人、只写事实和法律依据。」
  步骤二：「去公司所在地的劳动人事争议仲裁委员会提交材料。注意：是公司注册地的仲裁委，不是你住的地方。到了以后领表、填表、交材料。仲裁委5个工作日内决定是否受理。受理的话会给你开庭通知——通常在提交后1个月左右开庭。」
  步骤三：「开庭——不要紧张。仲裁庭比正式法庭轻松很多，仲裁员会引导流程。你只需要：①陈述事实时按照时间顺序讲 ②每说一件事后面跟一个证据（'这是公司发给我的解除通知'）③对方说的不属实的话平静地说'不属实'并提出你的反证。仲裁庭的主要目的是调解——80%的案子在开庭时调解解决了。」
  注意：「①仲裁是免费的，不需要请律师 ②仲裁时效是1年——从你知道权利被侵害那天起算，超时就失效了 ③公司不执行仲裁裁决怎么办？去法院申请强制执行，免费的。」

### 公式7：清单对比法
```
分类标准(一句话) → 正确做法(每项+法律依据) → 错误做法(避开+后果) → 总结规律
```
- **案例（离职时该签和不该签的文件）**:
  标准：「离职时HR递给你的每一张纸都关系到你能拿多少钱。对照这份清单——」
  该签的：「①《解除劳动合同证明书》——这是你入职下一家公司必须的材料。注意：上面只能写你的姓名、身份证号、岗位、入职离职时间，不能写任何负面评价 ②工资结算单——确认金额无误后签字 ③社保转移单——确保你的社保不断缴。」
  不该签的：「①《自愿离职申请书》——签了就等于你自己辞职，一分钱赔偿没有 ②《协商一致解除协议》——看仔细里面的赔偿金额和条款。如果上面有'双方再无其他争议''放弃追诉权利'这样的字眼——没拿到你应得的全部赔偿前不要签 ③《离职承诺书》——如果里面有'离职后不得在同行业工作'且没有写明补偿金，这是在变相签竞业限制 ④空白文件——任何有空白处的文件都不要签字。」
  总结规律：「离职签字前记住一句话——'谁给你纸，你给谁看'。看不懂的文件不要立刻签字，跟HR说'我带回去看一下明天给你'。这一个晚上够你咨询专业人士或者自己去查法律条文了。HR催你签的理由通常是'不签流程走不完钱拿不到'——但法律没有规定必须当场签字。」

### 公式8：问题解答型
```
一个核心法律问题 → 拆成3-4个子问题 → 逐一解答(法条+解释+操作) → 总结
```
- **案例（被裁员了怎么办）**:
  核心问题：「突然被HR通知裁员——接下来每一步都关系到你能拿到多少钱。」
  子问题一：「公司说的N+1合理吗？N=工作年限×月平均工资。比如干了5年、月薪1万——N=5万。+1=1个月代通知金，如果公司当天就让你走了且没有提前30天通知，就要+1。所以N+1=6万。但——前提是公司是'经济性裁员'，符合法定情形。如果公司说'业务调整'但实际只是想换人——那就是违法解除，你应该拿2N=10万。」
  子问题二：「离职协议要不要签、什么时候签？核心原则——没有算清楚赔偿金之前不要签。拿到协议以后做三件事：①把N+1的金额跟你自己算的对比 ②看有没有'双方再无争议'条款 ③看有没有竞业限制条款。如果拿不准，跟HR说'我带回去看一下'——这一晚上你可以咨询律师或劳动仲裁。」
  子问题三：「被裁了年终奖还能拿吗？如果公司有明确的年终奖制度——即使你在年终奖发放之前被裁，你仍然有权按比例拿到你工作期间对应的年终奖。这不是公司发善心——你已经在对应的月份付出了劳动。」
  子问题四：「离职证明被写了负面评价怎么办？法律规定离职证明上只能写客观事实——你的姓名、岗位、入职离职日期。如果写了'工作表现不佳''被辞退'等评价——你可以要求公司重新开，不重新开直接去劳动监察大队投诉。」
  总结：「被裁员不是你的失败——是公司的决策。你要做的是冷静下来、算清楚账、不要当场签任何东西。记住：HR说的'行业惯例''公司规定'在劳动法面前都要让路。」

### 公式9：话术模板型
```
场景描述 → 错误说法 → 正确说法 → 为什么这样说有效
```
- **案例（被HR约谈辞退时怎么说）**:
  场景：「HR把你叫到会议室，说'公司最近业务调整，你这个岗位要优化掉。我们按N+1给你，你这边签个字——'」
  错误说法：「'好的，我签。''为什么是我？''我再考虑一下行不行？'——这三种反应都会让你陷入被动。第一种直接放弃了维权可能；第二种暴露了你的情绪化；第三种给了对方继续施压的时间窗口。」
  正确说法：「'我理解公司的决定。在签字之前，我想确认几件事：第一，请给我一份书面的解除劳动合同通知书，写明解除的具体理由和法律依据。第二，请把赔偿金的计算明细给我看一下。第三，我的年假、加班费、未结工资是否都包含在内了？'」
  为什么有效：「①你没有拒绝签字——你只是'需要确认几件事'，不让对方有理由翻脸 ②你把对方的'口头告知'变成了'书面证据'——这是你以后维权的基础 ③你提的3个问题都是合法合理的要求——如果对方拒绝提供书面通知，这个行为本身就说明他们心里有鬼 ④你展现出的法律意识和冷静态度，会让HR重新评估'随便打发'的难度。」
- **案例（跟房东要押金怎么说）**:
  场景：「退房后房东列了一堆理由要扣押金。」
  错误说法：「'你这人怎么这样！''我住了这么久一点都没弄坏！'——情绪化的争吵解决不了问题。」
  正确说法：「'关于您提出的扣款项目，我说一下我的看法：墙面轻微污渍和地板自然磨损在《民法典》上属于租赁物正常损耗，依法由出租人承担。如果您坚持要扣，请提供这3样东西：扣款项目的维修发票、维修前后的对比照片、以及证明这些损坏不是正常损耗的鉴定报告。'」
  为什么有效：「你把'吵架'变成了'讲法律'。房东列的几个扣款理由在法律上大量属于'正常损耗'不需要你赔。你反过来要求他提供证据——维修发票和鉴定报告——99%的房东拿不出来。一旦你表现出你知道'正常损耗'和'损坏'的法律区别，大部分房东就不敢继续讹你了。」

### 公式10：法律文书模板型
```
文书用途 → 核心要素逐项列出 → 填写提示 → 使用场景和注意事项
```
- **案例（规范借条模板）**:
  用途：「写一张有法律效力的借条，让每一笔借款都能在法庭上被认可。」
  核心要素（逐项填写）：
  「①借款人：（姓名+身份证号，一字不差）②出借人：（你的姓名+身份证号）③借款金额：人民币（大写）元整（小写¥），大写的法律效力高于小写 ④借款用途：（比如'用于家庭装修'——这个用途决定了如果对方不还钱你申请财产保全的范围）⑤借款期限：自X年X月X日起至X年X月X日止 ⑥年利率：%（不超过合同成立时LPR的4倍，2025年大概在13.8%左右）⑦逾期利息：逾期后按年利率%计收逾期利息 ⑧违约责任：如借款人逾期不还，出借人为实现债权所支付的律师费、诉讼费、保全费等由借款人承担 ⑨借款日期：X年X月X日 ⑩借款人签字按手印+出借人签字。」
  关键提示：「①身份证号必须写——没有身份证号的借条，你连起诉对象都确定不了 ②大写的借款金额旁边让小写——如果两者不一致以大写为准 ③不要写'今借到'——写'今收到'，这两个字的区别在法庭上可能决定成败。'借到'=钱已经交付了，'借'=可能还没交付 ④利率区间内双方约定，不写的话视为无利息 ⑤违约责任里的律师费条款非常重要——有了这一条你赢了官司律师费对方出。」
  使用场景：「适用于朋友、亲戚、同事之间的借款。金额不论大小——5000块也应该写借条。不是不信任对方，是让双方都安心。」

- **案例**: 劳动合同中的自动续约条款——「合同到期自动续签一年」，标注「自动续约对员工一般没有坏处，但要确认'续约后薪资条件不变'是不是你能接受的」
- **案例**: 装修合同中的「增项另计」条款——被红框标注，注释「这就是'低价签约中途加价'的源头。要求把可能的增项和对应价格写进合同附件」
- **案例**: 物业合同中的收费项目——逐条分析哪些是合理收费（物业费、公共能耗费），哪些是可质疑的（装修管理费、出入证工本费等）

## 支柱五：排版呼吸感（10个公式）

> 以下10个公式全部提炼自法律行业300篇爆款笔记正文的真实排版模式。非通用排版教科书——每个公式都是法律内容生态中自然涌现的独特排版节奏。

### 公式1：法条+人话翻译体
```
先引用法条原文（用引号或特殊格式标识），紧接着一句「翻译成大白话就是——」，然后在下面用最通俗的语言解释。法条和人话之间空一行。
```
- **为什么法律爆款常用**：法律内容最大的阅读障碍是法条本身的晦涩。法条+人话翻译体把"看天书"变成了"听解释"——读者首先看到一段看不懂的话，产生一个微小的挫败感，然后立刻被一句大白话拯救。这种"先难后易"的节奏让读者产生一种"原来法律也没那么难"的正反馈。每一个法条翻译都是一个小型的"知识交付"——读完一段就感觉自己多了一个武器。

- **案例（《劳动合同法》第87条讲解）**:
  ```
  > 《劳动合同法》第87条：用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第47条规定的经济补偿标准的二倍向劳动者支付赔偿金。

  翻译成大白话就是——

  公司没有合法理由把你开除了 → 赔两倍的钱。

  举例：你月薪1万、干了4年。合法辞退 = 赔4万。违法辞退 = 赔8万。

  这就是 HR 最怕你知道的那条法律。
  ```

- **案例（《消费者权益保护法》第55条）**:
  ```
  > 经营者提供商品或者服务有欺诈行为的，应当按照消费者的要求增加赔偿其受到的损失，增加赔偿的金额为消费者购买商品的价款或者接受服务的费用的三倍；增加赔偿的金额不足五百元的，为五百元。

  翻译成大白话就是——

  买到假货 → 退款 + 赔3倍价格的钱。
  如果3倍金额不到500块 → 直接赔500块。

  你买了个100块的假面膜 → 退100+赔300=400。但400不到500 → 所以直接赔500。
  你买了个2000块的假包 → 退2000+赔6000=8000。实打实的。
  ```

### 公式2：案例复盘体
```
用"真实案例 → 他的错误 → 正确做法 → 结果对比"的四段式结构，像一个微缩版的法治节目。每个段落之间有明显的分隔，让读者像追剧一样跟着案例走。
```
- **为什么法律爆款常用**：法律内容是高度案例驱动的。抽象的法条很难引发共鸣，但一个"跟你情况一模一样"的案例能让人立刻产生代入感。案例复盘体本质上是在讲"法治小故事"——先讲这个人遇到了什么事、他犯了什么错误、正确做法是什么、结果有什么不同。这种排版让法律知识不再是干巴巴的条文，而是有情节、有冲突、有结果的微型叙事。读者读完一个案例，记住的不是法条编号，而是"那个人的故事"。

- **案例（被违法辞退的案例复盘）**:
  ```
  📋 真实案例：小张的14万和0元

  ── 发生了什么 ──
  小张在一家互联网公司做了5年设计师。去年底，HR突然约谈说"业务调整，你的岗位优化了"。递过来一份离职协议——签了拿N+1=6万走人。

  ── 他的第一个错误 ──
  小张差点当场就签了。他以为N+1就是"辞退的标准赔偿"。他完全不知道——公司说的"业务调整"很可能不是合法的经济性裁员，而是违法解除劳动合同。

  ── 正确做法 ──
  小张后来咨询了律师（在签字之前！）。律师告诉他：不要签。要求公司出具书面的解除劳动合同通知书。去申请劳动仲裁，请求2N赔偿。

  ── 结果对比 ──
  ❌ 如果签了协议：拿6万走人，放弃一切权利
  ✅ 实际结果：仲裁裁决公司违法解除，赔偿2N=14万

  ── 你现在应该知道的 ──
  那张HR递过来的纸，不是"手续"是"放弃权利声明书"。
  签字之前——你手里有选择权。签了字——什么都没有了。
  ```

### 公式3：维权步骤体
```
用「Step 1 → Step 2 → Step 3 → Step N」的步骤编号+箭头串联，每一步包含：动作+去哪里+带什么+注意什么。步骤之间空行，重要警告用⚠️标记。
```
- **为什么法律爆款常用**：法律读者最核心的诉求是"告诉我怎么做"。维权步骤体把一个复杂的法律流程拆成可执行的步骤清单——每一步都告诉读者"去哪""带什么""注意什么"。这种排版给处于焦虑中的读者提供了确定性和掌控感。步骤之间的空行让每一步都是独立的"任务单元"，读者可以不慌不忙地一步步执行。

- **案例（被欠薪讨薪全流程）**:
  ```
  被欠薪了怎么办？这个流程我亲自走过，每一步都有效👇

  Step 1️⃣：收集证据（今天就做）
  → 工资条（拍照保存）
  → 银行流水（去银行打印最近6个月）
  → 考勤记录（截图打卡系统）
  → 欠薪聊天记录（截图+录屏，证明老板承认欠薪）
  → 劳动合同（如果没有合同，上面这些更重要）
  ⚠️ 证据不要只存在公司电脑里——全部备份到自己的邮箱和手机

  Step 2️⃣：跟老板/HR正式交涉（用文字）
  → 发微信或邮件，不要口头说
  → 措辞："XX总，我X月到X月的工资共计XX元至今未发。请您在X月X日前结清。"
  → 保留对方的所有回复——哪怕是一句"知道了"
  ⚠️ 对方不回也没关系，你已经完成了"催告"这个法律动作

  Step 3️⃣：去劳动监察大队投诉（最快的方法）
  → 地址：公司所在地的劳动保障监察大队
  → 带：身份证+工资流水+劳动合同+欠薪证据
  → 不需要律师、不需要钱
  → 他们立案后会发《责令改正通知书》给公司
  ⚠️ 这一步90%的公司会乖乖发工资——因为不执行会被罚款

  Step 4️⃣：劳动仲裁（如果Step 3不奏效）
  → 去公司所在地的劳动仲裁委
  → 申请书模板现场可以领，填上：你被欠了多少钱+证据有什么
  → 免费、不需要律师
  → 欠薪争议一般45天内裁决
  ⚠️ 仲裁时效1年——从你知道欠薪那天算起

  Step 5️⃣：法院强制执行（最后手段）
  → 拿着仲裁裁决书去法院申请强制执行
  → 不执行公司会被列入失信名单——老板不能坐高铁飞机

  💰 我自己Step 3就解决了——劳动监察上门那天下午工资就到账了。
  ```

### 公式4：Q&A法律问答体
```
用一个高频法律问题开头，然后自问自答。每个Q&A之间用空行分隔。Q用粗体或特殊标记，A用分点回答。问题来自读者的真实困惑，回答力求精炼——每个A控制在3-5行。
```
- **为什么法律爆款常用**：法律是天然适合Q&A格式的内容领域——因为法律读者的困惑本身就是以"问题"形式存在的。Q&A体把读者心中"我遇到了这种情况怎么办"直接搬到了屏幕上。每一个Q都是读者内心的真实声音，每一个A都是他最需要的解决方案。这种排版让读者感觉自己不是在看一篇泛泛的法律科普，而是在参加一场专属的法律咨询。

- **案例（被辞退高频Q&A）**:
  ```
  最近收到太多私信问被辞退的事。今天把最常见的8个问题整理出来👇

  Q：试用期被辞退有赔偿吗？
  A：有。除非公司能证明你"不符合录用条件"——而且这个录用条件必须是在你入职前就明确告诉你的。如果公司只是说"你不适合"，拿不出证据——就是违法解除，你可以要求2N赔偿。

  Q：HR让我签离职协议，说签了钱一周到账，不签可能要拖几个月。签不签？
  A：看金额。如果协议上的金额≥你应该拿到的金额（且你确认没有其他可主张的权利了），可以签。如果金额明显少了——不要被"不签就更麻烦"吓到。仲裁免费、不需要律师，最多45天出结果。用一个月的等待换多一倍的赔偿，值不值你自己算。

  Q：公司不给我开离职证明怎么办？
  A：这是违法的。离职证明是你入职下一家公司的必要材料。你直接跟HR说——"如果在X月X日之前我拿不到离职证明，我会去劳动监察大队投诉。根据《劳动合同法》第89条，不出具解除证明给劳动者造成的损失，公司要赔偿。"——这句话基本管用。

  Q：被辞退后年终奖还能拿吗？
  A：能拿你工作时间对应比例的。如果公司有年终奖制度——你工作到10月被裁，你有权按10/12的比例拿年终奖。跟HR说这句话："我的年终奖请按我实际工作月份折算发放。如果拒绝发放，我会在仲裁请求中加入这一项。"

  Q：被辞退和主动辞职，赔偿差多少？
  A：天差地别。公司违法辞退你=2N。协商一致=多则N+1少则N。你自己提辞职=0。所以HR最希望你做的事就是"主动提离职"——他们会用各种话术引导你说出"我不干了"。守住底线：绝对不要自己说"我辞职"。
  ```

### 公式5：合同条款拆解体
```
将一份合同中的关键条款逐条拎出来，用"条款原文 → ⚠️风险点 → ✅修改建议"三段式。条款之间用分隔线隔开，每一条都独立成块。
```
- **为什么法律爆款常用**：合同是法律内容中最具操作性的品类。读者点开一篇合同避坑笔记，不是来学法律理论的，是来"对答案"的——对照着检查自己的合同有没有同样的问题。合同条款拆解体把一份合同中最危险的条款逐条检出，给每一条标注风险点和修改建议。读者可以拿着这篇笔记一条条对照自己的合同，像拿着参考答案对卷子。

- **案例（劳动合同避坑逐条拆解）**:
  ```
  拿到劳动合同不要直接翻到最后一页签字。
  先看这5个条款——每一个都可能让你损失几万块👇

  ──

  📝 条款一：试用期

  ⚠️ 警惕这种写法：
  "试用期6个月，试用期工资为转正工资的60%"

  ❌ 风险：合同期3年以上试用期最长6个月，但试用期工资不得低于转正工资的80%。60%是违法的。
  ✅ 修改：要求试用期工资不低于转正工资的80%，如果已经低于这个比例——保留证据，离职时可以要求补差额。

  ──

  📝 条款二：工作地点

  ⚠️ 警惕这种写法：
  "乙方同意甲方根据业务需要在全国范围内调动乙方的工作地点"

  ❌ 风险：签了这条=公司哪天想让你去外地你就得去，不去=不服从管理可以辞退你且不用赔。
  ✅ 修改：要求改为"工作地点为XX市"，或者加一句"如需调动，须经双方协商一致并签订补充协议"。

  ──

  📝 条款三：竞业限制

  ⚠️ 警惕这种写法：
  "离职后2年内不得从事与本行业相关的任何工作"

  ❌ 风险：写了限制但没有写补偿金=签了一份让自己失业2年的协议还没有任何补偿。
  ✅ 确认：①竞业限制必须有书面约定 ②必须有经济补偿（不低于离职前12个月月均工资的30%）③公司3个月不付补偿金→你可以请求解除竞业限制。

  ──

  📝 条款四：培训费

  ⚠️ 警惕这种写法：
  "乙方接受甲方提供的入职培训，如培训后1年内离职，需赔偿培训费XX元"

  ❌ 风险：普通入职培训不能约定服务期和违约金。只有"专项培训费用"（有发票的外派培训、考证培训等）才能约定服务期。
  ✅ 确认：问清楚"培训费"具体是指什么培训。如果是公司内部的入职培训——这个条款无效。

  ──

  📝 条款五：空白处

  ⚠️ 合同上有任何空白处——薪资？岗位？试用期？——都可能是你签完之后公司再填的。

  ✅ 做法：所有空白处要么填上内容，要么划掉。不要在留有空白的合同上签字。拍照保存你签字之后的每一页。
  ```

### 公式6：避坑清单体
```
用✅和❌符号逐条列出对vs错的做法。每条不超过2行，条与条之间空一行。整个清单像一份"操作手册"——读者对照着一项项检查自己做对了没有。
```
- **为什么法律爆款常用**：法律避坑内容的本质是"后果预警"——用别人踩过的坑警示读者。避坑清单体把最常见的坑和对应的正确做法以极简的格式对比呈现。✅和❌的视觉符号让正确和错误一目了然。每条不超过2行的限制保证扫读体验——法律读者通常是遇到问题了才搜索来看，他们需要快速定位"我有没有犯这个错"。

- **案例（打官司前最容易犯的10个错误）**:
  ```
  打官司之前对照检查——你犯了几个？👇

  ❌ 不知道对方的身份证号和住址就去法院起诉
  ✅ 借钱之前先拍对方的身份证照片，记下住址和电话
  → 没有明确的被告信息，法院无法立案

  ❌ 证据是手机里的截图，截图前没有显示日期和对方身份
  ✅ 截图必须包含：日期时间、对方昵称+头像、完整的对话内容。有条件的录屏
  → 没有日期和身份的截图，对方可以说"这不是跟我聊的""这是以前的"

  ❌ 重要沟通全靠口头——口头承诺、电话沟通、当面谈
  ✅ 所有重要沟通转化为书面形式：微信文字、邮件、短信。电话沟通后发一条微信"确认一下我们刚才电话说的…"
  → 口头说的话到了法庭上就是"没有证据"

  ❌ 觉得"我有理"所以不需要请律师、不需要准备材料
  ✅ 法律不是比谁有道理——是比谁有证据而且证据按法律要求呈现
  → 法官每天看几十个案卷，你的材料要让他在3分钟内看懂

  ❌ 欠条上写了"今借到"就以为万事大吉了
  ✅ "今借到"不如"今收到"——前者可能被理解为"约定了借钱但钱还没给"
  → 两个字的区别在法庭上可能决定案子的输赢

  ❌ 收到法院传票不理、不出庭
  ✅ 一定要出庭！不出庭=放弃答辩=法院可以缺席判决，结果对你极其不利
  → 不懂怎么应诉就去法院诉讼服务中心——免费咨询

  ❌ 起诉时只写了本金，忘了利息、诉讼费、律师费
  ✅ 诉讼请求里把这些都写进去：本金+利息+逾期利息+诉讼费+律师费（前提是合同里约定了）
  → 你不写法院不会主动帮你加

  ❌ 以为诉讼时效过了就彻底没办法了
  ✅ 立刻去要一次债——发微信、打电话并录音——对方只要回复"我知道了""下个月还"，诉讼时效重新起算
  → 时效中断只需要一次有效的催收

  ❌ 被辞退时赌气说了"我不干了"
  ✅ 永远不要自己说"我辞职""我不干了"。让对方说"你被辞退了"——并且留下书面记录
  → 你说的"我不干了"=主动辞职=0赔偿。对方说的"你被辞退了"=至少N赔偿

  ❌ 一次性提交所有证据，开庭前就把底牌全亮给对面
  ✅ 分批次、按节奏提交证据。举证期限内提交核心证据即可
  → 证据策略和证据本身一样重要
  ```

### 公式7：加粗重点突出法
```
关键法条编号、核心赔偿数字、可操作的动作指令用**加粗**。每段至少1处加粗、不超过3处。让扫读的人只看加粗就能获得70%的信息。
```
- **为什么法律爆款常用**：法律内容的信息密度极高——法条编号、赔偿金额、时效限制、操作步骤——读者需要在大量信息中快速提取关键点。加粗就像法律文件中的"高亮笔"，让读者3秒内判断"这段讲了什么"。法律读者通常带着具体问题来看——他们需要的不是全文通读，是快速定位"跟我情况相关的那个数字""那条法律""那个动作"。

- **案例（被公司辞退到底能拿多少钱）**:
  ```
  被辞退能拿多少钱——不是HR说了算，是法律说了算。

  你的赔偿金取决于一个关键问题：**公司辞退你的理由是什么？**

  ──

  情况一：协商一致解除 → **N 或 N+1**
  你跟公司商量好了，双方都同意解除合同。**N = 工作年限 × 离职前12个月月均工资。** 如果公司让你当天就走且没有提前30天通知 → +1个月的代通知金 → N+1。

  情况二：公司经济性裁员 → **N+1**
  公司真的在裁员——业务调整、部门裁撤——且经过了法定程序。注意：**不是HR嘴上说"业务调整"就是裁员，公司需要向劳动部门报备裁员方案。**

  情况三：公司违法解除 → **2N**
  这才是重点——**公司没有合法理由辞退你，或者理由看起来合法但其实不成立。** 比如：
  → 说"试用期不合格"但拿不出考核标准
  → 说"严重违反规章制度"但你的行为根本够不上严重
  → 在医疗期、孕期、工伤期间辞退你
  → 调岗降薪后你不服从就以"不服从管理"辞退

  以上这些全是违法解除 → **2N = N × 2**

  ──

  举例：你干了5年、月均工资1万。
  协商解除 → N+1 = 6万
  违法解除 → 2N = 10万
  **差了一个签字——差了4万块。**

  **HR为什么催你当场签字？因为他知道——你回去查了法律就不会签了。**
  ```

### 公式8：分段+小标题法
```
正文每200-300字用一个小标题分段。小标题用【】框住——一句话概括接下来的内容。让读者可以通过小标题快速跳读。
```
- **为什么法律爆款常用**：法律干货的信息结构复杂——同一个主题下可能涉及法条解释、案例分析、操作步骤、注意事项等多个维度。分段+小标题把信息做了清晰的分类和导航。用【】框住的小标题像目录一样让读者决定阅读顺序：我可以只看"【赔偿金怎么算】"跳过"【什么情况下拿不到赔偿】"。这种排版充分尊重法律读者的"目标导向阅读"——他们是来解决问题的，不是来通读全文的。

- **案例（离婚时财产怎么分）**:
  ```
  离婚最让人焦虑的不是感情没了——是财产不知道怎么分。
  这篇把离婚财产分割的底层逻辑讲清楚👇

  【哪些是夫妻共同财产？】
  婚后双方的工资奖金、投资收益、知识产权收益、继承或受赠的财产（除非遗嘱或赠与合同里写明只给你一个人）——这些都要分。还有一项90%的人都没想到的：**婚后缴纳的公积金**——也属于夫妻共同财产。

  【哪些是你自己的不用分？】
  婚前全款买的房（且登记在你名下）、婚前存款、因人身损害获得的赔偿（工伤赔偿、交通事故赔偿）、遗嘱或赠与合同里写明只给你的财产、专用的生活用品（比如你的衣服首饰）。

  【按什么比例分？】
  不是一刀切的一半一半。法律原则是——**照顾子女、照顾女方、照顾无过错方。** 如果对方在婚姻中有重大过错（家暴、出轨、赌博等），无过错方可以要求多分。如果一方恶意转移隐藏财产——分割时这一方可以少分甚至不分。

  【房子怎么分？——最高频的问题】
  婚前一方付首付、婚后一起还贷 → 房子归付首付方，但**婚后共同还贷部分+对应增值部分**要补偿给对方。
  婚后双方一起买的 → 不管登记在谁名下，都是共同财产，原则上平分。
  一方父母出资 → 看是赠与给自己子女还是给夫妻双方。没有明确说明的话→婚后出资视为对夫妻双方的赠与。

  【对方转移财产怎么办？】
  不要等到离婚后再追——**离婚前就申请财产保全。** 去法院提交申请，提供对方转移财产的初步证据（银行流水异常、大额转账等）。法院裁定保全后，对方的账户会被冻结。这一步是在保护你自己的份额。

  【如果你正在计划离婚，现在就该做的事】
  ①收集对方的银行卡号、股票账户、基金账户信息 ②保留近两年的家庭大额支出凭证 ③不要急着搬出去——居住状态会影响财产分割和抚养权判断。
  ```

### 公式9：留白呼吸法
```
两个大段落之间必须空至少一行。不同主题之间用分隔线(———)或三个点(...)断开。不能出现连续3段以上没有留白的情况。法律内容信息密度极高——留白是读者消化信息的"呼吸口"。
```
- **为什么法律爆款常用**：法律文本天然是信息密集型的——法条、案例、数据、步骤全部挤在一起会让读者产生"文字墙恐惧症"。而法律读者又经常是在焦虑状态下阅读（刚被辞退、正被欠薪、在经历离婚），他们的大脑认知负荷已经很高了。留白呼吸法降低了排版层面的认知负担——每个短段落独立成块，读者的眼睛有停顿和休息的空间。这不是装饰，是法律干货笔记的"可读性基础设施"。

- **案例（被家暴后第一时间该做什么）**:
  ```
  不要等。不要忍。不要给对方第二次机会。

  你现在要做的——

  第一步
  报警。打110。说清楚：你是谁、在哪里、正在发生什么事。
  警察来了以后——要求出具《家庭暴力告诫书》。
  这张纸很重要。非常非常重要。

  第二步
  去医院。验伤。告诉医生这是家暴导致的——医生会在病历上记录致伤原因。

  第三步
  拿着告诫书+验伤报告——去法院。
  申请《人身安全保护令》。
  法院收到申请后——24小时内必须裁定。

  保护令能做什么？
  禁止对方靠近你、骚扰你、进入你的住所。

  从我报警到拿到保护令——不到48小时。
  你也可以。
  ```

- **为什么法律爆款常用**：法律干货正文往往涉及高度紧张的情绪——维权焦虑、被侵害的愤怒、对法律程序的不确定感。读者读完正文后还处在"信息消化中"的状态。如果CTA直接黏在正文后面——读者很可能惯性跳过。明显的分离线制造一个"心理换挡"：干货结束了，现在可以放松一下，聊聊天、点个收藏。这个换挡大大提高了CTA的转化。
