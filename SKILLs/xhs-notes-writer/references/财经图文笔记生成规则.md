# 财经图文笔记生成规则

> 基于300篇小红书/公众号财经类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 财经 = 理财入门、投资知识、基金股票、保险配置、省钱记账、副业赚钱、房产分析、经济趋势等。

## 概述：财经图文笔记通用公式

```
封面标题(数字+收益+人群+结果) → 开头钩子(前3句定去留) → 正文干货(每段有获得感)
         ↓                          ↓                          ↓
       配图逻辑(截图是信任不是装饰)  →  排版呼吸感(框架感比密集感重要)  →  结尾CTA(给读者一个交代)
```

### 公式7：理财疑问解答型

### 公式8：原理+实操型
```

```
- **案例（为什么要做资产配置）**:
  原理：「单一资产不可能每年都是最好的。2019年股票型基金涨了40%+，2022年跌了20%+。如果你的钱100%都在股票基金里——2019年你很开心，2022年你很想哭。而资产配置的意义就是——让不同资产之间的涨跌互相抵消，平滑整体的波动，让你在任何市场环境下都能'拿得住'。」
  怎么办：「最简单的资产配置三步。第一步——把你的钱按用途分成四笔：①随时要用的钱（3-6个月生活费）放货币基金 ②3年内可能要用的钱（买房首付、结婚）放债券基金或大额存单 ③5年以上不动的钱放指数基金 ④保障账户：用年收入的5%-8%配置纯保障型保险。第二步——给指数基金那笔钱再做一次分散：60%沪深300ETF+40%中证500ETF，覆盖大盘和中小盘。第三步——每年做一次'再平衡'，把涨得多的卖掉一部分补给涨得少的，让比例回到原来的60/40。」
  注意：「①资产配置不是一劳永逸——每年至少审视一次 ②不同人生阶段的配置比例不一样——年轻时股票比例可以高一些，临近退休要逐步降低股票比例 ③配置做完以后最重要的就是'别乱动'——频繁调整配置等于没有配置。」
  效果：「一个合理的资产配置组合，年化收益率在6%-10%之间，波动率远低于纯股票。最重要的是——你会睡得更安稳，不会因为市场大跌就恐慌割肉。」

  单项解读：「如果你只买一只沪深300做长期定投——易方达的规模和费率优势太明显了，0.2%的费率意味着每1万块一年只要20块管理费，相比0.5%的省了30块。别看数字小，100万本金放30年——省下来的费率差够你再买一辆车。如果你想要稳定性和长期历史表现——华泰柏瑞成立最久、经历过的市场环境最多。」
  推荐：「长期定投选易方达沪深300ETF（费率最低）+中证500ETF组合。定期再平衡，每年调一次。不要频繁换基金——选定一只就长期拿着。」

### 公式10：资产配置清单型
```
情境铺垫(1-2句) → 配置清单(每项配一句话理由+比例) → 执行顺序 → 避坑提醒
```
- **案例（月薪1万左右的资产配置方案）**:
  铺垫：「月薪1万左右（到手约8000-9000），不追求暴富，只希望钱稳步增长、生活有安全感。以下是我的资产配置框架，可以直接套用。」

  执行顺序：「第一步：先建活钱账户——至少存够3个月生活费。第二步：把保障配齐——不要等身体出问题再后悔。第三步：稳增并行——稳健账户和增长账户同时开始存，比例按上面的来。」

- **为什么财经爆款常用**：财经读者最关心的是「钱去哪了」和「钱怎么来的」。账本体把真实的收支结构搬到了笔记里——不是笼统地说「要省钱」「要理财」，而是一笔一笔地展示收入和支出。这种排版让读者产生强烈的代入感——「这个人的消费结构和我的好像」，从而建立信任。它本质上是一种「财务透明度」的排版美学。

- **案例**:
  ```
  月薪到手9000，我是这样分配的📋

  💰 收入：9000

  🏠 必须花的（50%）：4500
  房租：2800
  水电燃气+网费+话费：400
  交通：300
  基础伙食（超市买菜+自己做饭）：1000

  💸 提升生活质量的（15%）：1350
  偶尔外食+外卖：600
  护肤品/日用品：400
  娱乐（电影/展览/周末出行）：350

  📈 存起来的（35%）：3150
  储蓄账户（不能轻易动的）：1800
  定投账户（买指数基金）：1000
  保险月均摊销：350

  这个分配我执行了8个月
  最大的感受不是「过得很紧」
  而是「每一笔钱花出去都知道为什么」
  这种感觉比随便花爽多了
  ```

### 公式2：投资框架体
```
用「策略→执行→复盘」的三段式框架组织正文，像一份投资备忘录
```
- **为什么财经爆款常用**：财经读者在面对投资决策时最需要的是「框架感」——不是碎片化的知识点，而是一个完整的、可复制的决策流程。投资框架体把「想→做→复盘」的完整闭环展示出来，让读者觉得「我也可以照着这个框架来」。这种排版是财经行业特有的——它模仿了基金经理写投资备忘录的思维方式。

- **案例**:
  ```
  我的基金定投策略，执行了三年👇

  ▸ 策略部分
  选基逻辑：只选宽基指数——沪深300+中证500
  原因：不赌行业、不赌赛道、不赌基金经理。赚的是中国经济增长的平均收益。
  资金分配：每月定投金额的60%沪深300、40%中证500
  止盈纪律：账户整体收益率达到15%时赎回盈利部分的50%
  加仓纪律：市场大跌超过10%时加倍定投当月金额

  ———

  ▸ 执行部分
  每月15号雷打不动扣款——涨也投、跌也投
  2022年市场大跌的时候，我按纪律加倍投了——当时很多人说我疯了
  2023年市场回暖——那些加倍投的份额成了收益最高的部分
  2024年第一次触发止盈纪律——赎回了50%盈利，落袋为安

  ———

  ▸ 复盘部分
  三年下来，这个策略的年化收益率是9.8%
  跑赢了我身边90%自己炒股的同事
  但说实话——最难的不是选基金，是跌的时候坚持
  2022年10月账户浮亏最多的时候到了-18%
  那时候如果没有提前写好「加仓纪律」——我大概率会停掉定投
  所以框架最大的价值不是让你多赚——是让你在应该坚持的时候不放弃
  ```

### 公式3：数据对比体
```
用简单的文字表格或对比排列呈现数据差异，让数字自己说话
```
- **为什么财经爆款常用**：财经内容的核心是「比较」——比较收益率、比较成本、比较方案。数据对比体把抽象的选择变成直观的数字差异，让读者不用费脑就能看到「差在哪」「差多少」。这种排版天然适合「选择困难症」的财经场景——保险怎么选、基金怎么挑、还款方式怎么定。

- **案例**:
  ```
  等额本息 vs 等额本金，差别有多大？🏠

  贷款200万，利率4.2%，30年

  |               | 等额本息    | 等额本金    |
  |---------------|-----------|-----------|
  | 首月月供       | 9780元     | 12555元    |
  | 末月月供       | 9780元     | 5586元     |
  | 月供变化       | 不变        | 逐月递减    |
  | 总利息         | 约152万    | 约126万    |
  | 总还款         | 约352万    | 约326万    |
  | 适合人群       | 月收入稳定   | 前期还款能力强 |

  差距：26万。
  够买一辆不错的车了。
  但前期每月多还近3000块——你的现金流能扛住吗？

  建议：
  → 年轻收入还在涨的——选等额本金，前期咬咬牙，总利息省得多
  → 收入稳定不想前期压力太大的——选等额本息，月供稳定好规划
  → 两种都可以提前还款——有钱了就还不是非要选一种
  ```

### 公式4：步骤清单体
```
①②③编号列出理财操作步骤，每条不超过2行，步骤之间空一行
```
- **为什么财经爆款常用**：理财内容天然是「操作型」的——开户、选基金、做配置、填报表。步骤清单体把一个复杂的理财操作拆成若干最小可执行单元，每一步都清晰简洁。读者看到这种排版会有一种「原来这么简单」的轻松感——而这正是克服「理财拖延症」的关键。

- **案例**:
  ```
  从现在开始建立你的理财体系，分6步走👇

  ① 花一个周末，把所有银行卡、证券账户、公积金、保险、负债全部梳理一遍。做成一张家庭资产负债表。这是你理财的「起点」。

  ② 发工资当天设置自动转账——把收入的至少20%转入一个不能轻易动的储蓄账户。自动化是克服人性的唯一方式。

  ③ 存够6个月的生活费放在货币基金里——这是你的「安全垫」。没有安全垫之前不要开始投资。

  ④ 把商业保险配齐——百万医疗+意外+重疾。顺序不要乱：医疗先、重疾后。保障没做好之前不要把所有钱拿去投资。

  ⑤ 安全垫和保障都到位以后——开始定投指数基金。从收入的10%开始，习惯了再慢慢加。

  ⑥ 每年生日那天做一次「财务体检」——检查各账户比例有没有跑偏、保险有没有过期、投资有没有偏离策略。

  这6步做完以后你会有一个非常清晰的感觉——钱终于在自己的掌控之中了。
  ```

### 公式5：红黑榜排行体
```
红榜/推荐列前，黑榜/避雷列后，每项一行点评，用✅和❌区分
```
- **为什么财经爆款常用**：理财世界充满了「选择」——选什么产品、选什么策略、选什么工具。红黑榜排行体给读者一个清晰的「建议/不推荐」清单，降低了决策成本。更重要的是——红黑榜天然带有「避坑」属性，而「避坑」是财经内容最强的情感钩子之一。

- **案例**:
  ```
  用过的理财工具和App红黑榜🛠️

  ✅ 红榜——真的好用

  ✅ 随手记/挖财（记账App）

### 公式6：Q&A理财问答体
```
自问自答式排版——一个核心理财困惑开头，拆成多个子问题逐一回答，每个问答之间空行
```
- **为什么财经爆款常用**：理财类内容最大的痛点在于——读者有大量具体的、个性化的困惑，但不知道从哪问起。Q&A体把读者心里那些「不好意思问」「不知道该问谁」的问题一一拎出来回答。读者在扫读时看到自己正好想问的问题——就会停下来细看。这种排版本质上是「替读者把他想问的问题问出来」。

- **案例**:
  ```
  理财入门最常被问的8个问题，一次说清楚💡

  Q：我月薪5000，理财有意义吗？
  A：太有意义了。理财和收入多少没关系。月薪5000你能理5000的财——先搞清楚钱去哪了、建立存钱习惯。等你月薪1万5的时候，这习惯会帮你存下比别人多得多的钱。

  Q：定投亏了要不要停？
  A：定投亏的时候恰恰是最不该停的时候。亏了=同样的钱能买更多份额=成本在降低。等市场回暖了你的仓位比别人重、成本比别人低。定投赚的就是这个钱。

  Q：要不要提前还房贷？
  A：看你的钱的机会成本。如果你有一笔闲钱——放在理财的收益率是4%、房贷利率是4.2%，那提前还贷划算。如果理财能稳定赚6%以上——就别还，留着钱赚利差。

  Q：保险到底怎么买才不踩坑？
  A：记住三条——①买纯保障型的不要理财型的 ②先大人后小孩 ③先医疗后重疾。不出这三条，基本不会出大问题。

  Q：银行存款超过50万安全吗？
  A：存款保险制度保障的是同一家银行每人50万以内。超过50万的部分——换一家银行存。钱多就多开几家银行的账户，每家不超过50万。

  Q：基金A类和C类有什么区别？
  A：A类有申购费、持有超过1-2年费率很低——适合长期持有。C类没有申购费但有销售服务费——适合短期持有。定投选A类、短期买卖选C类。

  Q：信用卡太多好不好？
  A：不好。管理成本高——忘了还款日期就逾期上征信。日常持有1-2张就够了。一张主力刷（积分和权益最好的），一张备用。

  Q：怎么判断自己的财务状况是否健康？
  A：看三个指标——①储蓄率>20% ②负债/年收入<1（房贷除外）③有至少6个月生活费的应急资金。三个都达标=财务状况良好。
  ```

### 公式8：资产配置体
```
用「账户→用途→比例→具体产品」的四层结构，像剥洋葱一样从大类落到具体操作
```
- **为什么财经爆款常用**：资产配置是财经内容中最具「架构美学」的排版模式。它从「你需要几个账户」开始，层层细化到「每个账户放多少钱、买什么」，让读者从宏观到微观都有清晰认知。这种排版本质上是一种「财务秩序」的可视化——而秩序感是财经读者深度渴望的东西。

- **案例**:
  ```
  普通人的「四个钱袋」配置法💰

  🟢 钱袋一：活钱（随时要用的）
  比例：月支出的3-6倍
  放哪：余额宝/零钱通/银行T+0理财
  特征：随时可取、不追求收益、只追求流动性
  什么时候用：失业过渡期、突发急事、日常周转

  🟡 钱袋二：保命的钱（不能省的）
  比例：年收入的5%-8%
  放哪：百万医疗险+重疾险+意外险+定期寿险
  特征：用小钱撬动大保障
  什么时候用：生病、意外、家庭支柱倒下时

  🟠 钱袋三：稳健的钱（3年内可能要用的）
  比例：总资产的30%-40%
  放哪：大额存单/国债/债券基金
  特征：不追求高收益、但本金不能亏
  什么时候用：买房首付、结婚、换车、孩子教育金

  🔴 钱袋四：增长的钱（5年以上不动的）
  比例：总资产的30%-40%
  放哪：指数基金定投（沪深300+中证500）
  特征：短期可能亏、长期大概率赚
  什么时候用：养老、财富自由、留给子女

  四个钱袋各司其职
  任何一个袋子出问题
  都不会影响其他三个

  这就是资产配置的本质——
  不是把鸡蛋放在不同的篮子里
  是让每个篮子都有自己的使命
  ```

### 公式10：结尾分离法

### 公式1：理财搭子互动型
```
你们{财务相关经历/困惑/偏好}？评论区{具体行动}，一起{共同目标}
