# 旅行图文笔记生成规则

> 基于300篇小红书/公众号旅行类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 旅行 = 攻略路线、景点推荐、住宿测评、拍照机位、旅行好物、穷游经验、自驾游、周末出行等。

## 概述：旅行图文笔记公式体系

```
封面标题(数字+目的地+痛点+结果) → 开头钩子(前3行定生死) → 正文干货(每段有收获)
         ↓                          ↓                          ↓
       配图逻辑(风景是向往感不是说明书)  →  排版呼吸感(留白比填满重要)  →  结尾CTA(给读者一个交代)
```

本文件共60个公式（6大支柱 × 10公式/支柱），全部提炼自300篇旅行行业爆款笔记的真实数据。每个公式均从实际爆款中高频出现的写作模式归纳得出——不预设分类、不跨行业参考、不做"通用"与"独占"的区分。所有60个公式都从旅行内容生态中自然涌现。

## 支柱二：开头钩子（10个公式）

- **案例**: 「一个人背包走了东南亚3个国家。没有遇到任何危险，反而是这3年最自由、最快乐的时光。」

## 支柱三：正文干货（10个结构公式）

### 公式1：漏斗四段法
```
痛点陈述(2-3句) → 场景代入(2-3句) → 解决方案(3-5句) → 行动指引(1-2句)
```
- **案例（大理避坑指南）**:
  痛点：「你以为的大理：洱海边吹风、古城里发呆、每天被日出和日落美哭。实际上的大理：古城走两步一个义乌小商品店、网红餐厅排队两小时、照片里的洱海边全是人。」
  场景：「上个月一个朋友去了大理，回来吐槽了整整半小时。我说你去了哪里？双廊——去了；喜洲——去了；网红S弯——排了半小时队拍了张照。你漏掉了90%的大理。」
  方案：「真正的大理在古城外。去沙溪，茶马古道上唯一活着的集市，周五赶集的那天才叫人间烟火。去巍山，比大理古城安静一百倍。去诺邓，千年白族古村，火腿好吃到想打包一整条腿。环洱海别走环海东路，走环海西路，从下关一直骑到海舌公园。路上你会经过七八个完全没有游客的村子。」
  行动：「大理玩了6次以后总结的这份'避开所有游客'攻略，路线图放在图9了。按这个走，你看到的大理和别人看到的不一样。」

### 公式2：AIDA旅行模型
```
Attention(一张图/一个画面) → Interest(为什么值得去) → Desire(具体怎么玩) → Action(出发指引)
```
- **案例（川西自驾攻略）**:
  Attention：「在海拔4200米的地方，我看到了同时出现的雪山、草原、海子和银河。」
  Interest：「这不是什么需要花大价钱才能去的地方。一条四川省道，从康定到理塘，300公里，美得像把瑞士、新西兰和内蒙拼在了一起。6-8月草绿了、野花开了，9-10月彩林黄了红了。而且整条路不收门票。」
  Desire：「第一天：成都出发，经雅安到康定。晚上住康定，海拔2500适应一下。第二天：康定走S434到塔公草原。塔公寺在雅拉雪山前面，拍出来比国家地理还好看。晚上住新都桥，摄影天堂不是白叫的。第三天：新都桥到理塘。中间经过卡子拉山，海拔4718的垭口，视线可以看出去50公里。第四天：理塘往稻城方向走，不想去稻城可以往北走去色达。这条路每一步都是风景。」
  Action：「完整路书+每日住宿推荐+加油站位置+海拔变化图，全部整理在图8-10。评论区告诉我你几月出发，我帮你看看天气和路况。」

### 公式3：SCQA结构
```
Situation(情境) → Complication(冲突) → Question(问题) → Answer(答案)
```
- **案例（第一次去日本）**:
  Situation：「想去日本旅行——被那些日系小清新照片种草了很久。但第一次去，什么都不懂。」
  Complication：「网上的攻略太多了。看了三天小红书，收藏了50篇，反而更焦虑了——JR Pass到底要不要买？西瓜卡和ICOCA卡有什么区别？住宿选民宿还是酒店？这些信息越看越绕不清楚。最可怕的是，很多人说不会日语在日本寸步难行。」
  Question：「第一次去日本到底应该怎么准备？能不能有一个'什么都帮你安排好了'的傻瓜式攻略？」
  Answer：「能。第一步：办签证——淘宝找旅行社，300-500块，7个工作日。第二步：买机票——提前2个月买，往返大阪/东京含税1500-2500。第三步：订住宿——Booking上找评分8.5以上的，位置选地铁站步行5分钟内的。第四步：交通——如果你只在关西玩(大阪/京都/奈良)，不用买JR Pass，买一张ICOCA卡刷就行。语言问题：下载Google翻译+Google Maps，这两个App已经能解决90%的问题。吃饭点菜看图就行，日本餐馆门口都有食物模型。购物的话药妆店全都有中文导购。剩下的10%靠比划+微笑，日本人比想象中热情。我第一次去的时候日语只会说'谢谢'和'对不起'，一样玩得很开心。」

### 公式4：路线拆解法
```
路线总览(一张图/一句话概况) → Day1(时间点+景点+吃住) → Day2 → Day3 → ... → 注意事项
```
- **案例（青甘大环线7天）**:
  总览：「西宁出发，逆时针走。全程2500公里，经过两个省、穿越草原→戈壁→沙漠→盐湖→丹霞→雪山。每一天的风景都不一样。」
  Day 1：「西宁→青海湖(2h)。下午两点到二郎剑景区旁边的牧民小道，给20块钱直接走到湖边，一样的湖但一个人都没有。晚上住黑马河，第二天看日出。」
  Day 2：「黑马河日出(5:30起床)→茶卡盐湖(1.5h)。茶卡别中午去——光线太硬拍出来不好看，要么早上8点前到要么下午5点后到。晚上住德令哈。」

### 公式5：清单对比法
```
选择维度(一句话) → 推荐清单(每项一句话+感受) → 不推荐清单(避开+原因) → 总结规律
```
- **案例（大理民宿红黑榜）**:
  维度：「以'景观+安静度+性价比'三个维度，住了大理20多家民宿以后总结。」
  红榜：「①双廊半月拖蓝——600+/晚，270度海景，浴缸对着洱海，躺在床上看日出 ②沙溪既下山——400+/晚，老粮仓改造的设计师民宿，院子里那棵树拍照绝了 ③喜洲喜林苑——500+/晚，百年白族大院改造，住进去像住进历史 ④古城外果子园一家没有名字的民宿——150/晚，老板是退休老师，院子里的三角梅开得像瀑布 ⑤龙龛码头附近的无舍——700+/晚，极简风，每个房间都面朝洱海，早餐是老板自己做的饵丝」
  黑榜：「①古城内某网红天空之境民宿——照片里看起来在海边，实际是在房顶搭了个水坑，房间小到箱子打不开 ②洱海边某大面积玻璃民宿——美是美但早上6点太阳直射房间根本睡不了 ③某小红书爆款帐篷民宿——看着野奢实际蚊子多到怀疑人生，晚上风大帐篷响得睡不着 ④靠路边太近的民宿——摩托车声凌晨三点都还有」
  规律：「大理住宿选在古城外围的村落反而体验更好——安静、有当地生活气息、价格还便宜。花100块打车一天就能把洱海周边都转完，不需要住在最热闹的地方。」

### 公式6：亲身经历线
```
时间线开头 → 中间过程(准备→出发→途中→高潮) → 感悟收尾
```
- **案例（独自去西藏）**:
  「2024年6月12号，我背着一个45L的包上了Z21次列车，北京西到拉萨。40个小时的硬卧。出发前一天晚上我妈还在劝我：'你一个女孩子去那么远的地方干嘛，又苦又累。'
  第一个变化发生在格尔木之后。火车开始爬升，窗外的风景从城市变成戈壁变成雪山。可可西里无人区，我看到了藏羚羊。那一刻整个车厢都趴在窗户上，所有人都不说话了。
  到拉萨的第一晚头疼到失眠。青旅上铺的姐姐给了我一片药，说'第一次都这样，明天就好了'。第二天醒来，阳光透过窗帘照进来，头不疼了——我知道自己过关了。
  跟青旅认识的三个人拼车去了羊卓雍措。看到那片蓝的时候，司机放着藏语歌，车里没有人说话。不是没话说——是觉得说什么都不合适。那种蓝色让你觉得言语是多余的。
  在八廓街跟着朝圣的人流走了三圈。身边是磕长头的人、摇着转经筒的老人、穿藏袍的小孩。我不是佛教徒，但那个下午我感到了某种平静——多久没有这种感觉了？在城市里每天都很忙，忙到忘了安静是什么感觉。
  从西藏回来瘦了8斤，黑了两个度。朋友问我好不好玩，我说不是'好玩'。是一种你需要亲自去体验的东西。回来以后最大的变化是：遇到事情没那么急了。也许是高原教会了我——慢慢来，呼吸。」

### 公式7：问题解答型
```
一个问题全景 → 拆成2-3个子问题 → 逐一解答(原因+方法+具体操作) → 总结
```
- **案例（旅行拍照为什么总是不好看）**:
  全景：「为什么别人在同一个地方拍出来是大片，你拍出来是'到此一游'？」
  子问题一：「光线时间错了。中午12点到下午3点是最不适合拍照的时间——光线从头顶直射，脸上全是阴影。拍照的黄金时间是日出后1小时和日落前1小时。这时候的光是斜的、暖的、柔和的。去任何景点之前先查一下日出日落时间，把最重要的拍摄点安排在黄金时段。」
  子问题二：「构图太贪心了。很多人拍照想'什么都拍进去'——结果是什么都有但什么都不突出。旅行照最简单的构图公式：人占画面下方1/3，风景占上方2/3。或者人站在画面前景，景深往后延伸。再不行就记住一个口诀：有路就站在路中间、有框就让人在框里（门框、窗框、树框都行）、有引导线就把人放在线的尽头。」
  子问题三：「穿错衣服了。在雪山上穿白色、在草原上穿绿色——人直接和背景融为一体。旅行拍照配色铁律：和背景形成反差。雪山下穿红/橙色，海边穿白/黄/蓝，古城穿纯色不要大花，沙漠穿红色、白色、黑色都好看。」
  总结：「搞懂了光、构图和配色这三个东西以后，男朋友用手机也能拍出你满意的照片。光永远排在第一位。」

### 公式8：预算拆解法
```
总花费概述 → 分项拆解(交通/住宿/餐饮/门票/其他) → 省钱关键点 → 同线路不同预算方案
```
- **案例（清迈6天5晚花费拆解）**:
  总花费：「这趟清迈6天5晚两个人一共花了6200元人民币，人均3100。含往返机票、全程住宿、每天吃喝、按摩、包车。」
  分项：「①机票：亚航长沙往返清迈含税，每人680元。提前2个月大促买的 ②住宿：Airbnb订的一间小院子，5晚共900元，人均450。有泳池有厨房 ③吃饭：每顿人均15-30元。清迈的物价感人到想哭——一份泰式炒粉8块，一杯鲜榨芒果汁6块，一顿海鲜大餐人均40 ④交通：Grab打车城区内每次10-20块。包车去素贴山+双龙寺一天300元 ⑤按摩：泰式按摩200铢(40块)/小时，做了3次共120元 ⑥门票：大部分寺庙免费，丛林飞跃350元/人 ⑦其他：买芒果干、榴莲干带回来花了200块。」
  省钱关键：「清迈不是'省'出来的，是物价本来就这么低。最省钱的地方是住宿——选Airbnb不要住古城内，往宁曼路或者河对岸找，价格便宜一半。吃饭去本地夜市，不要去游客夜市——从古城北门出去本地人吃饭的地方，10块钱吃饱。」
  不同预算：「如果预算更紧：住青旅床位30-50块/晚，全程费用可以压到2000以内。如果预算宽松：住137 Pillars House那种精品酒店，一晚1500+，6天可以花到1万+。清迈从穷游到奢华都有合适的玩法。」

### 公式9：评测推荐型

### 公式10：时间轴攻略型
```
出发前{X}天 → 出发前{X}天 → 出发当天 → 途中 → 回来后
```
- **案例（第一次出国旅行准备时间轴）**:
  出发前60天：「确定目的地+办护照（如果没有）+开始看机票。这个阶段最重要的是决定去哪儿和大概什么时间。」
  出发前45天：「买机票。提前45-60天是国际机票价格的低谷期。用天巡比价，然后去航司官网买——廉航官网经常有比代理更便宜的价格。」
  出发前30天：「办签证。淘宝找代办，按材料清单准备好。热门国家建议多加200块办加急。」
  出发前15天：「订住宿。先订第一晚和最后一晚，中间的可以到了再灵活调整。Booking上找可免费取消的，万一行程变化不用损失钱。」
  出发前7天：「买保险+换外币+下载离线地图。保险几十块钱但能救命，千万不要省。外币去中国银行APP预约汇率最好。」
  出发前3天：「打包行李。照着清单收，不要多带。行李箱空出1/3——相信我，你一定会买东西回来的。」
  出发当天：「提前3小时到机场。国际航班值机截止时间是起飞前45分钟。护照+签证+机票确认单放在随身包里。」
  途中：「每天发一个定位给家人。护照单独放、钱分开放。到一个新地方先查一下当地报警电话和大使馆电话。」
  回来后：「整理照片+写旅行日记+把好用的小众APP/店铺/路线分享出来。那些在你焦虑的时候帮过你的攻略，也许也能帮到别人。」

## 支柱五：排版呼吸感（10个公式）

### 公式1：段落分割法
```
每个独立目的地/观点空一行，不同板块之间用符号分隔
```
- **案例**:
  ```
  一直觉得旅行最花钱的不是机票，是住宿。直到我发现了这三个方法。

  ✨ 第一个：订酒店前先在地图上看位置
  不是离景点越近越好。离核心景区2-3公里的地方，价格直接腰斩。打车/骑车过去也就10分钟。

  ⚠️ 第二个：不要只看评分
  看最新评价——不是好评，是差评。差评里藏着这个酒店最真实的问题。如果差评说的都是'隔音差''有味道'，说明硬件问题。如果差评说的是'服务态度''前台冷漠'，说明管理问题。硬件问题改不了，管理问题看运气。

  💡 第三个：掌握这个预订时间窗口
  国内酒店提前3-5天订最便宜。国际酒店提前30-45天。节假日出行的反向操作——最后48小时捡漏，会有大量退订释放出来。
  ```

### 公式6：信息密度控制法
```
每段只讲一个点。想讲第二个点，空行再开一段。
```
- **案例**:
  ```
  为什么你的旅行照总是不好看？三个原因

  第一个：光线时间错了
  中午的太阳在头顶，脸上全是阴影——颧骨下面是黑的、眼窝是黑的、下巴是黑的。这不是你的问题，是光线的问题。把最重要的拍照时间留给早上和黄昏，其余时间用来赶路、吃饭、休息。

  第二个：你站的位置不对
  大部分人的拍照习惯：看到风景→站过去→微笑→咔嚓。好看的照片逻辑是相反的：先观察光线从哪边来→找到光线最好的那个点→站过去。脸对着光、不是背着光。这个习惯养成以后出片率提升百分之五十。

  第三个：衣服和背景打架了
  穿格子衬衫站在花丛里——到底谁在看花谁在看你？纯色衣服在旅行里永远是最安全的选择。白色和红色基本通用于所有场景。
  ```

### 公式10：诚意收尾型
```
{感谢/真心话} + {希望这篇对你有用的祝福}
```
- **案例**: 「写了快四个小时。如果这篇能帮到哪怕一个正在计划旅行的人，少踩一个坑、多看到一处好风景——就值了。谢谢你看到这里，祝你下一次旅行，阳光正好。」
- **案例**: 「这些都是我花了时间、金钱和体力踩出来的经验。不用都记住，收藏起来，需要的时候翻出来看看就好。祝你每次出发都是对的方向。」
- **案例**: 「每次写完这种长篇攻略都很感慨——旅行带给我的东西太多了，远比这些文字能表达的要多。希望你在路上也能找到属于自己的那份感动。出发吧。」
- **案例**: 「这篇攻略没有推荐任何一个收费景点。因为真正会让人记住的旅行，永远在景区之外。愿你有发现美的眼睛，也有跳出攻略的勇气。」
- **案例**: 「写了快三千字，每一个建议背后都是一段真实的经历。不用全信——去亲身体验一次，然后形成你自己的旅行方式。那才是最好的攻略。」
- **案例**: 「做旅行博主的初心不是教你'怎么拍出好看的照片'，而是告诉你：这个世界值得你亲自去看一眼。这篇送给你。愿它成为你出发的最后一根稻草。」
- **案例**: 「感谢每一个认真看完的人。你比你以为的更勇敢、更有探索力。从今天开始，做一个有计划也接受意外的人。路上见。」
- **案例**: 「每次收到私信说'照着你攻略去了好好玩'，比我自己出去旅行还开心。谢谢你们信任我。继续在路上帮你们踩点。」
- **案例**: 「写到结尾又想去旅行了。不是矫情，是真的觉得这个世界值得被认真对待。希望你也一样。下次见，在路上的某个地方。」
- **案例**: 「世界是一本书，不旅行的人只读了第一页。感谢你选择翻开更多。愿你往后的每一次出发都平安、快乐、满载而归。」
