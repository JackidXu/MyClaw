# 餐饮探店图文笔记生成规则

> 基于300篇小红书/抖音餐饮探店类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 探店 = 餐厅测评、网红店拔草、路边摊发掘、咖啡店打卡、火锅/烧烤/日料/西餐等各类餐厅测评、性价比评测、约会餐厅推荐、聚餐攻略等。
> 与美食行业的区别：美食侧重"自己做"（菜谱、备菜、烹饪技巧），餐饮探店侧重"出去吃"（餐厅测评、环境打分、菜品推荐、避雷指南）。

## 概述：餐饮探店图文笔记通用公式

```
封面标题(数字+店名+爆点+结果) → 开头钩子(前3行定去留) → 正文干货(每道菜有说法)
         ↓                          ↓                          ↓
       配图逻辑(图是食欲不是摆拍)  →  排版呼吸感(节奏比堆料重要)  →  结尾CTA(让读者有动作)
```

## 支柱二：开头钩子（10个公式）

### 公式1：直接抛结果
> {极致体验结果}，{具体到店名/菜名}。{制造悬念}...
- **案例**: 「吃完这家韩料，我取消了去首尔的机票。不是夸张，是这家的烤五花肉配芝麻叶，比我之前在明洞吃的任何一家都绝。往下看地址。」

- **案例**: 「这顿人均90的粤菜，比我上个月吃的米其林二星还要满足。关键就在那碗看起来普通的煲仔饭。」
- **案例**: 「连续去了三周——这是过去两年里唯一一家让我做到这一点的餐厅。连服务员的排班我都记住了。」
- **案例**: 「吃完出门走了三百米，又折回去打包了一份带走。这个葱油饼值得我错过一班地铁。」
- **案例**: 「我朋友是云南人，吃完这家的过桥米线沉默了很久。然后说:'跟我外婆做的味道一模一样。'」

- **案例**: 「同样的预算为什么别人总能吃到'很值'的店？不是他们运气好，是他们掌握了看菜单的方法。」

### 公式4：认知刷新型

- **案例**: 「很多人觉得吃粤菜就是喝茶吃点心。但广东人挑茶楼的唯一标准是——看虾饺的皮。皮薄到半透明还能夹起来不破的，这家店的水平不会差。」
- **案例**: 「你以为网红店都是昙花一现？能火两年以上的网红店有一个共同特点——菜单上必有一道'碳水炸弹'。因为拍照好看让顾客进门，但碳水让顾客反复回来。」

- **案例**: 「早餐吃不了太多但想吃好的——这家店的豆浆油条是我在南方吃到过最北方的味道。豆浆是自己磨的，油条是现炸的，早上七点就开始排队了。」

### 公式8：权威引用型

- **案例**: 「一个开了25年大排档的老板跟我说：'我不看点评不看小红书。我只看每天收摊时泔水桶里剩了多少菜。剩菜少的菜，第二天多做；剩菜多的菜，直接下架。顾客的身体比嘴巴诚实。'」

### 公式9：对比冲击型

### 公式7：问题解答型
```
一个问题全景 → 拆成2-3个子问题 → 逐一解答(原因+方法+推荐) → 总结
```
- **案例（为什么你挑的餐厅总踩雷）**:
  全景：「最常收到的私信：'为什么我看小红书上的探店笔记去吃的店十有八九踩雷？'今天系统性回答这个问题。」
  子问题一：「你是不是只看点赞和收藏量？爆款笔记≠真实好吃。探店博主的商业模式决定了他们会'美化'体验——因为餐厅付了推广费。一个判断标准：看博主有没有说过这家的缺点。如果通篇都是'绝了''太好吃了吧''一定还要去'但没有任何具体的口感描述——快速滑走。」
  子问题二：「你是不是只看了最热门的推荐？大众点评前五、小红书首页推荐——这些位置的餐厅都是花了钱的。真正的宝藏店在这些位置后面。一个技巧：在大众点评搜关键词后点'按时间排序'而不是'按评分排序'——你会看到刚吃完的真实评价，而不是刷的好评。」
  子问题三：「你是不是没搞清楚自己的口味偏好？再好吃的川菜放在不吃辣的人面前就是灾难。在探店之前先想清楚自己对这顿饭的核心需求——是追求极致味道、还是舒适的氛围、还是性价比。每家店能给你的东西不一样，你不能指望一家店满足所有期待。」
  总结：「好的探店笔记会让你看完以后知道'这家店适不适合我'，而不是'所有人都应该去'。后者是广告，前者才是真实的分享。」

### 公式8：多维度打分法
```
打分说明(每项满分+标准) → 菜品分(详写) → 环境分(详写) → 服务分(详写) → 性价比分(详写) → 综合推荐分+一句话总结
```

- **案例（一家日式烧肉店）**:

### 公式9：性价比拆解法

  逐项拆价：

  「荤菜——毛肚38元/份：分量是其他火锅店的1.5倍。每一片都很大，不是那种碎碎的边角料。👉 超值。」
  「荤菜——鸭肠28元/份：正常分量正常价格。👉 合理。」
  「荤菜——耗儿鱼42元/份：大概6条，个头偏小。👉 偏贵。」
  「荤菜——现切鲜牛肉48元/份：分量够两个人吃，肉是现切的不是冻品刨的。👉 超值。」
  「素菜拼盘22元：土豆藕片木耳娃娃菜，正常。👉 合理。」

### 公式10：探店攻略型
```
为什么选这家(1-2句) → 行前准备(交通/预约/时间) → 点菜攻略(必点+避雷) → 隐藏玩法(特殊吃法/隐藏菜单/周边联动) → 适合场景
```
- **案例（一家胡同里的私房菜）**:
  为什么选：「朋友推荐的原话是：'如果你想吃一顿能让客户觉得你有品味的饭，去这家。'人均300，但每道菜都有故事。」
  行前准备：「①必须提前至少三天预约——每晚只接待四桌，周末排到两周后。②开车的话停在胡同口停车场，胡同里进不去。③公共交通：地铁XX站B口出步行5分钟。④约的晚上7点到，但其实可以提前6:30到——可以在院子里喝茶。」
  点菜攻略：「菜单是手写的，每周换一次。必点：熟醉蟹——陈年花雕腌了48小时，蟹黄是半流质状态，酒香和蟹黄的鲜甜融合在一起。糖醋排骨——不是番茄酱勾芡的红色糖醋，是梅子酱调的对勾芡汁，酸甜层次分明。隐藏菜单——如果你主动问'今天师傅做了什么自己吃的'，可能会得到菜单上没有的一道家常菜。那天我们得到一份雪菜肉丝炒饭，是师傅给自己和员工做的晚饭——比菜单上任何菜都好吃。」
