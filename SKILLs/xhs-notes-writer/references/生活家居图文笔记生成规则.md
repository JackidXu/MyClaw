# 生活家居图文笔记生成规则

> 基于300篇小红书/公众号家居类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 家居 = 收纳整理、软装搭配、装修避坑、租房改造、好物推荐、清洁技巧、空间利用、居家氛围等。

## 概述：生活家居图文笔记通用公式

```
封面标题(数字+空间+痛点+效果) → 开头钩子(前3行定生死) → 正文干货(每段有收获)
         ↓                          ↓                          ↓
       配图逻辑(图是证据不是装饰)  →  排版呼吸感(留白比填满重要)  →  结尾CTA(给读者一个交代)
```

### 公式2：收纳四步法
```

- **案例（厨房收纳）**:

### 公式8：原理+实操法
```
