# 情感图文笔记生成规则

> 基于300篇小红书情感/恋爱/人际关系爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 情感 = 恋爱关系、婚姻经营、分手疗愈、暧昧心理、人性洞察、情绪价值、原生家庭等。

## 概述：情感图文笔记创作公式

```
封面标题(扎心+共鸣+悬念) → 开头钩子(前3行决定划不划走) → 正文干货(每段击中一个情绪点)
         ↓                          ↓                          ↓
       配图逻辑(图是证据不是网图)  →  排版呼吸感(留白让读者有喘息)  →  结尾CTA(给读者一个宣泄出口)
```

**方法论说明**：以下60个公式全部来源于对300篇情感行业爆款笔记的逐篇拆解与归纳。不做"通用"与"独占"的预设区分 —— 每一个公式的留存，都是因为它在情感爆款中高频出现且持续有效；被替换或删除的公式，是因为它们在情感场景下表现疲软。公式命名、模板结构、案例语感均从情感爆款数据中自然涌现，不跨行业借鉴。

```
"{一句扎心金句}"，{简短点破/翻译潜台词}
```
- **案例**: 「"你很好，是我不配。" 翻译过来是：我不想为你改变。就这么简单。」
- **案例**: 「"他只是不懂怎么表达。" 不是的。他懂，只是对你不需要表达。」

- **案例**: 「"你要是这么想我也没办法。" 这句话一出来，吵架就输了——对方已经不想沟通了。」
- **案例**: 「"你怎么变成这样了？" 没变，是不装了。」
- **案例**: 「"随你便。" 比吵架更伤人的三个字。翻译：我不在乎了。」
- **案例**: 「"我从来没要求你做过这些。" 翻译：你做的这些感动不了我。收手吧。」
- **案例**: 「"我只是不会表达。" 不是的。他在兄弟面前妙语连珠，在你面前无话可说——这就是表达。」

- **案例**: 「"我会改的。" 他说的"改"=再演三天，然后恢复原样。」

## 支柱二：开头钩子（10个公式）

### 公式1：结果直抛型

- **案例**: 「我终于能说出那句话了：离开他是我做过最好的决定。怎么做到的——往下翻。」

### 公式1：漏斗四段法

### 公式6：多维度诊断法

### 公式8：对话复盘型

  「她："那你提前说一声也行啊。每次都是我等到晚上你才说。"」

  逐句分析：
  - "加班有什么办法" → 潜台词：你的情绪是负担，我的工作是优先级。
  - "你别这么敏感" → 潜台词：问题在你，不在我。精准地把责任推到了她身上。
  - "你又来了" → 最伤人的三个字。把她的情绪归类为"老毛病"，意思是你有没有道理我都不听了。
  - "算了我不想吵" → 冷暴力的标准开场白。
  正确沟通模板：
  「他应该说："对不起，这周确实忙得有点失控。下周我排好时间，周末两天都陪你。现在先别生气，我们视频聊一会儿？"」
  结论：「同一个问题，沟通方式不同，结局完全不同。一段关系死掉，往往不是因为发生了什么大事——是一次一次的沟通失败。」

### 公式9：评分诊断型
```
评测维度说明 → 逐项评分(1-10分)+理由 → 总分+判断标准 → CTA
```
- **案例（给自己的感情打分）**:
  维度：「从5个维度给你们的感情打分，1-10分。打完你就知道该不该继续了。」
  评分：
  - 「情绪安全感：你在他面前能真实地表达自己吗？→ 不能=3分以下，偶尔能=4-6分，完全能做自己=7-10分。」
  - 「沟通质量：吵架之后问题是解决还是被搁置？→ 每次吵完同样的事再来一遍=1-3分，有时候能谈开=4-6分，吵完一定解决=7-10分。」
  - 「未来规划：他对你们的关系有具体的时间轴吗？→ 从不提未来=1-3分，提到未来但模糊=4-6分，有明确计划且在推进=7-10分。」
  - 「朋友圈公开度：他身边的人知道你吗？→ 几乎没有=1-3分，部分知道=4-6分，身边的人全都知道且经常带你出现=7-10分。」
  - 「自身状态变化：跟他在一起之后，你变得更好了吗？→ 变差了=1-3分，没啥变化=4-6分，变自信变好了=7-10分。」
  判断：「总分35分以上——健康的感情，好好珍惜。20-34分——有问题但有修复空间，需要一次深度沟通。低于20分——你知道答案了，你在等勇气。」
  CTA：「评论区报个分。你敢不敢打完给别人看？」

### 公式10：信件体


## 支柱五：排版呼吸感（10个公式）

  ```
  他今天没有说晚安

  我看了十七次手机

  每一次亮屏

  都不是他

  凌晨两点我把通知关了

  不是不想等了

  是等不起了

  你知道吗

  一个人不回消息

  不是因为没看到

  是因为你不重要

  我花了很长时间

  才敢把这句话

  说给自己听
  ```

### 公式2：金句悬浮卡
```
正文铺垫完成后，核心金句独立成段——前后各空两行，加粗。像一枚钉子，周围留足空白，让读者没有任何干扰地接住这句话的重量。
```
- **案例**:
  ```
  我一直以为他离不开我

  因为他生病是我照顾的
  他低谷是我陪着的
  他跟家里闹翻是我收留的

  后来他走了
  走得特别干脆

  我才明白


  **被需要不是被爱。你在他的生活里很重要，但你在他的心里不重要。**


  这两件事
  从来就不是一回事
  ```

### 公式3：对话体双声道
```
两个人的话用不同的对齐方式呈现——对方的话顶格左对齐，自己内心的真实想法用右对齐。空间关系在叙事：你们之间隔着的不是几行字，是说不出口的真相。
```
- **案例**:
  ```
  他说："我只是最近比较忙。"

  他说："项目结束就好了。"

  他说："你怎么又多想。"

                                                      其实不是多想。
                                                      是你每次说"忙"的时候
                                                      我刚好看到你
                                                      在朋友圈给别人评论。

                                                      但我不会说。
                                                      因为说出来
                                                      就是"我太敏感"。
  ```

### 公式4：时间戳情绪日记
```
用时间标记情绪变化的节点。时间不是装饰——凌晨的时间代表失眠和脆弱，清晨代表重新开始，深夜代表崩溃。时间戳之间的跨度本身就在叙事。
```
- **案例**:
  ```
  23:47
  翻到一张旧照片。他笑起来还是很好看。保存了吗？没有。删掉了吗？也没有。

  01:23
  还是没睡着。点进他的朋友圈——三天可见。以前是全部开放的。什么时候改的？跟我有关吗？不知道。也不该再想了。

  03:15
  起来喝水。厨房灯没关。以前他总说我忘关灯，现在没人说了。奇怪，以前觉得烦的事，现在有点空。

  06:42
  闹钟响了。天亮了。昨晚那些情绪好像做了一个很长的梦。刷牙的时候对着镜子说：又熬过了一天。

  挺好的。
  ```

### 公式5：内心独白碎片体
```
每行都是一块不完整的思想碎片，句子可以断裂、可以重复、可以矛盾。不追求逻辑连贯——情绪的本来面目就是碎片化的。排版的破碎感就是内心的真实状态。
```
- **案例**:
  ```
  今天在地铁上看到一个人
  背影很像你

  我盯着看了很久
  久到那个人回头
  不是你

  松了一口气
  然后又有点
  说不上来

  不是希望是你
  也不是不希望
  就是
  不知道

  你走以后
  我的情绪就是这样
  总是"不知道"

  不知道是想你
  还是想起你
  还是习惯性想起
  这三件事
  到底是不是同一件事
  ```

### 公式6：情绪阶梯递进式
```
每一段比上一段更短、更密集、更直接。从描述到剖析到一句定论——像下楼梯，越走越快，越说越狠，最后一级是沉默。段间距保持一致，但段落长度递减。
```
- **案例**:
  ```
  刚分手那阵，朋友问我什么感受。我说还好，没什么。其实不是没什么，是说不出来。堵着。像喉咙里卡了一颗糖，吞不下去也吐不出来。

  后来又有人问我。我说：有时候挺好的，有时候不好。不好的时候比较多。半夜不好，清晨不好，下雨天不好，超市不好——因为他爱吃的薯片还在货架上。

  再后来，有人问我走出来了吗。我想了很久说：走出来了。

  不是骗她。

  是真的。
  ```

### 公式7：一问一答自愈体
```
每一个问题独立成段（加粗），答案在下一段（不加粗），问答之间空一行。问题和答案之间空着的距离，就是思考的时间。像在跟自己对话，又像在跟读者对话。
```
- **案例**:
  ```
  **他到底爱没爱过我？**

  爱过。但爱过不等于还爱。就像昨天的太阳晒不干今天的衣服。

  **为什么是我放不下？**

  因为你投入得更多。不是他多好，是你太好了。你把自己最好的部分都给了一段不对等的关系。

  **他会不会后悔？**

  可能会。但那是他的事。你不需要等他后悔来证明自己的价值。你的价值不需要他的认可来盖章。

  **我还需要多久？**

  多久都不会太久。你想想三年前最难过的事，现在还记得那种痛吗？时间不是解药——但你往前走的样子，才是。
  ```

### 公式8：排比敲击式
```
同一个句式重复3-5遍，每次只换关键部分。排比不是修辞，是情绪的积累——每重复一次就重击一次，读到第三句时读者已经被带入节奏，第五句时已经在点头。
```
- **案例**:
  ```
  以前我以为爱是秒回消息

  后来我以为爱是吵架不分手

  再后来我以为爱是习惯了一个人就不想换

  现在我知道了

  爱是你在沙发上睡着了
  他把电视调成静音

  爱是你哭的时候他不说"别哭了"
  他说"我在这里"

  爱是你说"我觉得自己好糟糕"
  他看着你说"我觉得你好得很"

  以前那些都不叫爱
  叫年轻的错觉
  ```

### 公式9：截断式留白
```
一句话说到一半，故意不说完。用省略号或破折号截断，然后空一行、两行。读者会自己在沉默中补完那句话——而读者补进去的，往往比作者写的更扎心，因为补进去的是读者自己的故事。
```
- **案例**:
  ```
  分手那天我以为我会说很多话

  结果他关上门以后
  我坐着
  很久

  然后我打开备忘录
  打了一行字

  "从今天开始"

  又删掉了

  因为后面不知道该写什么

  从今天开始一个人？
  从今天开始忘记？
  从今天开始假装没事？

  后来我发现

  最好的告别
  就是那句没打完的话
  和那个空白的备忘录

  有些事情不需要结尾
  就像有些人
  ```

### 公式10：闭环呼应式
```
开篇第一句话和结尾最后一句话形成呼应——可以是同一句话、可以是反转、可以是回答。读者滑到最后一行的瞬间，会忍不住滑回第一行再看一遍。这"多看一遍"就是收藏和转发的心理动因。
```
- **案例**:
  ```
  你不必感谢那些伤害过你的人。

  他们没想让你成长。他们只是做了对自己最方便的选择——伤害你。你的成长是你自己一点一点从废墟里捡回来的。跟他们没有关系。

  但有一件事他们无意中教会了你——他们走了之后，你才发现：原来一个人也能活得好好的。

  原来你不用等别人说晚安才能睡。原来你可以自己给自己买花。原来周末一个人去吃火锅也没什么——不用照顾别人的口味，想吃脑花就点脑花。原来你比自己想象中强大得多。

  所以回到那句话——

  你不必感谢那些伤害过你的人。但你可以感谢那个从废墟里站起来的自己。
  ```

## 支柱六：结尾CTA（10个公式）

### 公式1：互动提问型
```

```
- **案例**: 「你们最长的冷战是多久？评论区说说看，顺便@那个正在跟你冷战的——但是算了，别@了」

- **案例**: 「一段关系里你最不能忍受的是什么？我先说——冷暴力，不接受任何解释」
- **案例**: 「你们觉得，分手后还能做朋友吗？能的和不能的评论区掐一下」

- **案例**: 「树洞来了。你在感情里最后悔的一件事是什么？评论区交换秘密。」
- **案例**: 「今晚评论区不聊方法论。就聊聊你现在最真实的感受。不用积极，不用正能量。允许自己难过。」

### 公式9：对号入座型
```
{几种典型情况分别描述}，你是第几种？评论区留下{你的答案}
```
- **案例**: 「放不下一个人的四种情况——①放不下他的人 ②放不下自己的付出 ③放不下不甘心 ④放不下那个无条件的自己。你是第几种？评论区对号入座。」
- **案例**: 「恋爱的四种模式：①互相消耗型 ②你追他跑型 ③表面和谐型 ④双向奔赴型。你现在是哪一种？敢不敢说？」
- **案例**: 「分手的五类人——①哭完就好的 ②假装没发生过的 ③反复崩溃的 ④死撑不联系的 ⑤真的放下的。评论区你是哪类？」
- **案例**: 「依恋类型自测——焦虑型(他三分钟不回消息就想很多) / 回避型(一靠近就想跑) / 安全型(内心稳定) / 混乱型(又怕被抛弃又怕太近)。评论区报一下你是哪种。」
- **案例**: 「感情里的三类人：①恋爱脑 ②极度理性 ③想爱但不敢爱。你是第几种？评论区排队。」
- **案例**: 「分手三个月的状态——①还在看他的朋友圈 ②不看了但还是会想 ③完全不在乎了。你到第几个阶段了？」
- **案例**: 「面对冷暴力的四种反应——①疯狂发消息 ②以冷制冷 ③假装没事 ④直接分手。你选了哪一种？」

### 公式10：抱团取暖型
```
{一句话号召}，评论区{集体行动}。我们一起。
```
- **案例**: 「所有正在经历分手的人，评论区扣一个"1"。不是为了统计——是为了告诉你：你不是一个人。下面全是1。」
- **案例**: 「今晚不劝你放下。你在评论区留一个"打卡"，我就陪你一天。第1天、第7天、第30天——我们一起数。」
- **案例**: 「被冷暴力过的人在评论区打"经历过"。这个评论区就是证据——冷暴力从来不是你的问题。」
- **案例**: 「正在努力戒掉一个人的姐妹，评论区留个"今天第X天"。我们互相看着——你每多一天，就有人为你鼓掌。」
- **案例**: 「今晚想哭的人集合。评论区发一个"💧"。不是让你难过——是让你知道，这个表情下面有几百个和你一样的人。」
- **案例**: 「想删他但还没勇气删的——评论区发一个"等一个勇气"。等你真的删了，回来把评论改成"已删"。我在这里等你。」
- **案例**: 「如果你现在很难过、又没有可以说的人，在评论区发一个"在"。我看到了会回你一句——你很重要，撑住。」
