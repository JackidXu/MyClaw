# 美食图文笔记生成规则

> 基于300篇小红书美食/做饭/探店爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 美食 = 家常菜、烘焙甜品、一人食、减脂餐、探店测评、备菜技巧、懒人食谱等。

## 概述：美食图文笔记公式体系

```
封面标题(数字+人群+痛点+结果) → 开头钩子(前3行定生死) → 正文干货(每段有收获)
         ↓                          ↓                          ↓
       配图逻辑(食欲是内容不是装饰)  →  排版呼吸感(留白比填满重要)  →  结尾CTA(给读者一个交代)
```

本文件共60个公式（6大支柱 × 10公式/支柱），全部提炼自300篇美食行业爆款笔记的真实数据。每个公式均从实际爆款中高频出现的写作模式归纳得出——不预设分类、不跨行业参考、不做"通用"与"独占"的区分。所有60个公式都从美食内容生态中自然涌现。

## 支柱三：正文干货（10个结构公式）

### 公式1：漏斗四段法
```
痛点陈述(2-3句) → 场景代入(2-3句) → 解决方案(3-5句) → 行动指令(1-2句)
```
- **案例（万能凉拌汁）**:
  痛点：「夏天一到就想吃凉拌菜，但每次调的汁都不对味——要么太酸、要么太咸、要么淡出个鸟来。」
  场景：「上周朋友来家里吃饭，我做了个凉拌鸡丝。朋友吃了一口问：'这个汁是买的吗？''我自己调的。'她不信。」
  方案：「其实就是一个万能配比：生抽2勺+陈醋1勺+蚝油半勺+糖小半勺+蒜末+小米辣+白芝麻。浇一勺热油滋啦一声，香味直接冲出来。这个配比适合一切凉拌——黄瓜、木耳、鸡丝、皮蛋、豆腐。食材不同调整的只是主料，汁不用变。」
  行动：「我把这个配比写在手机备忘录里了。每次做凉拌直接照着来，10秒调好汁，再也不纠结。图3是这个万能汁做出来的6种凉拌菜，每一盘都是同一个配比。」

### 公式2：AIDA模型
```
Attention(抓注意) → Interest(建兴趣) → Desire(造渴望) → Action(促行动)
```
- **案例（电饭煲叉烧）**:
  Attention：「同事以为我中午点了港式茶餐厅的外卖。」
  Interest：「其实是一块15块钱的梅花肉+电饭煲。最开始是在小红书刷到的方子，心想电饭煲做叉烧能好吃到哪去。但冰箱里正好有块肉，就试了一下——全程只花了5分钟动手，剩下的交给电饭煲。」
  Desire：「腌料：叉烧酱3勺+生抽1勺+老抽半勺+蜂蜜1勺+蒜末。腌至少2小时或者过夜。电饭煲刷一层油，把肉放进去按煮饭键。中间翻一次面。等电饭煲跳了以后打开盖子那一刻——那个色泽、那个香气、那个酱汁咕嘟冒泡的样子。切片之后肉是粉红色的，嫩到出汁。」
  Action：「比外面一份叉烧饭便宜五倍，肉多了三倍。方子在收藏夹里吃灰不如今天就去买块肉试试。」

### 公式3：SCQA结构
```
Situation(情境) → Complication(冲突) → Question(问题) → Answer(答案)
```
- **案例（炒肉嫩的秘诀）**:
  Situation：「我特别爱吃小炒肉、青椒肉丝、鱼香肉丝这类菜，但每次自己做出来的肉都是又干又柴，吃着像橡皮。」
  Complication：「试了各种网上说的方法——加蛋清、加淀粉、加嫩肉粉、加小苏打。有的有点效果但会有一股怪味，有的完全没用。上个月炒了一盘青椒肉丝，肉硬到我朋友以为我在做牛肉干。」
  Question：「为什么饭店的肉丝肉片都嫩到不行？他们不可能每一盘都加嫩肉粉吧？后来请教了一个做厨师的朋友，他说了一句话让我醍醐灌顶。」
  Answer：「他说：'腌肉最重要的不是加了什么，是加的顺序和抓肉的手法。'正确顺序——先加盐和料酒抓出黏性，再加少量水抓到被肉吸收，然后加蛋清抓匀，最后加淀粉封住。每一步都要抓到完全吸收才能加下一步。抓的方向一定要顺着一个方向，不能乱搅。试了一次，炒出来的肉嫩到我差点哭出来。」

### 公式4：步骤拆解法
```
准备工具(列出清单) → 步骤一(带细节) → 步骤二(带细节) → 步骤三(带细节) → 注意事项
```
- **案例（正确蒸蛋）**:
  准备：「鸡蛋2个、温水（蛋液1.5倍）、盐少许、滤网、保鲜膜、蒸锅。蛋和水的比例是1:1.5，水温40度左右——手摸着比体温稍暖。」
  步骤一：「鸡蛋充分打散，打到蛋清蛋黄完全混合、用筷子提起来不拉丝的程度。加盐在水里化开，再把盐水倒入蛋液搅匀——不是直接把盐打进蛋液。」
  步骤二：「最关键的一步——过滤。用滤网过两遍，把蛋液里的絮状物和泡沫滤掉。这一步决定了蒸蛋是嫩滑还是蜂窝状。」
  步骤三：「碗盖上保鲜膜，用牙签扎几个小孔。水开后放入蒸锅转中小火，蒸8分钟关火焖2分钟。不是大火猛蒸——大火会让蛋液沸腾产生气孔。」
  注意：「鸡蛋和水的比例永远不要靠感觉，用半个蛋壳量最方便——2个鸡蛋=6个半蛋壳的水。还有一点：从冰箱拿出来的鸡蛋要回温再蒸，不然蒸出来表面不平。」

### 公式5：清单对比法
```

```
- **案例（厨房工具红黑榜）**:
  标准：「以'使用频率+实用性+性价比'三个维度，盘点这些年我用过的厨房工具。」
  红榜：「①厨房剪刀——比菜刀处理鸡骨、葱花、干辣椒快三倍，30块用三年 ②硅胶刮刀——炒菜盛菜刮锅底一刮到底，不浪费一滴酱汁 ③厨房秤——烘焙必备，中餐也推荐，把'适量'变成可复制的克数 ④料理夹——比筷子好使一百倍，翻面、盛菜、拌沙拉全搞定 ⑤擦丝器——土豆丝胡萝卜丝30秒搞定，刀工不行工具来凑」
  黑榜：「①某网红切菜神器——洗它比切菜还费劲，缝隙里的菜渣洗到崩溃 ②手动榨汁机——使出吃奶的劲就挤出几滴，不如直接买果汁 ③各种造型模具——用一次就吃灰，占地方第一名 ④所谓的'三分钟切片器'——片没切好手指先见血」
  规律：「好用的厨房工具都有一个共同点：结构简单、好清洗、每天都有使用场景。花里胡哨多功能的大部分是智商税。」

### 公式6：亲身经历线
```

```
- **案例（从不做饭到爱上做饭）**:
  「三年前的今天，我的厨房唯一的作用是烧开水和煮泡面。那时候觉得做饭是一件特别浪费时间的事——买菜半小时、备菜半小时、炒菜半小时、吃饭十分钟、洗碗半小时。怎么算都不划算。转折发生在去年——外卖吃坏了肚子，上吐下泻请了三天假。躺在家里的三天只能喝自己熬的白粥——那是我第一次觉得'自己做的饭很干净'。然后买了一本菜谱、一口不粘锅。第一道菜——可乐鸡翅，按菜谱一步步来，做出来竟然能吃。第二道——西红柿炒鸡蛋，做出来和我妈的味道有七分像了。第三道、第四道...三个月后请了朋友来家里吃饭。做了六道菜，朋友吃完说了一句：'你可以开店了。'——我当他在开玩笑。但现在我真的每天都在期待下班回家做饭。以前觉得是负担，现在觉得是最好的放松。洗菜切菜的时候什么都不用想——这是另一种形式的冥想。从外卖重度用户到自己带饭上班，这个转变不是为了省钱、不是为了减肥。是为了每一天都有一顿饭是自己为自己做的。」

### 公式7：万能公式型
```
一个万能配方/配比，适应N种{食材/品类}
```
- **案例（万能凉拌汁配比）**:
  「记住了这个配比,你就能拌一切——生抽2勺+陈醋1勺+蚝油半勺+糖小半勺+蒜末+小米辣+白芝麻+热油。这个配比的力量在于：拌黄瓜清爽、拌木耳鲜香、拌鸡丝入味、拌皮蛋解腻、拌金针菇直接封神。不用每次重新想放什么调料，这个基础汁提前调好一瓶放冰箱，吃的时候舀两勺。」
- **案例（万能腌肉公式）**:
  「不管你是什么肉——猪肉鸡肉牛肉羊肉——腌肉都遵循这个顺序：盐+料酒→抓出黏性→少量水→抓到吸收→蛋清→抓匀→淀粉→封住。学会了这个顺序，从此告别又柴又干。不同的肉只是调料微调：牛肉加点小苏打、羊肉多放点孜然料酒、猪肉来点甜面酱。」
- **案例（万能炒菜顺序）**:
  「炒任何菜记住这个下锅顺序就不慌：锅烧热→油烧热→爆香（葱姜蒜辣椒）→荤菜（肉丝肉片）→断生盛出→重新放油→素菜（难熟的先下、易熟的后下）→荤菜回锅→调味→出锅。这个顺序能让肉不老、菜不黄、每一样都正好熟。」
- **案例（万能焖饭公式）**:
  「米+肉+菜+酱汁=无限种焖饭。米洗净加水正常量→铺上切好的肉类（腊肠、鸡腿、排骨都可以）→再铺菜（土豆胡萝卜香菇玉米）→淋上酱汁（生抽2+老抽1+蚝油1+香油少许）→按煮饭键。搞定。换个肉换个菜就是一种新焖饭。」
- **案例（万能蘸料公式）**:
  「火锅蘸料、饺子蘸料、白切肉蘸料、水煮菜蘸料——其实都是同一个基础变化出来的：蒜末+葱花+生抽+醋+香油+辣椒油。想吃麻酱版加芝麻酱，想吃蒜泥版多压一瓣蒜，想吃川味版加花椒油和花生碎。一个公式走天下。」

### 公式8：探店打分型
```
环境/口味/价格/服务 四维打分 → 各项详解 → 总结推荐
```
- **案例（一家面馆测评）**:
  维度：「这次去的是朋友按头安利的一家藏在巷子里的面馆——据说开了15年。用4个维度打分，满分5星。」
  环境★★★：「就是那种苍蝇馆子——门口一口大锅煮面，里面五六张桌子。椅子是塑料凳，桌上辣椒油瓶子有点油。但这就是烟火气，不扣分。」
  口味★★★★★：「点了招牌肥肠面。面是手擀的，粗细不一样但每一根都劲道。肥肠处理得非常干净没有异味，卤得软烂入味不腻。汤底是骨头汤熬的，鲜到我把汤喝完了。辣椒油是他们自己做的——香不是辣，加一勺就升华。」
  价格★★★★★：「肥肠面大碗18块。这个量这个味道，性价比炸裂。在商场里没有40块吃不到同级别。」
  服务★★★★：「阿姨端面的时候会说'小心烫'。没别的话了。但吃完以后老板会问'今天味道怎么样'——就这一句话就够了。」
  总结：「会反复去的店。适合一个人来吃，不用纠结点什么。唯一的缺点是没有外卖——老板说'面坨了就不好吃了'，这句话本身就值5星。」

### 公式9：对比盲测型
```
同一道菜 × {不同价位/做法/品牌} 对比 → 各项表现 → 意外发现
```
- **案例（不同价位牛排对比）**:
  对比对象：「买了三种价位的牛排做盲测——超市18块的调理牛排、65块的草饲原切、150块的谷饲安格斯。同样的锅、同样的火候、同一个朋友打分。」
  18块调理牛排：「煎出来样子不错但吃起来——完全没有牛肉味，口感像嫩肉粉调出来的。看了配料表：卡拉胶、三聚磷酸钠...不是纯肉。」
  65块草饲原切：「有牛肉味了，但比较瘦。煎的时候需要更注意火候，一不小心就老了。适合喜欢有嚼劲的人，性价比最高。」
  150块谷饲安格斯：「煎的时候就能闻到那股奶香味。切开是均匀的粉红色，咬下去汁水直接出来。确实好吃，但也不是天天吃得起。」
  意外发现：「65块的草饲如果煎之前回温半小时+煎完醒肉5分钟，和150块的差距缩小了至少40%。所以最终结论：日常吃选原切，关键在手法。」
- **案例（不同锅做同一道菜）**:
  「同一份红烧肉配方，分别用铁锅、不粘锅、砂锅、电饭煲做——结果是砂锅赢了。铁锅火力猛但容易烧干、不粘锅方便但收汁效果差、电饭煲省心但缺少那层焦香。砂锅做出来的红烧肉肥肉晶莹剔透瘦肉一夹就断。差别太明显了。」

### 公式10：备菜体系型
```
时间段 → 做什么准备 → 怎么存储 → 每天怎么用
```
- **案例（周末2小时搞定一周备菜）**:
  时间段：「周日下午2点到4点，固定是我的备菜时间。放个播客两个小时刚好。」
  做什么：「第一件事：列菜单。花10分钟规划下周5天的菜——周一炒肉丝、周二红烧鸡块、周三炒牛肉、周四炖排骨、周五清冰箱乱炖。原则是荤菜按'猪肉→鸡肉→牛肉→猪肉'的顺序轮换，这样不腻。」
  怎么处理：「买回来的肉先分成每顿的份量——肉丝切好腌好、鸡块剁好焯水、牛肉切片腌好、排骨焯水分好。每份装一个保鲜袋或密封盒，贴上标签写上日期和菜名。」
  怎么存：「腌好的肉放保鲜层——2天内吃的。焯好水的排骨和鸡块放冷冻——3天后吃的。蔬菜只洗不切——绿叶菜用厨房纸包好放保鲜袋，根茎类直接放通风处。」
  怎么用：「周一早上从冰箱拿一袋'周一肉丝'装进便当袋。到家直接下锅——菜已经洗好了、肉已经腌好了。从进门到吃上饭，15分钟。这才是真正的备菜自由。」

### 公式8：翻车对比型

> 以下10个公式全部提炼自美食行业300篇爆款笔记正文的真实排版模式。非通用排版教科书——每个公式都是美食内容生态中自然涌现的独特排版节奏。

### 公式1：食材清单式排版

```
- **为什么美食爆款常用**：食材清单是美食笔记区别于任何其他行业的核心排版元素。爆款笔记的食材清单不只是"列出来"，而是用勾选框制造"采购 checklist"的代入感——读者会下意识在心里打勾，参与感拉满。分区（主料/辅料/调料）让清单有层次而非扁平罗列。

- **案例（红烧肉食材清单）**:

  🧄 辅料

  🌿 香料
  ☐ 八角 2颗
  ☐ 桂皮 1小块（手指大小）

  🧂 调料

  ☐ 生抽 3勺
  ☐ 老抽 1勺（只上色不调味）
  ☐ 料酒 2勺
  ☐ 盐 少许（最后放）

### 公式2：步骤编号+时间戳排版
```
①→②→③每步标注耗时，读者一眼估算总时间；步骤之间空行，时间紧跟在步骤号后面括号标注
```
- **为什么美食爆款常用**：美食读者的核心焦虑是"这要花多少时间"。每一步标注耗时让他们可以判断"我下班后能不能做"、"周末值不值得花这个时间"。这是美食笔记特有的"时间决策辅助"排版。爆款笔记还会在最后加一个"⏱️ 总计"，帮读者做最终判断。

- **案例（电饭煲叉烧全流程）**:
  ```
  全程动手5分钟，剩下的交给电饭煲👇

  ① 腌肉（2分钟，需提前2小时或隔夜）
  梅花肉 400g 洗净擦干，叉烧酱 3勺+生抽 1勺+老抽半勺+蜂蜜 1勺+蒜末，抹匀按摩1分钟。保鲜膜封好放冰箱。

  ② 入锅（1分钟）
  电饭煲内胆刷薄薄一层油，把腌好的肉放进去，腌料汁也倒进去。按煮饭键。

  ③ 翻面（30秒）
  煮饭键跳到保温后，打开盖子把肉翻个面。这时候已经能闻到叉烧味了——忍住别偷吃。再按一次煮饭键。

  ④ 收汁（1分钟，可选）
  第二次跳保温后，如果汁还比较多，倒进小锅里大火收30秒到浓稠，淋在切好的叉烧上。

  ⑤ 切片装盘（30秒）
  斜着切薄片，摆盘。锅里的汁淋上去。搞定。

  ⏱️ 总耗时：动手5分钟 + 腌制2小时 + 电饭煲40分钟（你在追剧）
  💰 成本：梅花肉 15块 + 酱料约 3块 = 18块（外面一份叉烧饭都不止）
  ```

### 公式4：小贴士气泡嵌入法
```
每个主步骤下方，用💡缩进一行嵌入1-2条小贴士，字号感受上比正文小、不打断主流程、但随时可查阅
```
- **为什么美食爆款常用**：做菜流程中总有一些"不说会翻车、说了又打断节奏"的细节。爆款笔记用小贴士气泡把这些细节"折叠"在步骤下方——熟练的人跳过不读，新手停下来看一眼。这种双层信息结构是美食笔记特有的：主层给会做的人，气泡层给第一次做的人。

- **案例（完美蒸蛋步骤+小贴士）**:
  ```
  蒸蛋看起来简单，翻车率极高——蜂窝状、表面不平、底部有硬块。按这个流程来，一次成功👇

  ① 打蛋
  鸡蛋 2个打入碗中，用筷子充分打散。打到蛋清蛋黄完全混合、用筷子提起来不拉丝的程度。

  💡 冷藏蛋先回温 20 分钟再打，不然蒸出来表面会不平。

  ② 加水
  加入蛋液 1.5 倍的温水（约 40℃，手摸着比体温稍暖）。水中加少许盐化开，再把盐水倒入蛋液搅匀。

  💡 为什么是 1.5 倍不是 2 倍？1.5 倍蒸出来嫩滑有弹性，2 倍会太水像蛋花汤。用半个蛋壳量最方便：2 个鸡蛋 = 6 个半蛋壳的水。
  💡 水太冷蒸出来有腥味，水太热蛋液直接烫熟。40℃ 刚好——伸手不烫。

  ③ 过滤
  用滤网过滤蛋液 2 遍。把絮状物和气泡滤掉。这一步决定了蒸蛋是嫩滑还是蜂窝状。

  💡 没有滤网？用勺子把表面的泡沫撇掉也行，但不如过滤彻底。

  ④ 封膜
  碗盖上保鲜膜，用牙签扎 5-6 个小孔透气。水开后入蒸锅，转中小火蒸 8 分钟，关火焖 2 分钟。

  💡 大火蒸 = 100% 蜂窝。中小火让蛋液慢慢凝固，表面才能光滑如镜。
  💡 保鲜膜不能完全密封——不扎孔的话蒸汽压力会让保鲜膜塌下去贴在蛋面上。

  打开锅盖那一刻——duang duang 的、表面能照镜子。
  ```

### 公式8：锅具+火候+时间三要素链排版
```
每个步骤用 🍳工具 → 🔥火候 → ⏱️时间 三要素开头的链式结构，美食读者可以像查操作手册一样快速定位
```
- **为什么美食爆款常用**：这是美食内容特有的"操作手册式"排版。做菜最怕的不是不知道做什么，是不知道"用什么锅、开多大火、等多久"。三要素链把每个步骤的操作参数前置——读者不用读完整段就能提取关键信息。这种格式高度结构化，适合教程型美食笔记。

- **案例（红烧排骨完整流程）**:
  ```
  今日晚餐：红烧排骨。从焯水到出锅，每一步都精确到分钟👇

  🍳炒锅 🔥大火 ⏱️5分钟
  冷水+排骨下锅，加姜片+料酒。水开后煮到浮沫出来，捞出排骨用温水冲干净。
  → 冷水下锅血水才出得来，热水下锅表面锁住腥味出不来。

  🍳炒锅 🔥小火 ⏱️3分钟
  锅里放油+冰糖，小火慢炒。冰糖融化→变黄→变琥珀色→立刻下排骨。
  → 全程小火+不停搅拌。颜色一到位马上倒排骨，多一秒就苦。

  🍳炒锅 🔥中火 ⏱️3分钟
  排骨翻炒裹上糖色，加葱姜蒜+八角桂皮香叶炒出香味。
  → 这个阶段把排骨表面煸到微微焦黄，口感会更有层次。

  🍳炒锅→砂锅 🔥小火 ⏱️40分钟
  加开水没过排骨，生抽+老抽+料酒。烧开后转小火盖盖焖。
  → 换砂锅炖比炒锅更香（保温好、受热均匀），没有砂锅就用炒锅也行。

  🍳砂锅 🔥大火 ⏱️5分钟
  开盖大火收汁，看到汤汁浓稠冒大泡、排骨表面亮晶晶就可以关火了。
  → 收汁阶段人别离开，从浓稠到糊锅只有 30 秒。

  ⏱️ 全程 56 分钟，但真正需要操作的只有前 16 分钟。剩下 40 分钟在焖——你可以去洗澡、追剧、回消息。
  ```

```

- **案例（炒青菜的正确流程）**:
  ```
  炒青菜看起来最简单，翻车率最高——发黄、出水、不脆。
  今天这个流程配着图看，每一步长什么样都拍下来了👇

  图2 ← 锅烧到冒烟的状态
  锅里有微微青烟往上飘。滴一滴水进去，水珠在锅里滚来滚去不蒸发——这个温度就够了。
  很多人青菜炒黄了就是因为锅不够热就倒油。

  图3 ← 蒜末爆香到金黄的瞬间
  油热后下蒜末，炒到边缘微焦、蒜香冲出来——大概 15 秒。这时候马上倒青菜，多一秒蒜就苦了。

  图4 ← 青菜下锅前 vs 下锅后 30 秒
  青菜下锅的瞬间会有"滋啦"一声巨响——这是对的。30秒后叶子开始变软但茎还是脆的——这时候翻第一次。

  图5 ← 调味的最佳时机
  青菜体积缩小到原来一半、颜色变成翠绿色的时候——沿着锅边淋入生抽+盐。锅边的热度会让酱油先焦化再裹在菜上，比直接淋在菜上香 10 倍。

  图6 ← 出锅的最终状态
  全程大火、从下锅到出锅不超过 2 分钟。青菜翠绿、茎脆、叶嫩、盘底没有一滩水——这就是对的。

  最后一张图 ← 翻车版 vs 成功版对比
  左边：发黄、软趴趴、盘底一滩水（锅不够热+炒太久）
  右边：翠绿、爽脆、干爽（热锅热油+全程大火+2分钟出锅）

  差距就是一口热锅 + 2 分钟。
  ```
