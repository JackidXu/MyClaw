# 制造业图文笔记生成规则

> 基于300篇小红书/公众号制造业类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 制造业 = 工厂管理、生产流程优化、质量管理、供应链管理、精益生产、工业4.0/智能制造、设备维护（TPM）、安全生产、制造业创业/转型、toB销售获客。

## 概述：制造业图文笔记通用公式

```
封面标题(数字+痛点+结果+岗位身份) → 开头钩子(前3行定生死) → 正文干货(每段能落地的实操)
         ↓                          ↓                          ↓
       配图逻辑(图是车间现场的真相)  →  排版呼吸感(结构化比填满重要)  →  结尾CTA(给读者一个行动理由)
```

## 支柱二：开头钩子（10个公式）


### 公式1：成本账单开场型
```
{时间段}的{成本科目}出来了：{金额}。{利润/对比}只有{金额}。
```
- **案例**: 「上个月电费出来了：18万。毛利润21万，扣掉人工房租，到手3万。这台机还开不开？」
- **案例**: 「这个月工资发了47万，货款收了52万。中间5万差价就是我做了一个月的全部。」
- **案例**: 「去年的废品数据拉出来了：总损失146万。品质部6个人全年工资加起来才72万。」
- **案例**: 「这张单子报价87万，材料成本43万，看起来赚不少？往下算：模具摊6万、人工11万、包材运输5万、13个点的税、3个月的账期贴息——最后剩了多少？」
- **案例**: 「上个月的刀具费用出来了：12万。厂里32台CNC，平均每台每个月吃3750块钱的刀。」
- **案例**: 「一周停机损失统计：等料停了4次、换模停了3次、设备故障停了2次。合起来是18个小时，少出了多少货你算一下。」
- **案例**: 「车间的压缩空气年度账单我拉出来了：漏气损失7万度电，够注塑机开两个月。」

### 公式2：事故现场还原型
```
那天{具体时间}，{设备/工序}，{发生了什么}。{结果/后果}。
```
- **案例**: 「那天下午2点17分，冲床没有完全回程，新来的操作工把手伸进了模区。等安全栓插上的时候，来不及了。」
- **案例**: 「2019年6月，注塑机料管温度失控，料在里面碳化了两个小时没人发现。等拆开的时候，螺杆粘死了，更换螺杆+料管花了18万。」
- **案例**: 「那天夜班，焊工赶着下班，焊完没有做保温缓冷。第二天早上来，三条焊缝全裂了。不是焊工的问题，是夜班管理制度的问题。」
- **案例**: 「检测中心的硬度计坏了三个月没人校准。这三个月出了多少货？全部追回。客户是上市公司，永久拉黑。」
- **案例**: 「叉车在仓库门口转弯，一托盘电子元器件倒了。价值23万，全部报废。原因是那条通道的转弯半径早就不够了，但一直没人提。」
- **案例**: 「烤箱总闸跳了夜班自己合上去，没发现是其中一路加热管短路。第二天整个烤箱烧了，里面1200件半成品全毁。」
- **案例**: 「那个IPQC在巡检单上全部打勾，实际上根本没量。第4天客户投诉尺寸偏大0.3mm，追溯发现这一批5000件都偏了——这个IPQC三个月前才转岗，培训只有两天。」

### 公式3：一句破局总结型
```
{困扰已久的问题}，最后被{一个简单方案}治了。一句话说就是：{核心逻辑}。
```
- **案例**: 「招不到人这个死局，最后被一套快换工装治了。一句话说就是：把换模时间从40分钟压到8分钟，产能直接上去了，工人不用加班了，自然有人来。」
- **案例**: 「交期总是超，客户天天催。最后被一块白板治了。一句话说就是：把工单进度可视化，所有人看得到谁在卡脖子。」
- **案例**: 「仓库账实不符，年年盘年年烂。最后被一个规则治了：没有单据不准移动任何物料，一张都不行。」
- **案例**: 「品质投诉居高不下，开了无数次专题会都没用。最后被一张红牌卡治了：任何工位发现上道不良品，立刻停工，上道工序负责人过来处理完才能复线——一个月投诉下降了70%。」
- **案例**: 「模具经常爆，修模工天天骂设计。最后被一个清单治了：试模检查16项，逐项打勾签字才准量产。」
- **案例**: 「产线经常等料、等模具、等设备，整个车间有一半时间在'等'。最后被一个调度会治了：每天下午4点半，PMC、模具、设备、生产四方碰头15分钟，明天的问题今天解决。」

### 公式4：深夜车间瞬间型
```
{深夜时间}，{车间状态}。我{做的事情/心里的念头}。
```
- **案例**: 「凌晨1点，最后一台注塑机停了，不是干完了，是料管堵了。我一个人坐在车间门口，在想这条路还要不要走下去。」
- **案例**: 「晚上11点，客户通知明天早上8点到厂验货。这批货还有30%没检完。车间灯亮了一整夜，QC三个小姑娘没合眼。」
- **案例**: 「凌晨3点半，喷漆线终于调好了。这个色差，调了整整16个小时。客户只说了两个字：可以。」
- **案例**: 「夜里12点，模具车间只有我一个人在抛光。明天试模，这套模具花了两个月，能不能一次成功，就看这最后两个小时了。」
- **案例**: 「凌晨4点，冲床终于停了。这一天干了3万冲次。我数着冲床的节奏声，像心跳。哪天这个声音停了，说明真的干不下去了。」
- **案例**: 「半夜2点，我在守炉。热处理这批Cr12MoV不能出错，出错一套模具全废，客户等着装机。」
- **案例**: 「深夜11点，调试新设备。机械手抓取位置差了0.5mm，夹不住。工程师说'明天再调'。我说'调好了再走，明天有明天的活'。」

### 公式5：数据对比刺痛型
```
同行/行业平均{指标}是{数值}，我的/你们的{指标}是{数值}。问题不在{表面原因}，在{真问题}。
```

## 支柱三：正文干货（10个结构公式）


### 公式1：问题排查五步法
```
现象描述(2-3句) → 根因分析(逐层追问"为什么") → 对策制定(短期+长期) → 效果验证(量化数据) → 标准化(横展推广)
```
- **案例（设备频繁停机）**:
  现象：「冲压车间A线连续一周每天停机2次以上，每次停机15-30分钟。产线日产量从800件掉到600件。」
  根因：「第一个为什么：为什么停机？→ 模具卡料。第二个为什么：为什么卡料？→ 送料辊表面磨损。第三个为什么：为什么没提前发现？→ 点检表上没有送料辊的检查项。第四个为什么：为什么没有？→ 点检表是三年前编的，后来加的送料辊没更新进去。第五个为什么：为什么不更新？→ 设备保养标准没有定期评审机制。」
  对策：「短期：当天更换送料辊，恢复生产。长期：建立设备保养标准季度评审制度，所有新增或改造设备自动触发点检表更新。」
  效果：「整改后三个月，该冲压线零卡料停机。日产量稳定在820件以上。」
  标准化：「把这个五步分析的流程做成一页A3报告模板，所有设备停机超过30分钟必须填写，贴在设备旁边。」

### 公式2：改善案例复盘体
```
背景(改善前状态+数据) → 触发点(为什么要做) → 改善过程(做了什么) → 改善结果(量化对比) → 经验总结(可复制的点)
```
- **案例（注塑车间快速换模）**:
  背景：「注塑车间有8台机，平均换模时间110分钟。每天换模3-4次，每天浪费在换模上的时间超过5个小时。」
  触发点：「接到一个大客户紧急订单——50种不同规格的产品，每种数量都不大。按现有换模速度，交期至少要延后两周。客户说：延一天罚千分之三。」
  改善过程：「第一步：把换模全过程录下来，拆成38个动作。第二步：发现12个动作是'找工具''等行车''来回走路'——全是浪费。第三步：把内部作业(机器必须停)改成外部作业(机器运行中就能做)——提前备好模具和工具，模具预加热。第四步：做了模具快速定位销和气管快接头。」
  改善结果：「换模时间从110分钟降到22分钟。一天多出将近4个生产小时。这批订单提前三天交了货。」
  经验总结：「快速换模不需要花大钱。80%的改善靠的是分析视频+区分内外部作业。这个方法直接复制到其它产线，全厂平均换模时间降到了30分钟以内。」

### 公式3：数据看板拆解体
```
指标选择(为什么选这个指标) → 数据采集(怎么取数) → 可视化方式(怎么展示) → 改善机制(看到数据后做什么) → 迭代优化(指标怎么调整)
```
- **案例（车间日经营看板）**:
  指标选择：「选了5个指标：产量达成率、一次合格率、设备开动率、单位产值能耗、工时利用率。这5个指标加在一起，基本能看出来今天是赚了还是亏了。」
  数据采集：「产量和合格率从MES自动抓取。设备开动率从机台PLC取信号。能耗从电表自动采集。工时利用率从考勤系统+工单报工比对。」
  可视化：「车间入口放一块75寸屏幕。每2小时刷新一次。绿灯=达标，黄灯=偏差10%以内，红灯=偏差超过10%。」
  改善机制：「红灯一亮，班组长10分钟内到场。连续2次红灯，车间主任介入。每天下班前15分钟，所有班组在屏幕前复盘今天的红黄灯。」
  迭代优化：「第一个月只盯产量和合格率。第二个月加入设备开动率。第三个月加入能耗。第四个月加入工时利用率。不是一上来就5个指标一起上——那样没人看得懂。」

### 公式4：步骤拆解法
```
准备条件(前置要求清单) → 步骤一(带细节+注意事项) → 步骤二(带细节+注意事项) → 步骤三(带细节+注意事项) → 验收标准
```
- **案例（设备自主保全七步法）**:
  准备：「你需要：一块干净的抹布、手电筒、点检锤、润滑油、点检表、手机(拍照用)。先把这个工位的设备停机上锁挂牌。」
  步骤一(清扫即点检)：「不是打扫卫生。是拿着抹布一寸一寸地擦设备——擦的过程中用手摸、用眼看、用耳朵听。有没有松动？有没有异响？有没有漏油？发现任何异常，在那个位置贴一个红色标签。」
  步骤二(发生源对策)：「清扫完收集所有红色标签。分类：漏油/松动/异响/磨损/脏污。每个标签对应一个改善——漏油的换密封圈，松动的紧固，磨损的评估剩余寿命。」
  步骤三(制定暂定基准)：「根据这次发现的问题，把清扫、润滑、紧固的频率写下来。每天擦什么部位？每周给哪里加油？先写下来，这就是你的暂定基准。」
  验收标准：「做完一次自主保全之后，设备表面无油污、无积尘、螺丝无松动、润滑部位有油。最重要的是——操作工能说出自己这台设备今天哪里正常、哪里不正常。」

### 公式5：红黑榜对比法
```
维度说明(评价标准) → 红榜(推荐清单+每项一句话理由) → 黑榜(不推荐清单+避开原因) → 选型规律总结
```
- **案例（MES系统选型红黑榜——中小制造企业版）**:
  维度：「以'实施周期+功能匹配度+易用性+年费'四个维度，调研了8款面向中小工厂的MES系统。」
  红榜：「①黑湖智造——年费制轻量化MES，中小编织/服装/电子组装厂推荐，实施周期2-4周，无需自建服务器。②简道云——零代码搭MES，适合有IE或懂流程的人的工厂自己搭建，年费几千块起步。③羚数智能——聚焦离散制造，报工+质检模块做得最细。④新核云——汽配和机加工行业最匹配，CNC设备联网能力最强。」
  黑榜：「①某传统ERP厂商捆绑销售的MES——功能大而全但实施半年起步，适合大型集团，中小企业撑不住。②某免费开源MES——没有中文支持和本地服务，适合有IT团队的工厂，否则就是个坑。③某外资品牌——单许可证费用就够买三套国产MES，功能确实强但80%的中小工厂用不到。④某项目型定制MES——开发周期6个月+，需求一变全重来，不适合业务还在变化的工厂。」
  规律：「年营收5000万以下的工厂，不要买大而全的软件。选一个能管好报工+质检+设备三个模块的就够了。预算控制在年营收的0.3%-0.5%。」

### 公式6：亲身经历线
```
时间线开头 → 中间过程(失败→尝试→转折) → 高潮结果 → 感悟收尾
```
- **案例（推行TPM两年）**:
  「2019年3月，我们厂最大的那台冲床主轴断了。停机17天，直接损失180万，间接损失没法算。老板把我叫到办公室，说：'你是设备主管，这个事情你得给我一个交代，也得给你自己一个交代。'
  那之后我才开始真正学什么叫设备管理。以前我的工作模式就是等电话——哪里坏了去哪里修。修完就完了，从来不想为什么坏。那台冲床如果提前三个月检查轴承间隙，轴根本不会断。
  2019年6月，我硬着头皮在全厂推TPM。第一个月就快放弃了——操作工觉得打扫卫生是保洁的活，班组长觉得保养是维修工的事。老板也不支持，说'机器没坏你停它干嘛？'
  转折发生在第三个月。一台注塑机按新点检表发现液压油里有金属粉末，提前换了滤芯和油，避免了一次拉缸。这一次避免的损失大概在15万左右。老板知道之后态度变了，说'这个保养的事情你继续搞'。
  到2020年底，我们的设备综合效率从51%拉到了78%。意外停机从每月平均12次降到2次以内。维修费用同比下降了40%。
  现在回头看，TPM推成功就靠一点：让老板看到了一次'因为做了保养而避免的故障'。这个事实比一百份PPT都有说服力。」

### 公式7：原理+方法型
```
先说为什么(1-2句制造业原理) → 再说怎么办(2-3步落地方法) → 再说要注意什么(制造业特有坑点) → 预期效果(量化)
```
- **案例（为什么标准工时不能靠"拍脑袋"）**:
  原理：「标准工时是工厂管理的底层数据。排产用它算产能、财务用它算成本、HR用它算绩效。如果标准工时是错的，这三个系统全在瞎算。」
  怎么办：「第一步——用秒表实测。不是测一次，是连续测20次取平均值。第二步——加上评比系数。同一个动作，熟练工和新手差别可能到30%，要用评比系数修正。第三步——加上宽放率。生理宽放(上厕所喝水)+疲劳宽放(体力消耗)+作业宽放(换刀具、清废料)。一般宽放率在10-15%。」
  注意：「①绝对不要拿实测工时直接当标准工时——那等于不给宽放、不给效率提升空间。②工艺改进了要立刻重新测——很多工厂的标准工时是五年前的，工艺早就变了。③标准工时不是用来逼迫工人的工具——是用来发现异常的工具。工人今天的实作工时远超标准工时，说明要么标准错了，要么今天出问题了。」
  预期：「正确制定的标准工时，80%的操作工在正常速度下都能稳定达到。差距超过20%就说明数据有问题，不是人有问题。」

### 公式8：评测对比型
```
评测背景+维度说明 → 横向对比(表格/分项打分) → 单项深入解读 → 最终选型建议
```
- **案例（4款常用ERP系统制造模块横评）**:
  背景：「帮5家年营收2000万-8000万的中小制造企业选ERP，核心需求：进销存+MRP+BOM管理+成本核算。实测周期6个月。」
  维度：「MRP逻辑准确性/BOM管理灵活性/成本核算精细度/实施难度/年费。」
  对比：「金蝶云星空——MRP 4.5/BOM 4/成本 4.5/实施 3.5/年费中等。用友U8+——MRP 4/BOM 3.5/成本 4/实施 3/年费中等偏高。鼎捷T100——MRP 5/BOM 4.5/成本 4.5/实施 3/年费较高。Odoo(开源)——MRP 3.5/BOM 4/成本 3/实施 2/年费低。」
  深入解读：「如果你的产品结构复杂(BOM超过5层)，MRP逻辑最重要——鼎捷T100在制造业MRP方面最成熟。如果你需要灵活自定义BOM和工艺路线——Odoo开源的优势是可以自己改。如果你最关心财务+成本核算——金蝶和用友在财务端的积累更深厚。如果你的IT团队几乎为零——不要碰开源，选有本地实施团队的。」
  建议：「2000-5000万营收的工厂推荐金蝶云星空旗舰版(制造业包)，实施+首年费用控制在15-25万。5000万-1亿推荐鼎捷T100或定制化方案。」

### 公式9：检查清单型
```
使用场景(什么时候用) → 检查项清单(逐条列出) → 每项检查方法和标准 → 异常处理方式 → 版本管理
```
- **案例（客户验厂前自查清单）**:
  场景：「大客户通知一周后验厂。QA经理连夜准备——这份清单帮你把最容易出问题的15个点提前过一遍。」
  清单：「①消防通道——走一遍，不能有任何障碍物。灭火器指针在绿色区域，检查日期在有效期内。②车间地面——有没有油污？有没有绊倒危险？地标线是否清晰？③物料标识——抽10个物料，看标识卡与实物是否一致。不一致=重大不符合。④量检具校准——随机抽3把卡尺查校准标签，过期=直接开不符合。⑤生产记录——近一周的日报表和首件检验记录必须完整可追溯。⑥化学品管理——二次容器是否到位？MSDS有没有放在化学品旁边？⑦员工考勤——随机抽查5名员工的工时记录和工资单是否匹配。⑧不良品区——是否明确标识？不良品和良品是否有物理隔离？⑨设备点检——近一个月的设备点检表是否有空白项？空白=没做=不符合。⑩员工培训记录——新员工的三级安全教育记录必须完整。⑪5S——重点是角落和看不到的地方。⑫洗手间——审核员一定会去。⑬食堂——食品留样和健康证。⑭急救箱——药品在保质期。⑮文档管理——程序文件和现场记录一致。不一致说明体系未落地。」
  异常处理：「发现一条处理一条。来不及处理的列入整改计划，审核时主动出示——审核员更看重你发现问题并计划整改的态度。」
  版本管理：「每次验厂后更新这份清单——把这次新发现的问题加进去。」

### 公式10：工具/模板推荐型
```
情境铺垫(用这个工具解决什么问题) → 工具清单(每个配一句话推荐理由+适用场景) → 使用方法 → 哪里获取
```
- **案例（车间日常管理必备的6个Excel模板）**:
  铺垫：「管车间每天面对一堆杂事——产量、质量、设备、人员、物料。这6个Excel模板是我用了三年迭代出来的，每天花15分钟填完，整个车间的运营状态一清二楚。」
  清单：「①《生产日报表》——每小时填一次产量+不良数，自动算达成率和不良率。适用所有生产车间。②《设备点检异常追踪表》——所有点检发现的异常集中登记，闭环追踪。设备主管必备。③《交接班记录表》——不是流水账，是结构化模板：本班产量/异常/待办/注意事项。④《员工多能工技能矩阵》——横轴是工序，纵轴是员工名字，颜色代表熟练度。排班和培训都用得上。⑤《快速换模检查清单》——换模前/中/后的动作拆成检查项，做完一项打勾。⑥《问题解决A3报告》——一张A3纸讲清楚一个问题：现象→根因→对策→验证→标准化。」
  使用：「每天早上8:30前填完日报表。每班交接时填交接记录表。每周五更新技能矩阵和异常追踪表。A3报告只在发生重大异常时用，一个月最多做3-4张。」
  获取：「模板链接在评论区置顶，直接下载改一下工段名称就能用。」

### 公式1：车间实拍对比图
```

```
- **案例**: 左右分屏——左边工位周围堆满在制品、工具散乱，右边工位整洁、工具上墙、地面标线清晰。标题大字：「同一个工位，两周的变化」。右下角标注「换模时间：110min→22min」

- **案例**: 员工休息区——左边脏乱差没人愿意去，右边干净整洁有绿植有饮水机

```
改善前状态 → 改善后状态，用箭头连接 + 标注改善措施+ 量化效果
```

## 支柱五：排版呼吸感（10个公式）

### 公式1：流程拆解体
```
按工艺流程/生产工序一步步拆解，每步一个关键点+落地方法
```
- **案例**:
  ```
  我们工厂做了三年的精益，最后发现真正有效的就这四个步骤。按顺序来，跳过任何一步都会反弹。

  ❶ 第一步：稳定化
  先把产线稳定下来。每天同一时间开工、标准作业、不插单不乱改。这一步听起来最简单，90%的工厂做不到——因为老板的电话一来什么都乱了。

  ❷ 第二步：标准化
  把稳定的操作写下来。SOP不是写给审核员看的——是写给下一个接手的人看的。写标准的人必须是一线操作工，文控只负责格式。

  ❸ 第三步：可视化
  让异常能被看见。地上画线、机台上贴标签、看板上亮红灯。一个外人走进车间，不需要问任何人就能看到哪里正常哪里不正常。

  ❹ 第四步：持续改善
  前三个步骤做到位了，改善才有意义。否则你今天改了明天又变回去。改善是一个动作重复一万次，不是搞一次运动。
  ```

### 公式3：改善案例复盘体
```
问题→原因→对策→效果→标准化，用这个固定结构复盘任何改善案例
```
- **案例**:
  ```
  【改善案例】装配线U型布局改造

  🔴 问题
  装配线直线型布局，长25米。产品从一头做到另一头，最后一个工位的工人每天要走2万步取料。日产量800台，瓶颈工位CT比Takt Time长了18秒。

  🟡 原因分析
  直线布局导致：①物料配送距离太长 ②工位间在制品堆积 ③瓶颈工位前后没有缓冲 ④工人互相看不到协作困难

  🟢 对策
  改为U型布局：入口和出口在同一端，物流路径缩短60%。瓶颈工位拆分到U型两端，各只做一半工作。增加线边物料超市，水蜘蛛定时补料。

  🔵 效果
  日产量从800台提升到1350台(↑68%)。在制品从300件降到20件。操作工日均行走步数从20000降到6000。

  ⚪ 标准化
  U型线布局标准形成《装配线设计指南》，新建或改造装配线必须按此标准评审。
  ```

### 公式4：检查清单体

  ```
  ☐ 2. 润滑油位：各油窗油位是否在刻度线之间？

  ☐ 4. 安全装置：急停按钮按下→复位→功能正常？
  ☐ 5. 防护罩/门：联锁开关工作正常，打开即停机？
  ```

### 公式5：问题诊断体
```
异常现象→可能根因(2-3个方向)→快速排查步骤→初步对策
```
- **案例**:
  ```
  注塑件出现毛边（飞边）——最全排查路径

  🔍 现象
  产品分型面有薄片状塑料溢出，厚度0.1-0.5mm，集中在模具边缘

  🤔 先排查这三个方向（按概率从高到低）

  方向一：锁模力不足
  → 检查锁模力设定值 vs 实际需要值（这个产品模具投影面积×模腔压力）
  → 如果设备吨位偏小，可能需要换大吨位机台或减少模腔数

  方向二：模具问题
  → 模具分型面有异物或损伤？用铜片清理，检查有无凹陷
  → 模具平行度？用塞尺检查四角间隙是否均匀

  方向三：工艺参数
  → 注射压力/速度是否过高？尝试降低5-10%
  → 料温是否偏高？降低料筒温度5-10℃试试
  → 保压压力是否过大？保压切换位置是否太晚？

  💡 老师傅经验：80%的飞边是因为锁模力不够或模具磨损。先查这两个，别一上来就调参数。
  ```
