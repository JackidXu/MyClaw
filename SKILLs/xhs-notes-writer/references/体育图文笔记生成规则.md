# 体育图文笔记生成规则

> 基于300篇小红书体育/运动类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 体育 = 健身训练、跑步经验、球类运动、瑜伽冥想、运动装备测评、减脂增肌、运动康复、户外运动等。

## 概述：体育图文笔记通用公式

```
封面标题(数字+目标+时间+效果) → 开头钩子(前3句定去留) → 正文干货(每段有练后感)
         ↓                          ↓                          ↓
       配图逻辑(图是见证不是摆拍)  →  排版呼吸感(节奏比密度重要)  →  结尾CTA(给运动搭子一个交代)
```

## 支柱二：开头钩子（10个公式）

### 公式1：跟练拆解法
```
准备条件(场地/器械/难度) → 动作一(带要领) → 动作二(带要领) → 动作三(带要领) → 训练量建议 → 易错点警告
```
- **案例（在家练臀5个动作）**:
  准备：「只需要一张瑜伽垫+一根弹力带。没有弹力带也可以徒手完成。难度：新手友好。」
  动作一：「臀桥——仰卧屈膝脚踩地，臀部发力向上顶。关键：到顶端时停留2秒，感受臀部收紧。不是腰往上顶，是臀往上送。做15个×3组。」
  动作二：「蚌式开合——侧卧膝盖弯曲，弹力带套在大腿中段。上面那条腿的膝盖往上打开，像贝壳打开一样。关键：骨盆不要跟着翻转。每边15个×3组。」
  动作三：「跪姿后蹬——四足跪姿，弹力带套在脚踝。一条腿向后蹬出，大腿与身体平行即可，不需要蹬太高。关键：核心收紧不让腰部塌陷。每边12个×3组。」
  动作四：「相扑深蹲——双脚两倍肩宽外八字站立。下蹲时臀部向后坐，像坐在椅子边缘。关键：膝盖方向与脚尖一致，不要内扣。15个×4组。」
  动作五：「单腿臀桥——比普通臀桥难一倍。一只脚踩地，另一条腿伸直抬起。关键：髋部保持水平不能倾斜。每边8个×3组。」
  训练量：「整套动作做完约25分钟。每周做3次，间隔48小时。第二周开始弹力带换更粗的。」
  易错点：「❌臀部没感觉只有大腿酸 → 髋伸不够，减少幅度先把发力感找到 ❌腰酸 → 核心没收紧、骨盆前倾。全程肚脐往脊椎方向收。」

  | 热量      | 缺口300-500大卡 | 盈余200-400大卡 |

  | 最怕的事   | 低碳导致暴食    | 脏增肌变胖      |

  新手福利期（训练前6-12个月）：可以
  进阶者：很难，建议分周期进行

### 公式7：对话提问体
```

```
- **案例**:
  ```
  关于跑步，新手的10个高频问题🏃

  Q：跑步会让小腿变粗吗？
  A：不会。跑完小腿看起来粗是因为肌肉充血，拉伸+按摩后就会恢复。长期跑步+拉伸小腿会越来越细。

  Q：早上跑还是晚上跑好？
  A：能坚持跑的那个时间最好。不用纠结晨跑还是夜跑，先把跑鞋穿上出门再说。

  Q：跑多久开始燃脂？
  A：从第一步就开始了。不存在「30分钟后才燃脂」这种事。你跑一分钟就消耗一分钟的热量。

  Q：跑步膝盖疼怎么办？
  A：先休息。然后检查：①跑姿（落地时膝盖是否微屈）②跑鞋（缓震是否够）③臀腿力量（臀肌弱膝盖就遭殃）。

  Q：大体重能跑步吗？
  A：BMI>28建议从快走/椭圆机/游泳开始。等体脂降下来再跑步，保护膝盖。

  Q：每天跑还是隔天跑好？
  A：新手隔天跑。身体需要48小时恢复。每周3-4次足够出效果。

  Q：跑步前要吃东西吗？
  A：30分钟内的轻松跑可以空腹。超过30分钟建议吃半根香蕉或一片吐司。

  Q：跑鞋怎么选？
  A：先搞清楚自己的足型（正常/扁平/高足弓），再去选对应的支撑/缓震/稳定型跑鞋。

  Q：跑步减肥效果好吗？
  A：配合饮食控制效果非常好。但只跑步不控制吃——跑1小时的热量一杯奶茶就回来了。

  Q：什么时候能看到效果？
  A：坚持4周你能感觉到变化。坚持8周别人能看出来。坚持一年你会变成另一个人。
  ```

- **案例**: 「下次在健身房看到练得好的人时，不要羡慕不要嫉妒。走上前去说一句'你的动作好标准能不能教我一个'。健身圈最热情的就是愿意分享的人。」
- **案例**: 「今天就把这篇转发给你的那个一直说'想运动但不知道怎么开始'的朋友。有些改变需要别人推一把。」
- **案例**: 「现在放下手机，做一组——随便什么动作。10个深蹲、10个俯卧撑、30秒平板支撑都行。就这一组。做完再回来看。」

### 公式9：情感共鸣收尾型
```
{一句走心的感悟}，{对读者的祝愿或鼓励}
```
- **案例**: 「运动最难的不是最后那一下力竭，是穿上鞋走出门的那一步。你已经看完这篇了，现在去铺开瑜伽垫。加油。」
- **案例**: 「身材从来不是运动最重要的收获。是你发现自己竟然能坚持一件事这么久的那种自爱和自豪。那比你练出的任何线条都珍贵。」
- **案例**: 「有人说健身是孤独的——一个人举铁、一个人跑步。但我想说，每一个在变好的路上独行的人，你们都在同一条路上。不孤单。」
- **案例**: 「你不是在跟别人比。你是在跟昨天那个不想动、但最后还是出了门的自己比。你已经赢了。」
- **案例**: 「健身三年教会我最重要的一件事：成就感不是练出马甲线的那一天，是每一次'不想去但还是去了'的抉择之后。」
- **案例**: 「如果说有一件事我后悔了，就是没有更早开始运动。所以现在看到每一个刚开始运动的人，我都想说：别放弃，以后你会感谢今天咬牙坚持的自己。」
- **案例**: 「运动不是为了取悦谁——是为了让你在照镜子的时候，可以从心底笑出来。那种'我知道我付出了什么'的笑容。」
- **案例**: 「跑步教会我的不是坚持，是耐心。42公里不是一口气跑完的，是一步一步跑完的。人生也是这样。」
- **案例**: 「每一个在运动路上的人，都有一个共同点——他们知道改变不会明天就发生。但一百个、两百个、三百个'明天'加起来，就是另一个自己。」
- **案例**: 「这篇笔记写了四个小时。每一个字都是我在健身房里流的汗水验证过的。希望看到这里的你，能找到属于自己的运动节奏。慢慢来，比较快。」

### 公式10：诚意收尾型
```
{感谢/真实感受} + {希望这篇对你有用} + {一句简洁的力量感结束语}
```
- **案例**: 「写了快三个小时。如果这篇能让哪怕一个人放下手机去铺开瑜伽垫，就值了。谢谢你看到这里。现在去练吧。」
- **案例**: 「这些都是我用汗水、酸痛、偶尔的眼泪试出来的经验。希望你能少走一点弯路。动了就是满分。」
- **案例**: 「每次写完这种长篇干货，就像完成了一次训练——过程累但结束以后很爽。感谢你看到最后。我们训练场上见。」
- **案例**: 「这篇笔记没有推荐任何一个产品。因为最好的装备也替代不了你的行动。现在，穿上你现有的鞋，出门。」
- **案例**: 「几千字的干货总结成一句话：先动起来，再谈其他的。身体比我们想象的更有潜力，去把它挖出来。」
- **案例**: 「我不是什么大神，只是一个比你早练了几年的普通人。这篇分享给你，希望能帮你建立对运动的信心。你可以的。」
- **案例**: 「感谢每一个认真看完的人。你已经比90%的人更有耐心了——你能看完这篇干货，就能完成一次训练。练起来。」
- **案例**: 「写了这么多，最想说的是——健身、跑步、瑜伽、打球，不管是什么运动，找到你喜欢的然后坚持。不是为了瘦，是为了健康地活很久。」
- **案例**: 「每次收到私信说'看了你的笔记开始运动了'，那种开心比我自己练出腹肌还强烈。谢谢你让我知道这些文字是有力量的。」
- **案例**: 「写到结尾突然想起来自己第一天去健身房的样子——站在门口犹豫了五分钟才进去。现在想想，那五分钟就是我整个人生的转折点。希望你今天，也给自己一个转折点。」
