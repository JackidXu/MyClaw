# 美业图文笔记生成规则

> 基于300篇小红书美业/护肤爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 美业 = 美容院、皮肤管理、医美、护肤品牌、美甲美睫、化妆品等。

## 概述：美业图文笔记通用公式

```
封面标题(数字+人群+痛点+结果) → 开头钩子(前3行定生死) → 正文干货(每段有收获)
         ↓                          ↓                          ↓
       配图逻辑(图是证据不是装饰)  →  排版呼吸感(留白比填满重要)  →  结尾CTA(给读者一个交代)
```

### 公式1：段落分割法
```

  ⚠️ 第二步：停掉刺激成分
  美白期不要和酸类叠加。果酸+维C=烂脸的开始。

  💡 第三步：修复型美白
  选含烟酰胺+神经酰胺的产品。一边阻断黑色素一边修复屏障。白了还不反弹。
  ```
