# 服饰图文笔记生成规则

> 基于300篇小红书/公众号服饰类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 服饰 = 穿搭技巧、OOTD分享、身材搭配公式、胶囊衣橱、单品测评、季节穿搭、色彩搭配、通勤穿搭、约会穿搭、平价替代、品牌测评等。

## 概述：服饰图文笔记通用公式

```
封面标题(身材+场景+痛点+解决方案) → 开头钩子(前3行制造代入感) → 正文干货(每段有搭配可抄)
         ↓                          ↓                          ↓
       配图逻辑(上身效果是唯一证据)  →  排版呼吸感(单品清单/搭配公式的节奏感)  →  结尾CTA(让读者想打开衣柜)
```

服饰类笔记的底层逻辑：**每个女生打开衣柜的那一刻都在问同一个问题——"我今天穿什么？"** 你的笔记就是帮她回答这个问题的。所有公式都围绕"解决穿衣焦虑"展开。

## 支柱三：正文干货（10个结构公式）

### 公式1：身材分析+搭配方案法
```
身材特征描述(2-3句) → 穿搭雷区分析(2-3句) → 具体搭配方案(3-5套) → 选品要点总结
```
- **案例（梨形身材显瘦穿搭）**:
  身材：「典型的梨形身材——上半身S码、下半身L码。锁骨和手腕细得像营养不良，但胯宽、大腿粗、假胯宽一个不少。买裤子从来没合适过——腰合适的腿进不去，腿合适的腰能塞两个拳头。」
  雷区：「梨形身材最大的坑——跟风买紧身牛仔裤。大腿根粗+假胯宽+紧身裤=灾难三连。还有A字短裙——你以为A字遮胯，其实裙摆在臀部最宽处炸开，视觉上加宽5cm。」
  方案：「我的三套救命搭配——①直筒西裤+修身针织（上半身贴身凸显纤细优势，下半身直筒裤垂坠遮胯，上紧下直是梨形黄金公式） ②A字中长裙+短款上衣（裙长过小腿肚，裙摆从臀部最宽处开始往下散，配合露腰线转移注意力） ③H型长款大衣+窄脚裤（大衣的H线条把身体切成一个规则的矩形，胯宽直接失踪）。」
  要点：「选下装看三点——①面料要有垂坠感（西装料、三醋酸最佳） ②裤管/裙摆从最宽处开始散 ③避开一切在胯部有装饰的款式（口袋、褶皱、荷叶边，全是雷区）。」

### 公式2：一衣多穿拆解法
```
主角单品介绍(1-2句) → 搭配公式一(场景+组合+效果) → 搭配公式二 → 搭配公式三... → 搭配法则总结
```
- **案例（白衬衫的6种穿法）**:
  单品：「这件优衣库基础款白衬衫，3990日元（折合人民币不到200块）。买了两年，穿了不下100次。现在不管出差、约会、上班、逛街、看展、还是周末遛弯，它都能上场。」
  公式一：「上班：白衬衫+黑色微喇西裤+尖头猫跟鞋。衬衫下摆塞一半、留一半——前面塞进去显腿长，后面留出来遮屁股。加上一条细项链，直接从普通打工人变成'今天下班可能要去相亲'的打工人。」
  公式二：「约会：白衬衫当外套穿。里面穿一件细吊带裙，衬衫不系扣、衣摆在胸前打个结。风吹过来的时候衬衫飘起来——氛围感拉满。」
  公式三：「逛街：白衬衫反着穿。扣子在背后，前面平坦一片。下面配高腰阔腿牛仔裤+平底凉鞋。不刻意但超时髦。」

### 公式8：色彩搭配教学法
```
配色痛点(1-2句) → 色彩理论(简化版,一看就懂) → 具体配色方案(3-5组,每组附案例) → 配色万能口诀
```
- **案例（灰色穿搭全攻略）**:
  痛点：「灰色是衣柜里最多的颜色——灰色毛衣/灰色大衣/灰色西裤/灰色卫衣。但灰色穿不好真的显老气、显灰头土脸、显没精神。」
  理论：「先搞清楚灰色的三个变量——①深浅（浅灰/中灰/深灰/炭灰）②冷暖（暖灰色带棕调，冷灰色带蓝调）③质地（羊毛灰=哑光软糯/丝绸灰=光泽流动/牛仔灰=粗粝有筋骨）。同一件灰色单品，这三个变量决定了它是'高级灰'还是'抹布灰'。」
  方案：
  「灰+白=清冷知识分子风。浅灰毛衣+白衬衫领子翻出来+白裤子。全身上下不超过两个颜色，靠灰白之间的层次变化制造丰富度。适合：上班/看展/见客户。」
  「灰+粉=温柔到犯规。炭灰大衣+裸粉色针织连衣裙。灰色压住粉色的甜腻，粉色解掉灰色的沉闷。适合：约会/见长辈/周末下午茶。」
  「灰+红=不费力的时髦。灰色西装套装+正红色内搭/红色芭蕾鞋。全身灰做底色，一抹红做亮点。适合：年会/派对/想被注意到但不张扬的场合。」
  「灰+蓝=天生一对。灰色针织衫+蓝色直筒牛仔裤。最常见的搭配但最容易穿出质感——诀窍是灰色选浅灰、牛仔裤选中蓝，两个颜色明度接近才和谐。适合：日常所有场合。」
  「不同深浅灰叠穿=最高级的穿法。炭灰大衣+中灰毛衣+浅灰西裤+白银首饰。同色系的明度从外到内/从上到下渐变。这是只有会穿的人才懂的玩法。」
  口诀：「记住四句话——灰配白清冷高级 / 灰配粉温柔到犯规 / 灰配红点到为止 / 灰配蓝闭眼不出错。还有最重要的一句：灰色最怕'乌涂'——面料没质感+颜色发乌=老气横秋。所以买灰色单品，面料质感大于一切。」

  「周四 | 内部培训 | 黑色高领打底+格纹西装外套+牛仔裤+帆布鞋。培训坐了一整天，牛仔裤比西裤舒服一百倍。决定以后坐办公室多的日子多穿牛仔裤。」
  「周五 | Casual Friday | 灰色卫衣+黑色皮裙+厚底乐福鞋+银色项链。下了班直接去朋友生日局，不用换衣服。皮裙把卫衣的随意感拉回来了一点。」
  复盘：「翻了一遍这五天的照片，发现——①颜色使用率最高：黑/白/灰/蓝/米，全是中性色 ②最舒服的下装：阔腿裤>牛仔裤>西裤>针织裙 ③鞋子的重要性：磨脚的鞋毁一天 ④配饰的力量：有项链/皮带的搭配明显比没有的看起来更完整。」
  规律：「由此提炼出我的通勤穿搭公式——中性色为主+一件有质感的单品+舒适的鞋+一件配饰点睛。以后买衣服也按这个逻辑：不买'好看但只能周末穿'的单品，只买'工作日和周末都能穿'的。」

## 支柱四：配图逻辑（10个公式）

### 公式1：上身对比图
```
左Before（穿搭雷区/不适合的款式） vs 右After（正确穿法/适合的款式） + 文字标注关键差异
```
- **案例**: 左右分屏——左边穿错版型的阔腿裤（胯宽被放大），右边穿对版型的直筒裤（胯部线条流畅）。标注：「同一个人、同一体重、不同的裤子版型」
- **案例**: 上半张图：穿泡泡袖的肩宽女生（肩部横向扩张），下半张图：穿V领插肩袖（视觉收窄），标题「肩宽女生请远离泡泡袖」
- **案例**: 并排：小个子穿及膝长外套 vs 及踝长外套。前者把身体切成两段显矮，后者一个修长的长方形显高
- **案例**: 同一件白衬衫：规矩穿（扣子全系+衣摆全塞）vs 随意穿（解开两颗扣子+塞一半+挽袖口），前者像中介后者像博主
- **案例**: 同一个女生配不同长度的半身裙——膝上5cm/刚好在膝盖/小腿肚/脚踝上5cm，红圈标注最佳长度
- **案例**: 正面vs侧面vs背面三角度对比——穿对了的衣服三个角度都好看，穿错了的衣服总有一个角度暴露问题
- **案例**: 紧身牛仔裤 vs 直筒牛仔裤——大腿根部+膝盖+脚踝三处对比，紧身暴露腿型、直筒修饰腿型
- **案例**: 素人改造前后——进门时穿的自己搭的一套 vs 改造后的一套，大字「换了穿搭思路像换了一个人」
- **案例**: 微胖女生穿大一号卫衣（像桶）vs 穿合身V领针织（有腰有曲线），标题「遮肉≠穿大一号」
- **案例**: 同一件基础款打底，左边搭配错误显廉价，右边搭配正确显质感，标注价格「两套加起来都不超过300块」

### 公式2：单品平铺搭配型
```
主角单品居中/平铺 + 搭配单品环绕摆放 + 文字标注每件的品牌/价格/选购要点
```
- **案例**: 一条牛仔裤平铺在画面中央，四周环绕搭配的5件上衣+3双鞋+2只包，每件旁边小字标注品牌和价格
- **案例**: 黑色半身裙放中间，周围呈放射状摆放：针织衫/衬衫/卫衣/T恤/吊带+短靴/乐福鞋/运动鞋，标题「一条半裙搭所有」
- **案例**: 胶囊衣橱全览——所有15件单品按类别分区平铺：外套区/上衣区/下装区/连衣裙区，每件标注面料成分
- **案例**: 通勤穿搭一周5套look，每套以上衣+下装+鞋的平铺组合展示，标注星期一到星期五
- **案例**: 配饰合集——主角是一条小黑裙，旁边环绕搭配的不同配饰（珍珠项链/金色链子/丝巾/腰带/包包），展示「换配饰=换一套」
- **案例**: 同一件风衣+不同的内搭+不同的裤子，三套组合平铺，展示「一衣三穿」
- **案例**: 出差的7件单品全部平铺——2件上衣+2件下装+1件外套+1条连衣裙+1双鞋，标注「7件单品5天不重样」
- **案例**: 按色系平铺——所有的驼色单品放一排、黑色放一排、白色放一排，展示衣橱色彩管理
- **案例**: 购物开箱——快递盒+拆开的包装+新衣服平铺+搭配的旧单品，展示「新买的这件能搭衣柜里已有的哪些」
- **案例**: 旧衣新搭——一件三年前买的外套+今年新买的裤子和鞋子平铺，标注「旧衣服+新思路=新look」

### 公式3：一衣多穿拼图型
```
主角单品多次出镜 + 不同日期/场景的全身照 + 日期/场景标签
```
- **案例**: 六宫格——同一件白衬衫在6个不同场景：开会/约会/逛街/看展/出差/周末。每格标注场景+关键搭配变化
- **案例**: 同一件黑色西装外套的7天穿搭记录，每天标注星期几+去了哪里+搭配思路一句话
- **案例**: 一件针织开衫从秋天穿到冬天的8套look拼图，按温度排列——从20°C穿到5°C的搭配变化
- **案例**: 一周七天，同一条牛仔裤搭配不同上衣+外套+鞋子，展示牛仔裤的百搭力
- **案例**: 同一件连衣裙的三个季节穿法——夏天单穿/秋天叠穿打底+外套/冬天加厚袜+大衣，配文「一件穿三季」
- **案例**: 同样的3件基础款（白T+牛仔裤+风衣），换了不同的鞋和配饰，呈现出完全不同的4种风格
- **案例**: 四宫格——同一件针织背心的4种叠穿：内搭衬衫/外搭西装/配T恤/叠穿在连衣裙外
- **案例**: 一件碎花裙从度假穿到上班——换一双鞋换一只包，同一件裙子两个场景无缝切换
- **案例**: 年度回顾拼图：12个月12套look，同一件大衣出场了8次，标注「年度利用率最高单品」
- **案例**: 九宫格——同一件皮衣搭出了9种风格，每张照片旁边文字标注搭配公式

### 公式4：试衣间实拍型
```
对镜自拍（试衣间/衣柜镜/全身镜） + 试穿单品特写 + 文字标注试穿感受
```
- **案例**: 试衣间对镜自拍三连——正面/侧面/背面，手里拿着吊牌露出价格，标注「试穿三角度，每个角度都OK才会买」
- **案例**: 优衣库试衣间实拍——同一件外套试了M和L两个码，并排对比标注「M合身/L有慵懒感，最后买了L」
- **案例**: 试穿时用手机拍下标签上的面料成分，旁边附上上身效果，标注「看成分表：含羊毛30%所以有挺括感」
- **案例**: ZARA试衣间真实试穿——原相机+自然光+没有P图+没有凹造型，配文「普通人的真实上身效果」
- **案例**: 退货运费险拯救世界——试了5件留了1件，附4件退货的原因（版型/面料/色差/长度），每件简短说明
- **案例**: 同一家店试了七八件，只推荐3件——每件附在试衣间拍的图+一句话优缺点+是否购买
- **案例**: 实体店试穿网红同款——博主穿的样子（截图）vs 我穿的样子（实拍），对比差距，「网红滤镜 vs 现实」
- **案例**: 对镜自拍时用另一只手指出衣服的关键细节——领口大小/袖长/腰线位置，标注「这些小细节决定上身效果」
- **案例**: 试穿时不只看站立效果——坐下/弯腰/抬手三个动作拍照，测试日常活动是否舒适不走光
- **案例**: 同一件衣服在不同的试衣间灯光下（暖光/冷光/自然光），展示颜色的真实面貌，「灯光骗了多少人」

- **案例**: 一件衣服的辅料特写——扣子（天然牛角vs塑料）/拉链（YKKvs杂牌）/里衬（真丝vs化纤），标注「辅料决定了一件衣服的档次」
- **案例**: 起球测试——同一件毛衣穿了一个月后的袖口/腋下/侧腰，展示起球情况，「哪些部位最容易起球？为什么？」
- **案例**: 水洗标大全——一件衣服上有4个水洗标，逐一解读每个图标代表什么，科普「看标签就会洗衣服」

### 公式5：问答对话体
```

```
- **案例**:
  ```
  穿搭咨询室里被问最多的5个问题答案全在这了。

  Q：怎么找到适合自己的风格？
  A：三个步骤——①打开衣柜，找出你穿得最多的5件衣服，看它们有什么共同点（颜色？版型？面料？） ②拍下你被夸得最多的5套look，分析为什么被夸 ③在Pinterest/小红书建一个穿搭灵感文件夹，存50张你喜欢的look图，然后找规律——超过30%的图都是同一个风格=那就是你喜欢的风格。风格不是一天找到的，是你穿过来的。

  Q：小个子真的不能穿平底鞋吗？
  A：能。但有几个条件——①下装必须是高腰 ②裤长/裙长必须在脚踝以上 ③鞋型选尖头/窄长款 ④上下身颜色统一（同色或相近色）=视觉无分割线。满足这四个条件，平底鞋比高跟鞋还显高。高跟鞋反而因为走路姿态变了而破坏比例。

  Q：微胖女生除了黑色还能穿什么颜色？
  A：藏蓝、炭灰、酒红、苔绿、巧克力棕。这些颜色的共同点是——深但有色相。纯黑的显瘦效果其实不如深色+有纹理的面料。一件炭灰绞花毛衣比一件黑色平针织显瘦一倍——因为它有纵向延伸的纹理。

  Q：一柜子衣服还是觉得没衣服穿怎么办？
  A：问题不在数量在搭配。试一下这个——拿出一件你最喜欢的下装，然后去衣柜里把所有能跟它搭的上衣都找出来试一遍。你会震惊——原来有这么多搭配你从来没想到过。如果一件下装搭不出一件上衣，那就该考虑这件下装该不该留了。

  Q：怎么知道一件衣服值不值得投资？
  A：算'每次穿着成本'。¥2000的大衣穿了3年、每年穿30天=¥2000÷90≈¥22/次。¥200的快时尚穿了3次=¥66/次。贵的不一定贵，便宜的不一定便宜。投资那些你会穿30次以上的单品——大衣、牛仔裤、通勤包、基础款打底。别投资只在特定场合穿的单品。
  ```

### 公式6：穿搭法则体
```

```
- **案例**:
  ```
  会穿搭的人都在用这5个法则。学会以后穿搭再也没翻过车。

  法则一：三色原则
  一身搭配不超过三个颜色。黑白灰金银不算颜色。这个法则能防止你把彩虹穿在身上。超过三个颜色→看起来杂乱→质感掉线。
  示范：驼色大衣+白色打底+蓝色牛仔裤。驼+白+蓝=三色。配黑色鞋（黑色不算）+金色项链（金色不算）=完美。

  法则二：上短下长/上长下短
  上下半身的比例决定了你的视觉身高。上短下长=腿长+10cm。上长下短=慵懒但只适合高个子。小个子请把上短下长焊在身上。
  示范：短款针织（衣长在肚脐以上）+高腰阔腿西裤=三七分身材。反例：长款卫衣+紧身裤=五五分。

  法则三：一松一紧
  上下半身不要同时松或同时紧。全身宽松=像睡衣。全身紧身=太用力。松+紧的对比才有时髦感。
  示范：宽松毛衣+紧身牛仔裤✅ / 修身打底+阔腿裤✅ / 宽松卫衣+宽松运动裤❌

  法则四：露出最瘦的部位
  手腕、锁骨、脚踝、腰线——这四个位置是所有人相对最瘦的地方。穿衣服时至少露出其中一个。把最瘦的地方亮出来，其他的藏在衣服里。
  示范：穿大衣时把袖子卷一圈露出手腕 / 穿高领时把头发扎起来露出脖子和锁骨 / 穿长裤时穿九分裤露出脚踝。

  法则五：一件点睛
  全身基础款+一件有点睛效果的单品=不费力的时髦。点睛可以是：红色芭蕾鞋、金属色手袋、一条印花丝巾、一件彩色的打底。只要一件，不要多。
  示范：全身黑（黑大衣+黑毛衣+黑裤子）+一双红色尖头鞋。3秒出门，被路人问是不是博主。
  ```

- **案例**:
  ```
  花了一年搞清楚自己是什么身材。后悔没早做这件事。

  第一步：量数据
  肩宽 38cm / 胸围 86cm / 腰围 70cm / 臀围 96cm / 大腿围 56cm

  第二步：对答案
  臀围(96)-肩宽(38)=58 > 5cm → 梨形身材

  第三步：梨形的穿搭逻辑
  核心思路八个字——凸显上半身，弱化下半身。

  上半身策略：增加量感
  • 泡泡袖/灯笼袖/荷叶边——增加肩部视觉宽度
  • V领/方领/一字领——露出锁骨转移注意力
  • 浅色/亮色/有图案的上衣——让目光停留在上半身
  • 项链/耳环/丝巾——配饰同样是目光吸铁石

  下半身策略：减少量感
  • 深色下装——黑色/深蓝/炭灰
  • 直筒/阔腿/微喇裤型——避开紧身和锥形
  • A字裙/直筒裙——避开包臀裙和百褶裙
  • 面料选有垂坠感的——避开硬挺和蓬松的面料

  推荐款式（梨形本梨亲测）：
  ✅ 直筒西裤（垂坠面料）——胯宽一秒隐形
  ✅ A字中长半身裙——裙摆从最宽处向下散
  ✅ 微喇牛仔裤——平衡大腿和脚踝的宽度
  ✅ 阔腿裤（非硬挺面料）——飘逸的阔腿不显胯
  ❌ 紧身牛仔裤——所有身材问题一次性放大
  ❌ 包臀裙——把缺点明明白白地展示出来
  ❌ 百褶裙——褶子被胯撑开=灾难

  最重要的结论：
  梨形身材不是缺点——是一种需要特定穿搭逻辑的身材类型。学会逻辑以后，你会发现梨形其实是一种很美很女性的身材。
  ```

### 公式10：购物决策体
```
购物场景 + 犹豫点 + 决策框架 + 最终决定 + 决策心得
```
- **案例**:
  ```

  场景：COS试衣间，驼色羊毛大衣，¥1750。

  让我犹豫的理由（想买）：
  • 面料含80%羊毛，手感绝了
  • 颜色是我一直在找的那种驼——不偏黄不偏粉
  • H型+过膝长度=梨形身材友好
  • 穿上那一刻我在镜子里看到的是「我希望自己成为的样子」

  让我犹豫的理由（不想买）：
  • ¥1750，占我月度穿搭预算的70%
  • 广州的冬天能穿大衣的天数不超过30天
  • 衣柜里已经有2件大衣了（虽然面料和颜色不一样）
  • 试穿的时候我发现——袖长偏长需要改、肩线有一点点塌

  用决策框架：
  ① 会穿30次以上吗？
  广州30天/年×3年=90次，如果穿3年可以达到。但要穿3年。

  ② 能搭衣柜里至少3件单品吗？

  袖长要改、肩线有点塌——这是「差一点就完美」。不是「这就是我要的」。

  决策心得：

  不买不是因为¥1750太贵——是因为它不够好。
  真正值得投资的大衣是：你穿上以后没有任何不满意的大衣。哪怕价格翻倍，你会穿十年。
  继续等。
