# 三农图文笔记生成规则

> 基于300篇小红书/抖音三农类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 三农 = 农村生活、农业种植、养殖经验、乡村美食、农产品带货、乡村改造、田园生活、赶海/采摘、农技科普等。

## 概述：三农图文笔记通用公式

```
封面标题(数字+农时+人群+成果) → 开头钩子(前3行定生死) → 正文干货(每段有收获)
         ↓                          ↓                          ↓
       配图逻辑(土地是证据不是背景)  →  排版呼吸感(泥土气比精致更重要)  →  结尾CTA(给读者一个交代)
```

本文件共60个公式（6大支柱 × 10公式/支柱），全部提炼自300篇三农行业爆款笔记的真实数据。每个公式均从实际爆款中高频出现的写作模式归纳得出——不预设分类、不跨行业参考、不做"通用"与"独占"的区分。所有60个公式都从三农内容生态中自然涌现。

## 支柱三：正文干货（10个结构公式）

### 公式1：漏斗四段法
```
痛点陈述(2-3句) → 场景代入(2-3句) → 解决方案(3-5句) → 行动指令(1-2句)
```
- **案例（阳台种番茄）**:
  痛点：「在阳台种番茄，花开了不少，就是不结果。好不容易结了一两个又小又酸。每次刷到别人家阳台番茄红彤彤一片我就怀疑自己是不是不适合种菜。」
  场景：「上个月朋友来家里，看到我阳台上那盆开了花不结果的番茄说：'你这番茄缺的不是肥，是——'然后她用手在花上面弹了一下。我当时觉得她在开玩笑。三天以后花谢的地方冒出了小果子。」
  方案：「缺的是授粉。封闭阳台没有风、没有蜜蜂。解决方法超级简单——每天用手轻轻弹一弹开花的枝条，或者拿一根棉签在每朵花的花蕊上蘸一蘸。弹完的花两天后花萼就会膨大，一周后小番茄就冒头了。还有一个细节：花期中不要施氮肥，施磷钾肥——氮肥会让番茄光长叶子不结果。」
  行动：「现在每根枝条上都挂着四五串果子——最大的已经拇指大了。图4是弹花授粉的具体手法，图5是用了磷钾肥前后两周的对比。阳台党存图照着做。」

### 公式2：AIDA模型
```
Attention(抓注意) → Interest(建兴趣) → Desire(造渴望) → Action(促行动)
```
- **案例（家庭堆肥）**:
  Attention：「三年没买过一袋营养土，菜还越长越好。」
  Interest：「不是买了什么神奇肥料——是从三年前开始把厨房垃圾变成了最好的土。最开始是被垃圾处理器堵了一次，堵到怀疑人生。后来看到一篇讲堆肥的文章，心想反正垃圾要扔不如试试。」
  Desire：「需要一个堆肥桶——最便宜的十几块一个。每天把果皮、菜叶、咖啡渣、鸡蛋壳扔进去，加一层锯末或者干树叶盖住。两周翻一次。第一周没什么变化，第二周开始发热——那是菌群在工作。一个月以后桶里的东西变成了黑色松软的土，闻起来不是臭味，是一股雨后森林的泥土味。用这个土种的菜和买的营养土种的菜做了一次对比——根系发达程度完全不在一个级别。」
  Action：「具体的碳氮比、什么能堆什么不能堆、怎么判断堆好了——全写在图2到图5里了。今天就别把果皮扔垃圾桶了——找个桶开始堆。」

### 公式3：SCQA结构
```
Situation(情境) → Complication(冲突) → Question(问题) → Answer(答案)
```
- **案例（小鸡成活率）**:
  Situation：「今年春天第一次养小鸡——买了20只活泼可爱的土鸡苗，想着年底就有土鸡和土鸡蛋吃了。」
  Complication：「前三天好好的。第四天早上起来发现死了两只。以为是个别体质不好没管。第五天又死了三只。第六天我慌了——上网查了各种资料、问了卖鸡苗的老板。老板说'小鸡就这样，有损耗正常'。但接下来一周又死了五只——20只剩10只。」
  Question：「为什么有的小鸡活得好好的有的说死就死了？明明吃的一样喝的一样温度一样。后来请教了一个养了十几年鸡的农村大爷，他来看了一眼我的鸡舍就笑了。」
  Answer：「他说：'你把小鸡的热水袋放在鸡舍正中间，小鸡冷了就往中间挤、挤在最下面的就被压死了。'正确做法是把保温区域放在角落，让小鸡自己选择离热源多近——冷了靠近点、热了远一点。另外饮水器不能放地上——小鸡踩进去水弄湿了垫料、喝了脏水就拉稀。这两点改完以后剩下的10只全部活到了现在。」

### 公式4：步骤拆解法
```
准备工具(列出清单) → 步骤一(带细节) → 步骤二(带细节) → 步骤三(带细节) → 注意事项
```
- **案例（正确育苗）**:
  准备：「育苗盘（推荐72孔的，不大不小）、育苗土（泥炭土+蛭石+珍珠岩3:1:1）、种子、喷壶、标签牌、一个透明盖子或者保鲜膜。育苗土提前喷水拌匀——手感是'握紧成团、一碰就散'的湿度。」
  步骤一：「把育苗土装满育苗盘——装满就行，不要压实。用手指在每个孔戳一个0.5厘米深的小洞。把种子放进去——大粒种子一个孔一粒、小粒种子一个孔两三粒。然后薄薄盖一层土，厚度是种子直径的2倍。」
  步骤二：「用喷壶喷湿表面——不是浇水是喷水。然后盖上透明盖子保持湿度。放在温暖的地方——25度左右。每天打开盖子透气5分钟。这期间不要浇水除非土表面干了。」
  步骤三：「3-10天出苗（不同品种时间不一样）。看到小绿芽冒头的时候立刻拿掉盖子、移到光照最充足的地方。这时候最容易出问题——光照不够苗就徒长，又细又高东倒西歪。如果家里光照不够，补光灯离苗5厘米照每天12-16小时。」
  注意：「育苗期浇水用浸盆法——把育苗盘坐在浅水里让土从底下吸水。从上面浇水会把小苗冲倒。还有——苗长到两片真叶的时候才能移栽，不要太心急。」

### 公式5：红黑榜清单法
```
分类标准(一句话) → 红榜推荐(每项一句话) → 黑榜避雷(避开+原因) → 总结规律
```
- **案例（阳台种菜品种红黑榜）**:
  标准：「以'好种程度+产量+阳台适配度'三个维度，测了三年十几个品种。」
  红榜：「①樱桃萝卜——从播种到收获28天，不用怎么管，拔出来那一瞬间超解压。②韭菜——种一次吃三年，割了长长了割，越割越旺。③小葱——水培土培都行，做饭随剪随用再也不用买。④矮生番茄——不占地方不用搭架子，一棵能结几十个。⑤空心菜——给水就疯长，夏天一天一个样。⑥辣椒——阳台上的'定心丸'，不招虫、不挑土、一盆能结整个夏天。」
  黑榜：「①大番茄——需要大盆、需要搭架子、容易生病、周期长，阳台党慎入。②黄瓜——爬藤占地方、需水量巨大、一天不浇水就蔫给你看。③西葫芦——长开了能占半平米、白粉病防不胜防。④豆角——爬藤需要大面积、容易红蜘蛛。⑤茄子——需要长时间日照和高温、北方阳台很难养好。」
  规律：「阳台选菜第一原则：选你阳台条件能养好的，不是选你想吃的。光照少就种叶菜、光照好再考虑结果的。」

### 公式6：亲身经历线
```
时间线开头 → 中间过程(失败→尝试→转折) → 高潮结果 → 感悟收尾
```
- **案例（从城市到乡村）**:
  「两年前的今天，我坐在26楼的办公室里对着电脑吃外卖。窗外能看到城市的全景但看不到一棵树。那时候每天最开心的事是下班路过花店买一束花放在办公桌上。花三天就蔫了，下周再买一束。后来有一天加班到凌晨，打车回家的路上看到路边的银杏树变黄了。我愣了一下——我已经两个星期没在白天出过门了，不知道银杏黄了。那个周末我去了郊区一个采摘园。蹲在地上摘草莓的时候突然觉得：原来脚踩在土上的感觉是这样的。回来以后我开始在阳台上种菜——从一盆小葱开始、到一盆辣椒、到一个三层的种植架。去年做了一个决定——搬到郊区租了个带院子的房子。每天通勤多了40分钟，但每天早上推开窗能看到自己种的花在开。今年是第二个春天——院子里桃树第一次开花了。昨天摘了一把韭菜炒了鸡蛋——从地里拔出来到入锅不到五分钟。我现在还是会加班、还是会焦虑，但下班回家路上不再是一片灰色的水泥——而是一条两排银杏的小路。银杏黄的时候，整个村子都是金色的。」

### 公式7：农技科普型
```
一个常见误区 → 科学原理(简单说清楚) → 正确做法 → 效果预期
```
- **案例（为什么浇水太多会把植物浇死）**:
  误区：「大多数人以为植物黄叶就是缺水——于是拼命浇水。结果是越浇水越黄、最后整棵烂掉。」
  原理：「植物的根不是在'喝水'，是在'呼吸+喝水'同时进行。土壤里除了水还有空气——根需要氧气。你把土壤浇得透透的，所有的空隙都被水填满了——根泡在水里没法呼吸，等于人把头按在水里。」
  正确做法：「手指插进土里两厘米——干了再浇、湿着绝对不浇。浇水要浇透——浇到底下流出水为止。浇透≠天天浇。不同季节浇水频率完全不同：夏天可能每天浇、冬天可能一周一次。更重要的是——早上浇水比晚上浇水好。晚上浇水土壤整夜潮湿容易烂根。」
  预期：「改了浇水习惯以后最明显的变化：黄叶不再出现了。如果你以前每周浇三次现在改成干了才浇——可能一周就浇一次。植物不但不会死反而状态更好。」

### 公式8：四季种植日历型
```
当前月份/节气 → 可以种什么(3-5种) → 每种的关键要点 → 下个月预告
```
- **案例（三月种植指南）**:
  三月：「惊蛰到春分——万物复苏的月份。北方还在乍暖还寒，南方已经春暖花开。这个月是全年最关键的播种窗口。」
  可以种：「①生菜/油麦菜类——三月初就可以直播，耐寒，长到五厘米就可以间苗吃，越间越长。②菠菜——耐寒性强，三月初播种三月底就开始收了。③土豆——三月中旬埋种薯，切块每块带一两个芽眼，切面蘸草木灰防止腐烂。④豌豆——三月初点播，搭个小架子，差不多五月份就能吃上嫩豆荚。⑤小萝卜——三月中旬播种，三十天收获，是春天最早的成就感。」
  要点：「北方三月土还比较凉——育苗最好在室内或者用一个小暖棚。南方三月已经很暖了——注意防虫防蜗牛。不管是南是北——三月不施肥。植物刚从冬天缓过来根系还弱，施肥反而烧根。」
  下月预告：「四月是移栽的黄金月——三月份育的苗到四月就可以移到地里了。四月该种什么下周出。」

### 公式9：改造记录型
```
改造前状态(2-3句) → 改造思路(怎么规划的) → 改造过程(关键步骤+花费) → 改造后效果
```
- **案例（30天改造农村小院）**:
  改造前：「老家的院子荒了快十年——杂草比人高、地上全是碎砖乱石、唯一一棵柿子树被藤蔓缠得快看不见了。我爸说：'这院子弄不出来了。'」
  规划：「不是设计师但我画了一张图——左边菜地右边花园、中间一条石板路、柿子树清理出来做院子的C位、靠墙搭一排葡萄架。预算控制在2000以内。」
  过程：「第一周除草——借了邻居的割草机半天搞定，碎砖石铺成了石板路（免费）。第二周翻地——土太硬了加了堆肥和沙子改良（堆肥免费，沙子两袋40块）。第三周种菜种花——菜苗和花苗花了300块，种子100块。第四周搭葡萄架——竹子是在附近竹林砍的（不要钱）、买铁丝和工具花了80块。最后在柿子树下放了把旧长椅——刷了一遍清漆焕然一新。」
  效果：「30天花了不到600块——我爸来看的时候愣了很久。现在院子里番茄红了、月季开了、葡萄藤爬了半架。那把旧长椅成了我在村里最喜欢的地方——傍晚坐在这里看夕阳从柿子树后面落下去，比任何旅游景点都美。」

### 公式10：丰收记录型
```
品种+收获数据 → 种植过程关键节点回顾 → 经验总结 → 下一季计划
```
- **案例（夏季番茄丰收记录）**:
  品种和收获：「今年种了三个番茄品种：矮生汤姆（阳台品种）、大粉番茄和千禧小番茄。矮生汤姆最先熟——一棵结了40多个小果子，当零食吃刚好。大粉番茄个头大到离谱——最大的一个380克快一斤了。千禧小番茄是产量王——两棵摘了快10斤。」
  回顾：「三月初室内育苗——四月中旬移栽到地里——五月初开始开花——六月中旬第一颗红了——七月初进入盛果期——七月底快结束了。整个周期差不多五个月。中间经历了两次虫害——蚜虫和白粉虱。蚜虫用洗洁精兑水喷了三次就好了，白粉虱挂了黄板也控制住了。」
  经验：「今年最大的教训——番茄不要种太密。两棵之间至少留40厘米，不然通风不好容易生病。还有——番茄底部的老叶黄叶要及时打掉，不然消耗养分还招虫。」
  下一季：「秋天打算试试种秋延后番茄——八月中育苗、九月移栽、十一月在棚里收。冬天吃自己种的番茄想想就开心。」

## 支柱五：排版呼吸感（10个公式）

> 以下10个公式全部提炼自三农行业300篇爆款笔记正文的真实排版模式。非通用排版教科书——每个公式都是三农内容生态中自然涌现的独特排版节奏。

### 公式1：劳作日记体
```
日期+天气+农活记录→观察发现→明日计划，像写农事日记一样自然分行
```
- **为什么三农爆款常用**：三农内容天然适合日记体——农事本身就是日复一日的记录。爆款笔记用日记体排版让读者有"翻开别人的务农日记"的偷窥感和代入感，每一条记录空一行、天气和日期单独一行，营造出真实的田间记录氛围。这种排版也和平台"真实记录"的内容调性高度一致。

- **案例**:
  ```
  2026年3月15日 · 晴 · 15℃

  今天在地里待了四个小时。

  🌱 早上：把育好的番茄苗移到地里了。一共32棵。挖坑的时候土还有点凉，加了点腐熟的鸡粪做底肥。

  🌧️ 下午：浇了一遍定根水。天气预报说明天有雨，但定根水不能省——新移栽的苗如果根周围的土不压实不浇透，根和土接触不紧密容易翘死。

  🐛 发现：有两棵苗的叶子上有潜叶蝇的痕迹——叶片上有弯弯曲曲的白线。明天带点黄板挂上。

  ⚠️ 教训：去年移栽太早倒春寒死了一半。今年特意等到3月中旬稳定了再移。种地不能急——按节气来比按心情来靠谱。

  📝 明日计划：搭番茄架子、挂黄板、给刚出苗的豆角间苗。

  图2是今天移栽的番茄苗定植照，图3是潜叶蝇痕迹特写——遇到了别慌，挂黄板就行。

### 公式2：种植教程体
```
每一步用emoji+阶段名开头 → 细节说明 → 图片提示，步骤间用空行呼吸
```
- **为什么三农爆款常用**：种植/养殖教程是三农内容的核心品类。爆款笔记的教程体不是机械的①②③编号——而是每步用相关emoji（🕳️挖坑、💧浇水、✂️修剪）作为视觉锚点，步骤描述像跟朋友聊天一样口语化，关键操作加**加粗**提醒。图片提示在教程体中至关重要——"图X ← 这个步骤应该长这样"让读者在操作时可以对照。

- **案例（种土豆全流程）**:
  ```
  今天种土豆。品种是东北的"尤金"，粉糯型的适合炖着吃👇

  🥔 选种薯
  挑表面光滑、芽眼饱满的土豆。有小芽冒头的更好——说明已经打破休眠了。一个土豆切成2-3块，**每块至少带1-2个芽眼**。切面蘸草木灰晾一天再种——防止烂种。

  图3 ← 切好的种薯，芽眼朝上放的样子

  🕳️ 挖沟
  沟深15厘米、行距60厘米。太浅了土豆露出来见光会变绿（绿了就不能吃了），太深了出苗慢。

  🌱 下种
  把种薯芽眼朝上放进沟里。株距30厘米——别太密，土豆需要空间膨大。然后在种薯旁边撒一把腐熟的羊粪或者堆肥——**肥料不要直接接触种薯，隔一层土**。

  💧 覆土浇水
  覆土5-7厘米，轻轻压实。浇透水——浇到土完全湿润但不积水。

  ⏱️ 接下来等什么
  15-20天出苗。苗长到15厘米高的时候培一次土——把两边的土往植株根上堆。培土=给土豆膨大留空间，不培土产量减半。

  图7 ← 培土的手法和高度示意

  全程从切种薯到下地花了不到一小时。接下来就等6月份挖土豆了——**收土豆的信号是植株地上部分开始变黄枯死**。
  ```

- **为什么三农爆款常用**：农产品带货的排版不能太精致——太精致像广告、不像三农。爆款笔记的带货体保留了"农贸市场吆喝"的节奏感：产地两三句交代清楚、种植方式用细节建立信任（"不打除草剂全靠手拔"）、口感描述不用华丽辞藻用最直接的味觉语言（"甜"就是"甜"不是"甘甜"）、购买信息简洁到像村里人跟你说"去村口找老张就行"。每段短而有力，读起来像有人在跟你唠嗑。

- **案例（自家种的贝贝南瓜）**:
  ```
  家里的贝贝南瓜熟了。

  📍 产地
  山东潍坊寿光。对就是那个全国知名的蔬菜之乡。

### 公式8：农家菜谱体
```
食材来源+处理方式+烹饪步骤+吃的感觉，穿插"为什么农家做法更好吃"的对比
```
- **为什么三农爆款常用**：三农美食和普通美食最大的区别在于"食材来源的故事"。爆款笔记的农家菜谱体不是先列食材清单——而是先说这个食材是"今天早上从地里拔的"还是"鸡窝里刚摸的"。做法也突出"农村土做法"——柴火灶、铁锅、土窑，每一种工具都带着场景感。步骤之间穿插"为什么要这样做"的解释，把烹饪技巧和农村生活智慧融合在一起。

- **案例（柴火灶炖土鸡）**:
  ```
  今天炖了只鸡。自己养的、养了八个月的芦花鸡。

  早上杀的。烧水褪毛的时候隔壁大妈过来看了一眼说：
  "这鸡好——看鸡油的颜色就知道是吃粮食长大的。"

  ———

  🔪 处理
  土鸡和超市买的鸡处理方式不一样。
  不用焯水——土鸡没有腥味，焯水反而把鲜味焯没了。
  冷水泡半小时泡出血水就行。

  ———

  🍳 做法

  柴火灶。铁锅烧热，放一点菜籽油。
  姜片爆香——姜要多放，土鸡配老姜。

  鸡块下锅大火爆炒。炒到鸡皮收紧、微微焦黄。
  这一步很关键——**爆炒锁住肉汁，炖出来才嫩**。

  加开水没过鸡肉——一定是开水。
  冷水一激鸡皮收缩肉就柴了。

  放两段葱、两颗八角、几粒花椒。
  盖上木盖——柴火灶小火慢炖。

  ———

  ⏱️ 炖了一个半小时。

  中间没揭盖子。柴火灶的好处是火力均匀——不急不慢地炖。
  揭盖那一瞬间——整个厨房都是鸡肉的香味。
  汤是金黄色的——表面浮着一层细细的鸡油。

  夹一筷子——肉从骨头上脱下来但又不烂。
  有嚼劲但不是柴。是那种——你知道这只鸡在院子里跑了大半年的韧劲。

  ———

  城里高压锅20分钟也能炖熟。
  但高压锅炖不出来——那种时间慢慢熬出来的味道。
  ```

### 公式9：田园问答体
```
Q&A形式，一问一答，问题来自真实评论/私信，回答像聊天，问答之间大量空行
```
- **为什么三农爆款常用**：三农内容的读者互动极活跃——新手的疑问非常多且重复。爆款笔记用问答体一次性回应高频问题，排版上每个Q&A独立成块，Q用粗体、A自然展开。问答之间空一行让每个问题都像一个独立的小话题。这种排版的好处是——读者可以有选择性地只读自己关心的问题，不需要通读全文。

- **案例（阳台种菜常见问题）**:
  ```
  阳台种菜三年，整理了被问到最多的10个问题。今天统一回答👇

  **Q：封闭阳台没有蜜蜂怎么授粉？**

  A：用一根棉签或者一支小刷子。在每朵花的花蕊上轻轻蘸一蘸——从这朵蘸到那朵。或者最简单的：每天用手弹一弹开花的枝条，花粉自己就飘过去授粉了。番茄、辣椒、茄子都能用这个方法。

  **Q：为什么我的菜光长个子不开花？**

  A：八成是氮肥太多了。氮肥管长叶子，磷钾肥管开花结果。如果只施通用的复合肥或者老浇淘米水——氮过量，菜就徒长不结果。改施磷酸二氢钾，每10天一次。

  **Q：怎么判断浇水浇够了？**

  A：手指插进土里两厘米——干的就浇、湿的不浇。浇到盆底流出水为止。阳台种菜夏天基本每天浇、春秋两三天一次、冬天一周一次。但没有绝对的频率——关键看土不看日历。

  **Q：为什么我的菜长虫了你却不长？**

  A：我没有不长虫。我只是每天早上巡一遍——看到虫子立刻手动抓。蚜虫用洗洁精兑水喷（1:500），菜青虫手抓，蜗牛晚上打手电抓。虫子不是一次解决的事——是每天的战斗。

  **Q：小阳台适合种什么？**

  A：叶菜类——生菜、菠菜、韭菜、小葱、香菜、空心菜。不占地方、长得快、收获周期短、成就感来得快。等叶菜成功了再挑战番茄辣椒。

  ———

  还有什么问题评论区继续问。问得多的我会再出一期。
  ```

### 公式10：土货展示体
```
产品名+外观+来源+特点+实用场景，像赶集摆摊一样自然罗列，用符号做视觉标记
```
- **为什么三农爆款常用**：三农带货不同于美妆/服饰——农产品不需要精致排版，需要的是"真实感"和"踏实感"。土货展示体模拟农村集市上摊主介绍货品的方式——每样东西三两句说清楚是什么、哪来的、有什么特点。用符号做视觉标记（🥚、🍯、🧄）让农民朋友也能一眼看懂——三农内容面向的受众有很大比例是真实生活在农村的人，排版不能太复杂。

- **案例（村里赶集带回来的好东西）**:

  今天赶集，带回来这些👇

  🥚 土鸡蛋
