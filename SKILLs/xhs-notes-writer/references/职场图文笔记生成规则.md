# 职场图文笔记生成规则

> 基于300篇小红书/公众号职场类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 职场 = 求职面试、职场沟通、升职加薪、副业赚钱、职场人际关系、跳槽攻略、职业规划、办公效率、职场穿搭、向上管理等。

## 概述：职场图文笔记公式体系

```
封面标题(数字+身份+痛点+结果) → 开头钩子(前3行定生死) → 正文干货(每段有收获)
         ↓                          ↓                          ↓
       配图逻辑(截图是证据不是装饰)  →  排版呼吸感(话术模板>长篇大论)  →  结尾CTA(给读者一个交代)
```

本文件共60个公式（6大支柱 × 10公式/支柱），全部提炼自300篇职场行业爆款笔记的真实数据。每个公式均从实际爆款中高频出现的写作模式归纳得出——不预设分类、不跨行业参考、不做"通用"与"独占"的区分。所有60个公式都从职场内容生态中自然涌现。

## 支柱三：正文干货（10个结构公式）

### 公式1：漏斗四段法
```
痛点陈述(2-3句) → 场景代入(2-3句) → 解决方案(3-5句) → 行动指令(1-2句)
```
- **案例（谈薪策略）**:
  痛点：「每次跳到谈薪环节就开始紧张。开口怕要高了offer飞了，要低了回去越想越气。最崩溃的一次——入职后发现同岗位比我晚来半年的同事工资比我高3K。」
  场景：「最近这次跳槽，HR报了一个数问我能接受吗。我沉默了几秒，说了一段事先准备好的话。HR愣了一下然后说'我去申请一下'。两天后offer上的数字比最初高了5K。」
  方案：「谈薪最核心的不是怎么说，是提前做的3件事——第一，面试前在脉脉和Boss直聘上把这个岗位的薪资范围摸清楚，记下最高值。第二，手里至少要有另一个在流程中的offer——不一定要真的，但要有。第三，HR报完价不要秒回，沉默3-5秒以后用一种'我在认真考虑'的语气说：'基于我对这个岗位的理解和市场行情，我期望的薪资范围是在XX-XX之间。'」
  行动：「这段话我打印出来放在电脑旁边，每次电话谈薪就照着念。图3是我最近三次谈薪的结果对比——每次都比HR的初始报价高。」

### 公式2：AIDA模型
```
Attention(抓注意) → Interest(建兴趣) → Desire(造渴望) → Action(促行动)
```
- **案例（简历改写）**:
  Attention：「改了一行字，面试邀请从0变成了8。」
  Interest：「之前我的简历写的是'负责公司公众号日常运营'。改了之后变成：'从0到1搭建公众号内容体系，6个月内粉丝从2K增长到5W，单篇阅读量最高破10W+。'——不是编的，是换了一种写法。」
  Desire：「我帮三个朋友用同样的方法改了他们简历上的'负责XX工作'——第一个人改完投了5家收到3个面试，第二个人改完一周内拿到两个offer，第三个人说'这是我第一次觉得自己的简历看起来像个厉害的人'。」
  Action：「这个方法我整理成一个公式：动词+具体动作+量化结果+业务影响。图2-5是4种不同岗位的改写案例。现在打开你的简历，找一句'负责XX'，用这个公式重写一遍。」

### 公式3：SCQA结构
```
Situation(情境) → Complication(冲突) → Question(问题) → Answer(答案)
```
- **案例（向上管理）**:
  Situation：「我上一份工作干了两年，自认为表现不错——项目没延期、产出按时交、同事关系也不差。」
  Complication：「但年终考评是B。同时入职的一个同事拿了A。我观察了他一阵子，发现他干的活不比我多、加班也不比我狠。但他做了一件我从来没做过的事——每周主动约领导做1v1沟通。」
  Question：「为什么同样是干活，有的人被看见、有的人被忽略？向上管理到底是不是拍马屁？不擅长社交的人能不能做好向上管理？」
  Answer：「后来我专门研究了这个事。向上管理不是拍马屁——它的核心是三件事：第一，让你的领导知道你正在做什么（同步进度）；第二，让你的领导知道你遇到了什么问题（降低他的决策成本）；第三，让你的领导知道你的成果对业务有什么影响（建立价值感）。做这三件事不需要任何社交天赋——只需要一个固定的沟通节奏。我现在的做法是：每周五下午发一封邮件给领导，三段式——本周完成了什么、遇到了什么问题需要他决策、下周计划做什么。一个月后领导在部门会上当众说了一句：'XX是我带过最让我省心的人。'」

### 公式4：步骤拆解法
```
准备阶段(列出清单) → 步骤一(带细节) → 步骤二(带细节) → 步骤三(带细节) → 注意事项
```
- **案例（跳槽全流程）**:
  准备：「跳槽不是从投简历开始的，是从'评估现状'开始的。你需要：一张纸、一支笔、以及对自己诚实的勇气。写下——你现在的薪资、你想要的薪资、你不满意的3件事、你不能妥协的2个底线。」
  步骤一：「更新简历——不是刷新一下之前的简历，是全部重写。用'动词+数据+影响'重写每一段经历。去掉所有'负责''参与''协助'开头的句子。写完之后发给3个朋友看，问他们：'看完你觉得我值多少钱？'如果3个人给的价格差不多——那就是你的市场价定位。」
  步骤二：「精准筛选——不要海投。在Boss直聘和脉脉上筛选：行业+岗位+薪资范围+规模阶段。收藏15-20个目标岗位。然后做一件事：研究每一家公司的业务逻辑和岗位描述里的关键词，把这些关键词嵌入你的简历。」
  步骤三：「面试准备——每一场面试前花1小时研究这家公司：他们的核心产品是什么、竞品是谁、最近有什么动态。准备3个'你对这家公司的看法'的回答。面试时反问面试官的3个问题提前准备好——一定要和业务相关，而不是问'福利好不好'。」
  注意：「跳槽最忌讳冲动。不要因为跟领导吵架了就投简历，不要因为同事走了就跟着走。每一次跳槽都应该有一个明确的'目标增量'——要么涨薪、要么换赛道、要么能力升级。如果这三个都没有，那就先别跳。」

### 公式5：清单对比法
```

```
- **案例（offer选择维度）**:
  标准：「以'薪资成长性+行业发展+直属领导+工作强度+公司稳定性'五个维度，帮你在多个offer之间做选择。」
  推荐选择的信号：「①HR能清晰说出你的晋升路径和考核标准——说明公司有成熟的人才体系 ②直属领导在面试时问了具体的技术/业务问题而不是只聊价值观——说明他懂行、能带你成长 ③公司所处的赛道在增长——你涨薪靠的不是个人努力，是行业红利 ④薪资结构中固定部分占比高、浮动部分占比低——别被'最高能拿XX'迷惑 ⑤面试过程中安排了你见未来的同事——说明公司重视团队匹配度。」
  不推荐选择的信号：「①HR对薪资结构含糊其辞、一直强调'发展空间'——说明实际能给的有限 ②公司成立超过3年但还在说'创业氛围'——大概率管理混乱 ③直属领导在面试时迟到、走神、频繁看手机——入职后他不会尊重你的时间 ④JD上写着'抗压能力强''能接受高强度工作'——翻译一下就是'加班很多还没加班费' ⑤面试流程特别短、当天就发offer——说明他们急着找人填坑，不是真的在筛选。」
  规律：「选offer最重要的一条：选直属领导，而不是选公司。一个好领导能给你带来的成长和机会，远大于一个大厂的title。」

### 公式6：亲身经历线

- **案例（被裁到上岸）**:
  「去年11月的一个周五，我被叫进了会议室。HR和我的领导坐在桌子对面，中间放着一个信封。'公司业务调整...'后面的话我已经听不进去了。那年我32岁，在这家公司干了4年，房贷还剩25年。走出公司的那一刻，我在楼下站了很久，不知道接下来该干什么。第一周——疯狂投简历，一天投了50份。一个面试都没有。第二周——开始怀疑自己，后悔当初为什么要来这家公司。第三周——不再海投，花了一整天重新写了简历。把每一段经历都从'负责XX'改成了'做了什么+数据是什么+影响是什么'。投了5家，收到4个面试。第一个面试表现很差——太久没面试了，自我介绍都说不利索。回去以后我把自己关在房间里，对着镜子练了20遍自我介绍。第二个面试——进了终面但最后被一个更年轻的候选人PK掉了。第三个面试——面试官是我的前同事。这个机会我没抱太大希望，但过程意外地顺利。终面结束那天晚上，我一个人在楼下吃麻辣烫，收到了offer。涨了30%。现在回头看——被裁那一天我以为那是终点。但那其实是一个新起点。只是当时站在起点上，还以为是终点。」

### 公式7：问题解答型
```
一个职场核心问题 → 拆成2-3个子问题 → 逐一解答(原因+方法+案例) → 总结
```
- **案例（为什么你总是升不上去）**:
  核心问题：「工作3年以上、业绩不差、态度端正——但每次晋升名单上都没有你的名字。」
  子问题一：「你的工作成果被看见了吗？干了很多活但从来没主动汇报过——领导根本不知道你做了什么。不是他不关心，是他管着十几个人根本没精力关注每一个人。解决方法：建立固定的向上汇报节奏——哪怕只有5分钟，哪怕只是一条消息。」
  子问题二：「你做的事情在公司的核心价值链上吗？你可能一直在做边缘业务——虽然做得好，但边缘业务的'好'天花板太低。核心业务哪怕做得一般，曝光度和资源倾斜也远超边缘业务。解决方法：盘点你现在的工作，算一笔账——这个工作离公司的收入和增长有多远？如果很远，想办法往核心业务靠近。」
  子问题三：「你有'不可替代性'吗？如果你明天离职，公司招一个人来接手需要多久？如果答案是'几天就能上手'——那你不是在被提拔的名单上，你是在被优化的候选名单上。解决方法：找到至少一个'只有你能做好、换别人至少需要3个月才能上手'的能力或资源。」
  总结：「升职不是因为努力，是因为'你对公司的价值+你的不可替代性+你做的工作被看见了'。只要缺一个，升职就轮不到你。」

### 公式8：原理+方法型
```
先说为什么(1-2句原理) → 再说怎么办(2-3步) → 再说要注意什么 → 效果预期
```
- **案例（如何写好周报）**:
  原理：「领导看周报不是想知道你干了什么——他是想知道你干的事情对业务有没有用。所以周报的核心不是'汇报工作量'，是'汇报价值增量'。」
  怎么办：「用三段式写周报。第一段——本周完成了什么，每一项后面跟一个'这意味着什么'（比如：完成XX功能开发→这意味着用户的核心体验路径已经打通）。第二段——本周遇到了什么问题，需要领导做什么决策（降低他决策成本）。第三段——下周计划做什么，优先级排序（让领导知道你接下来会把精力放在哪）。」
  注意：「①周报不要写成流水账——'周一做了什么周二做了什么'这种写法领导根本不会读完 ②不要只写完成的事——卡住的事更要写，因为那才是领导真正需要介入的部分 ③数字比形容词有说服力——'优化了XX'不如'将XX从30%提升到42%'。」
  预期：「第一周领导可能会多看你一眼。第三周他会开始主动回复你的周报。一个月后，他会养成期待你周报的习惯——因为你帮他省了去问'进度怎么样了'的时间。」

### 公式9：话术模板型
```
场景描述 → 错误说法 → 正确说法 → 为什么这样说有效
```
- **案例（提离职怎么说）**:
  场景：「决定离职了，不知道怎么跟领导开口。怕撕破脸、怕被挽留不知道怎么拒绝、怕影响背调。」
  错误说法：「'我觉得在这里没有成长空间了。'——领导听完会觉得你在指责他，关系立刻变僵。」
  正确说法：「'X总，跟您聊个事。我认真考虑了一段时间，决定去探索一个新的方向。在咱们公司的这段时间我学到了很多，特别感谢您的指导。离职不是对公司不满意，是我个人职业规划上的一个选择。我会在离开前把手里的事情交接好，确保不影响团队运转。'」
  为什么有效：「①把离职归因于'个人选择'而不是'对公司不满'——给双方台阶下 ②表示感恩——让领导觉得你不是忘恩负义的人 ③主动提交接——说明你是一个负责任的人 ④没有说出真实的下一份工作信息——给自己留退路。」
- **案例（被问期望薪资怎么说）**:
  场景：「面试官问：'你期望的薪资是多少？'」
  错误说法：「'您觉得我值多少就给多少吧。'——把定价权完全交给对方，最后大概率会被压价。」
  正确说法：「'基于我对这个岗位的理解、行业薪资水平、以及我能带来的价值，我期望的年薪范围在XX到XX之间。当然，这个数字是可以根据具体的岗位职责和福利包来综合看的。'」
  为什么有效：「①说了'基于理解+行业水平+价值'——说明你不是乱要 ②给的是一个范围不是固定值——留了谈判空间 ③最后加了'可综合看'——让对方觉得你理性、不固执。」

### 公式10：案例复盘型
```
一个真实案例 → 当事人的错误/困境 → 转折点/关键动作 → 最终结果 → 可复制的经验
```
- **案例（从边缘到核心的转岗）**:
  案例：「我一个朋友，在某中型互联网公司做了3年内部运营——就是那种'公司内部系统的维护和数据分析'。三年里绩效全是B+，不算差但也绝不突出。去年年底他做了一个决定：申请转到业务部门做产品运营。」
  困境：「转岗申请第一次被HR驳回了——理由很简单：'你没有业务经验'。但真正的原因是——他的原部门leader不放人，因为招一个替代他的人在年底很难。」
  关键动作：「他没有放弃。做了三件事——第一，花两个月在业余时间做了一个竞品分析报告，针对公司即将上线的新业务线；第二，主动约那个业务线的leader喝咖啡，把报告给他看；第三，再提转岗申请的时候，那个leader帮他说了话。」
  结果：「转岗成功。在这个新岗位上做了半年，因为之前的竞品分析帮团队少走了弯路，绩效第一次拿了A。一年后业务线扩招，他也成了小组长。薪资比原来涨了40%。」
  可复制的经验：「①转岗不是靠提交申请——是靠提前证明：你对新岗位有价值 ②跟目标部门的leader先建立关系——让他主动要你 ③不要裸辞转行，内部转岗是最低风险的跳板。」

## 支柱五：排版呼吸感（10个公式）

> 以下10个公式全部提炼自职场行业300篇爆款笔记正文的真实排版模式。非通用排版教科书——每个公式都是职场内容生态中自然涌现的独特排版节奏。

### 公式1：话术模板体
```
给读者可直接复制粘贴的对话脚本，用「你说：」「对方说：」的对话格式排版，像剧本一样清晰
```
- **为什么职场爆款常用**：职场人最焦虑的不是不知道道理，是不知道"话要怎么说出口"。话术模板体的核心价值在于——把抽象的沟通技巧转化为可以直接复制粘贴的对话脚本。读者不需要自己组织语言，照着说就行。这是职场笔记区别于任何其他行业的独特排版——对话剧本式排版。

- **案例（谈薪话术模板）**:
  ```
  谈薪场景：HR电话沟通薪资，你该怎么回？

  📞 HR说：'我们给到的薪资是XX K，你觉得怎么样？'

  不要秒回！沉默3-5秒。然后说👇

  💬 你说：'谢谢。在收到这个数字之前我做了一些功课——基于这个岗位在行业内的薪资水平、以及我能带来的价值，我期望的范围是在YY K到ZZ K之间。当然，这个数字可以结合具体的福利包和年终奖金来综合看。您看这个区间在预算范围内吗？'

  📞 HR可能说：'这个数字有点高了，我需要再去申请一下。'

  💬 你说：'好的，麻烦您了。我对这个机会很感兴趣，也相信我们能找到一个双方都满意的方案。'

  ⚠️ 关键点：
  → 不要主动降价，等HR先开口
  → 不要报一个具体数字，报一个范围
  → 不要表现出"非这份工作不可"的急切感
  → 最后加一句"综合看"，给对方台阶下

  我就是用这段话，初始报价12K谈到17K。多了一句话，每个月多5K。

  图3是HR跟我谈薪的真实聊天记录，数字打了码但过程可以看。
  ```

### 公式2：Q&A体
```
自问自答式排版——用一个核心问题开头，然后分拆成多个子问题逐一回答，每个问答之间空行
```
- **为什么职场爆款常用**：职场问题天然适合Q&A体——因为职场人的困惑本身就是以"问题"的形式存在的。"要不要跳槽""怎么谈薪""被PUA了怎么办"——这些是读者在深夜反复琢磨的问题。Q&A体把他们的内心对话搬到了屏幕上，"你问的我都替你答了"的排版逻辑让读者觉得这篇笔记是专门为他写的。

- **案例（跳槽决策Q&A）**:
  ```
  最近收到太多私信问：'我不知道该不该跳槽，帮我看看。'

  今天把最常见的5个纠结整理出来，自己对号入座👇

  Q：我觉得现在的工作没成长了，要不要跳？
  A：先问自己三个问题——是工作本身没成长了，还是你停止了学习？同一份工作有人能做出10分的成长有人只做出3分。如果确定是前者——跳。如果是后者——先改变自己的工作方式，半年后还是没成长再跳。

  Q：同事跳槽涨了50%，我该不该跟风？
  A：不要跟风跳槽。你同事涨50%可能是因为他刚好匹配了某个稀缺岗位。你要跳的唯一理由是——你对现状有明确的不满+你对下一份工作有清晰的目标。跟风跳槽的人大概率会后悔。

  Q：领导对我还行，但公司发展不行，要不要走？
  A：好领导和好公司如果能二选一——选好领导。但公司快倒闭了好领导也保不住你。判断标准：公司是在经历阶段性的困难，还是已经在下坡路上刹不住车了。前者可以陪一段，后者建议尽早走。

  Q：拿了offer但在犹豫要不要去？
  A：用5个维度打分——薪资成长性、行业发展、直属领导、工作强度、公司稳定性。每一项1-5分。低于18分的offer建议慎重。

  Q：裸辞还是骑驴找马？
  A：90%的情况建议骑驴找马。除非你现在的精神状态已经严重被工作影响——失眠、焦虑、周日晚上就开始心悸。那种情况下，健康 > 一切。
  ```

### 公式3：清单对比体
```
用✅和❌符号逐条列出对vs错的做法，同一条目下正确和错误形成直接对比，让读者一眼看到"差在哪"
```
- **为什么职场爆款常用**：职场是高度结果导向的——读者想知道的是"这样做对还是错"。清单对比体把好坏做法并排展示，让差别一目了然。这种排版天然适合职场内容的"教程属性"——不是在讲道理，是在给操作指南。

- **案例（简历自查清单）**:
  ```
  对照检查你的简历，一条一条过👇

  ❌ '负责公司公众号日常运营'
  ✅ '从0到1搭建公众号内容体系，6个月粉丝增长至5W+，单篇阅读量最高10W+'
  → 你做的事情 ≠ 你做的事情带来的结果。前者是流水账，后者是价值证明。

  ❌ '参与了XX项目的开发'
  ✅ '主导XX项目核心模块开发，上线后系统响应速度提升40%，支撑日活从10W增长至25W'
  → '参与'是简历上最无力的词。要用'主导'并用数据说明影响力。

  ❌ '熟练使用Office办公软件'
  ✅ '用Excel搭建部门数据看板，从原始数据到可视化报告全流程自动化，节省每周3小时人工统计时间'
  → 工具本身不值钱，用工具解决了什么问题才值钱。

  ❌ '具有良好的沟通能力和团队协作精神'
  ✅ '跨部门协调市场、产品、研发三方资源，推动XX项目提前2周上线'
  → '具有良好的XX能力'=没话找话。用具体案例证明你的能力。

  ❌ 一份简历投所有岗位
  ✅ 每份简历针对JD关键词做微调——把对方JD里的关键词嵌入你的经历描述
  → 海投是在赌概率，精准投是在做转化。

  改完简历以后发给3个朋友看。问他：'读完你觉得这个人值多少钱？'
  如果3个人给的价格差不多——那就是你的真实市场定位。
  ```

### 公式4：阶段拆分体
```
把一个大主题按时间/流程拆成几个阶段，每个阶段用【阶段名】开头，阶段之间空行分隔
```
- **为什么职场爆款常用**：职场的大多数行动——跳槽、转行、晋升、谈薪——都是多阶段的过程。阶段拆分体把一个复杂过程拆成可执行的步骤，降低了读者的认知负担。这种排版给读者一种"我可以一个阶段一个阶段来"的掌控感——而掌控感正是职场人最需要的心理安慰。

- **案例（跳槽四阶段全流程）**:
  ```
  一次成功的跳槽需要2-3个月。分四个阶段走，每一步都不难👇

  【第一阶段：准备期（第1-2周）】
  不要着急投简历。先做这三件事——
  → 更新你的简历，用'动词+数据+影响'重写每一段经历
  → 在脉脉上更新你的在线简历，打开'求职状态'（选'观望'而不是'急寻'）
  → 确定你的目标：你下一份工作最想要什么？薪资？成长？WLB？只能选一个最重要的

  【第二阶段：投递期（第3-4周）】
  不要海投。每周精准投10-15家——
  → 在Boss直聘筛选：行业+岗位+薪资范围+公司阶段
  → 每投一家之前花15分钟了解这家公司
  → 记录你投过的每一家公司（excel表格），追踪进度

  【第三阶段：面试期（第5-8周）】
  面试是可以练习的——
  → 每次面试之后当天写复盘笔记：哪个问题答得不好、下次怎么答
  → 高频问题提前准备：离职原因、期望薪资、职业规划、优缺点
  → 手里至少保持有2-3个同时在走的流程——给自己选择权

  【第四阶段：收尾期（第9-10周）】
  → 拿到offer后至少考虑24小时再回复
  → 提离职：说'个人选择'不说'对公司不满'
  → 交接期做好文档，离职也要留口碑
  → 入职前休息一周——跳槽中间的空档比你想的更珍贵

  完整走完这四个阶段，大概率能拿到一个比你预期更好的offer。
  ```

### 公式5：加粗重点突出法
```
关键结论/核心数据/可操作的话术用**加粗**，让扫读的人一眼抓到重点。每段至少1处加粗、不超过3处
```
- **为什么职场爆款常用**：职场人阅读笔记通常是碎片时间——通勤路上、午休间隙、睡前。他们没有时间逐字阅读，而是在"扫读"。加粗让他们3秒内判断"这篇值不值得细看"。职场内容的信息密度高，加粗就像给关键信息打了高亮标记——扫读的人只看加粗也能获得70%的价值。

- **案例（年终总结写作法）**:
  ```
  年终总结不是写你做了什么，是写你创造了什么价值。

  大多数人的年终总结写成了一年的工作流水账——1月做了A、3月做了B、6月做了C。**领导看到这种总结的第一反应不是'你好辛苦'，而是'你跟我说这些干什么'。**

  正确写法：**只写3件事。** 不是3件你做的最多的事，是3件对业务影响最大的事。

  每件事用这个结构写——
  **背景：当时业务面临什么问题？**
  **动作：你做了什么？**
  **结果：带来了什么可量化的变化？**

  举例：
  ❌ '今年负责了公众号运营，每周更新3篇，粉丝增长了。'
  ✅ **'公众号从周更2篇调整到周更5篇，通过选题优化和标题测试，阅读量提升120%，为公司带来了XX条销售线索，直接转化XX万。'**

  **年终总结不是给你自己看的，是给决定你升职加薪的人看的。** 你写的内容应该让他看完以后可以拿去在他的老板面前帮你说话。

  最后一句最重要：**在总结的结尾，写下你明年的目标和需要的资源。** 这不是在汇报过去，是在预约未来。
  ```

### 公式6：短句+换行法

```
一句话不超过20字，一句话一行。情绪强烈的关键句独立成行，制造节奏感。
```

- **为什么职场爆款常用**：职场是高压的、情绪化的。短句+换行的排版模拟了职场人内心那种"一句一句往外蹦"的真实状态——被裁后的无力感、拿到offer的狂喜、被PUA后的愤怒。长篇大论不符合职场人的阅读习惯，短句像子弹一样一句句打过来——简洁、有力、有冲击感。

### 公式7：符号标记引导法
```
💡⚠️✅❌📋💬→等符号作为段首标记，一眼区分段落的类型——提示/警告/正确/错误/清单/话术/结论
```
- **为什么职场爆款常用**：职场笔记的"操作手册"属性决定了它需要清晰的导航标记。读者不是来读散文的，是来找解决方案的。符号标记让读者可以跳过不相关的段落，直接定位到"我需要的那一段"。不同符号对应不同的信息类型——像App的功能图标一样直观。

- **案例（如何识别一份烂工作）**:
  ```
  面了50家公司，总结了烂工作的10个信号。面试时对照着看👇

  ⚠️ '我们这里比较扁平化，没有明确的职级'
  → 翻译：晋升路径不明，涨薪靠老板心情

  ⚠️ '薪资open，主要看能力'
  → 翻译：薪资没有标准，最后大概率按最低给

  ⚠️ '我们希望你是一个多面手'
  → 翻译：一个人干三个人的活，还不加工资

  ⚠️ '试用期6个月，看表现转正'
  → 翻译：可能会在试用期结束前把你换掉

  ✅ 好的信号
  → 能明确说出晋升标准和考核周期
  → 薪资结构清晰，固定部分占比高
  → JD上岗位职责明确，不是'什么都做'
  → 面试官问的是具体的业务问题而不是空泛的价值观问题

  💡 面试时你也在面试公司
  → 观察面试官是否准时、是否认真听你说话
  → 观察办公区的氛围——大家看起来是忙碌还是疲惫
  → 观察厕所和茶水间——这两个地方最能反映公司的真实管理水平

  面试不只是公司在选你，你也在选公司。
  ```

### 公式8：分段+小标题法
```
正文每200-300字用一个小标题分段，小标题用【】框住，一句话概括接下来的内容
```
- **为什么职场爆款常用**：职场内容信息密度高——跳槽策略、薪资谈判、向上管理——每个主题都有大量细节。不分段=信息过载。用【】框住的小标题像内容的路标，即使读了标题就划走的读者也得到了核心观点。这种排版让职场干货看起来"结构化""成体系"——而这正是职场人做决策时最需要的"有框架感"。

### 公式10：结尾分离法

- **案例**: 「现在把你上个月的工资单拿出来。算一下：你的时薪是多少。然后问问自己——你的一个小时值这个钱吗？」
- **案例**: 「这周找一个中午，不看手机、不和同事吃饭、不用social——就自己安安静静地吃一顿饭。感受一下那种'不被打扰'的珍贵。」
- **案例**: 「睡前做一件事：写下你明天上班最想做好的那一件事。只写一件。明天做完这件事以后，你会觉得今天没有白过。」

### 公式10：诚意收尾型
```
{感谢/真心话} + {希望这篇对你有用的祝福}
```
- **案例**: 「写了五个小时。如果这篇能帮到哪怕一个正在犹豫要不要离职、正在焦虑面试结果、正在纠结offer选择的你——就值了。谢谢你看到这里。」
- **案例**: 「这些都是我用自己的时间、焦虑、和被拒的经历换来的。希望你能少走弯路。下一个offer，一定会更好。」
- **案例**: 「每次写完这种长篇都很感慨——回头看那些曾经以为熬不过去的坎，都变成了可以写出来的经验。谢谢你们看到最后的耐心。」
- **案例**: 「这篇笔记没有推荐任何捷径。职场没有捷径——但有方法。希望你现在就知道，而不是像我一样用三年去试错。」
- **案例**: 「写了快4000字，每一个字都是真的。不信的话选一个话术模板下次面试试试。效果好的话记得回来告诉我。」
- **案例**: 「做职场博主的初心：让每一个打工人都不再孤立无援。这篇送给你。你不是一个人在战斗。」
- **案例**: 「感谢每一个认真看完的人。你值得一份让你骄傲的工作——不是完美的、但让你觉得自己的时间没有白白花掉。」
- **案例**: 「每次收到私信说'看了你的笔记拿到了更好的offer'——比我涨薪还开心。真的。」
- **案例**: 「八年职场教会我的不是怎么往上爬，是怎么让自己在往上爬的过程中不丢了生活。共勉。」
- **案例**: 「写到结尾眼眶有点热。不是矫情，是真的觉得每一个还在坚持的打工人都不容易。今天下班给自己买杯奶茶吧——你配得上。」
