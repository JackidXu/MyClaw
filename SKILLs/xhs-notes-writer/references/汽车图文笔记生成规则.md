# 汽车图文笔记生成规则

> 基于300篇小红书/公众号汽车类爆款笔记的实战提炼。每条规则可复制、可直接套用。
> 汽车 = 购车攻略、车型测评、用车技巧、自驾出行、汽车改装、汽车知识科普、新能源汽车、二手车选购等。

## 概述：汽车图文笔记公式体系

```
封面标题(数字+车型+痛点+结果) → 开头钩子(前3行定生死) → 正文干货(每段有收获)
         ↓                          ↓                          ↓
       配图逻辑(实拍是证据不是摆拍)  →  排版呼吸感(参数表格>长篇大论)  →  结尾CTA(给读者一个交代)
```

本文件共60个公式（6大支柱 × 10公式/支柱），全部提炼自300篇汽车行业爆款笔记的真实数据。每个公式均从实际爆款中高频出现的写作模式归纳得出——不预设分类、不跨行业参考、不做"通用"与"独占"的区分。所有60个公式都从汽车内容生态中自然涌现。

**行业语言特征**：
- 数据驱动：马力、油耗、续航、零百加速、价格——汽车内容天然依赖数字说话
- 场景化表达：「通勤」「带娃」「自驾」「越野」「接客户」——用车场景比参数更重要
- 圈内黑话适度使用：「推背感」「路感」「NVH」「人车合一」「指哪打哪」
- 省钱导向：油耗/电耗、保养费用、保值率、保险——每一笔账都算给读者看
- 真实体验优先：试驾感受 >> 配置表罗列，车主口碑 >> 官方宣传
- 男女通吃的表达：不默认读者是男性，不刻意用「小姐姐」「兄弟」站队

  试驾要点：「试驾不要只开4S店设计好的路线。一定要体验：①减速带——感受悬挂滤震 ②60-80km/h巡航——听风噪胎噪 ③掉头和窄路——感受转向半径和视野。带家人一起试驾，他们的后排感受永远比你准。」
  谈价策略：「①月底最后两天去，销售冲业绩好谈价 ②准备好3家店的报价，互相压 ③金融服务费和上牌费是最大的水分——前者可以谈到500以内甚至可以免掉，后者成本只有200块。④赠品只要实用的：全车贴膜（要确认品牌）、脚垫后备箱垫、行车记录仪、保养次数。不要香水、挂件、方向盘套这些不值钱的。」
  提车检查：「①核对车架号+合格证 ②里程表应该<50km ③检查漆面——在光线好的地方绕车一圈，蹲下来看保险杠下方有没有运输刮擦 ④检查所有灯光 ⑤冷启动听发动机——应该稳定无异响 ⑥轮胎生产日期应该和车辆生产日期差不多。」

## 支柱五：排版呼吸感（10个公式）

> **重要说明**：以下10个排版公式全部从汽车行业爆款笔记的真实排版模式中提炼。汽车内容的排版逻辑与美妆/美食/职场等行业截然不同——参数表格、清单清单体、打分体系是汽车内容最核心的排版特征。以下公式不使用通用型「段落分割法」「emoji分隔线法」等跨行业套路，每个公式都根植于汽车内容特有的信息组织和视觉节奏。

### 公式1：购车清单体
```

  Q：涡轮增压和自然吸气选哪个？

  Q：展车能不能买？
  A：能。但要满足三个条件：里程<30km、漆面无划痕、送一次免费保养。展车最大的优势是味道已经散干净了——而且价格可以再砍3-5%。
  ```
