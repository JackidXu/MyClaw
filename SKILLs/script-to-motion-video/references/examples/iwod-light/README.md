# 满分范例 · iWOD 私教改期（浅色风 iwod-light）

本目录是技能的**「质量锚点（满分范例）」**，不是模板，也不是新风格——它是一次真实跑出 iWOD 级效果的成片**原样存档**（index.html / styles.css / app.js 与 `/heyclaw/project/iword-video/composition/` 逐字节一致）。

**用途**：以后每生成一条视频，AI 都先读本目录，对照它的「丰富度结构」，确保新视频填满了脚手架、而不是只填了骨架。质量由「结构丰富度」决定，与风格无关——本范例是浅色风，但深色/霓虹/奶油风也要达到同等丰富度（见 `../../style-skins/`）。

---

## 这条范例为什么是「满分」——可计数的丰富度指标

| 指标 | 本范例数值 | 门禁下限（见 `../../quality-gate.md`） |
|---|---|---|
| 场景数（80s 视频） | 10 个 | 6–8 个/分钟，本片落在 8–10.7 区间内 ✅ |
| 具象 UI mockup | **10 个场景每场景 ≥1 个**，共约 9–10 个具体界面 | 每场景 ≥1 |
| b-roll 视频窗口 | 5 个实拍窗（约课现场/器械/签到/击掌/跑步…） | ≥60% 场景有实拍窗 |
| 动效组/节拍 | ≥3 组（kicker+标题+视频弹入+卡片旋转+行级联+印章 back.out+提示条+持续浮动） | ≥3 组 |
| 排版字号级 | 主标题 86px / 导语 36px / kicker 25px 三级同框 | ≥3 级 |
| 景深 | L0 底板 + L1 网格/颗粒 + L2 实拍窗/内容卡 + L3 前景印章 | ≥4 层 |
| 紧凑化 | tighten.txt 10 段精确 trim，场景间隔 ≤0.65s | 必须跑，间隔 ≤0.65s |
| 设计系统 | 自建 :root（--brand/--accent/--green 三语义色分工） | 5 项齐全 |

## 10 个场景的具象界面清单（AI 应学会这种密度）

- **S1** 手机预约卡（课表行 + "改不了"红印章）
- **S2** 深色大卡 + 实拍窗（痛点强化）
- **S3** 微信聊天时间轴 + 聊天气泡 + 提示条
- **S4** 痛点清单卡（逐行级联）
- **S5** 改期申请表单 + 时段占用格子 + 提交拦截提示
- **S6** 设备三连屏（手机 + 平板 + 桌面）
- **S7** 微信通知卡（成功态）
- **S8** 数据卡（7000+ 数据强调）
- **S9** 评论/留言输入框（互动引导）
- **S10** 大标题 + CTA 框 + 留资提示

## 给 AI 的阅读方式

1. 打开 `index.html` 看每场景的「背景窗 + 内容卡 + 前景印章」三层以上嵌套。
2. 打开 `styles.css` 看 `:root` 语义三色分工、`#paper`/`#grain` 底板、每场景追加的绝对定位布局。
3. 打开 `app.js` 看每节拍 `gsap.fromTo()` 的多组级联入场 + 入场后的 `repeat:-1,yoyo` 持续动效。
4. 生成新视频时，把新片的「具象 UI 数 / b-roll 数 / 动效组数」对齐本范例量级，再过多风格门禁。

> 注意：本目录的 `index.html` 引用了 `../bg/*.mp4` 与 `assets/vendor/gsap.min.js`，这些素材在原项目里，本目录仅作「结构学习范本」，不保证独立渲染。需要独立可渲染的起手骨架请用 `../../composition-template.html`。
