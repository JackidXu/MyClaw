## 检查方法

### 自动检查

```bash
# 抽帧验证关键时间点
node render.js . --snapshot --at 5,15,25,35 --output /tmp/snaps

# 检查布局
# 列出每场景所有 absolute 元素的 top/left/width/height
# 跑 bbox 相交检查
```

### 人工检查

抽 3-5 个关键时间点的帧（每场景元素最多可见时刻），逐帧检查：

1. 元素有无重叠？
2. 有无元素超出顶部 kicker 区域？
3. 有无元素侵入底部字幕区？
4. 分布是否均匀（上紧下空？三集中带？）
5. 元素是否被拉得过宽（贴边）？
6. 字幕是否一行显示不断词？
7. 标题是否前 6 秒展示？
8. 动效是否可见（循环动画幅度足够）？

### 不通过的处理

某项不通过 → 修复该问题 → 重新抽帧验证 → 全部通过后再渲染。
