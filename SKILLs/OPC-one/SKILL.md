# OPC-one — 一人内容公司全流程体系

从「写什么」到「怎么写」到「怎么发」到「怎么迭代」，一个体系跑通的内容生产系统。

## 子技能目录

| 技能 | 用途 |
|------|------|
| `OPC-one` | 主体系入口，内容全流程搭档 |
| `OPC-one-de-ai` | AI 内容生产与辅助 |
| `OPC-one-hook` | 钩子/开头文案写作 |
| `OPC-one-illustration` | 配图与插画生成 |
| `OPC-one-motion` | 动效/视频内容制作 |
| `OPC-one-wiki` | 知识库与资料管理 |
| `OPC-one-xhs-check` | 小红书内容检查与优化 |

## 使用方式

以 `OPC-one` 为主入口，根据用户的内容需求自动路由到对应子技能。支持从选题、调研、写作、配图到发布的完整流程。

## 注意事项

- 所有子技能已移除 YAML frontmatter，保留核心指令
- 效率优先，能合并执行的阶段不拆开
