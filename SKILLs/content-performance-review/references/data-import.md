# 数据导入与回填关联

本文件定义 **步骤① 数据导入** 与 **步骤② 回填关联** 的具体规则。

---

## 一、双入口

### 入口 A：CSV 导入

用户提供从平台后台导出的 CSV（或用户自建表格），推荐字段如下：

```
平台,发布日期,标题,播放量,完播率(%),点赞,评论,转发,收藏,涨粉,选题卡文件
抖音,2026-08-03,为什么这个客户我坚持亲自去,120000,38,8600,420,310,1500,320,选题卡_黑墙_客户亲访.md
视频号,2026-08-05,这个行业通病90%的人都在踩坑,95000,46,7200,510,280,1300,260,选题卡_黑墙_行业通病.md
```

**获取位置**（用户从后台复制数字填入）：
- 抖音：创作者中心（douyin.com/creator 或 App「我 → 创作者服务中心 → 数据看板」）逐条查看或导出
- 视频号：微信 → 视频号 → 右上角「…」→ 数据中心 / 视频号助手小程序
- 小红书：小红书 App → 我 → 创作中心 → 数据

**解析规则**
- 表头顺序可微调，按列名匹配；支持别名映射（如"播放"="播放量"、"完播"="完播率"、"粉"="涨粉"）
- `完播率` 缺列则跳过该指标；`涨粉` 来自后台"单条涨粉"
- `选题卡文件` 列可留空，进入回填关联时按标题匹配

### 入口 B：手动录入

逐条引导用户口述/粘贴，缺项可空：

```
请给这条视频的数据（缺项直接跳过）：
· 平台 / 发布日期 / 标题
· 播放量 / 完播率(%) / 点赞 / 评论 / 转发 / 收藏 / 涨粉
· 关联选题卡文件名（有就给，没有我帮你匹配或标注）
```

---

## 二、回填关联（核心）

把每条视频关联到三维定调的方法论标签。**优先级**：

1. **指定选题卡文件** → 读取其结构化字段：
   - 子枝：取自 `## 内容方向` 各方向的 `三维映射：[维度]·[子枝]`，或 `## 一鱼多吃建议` 表的「子枝」列
   - 六感：取自 `## 六感识别` 的「主触发器」/「次触发器」，或方向里的「触发感」
   - 视频类型：取自方向里的「推荐视频类型」
   - 主枝：由子枝反查所属主枝（人物感性 / 业务性感 / 信任背书）
2. **无文件 → 按标题模糊匹配** `选题卡_{客户}_*.md`，命中最相似者按上法提取
3. **都失败 → 引导用户标注**：从 18 子枝里选 1 个主枝+子枝，六感/钩子/类型标"待标注"

**内容型（信息型 / 信任型）推导**
- 主枝 = 信任背书 → 信任型
- 主枝 = 人物感性 / 业务性感 → 默认信息型；若子枝属"客户证言 / 实绩成果 / 履约实拍 / 长期口碑"等强信任子枝，标记信任型
- 参考 IP 档案的「信任/信息配比建议」做交叉校验

**钩子类型识别**
- 选题卡未直接给钩子类型时，按标题/角度推断（悬念 / 结果前置 / 反差 / 提问 / 共鸣 / 数字 / 痛点），标"待标注"亦可

**写入数据档案**
- 按 `SKILL.md` 第 6 节的记录格式，追加到 `数据档案_{客户}.md`
- 跨月累积，新记录追加在文末，不覆盖历史

---

## 三、解析容错

- 数字含"万""k""w"等单位 → 统一换算为纯数字（1.2万 = 12000，3k = 3000）
- 完播率为百分比字符串（"38%"）→ 存数值 38
- 某视频多平台分发 → 每条平台各记一行，标题相同便于跨平台对比
- 字段缺失 → 该项标"-"，不报错中断
- 单条数据异常（如播放量为 0 或明显乱码）→ 标记并跳过率值计算，不污染整体均值
