# 效果分析框架

本文件定义 **步骤③ 效果分析** 的指标口径、归因逻辑与对比方法。所有结论必须落到方法论维度，不许空泛。

---

## 一、仪表盘（整体表现）

对当月所有记录计算（完播率缺项者不计入完播率均值；播放量为 0 者剔除出率值计算）：

| 指标 | 计算口径 | 含义 |
|------|---------|------|
| 播放量 | 原始均值 / 合计 | 触达规模 |
| 完播率 | 完播 / 播放（均值） | 内容质量核心 |
| 互动率 | (赞+评+转+藏) / 播放 | 共鸣强度 |
| 点赞率 | 赞 / 播放 | 分项 |
| 评论率 | 评 / 播放 | 讨论度 |
| 转发率 | 转 / 播放 | 传播力 |
| 收藏率 | 藏 / 播放 | 价值感 |
| 涨粉 | 原始均值 / 合计 | 转化价值 |

---

## 二、最优 TOP3 归因

**排序口径**：默认按 `完播率 + 互动率` 综合（各 50%）排序；播放量单列作触达参考，不参与排序。用户可指定主排序指标（如"按涨粉排"）。

**每条归因必须落到 ≥2 个方法论维度**：
- 哪根子枝（18子枝）
- 哪种六感触发
- 哪种钩子类型
- 哪种视频类型
- 哪个平台
- 信息型 or 信任型

输出示例：
```
1.《为什么这个客户我坚持亲自去》
   标签：信任背书·客户证言 / 六感=温度 / 钩子=结果前置 / 类型=VLOG / 视频号
   表现：完播52% 互动9.1% 涨粉320
   归因：真实现场 + 结果前置钩子，前3秒留人强；客户证言子枝天然高信任
```

---

## 三、最差归因检查清单

逐条排查，找到主因即停（按此顺序）：

1. **开头流失**：完播率 < 当月均值 且 播放量不低 → 钩子/开头问题
2. **选题错配**：播放低 + 互动低 → 子枝/角度不对 IP 受众
3. **平台错配**：同内容跨平台表现差 → 分发平台选错
4. **配比失衡**：信任型内容完播明显低于信息型，而 IP 象限要求信任为主 → 配比问题
5. **标签缺失**：标"待标注"过多 → 先补全标签再判

输出最差 1-3 条 + 主因结论。

---

## 四、跨维度对比

对每个维度分组，算 `平均完播率 / 互动率 / 涨粉`，输出排名（用 █ 条形直观）：

| 维度 | 分组 |
|------|------|
| 子枝 | 18子枝各自聚合 |
| 六感 | 痛/手/温/证/鲜/悟 |
| 钩子类型 | 悬念/结果前置/反差/提问/共鸣/… |
| 视频类型 | 11种之一 |
| 平台 | 抖音/视频号/小红书 |
| 内容型 | 信息型 vs 信任型 |

示例：
```
子枝维度（按平均完播率排名）：
1. 信任背书·客户证言  52%  ███████
2. 业务性感·痛点拆解  44%  ██████
3. 人物感性·成长经历  31%  ████   ← 该IP此枝留人弱，待换角度
```

---

## 五、战役卡目标达成度

读取当月战役卡（`content-marketing-strategy-map` 产出）的：
- **重点子枝**（人物感性主攻 / 业务性感主攻 / 信任背书主攻）
- **内容目标**（如涨粉 N、互动率 M%）

对照实际：
- 实际发了哪些子枝 vs 计划重点子枝（覆盖度）
- 内容目标数值达成 %（实际 / 计划）
- 未覆盖的子枝 → 下月补拍建议
