# 反哺规则（三端）

反哺结论必须是 **可执行的加权 / 调整清单**，不写空话。输出内嵌于 `复盘报告_{客户}_{YYYYMM}.md` 的「反哺清单」节，同时可作为上游的下次输入。

---

## 一、反哺选题引擎（content-topic-engine）

**依据**：跨维度对比中 **子枝 / 六感** 的表现排名。

**格式**：
```
【下月选题加权】
· {子枝} 权重 +{x}%  ← 完播率/互动率最高
· {子枝} 维持
· {子枝} 权重 -{x}%  ← 完播率最低，减量观察
· 六感侧重：下月多从 {六感} 触发切入
```

---

## 二、反哺脚本撰稿（content-script-writer）

**依据**：跨维度对比中 **钩子类型 / 视频类型** 表现 + 最优 TOP3 的结构特征。

**格式**：
```
【钩子/结构沉淀】
· {钩子类型}：完播率 {x}%，列为优选模板
· {钩子类型}：5s 流失高，降级使用
· 结构：{痛点→案例→证据} 三段式互动率最高，固化为该IP默认结构
· 视频类型：{类型} 表现最佳，下月优先采用
```

---

## 三、反哺战略地图（content-marketing-strategy-map）

**依据**：战役卡目标达成度 + 信息/信任型配比 vs 效果。

**格式**：
```
【月度战役调整】
· 计划信任:信息 = 7:3；实际信任内容完播更高 → 下月调 8:2
· 主攻子枝：{子枝A} + {子枝B}（本月表现 Top2）
· 减量：{子枝C}（待换角度再测）
· 内容目标：本月涨粉 {实际} / 计划 {目标}，达成 {x}%，下月目标 {调整值}
```

---

## 四、反哺清单汇总（报告节选样例）

```
## 四、反哺清单

### 选题引擎
· 客户证言（信任背书）权重 +20%
· 成长经历（人物感性）权重 -15%

### 脚本撰稿
· 结果前置钩子：完播51%，列优选模板
· 提问式钩子：降级
· 默认结构：痛点 → 案例 → 证据

### 战略地图
· 信任:信息 7:3 → 8:2
· 主攻：客户证言 + 履约实拍
```
