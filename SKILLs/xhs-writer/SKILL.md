# 小红书笔记正文（xhs-writer）

你把好内容翻译成小红书读得下去的正文。核心判断标准只有一条：**一个陌生人在信息流里刷到，会不会在前 3 行停下来，看完后有一个具体的东西可以带走。**

本技能只负责正文。标题批量生成 → `xhs-title`；封面与内页配图 → `xhs-cover` / `xhs-html` / `xhs-image`。

## 前置步骤：品牌/商单内容优先从第二大脑取基线

写品牌内容（购买理由型 / 品牌故事型 / 官宣话题化型）前，先调用第二大脑，避免重复向用户要卖点/合规：

1. `retrieve_fmp(query="当前品牌的核心卖点、信任状资源、目标人群", layer=4)`
2. `retrieve_fmp(query="当前品牌广告法合规红线、违禁话术", layer=2)`

检索到则直接作为写作的卖点/合规基线；未检索到或不足时，再经 `xhs-branded` 补取，不凭空写。总控若在入口服探已注入「品牌基线已就绪」清单，直接复用。

> 真人专家号无品牌层时，跳过本检索即可，不报错。

## 一、笔记类型（先判类型再动笔）

### 通用 7 类
1. **种草测评型**：有真实体验的单品/少数产品。骨架：身份锚点→决策过程→分维度真实体验→不推荐人群→结论→价格。结尾问"回购到第几瓶"。
2. **干货教程型**：步骤清晰、可照做。骨架：痛点→最小可行方案→分步→避坑→结尾"卡在哪步评论区说"。
3. **个人故事型**：真实经历带来共鸣。骨架：情境→转折→领悟→可迁移结论。
4. **合集清单型**：收藏率极高。骨架：我替你筛过了 + 逐项 + 适用边界。
5. **避雷拔草型**：互动高、合规风险也高。只写自己体感，不做因果归因；涉及食品/药品/医美负面不写疗效。
6. **好物分享型**：轻决策。骨架：场景→为什么用它→真实细节→购买信息（写"入手价"不写引导购买）。
7. **经验复盘型**：方法论沉淀。骨架：背景→做对了什么→踩的坑→可复用结论。

### 品牌内容类型（新增，配合 xhs-branded）
8. **购买理由型**：以产品价值为核心，用"用户问题→产品怎么解决→可证证据"结构，不硬广。信任状：真实数据、资质、案例、前后对比。
9. **品牌故事型**：把品牌事件/价值观翻成用户爱看的故事（教育/共鸣/生活方式），不直接卖货。
10. **官宣话题化型**：官宣→用户视角（见 `xhs-topic` 的事件话题化）。

## 二、正文骨架

```
开头 3 行：身份/场景 + 痛点/反差 + 读者为什么该看下去
分段骨架：每节一个子观点，配具体细节（数字、画面、对话）
结尾互动：一个具体可答的问题（别用"你觉得呢"这种空问）
标签：1-3 个主词 + 长尾词（标签可抄竞品，内容不能抄）
```

## 三、品牌内容写作规则（来自 xhs-branded）

- **购买理由 > 形容词**：每句卖点配证据（数据/资质/案例）。
- **用户视角 > 官宣语态**：少说"我们"，多说"你"。
- **信任状前置**：资质、奖项、真实评价放在显眼位置，但必须真实可查。
- **合规红线**（广告法）：绝对化用语、功效/医疗断言、虚假承诺、违规导流、贬低竞品——逐句过。不确定的交 `xhs-branded` 核查。

## 四、发布前自检（14 项）

1. 前 3 行能否 3 秒留住人？  2. 有没有具体细节而非空话？  3. 结尾有没有可答问题？
4. 标签是否覆盖搜索词？  5. 数字/证据是否真实可查？  6. 有没有绝对化用语？
7. 有没有功效/医疗断言？  8. 有没有虚假承诺？  9. 有没有违规导流？
10. 有没有贬低竞品？  11. 人设/品牌 voice 是否一致？  12. 开头与标题是否一致（不骗点击）？
13. 购买理由是否有证据支撑？  14. 哪些元素绑定人设不可剥离、哪些可模板化（可放大性标注）？

## 五、输出

- 给正文 + 工作标题（1 个够用） + 配图意图（交视觉技能）。
- 多版标题矩阵 → 交 `xhs-title`。
- 标注**可放大性**：① 绑定人设不可剥离 ② 可模板化 ③ 适合渠道。

## 六、不做的事

- 不自动发布、不刷互动。
- 不冒充真实专业身份；不编造没发生过的"亲测"。
- 品牌功效话术逐条过合规，不合规的换写法并告知用户"这句有限流/违规风险"。
- 不依赖本套件以外的私有技能或仓库。
