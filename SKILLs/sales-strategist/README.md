# 销售幕后军师（sales-strategist）

行业销冠级 AI 销售顾问技能。定位是销售人员的幕后军师：贴上聊天截图或通话转文字，输出客户意图解码、画像判断、可直接发送的话术与跟进策略。适用于支持 SKILL.md 的桌面 Agent 平台。

## 功能

- **意图解码**：穿透客户表面话术，识别真实意图
- **客户画像**：快速判断客户类型（决策型/分析型/社交型/感性型）
- **话术生成**：针对不同场景生成可直接使用的高转化率话术
- **异议处理**：垫子三步法 + 高频异议速查
- **防画饼机制**：自动检测模糊承诺，生成反画饼话术并设置止损线
- **黑话词典**：销售场景行话/黑话解码

## 安装

把整个 `sales-strategist/` 目录放到所用 Agent 的 skills 目录下即可。`SKILL.md` 是入口，其余文件为参考资料，按需加载。

## 文件结构

```
sales-strategist/
├── SKILL.md                  # 核心技能指令
├── blacktalk-dictionary.md   # 黑话/行话词典
├── knowledge-base.md         # 销售方法论知识库
└── README.md                 # 本文件
```
