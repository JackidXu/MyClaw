# 合规规则参考

> 本文件是 content-quality-guard 的合规检查规则参考库。按维度组织，供§5.1合规检查时加载。
> 规则会随法律法规和平台政策更新而变化，使用时以最新规则为准。

---

## 一、广告法违规词

### 1.1 最高级用语（绝对禁止）

| 类型 | 违规词 | 替换建议 |
|------|--------|---------|
| 排名型 | 第一、唯一、首个、首家、独家、首选、首推 | 领先、少有、较早、之一 |
| 程度型 | 最、最佳、最好、最大、最小、最多、最高、最低、最强、最优 | 领先、较高、较多、较强 |
| 品质型 | 顶级、极品、万能、巅峰、极致、王牌、皇冠 | 优质、专业、出色 |
| 时间型 | 永远、永久、终身、万代、千年 | 长期、持续 |

> **检查规则**：扫描口播文本+标题+话题标签，发现上述词汇标记为P0。

### 1.2 绝对化用语（绝对禁止）

| 类型 | 违规词 | 替换建议 |
|------|--------|---------|
| 确定性 | 100%、绝对、必然、肯定、确保、保证 | 大概率、通常、致力于、追求 |
| 承诺型 | 包治、包好、包过、包赚、稳赚、必胜 | 有助于、可能、有望 |
| 无条件 | 无条件、无风险、零风险、零门槛 | 低风险、有条件 |

> **检查规则**：特别注意"保证""确保"在服务承诺中的使用——即使是真实承诺，广告法也不允许在宣传中使用绝对化用语。

### 1.3 虚假承诺（绝对禁止）

| 类型 | 违规示例 | 修改方向 |
|------|---------|---------|
| 效果保证 | "保证帮你赚到100万" | 删除"保证"和具体金额 |
| 收益保证 | "稳赚不赔""保本保息" | 改为风险提示+不保证收益 |
| 升学保证 | "保送上名校""保证录取" | 改为"帮助学生提升" |
| 胜诉保证 | "保证打赢官司""100%胜诉" | 改为"维护您的合法权益" |
| 疗效保证 | "包治百病""7天痊愈" | 改为"遵医嘱""因人而异" |

### 1.4 贬低他人（禁止）

| 类型 | 违规示例 | 修改方向 |
|------|---------|---------|
| 直接贬低 | "XX公司是骗子""别找XX他们不专业" | 删除具体公司名，改为正面表述自己的优势 |
| 间接贬低 | "其他公司都做不到，只有我们能" | 删除"其他公司都做不到" |
| 对比贬低 | "比XX公司强多了" | 不做直接对比，只说自己的数据 |

## 二、平台规则

### 2.1 抖音

#### 违禁内容（绝对禁止）

| 类型 | 说明 |
|------|------|
| 涉黄涉赌涉毒 | 色情、赌博、毒品相关内容 |
| 暴力恐怖 | 暴力、血腥、恐怖内容 |
| 政治敏感 | 涉及政治人物/政策的敏感表述 |
| 传销诈骗 | 传销模式、诈骗套路 |

#### 限流词（可能限流）

| 类型 | 词汇 | 替换建议 |
|------|------|---------|
| 导流词 | 加微信、加V、私信我、加好友 | 主页、评论区、后台 |
| 金融词 | 赚钱、暴利、躺赚、日入 | 增加收入、提升收益 |
| 医疗词 | 治疗、治愈、疗效、药到病除 | 改善、缓解、有助于 |
| 夸张词 | 爆款、疯抢、秒杀、必买 | 热门、受欢迎 |
| 绝对词 | （同广告法） | （同广告法） |

#### 行业限制

| 行业 | 限制内容 |
|------|---------|
| 金融投资 | 不得推荐具体股票/基金/保险产品；不得承诺收益；需有"投资有风险"提示 |
| 医疗健康 | 不得提供具体诊疗建议；不得推荐具体药物；需有"遵医嘱"提示 |
| 法律服务 | 不得对具体案件做判断；不得承诺胜诉率 |
| 教育培训 | 不得承诺升学率；不得制造教育焦虑；不得引用具体学生成绩 |

### 2.2 小红书

| 类型 | 限制内容 | 比抖音更严的地方 |
|------|---------|----------------|
| 导流 | 禁止任何形式的微信号/手机号/QQ号 | 比抖音更严，连"主页"都可能被限 |
| 医美 | 禁止术前术后对比照；禁止推荐具体医美项目 | 医美内容限制最严 |
| 功效 | 禁止夸大功效；禁止"用了就白""擦了就瘦" | 功效宣称限制更严 |
| 品牌对比 | 禁止直接对比品牌说谁好谁差 | 品牌对比限制更严 |

### 2.3 视频号

| 类型 | 限制内容 |
|------|---------|
| 金融 | 同抖音，金融类内容需资质认证 |
| 医疗 | 同抖音，医疗类内容需资质认证 |
| 导流 | 相对宽松，但仍不建议直接放联系方式 |
| 政治 | 政治类内容审核最严 |

> **通用原则**：如果内容同时发多个平台，按最严格的平台规则审查。

## 三、隐私保护

### 3.1 个人信息

| 类型 | 规则 | 严重度 |
|------|------|--------|
| 真实姓名 | 除非已获授权，不得出现客户真实姓名 | P0 |
| 联系方式 | 电话/微信号/身份证号/地址不得出现 | P0 |
| 头像照片 | 客户正面照片需打码或获授权 | P0 |
| 聊天截图 | 姓名/头像/手机号需打码 | P0 |
| 未成年人 | 未成年人面部需打码；未成年人信息需特别保护 | P0 |

### 3.2 客户案例

| 类型 | 规则 | 严重度 |
|------|------|--------|
| 正面案例 | 建议获客户授权后使用 | P1 |
| 负面案例 | 必须获客户授权；不得暴露客户身份 | P0 |
| 案例金额 | 建议脱敏具体金额（"百万级"而非"327万"） | P1 |
| 案例细节 | 不得暴露可识别客户身份的细节（公司名+行业+时间可能被识别） | P1 |

### 3.3 企业信息

| 类型 | 规则 | 严重度 |
|------|------|--------|
| 企业名称 | 竞争对手企业名称不建议直接提及 | P1 |
| 内部数据 | 他人企业的内部经营数据不得泄露 | P0 |
| 商业机密 | 涉及商业机密的信息不得公开 | P0 |

## 四、版权

### 4.1 文字引用

| 类型 | 规则 | 严重度 |
|------|------|--------|
| 引用他人观点 | 需标注来源（"XX老师说过""XX书中提到"） | P1 |
| 引用数据 | 需标注来源（"据XX报告显示"） | P1 |
| 大段引用 | 不得大段复制他人文章/文案 | P0 |

### 4.2 素材使用

| 类型 | 规则 | 严重度 |
|------|------|--------|
| 他人视频 | 不得直接使用他人视频片段 | P0 |
| 他人图片 | 不得直接使用他人照片/图片 | P0 |
| 音乐版权 | 使用平台音乐库内的音乐；不得使用未经授权的商业音乐 | P1 |
| 字体版权 | 商业用途需使用免费商用字体 | P1 |

### 4.3 商标/品牌

| 类型 | 规则 | 严重度 |
|------|------|--------|
| 商标使用 | 他人商标需规范使用（不得歪曲/贬低） | P1 |
| 品牌对比 | 不得通过贬低他人品牌来突出自己 | P0 |
| 品牌暗示 | 不得暗示与某品牌有合作关系（除非真实存在） | P0 |

## 五、行业特殊规定详解

### 5.1 金融/保险行业

| 规则 | 说明 | 严重度 |
|------|------|--------|
| 不得承诺收益 | "年化10%""稳赚""保本" | P0 |
| 不得推荐具体产品 | 不得推荐具体股票/基金/保险产品名称 | P0 |
| 风险提示 | 涉及投资内容需有"投资有风险"提示 | P1 |
| 不得夸大保障 | 保险不得夸大保障范围/理赔金额 | P0 |
| 资质要求 | 金融类内容发布者需有相应资质 | P1 |

### 5.2 医疗/健康行业

| 规则 | 说明 | 严重度 |
|------|------|--------|
| 不得承诺疗效 | "包治""根治""7天痊愈" | P0 |
| 不得推荐具体药物 | 不得在内容中推荐具体药品名称 | P0 |
| 遵医嘱提示 | 涉及健康建议需有"遵医嘱""因人而异"提示 | P1 |
| 不得替代诊疗 | 不得声称内容可替代医生诊断 | P0 |
| 资质要求 | 医疗类内容发布者需有医师资质 | P1 |

### 5.3 教育培训行业

| 规则 | 说明 | 严重度 |
|------|------|--------|
| 不得承诺升学率 | "保送上名校""100%录取" | P0 |
| 不得制造焦虑 | "不补课就落后""别的孩子都在学" | P1 |
| 不得引用学生成绩 | 不得公开具体学生的考试成绩/排名 | P0 |
| 不得承诺效果 | "学完就能涨50分""保证学会" | P0 |

### 5.4 法律服务行业

| 规则 | 说明 | 严重度 |
|------|------|--------|
| 不得承诺胜诉率 | "100%胜诉""保证打赢" | P0 |
| 不得对具体案件做判断 | 不得对正在审理的案件发表确定性判断 | P0 |
| 不得贬低同行 | 不得通过贬低其他律师来突出自己 | P1 |

### 5.5 食品行业

| 规则 | 说明 | 严重度 |
|------|------|--------|
| 不得宣称治疗功效 | 食品不得宣称可治疗疾病 | P0 |
| 保健食品提示 | 保健食品需有"本品不能代替药物"提示 | P1 |
| 不得夸大功效 | 普通食品不得宣称保健功效 | P0 |

## 六、敏感词快速参考

### 6.1 政治敏感（P0）

涉及以下内容需特别谨慎：
- 政治人物评价
- 政策制度评价（可讨论政策影响，不评价制度本身）
- 两岸关系/领土问题
- 民族问题
- 宗教评价

### 6.2 社会敏感（P1）

| 类型 | 敏感词/方向 | 建议 |
|------|------------|------|
| 性别 | 男女对立/彩礼/婚恋观念 | 避免站队，客观陈述 |
| 地域 | 地域黑/刻板印象 | 不使用地域标签做负面评价 |
| 收入 | 炫富/仇富/具体收入数字 | 避免晒具体收入数字 |
| 阶层 | 阶层固化/阶层对立 | 避免制造阶层对立感 |

### 6.3 商业敏感（P1）

| 类型 | 敏感方向 | 建议 |
|------|---------|------|
| 竞争对手 | 直接提及竞争对手名称做负面评价 | 不点名，只说行业通病 |
| 客户负面 | 暴露客户的不利信息 | 必须脱敏+获授权 |
| 行业黑幕 | 揭露行业内部问题 | 确保事实准确，用"部分""有些"限定 |
