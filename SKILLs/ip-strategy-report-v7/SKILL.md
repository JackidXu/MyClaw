# IP Business Strategy Report Skill (HeiQiang v7.0 Five-Layer Progressive Model)

## Overview

This skill creates client-ready IP (Personal Brand) commercial strategy reports using the HeiQiang v7.0 Five-Layer Progressive Model.

**Core upgrade vs v6.2**: The five plates are no longer parallel modules — they form a causal chain. Each layer is the cause of the next, and the next is the effect of the previous. The client reads the report as an irreversible reasoning chain, not a checklist.

**Core formula**: Business Diagnosis → Value Definition → Identity Engineering → Content System → Growth Engine

**Core philosophy**: Don't become an influencer — grow the business. IP is just the surface; business growth is the goal. Strategy first — the boss's head must be clear or everything downstream fails.

## The v7.0 Five-Layer Model

```
Layer 1: Business Diagnosis    →  Your business — where's the real money?
Layer 2: Value Definition      →  Why you? What's your irreplaceable value?
Layer 3: Identity Engineering  →  Who are you? How do people remember you in one sentence?
Layer 4: Content System        →  How to amplify your value through content?
Layer 5: Growth Engine         →  How to turn traffic into money? How to sustain growth?
```

Each layer has a corresponding theoretical foundation:
- L1: Strategic Management (internal+external analysis) / Positioning Theory / Lanchester Strategy
- L2: VRIO Framework / CBBE Brand Equity Pyramid / Value-Based Pricing
- L3: Brand Identity Prism (Kapferer) / Positioning Theory / Signaling Theory
- L4: Customer Journey Map / Diffusion of Innovations / Ansoff Matrix / AIDA
- L5: Growth Flywheel / Conversion Funnel / Lean Startup (Build-Measure-Learn)

A feedback loop connects L5 back to L1 — data from execution validates or corrects the initial diagnosis.

### Step 2: Generate the Report

Build the report in strict five-layer order. Never skip a layer. Never reorder them. The causal chain is the persuasion engine.

The report MUST be delivered as a .docx file with the following formatting:
- Font: Arial, 11pt body text
- Line spacing: 1.2x (276 in OOXML units)
- Headings: bold, hierarchical (H1=16pt, H2=13pt, H3=12pt)
- Tables: styled with header rows in light purple (#EEEDFE) or light blue (#E6F1FB)
- Sections clearly separated with page breaks
- No markdown formatting in the docx output (bold is native Word bold, not **)

## Layer-by-Layer Deliverables

### Layer 1: Business Diagnosis

**Core question answered**: "Your business — where's the real money?"

**Deliverables**:
1. Business line revenue-profit matrix (with profitability, replicability, IP fitness columns)
2. Customer value map (from demographic to pain-point scenarios)
3. Competitive landscape analysis with mental-space mapping (Positioning Theory lens: what slots exist in the customer's mind, which are empty?)
4. Battle-winning statement — a concrete, focusable direction ("In the next 90 days, all IP content converges on establishing XX as the industry's preferred standard")

**Whats different from v6.2**: The diagnosis must produce a clear CONCLUSION, not just a list of facts. The client should feel "you understand my business better than I do."

### Layer 2: Value Definition

**Core question answered**: "Why you? What's your irreplaceable value?"

**Deliverables**:
1. **Founder Gene Decoding** (NEW — not in v6.2): Map the founder's experience → capabilities → unique cognitive advantages. This is not a biography; it's structured extraction of what the 10/20/30-year journey has deposited in their brain that no one else has.
2. Scarcity Pyramid (4 tiers): Unique Results → Unique Methodology → Unique Experience/Perspective → Unique Resources/Endorsements
3. Purchase Reason Formula: "If you're facing [pain point] and value [hidden need], choose me not because of A or B, but because I can uniquely deliver [perceptible unique result]"
4. Pricing Power Logic: Three layers of why you command your price (Standard-setter / Investment not cost / Person of substance)

### Layer 3: Identity Engineering

**Core question answered**: "Who are you? How do people remember you in one sentence?"

**Deliverables**:
1. IP Positioning Formula: Role Tag (memory hook) = [Unique Result] + [Core Role]; One-Sentence Value (value container) = N years + core action + benefit to multiple audiences
2. Identity Tag System: 3-5 unified external tags
3. Four-Test Validation: Dinner test / Can't-copy test / Customer action test / Subconscious test
4. Account Four-Piece Set: Name / Bio / Avatar / Cover
5. Usage scenarios: Different scripts for dinner parties, business meetings, industry forums, and social media

### Layer 4: Content System

**Core question answered**: "How to amplify your value through content?"

**Deliverables**:
1. Three-Phase Strategy: Ice-breaking (days 1-30, establish recognition) → Trust-building (days 31-90, prove capability) → Leadership (days 91+, shape influence)
2. Three Pinned Videos (permanent online business card): Positioning Manifesto + Results Showcase + Value Preview — each with full script direction
3. 90-Day Content Plan (33 pieces: 3 pinned + 30 regular): Weekly schedule with purpose statements, value objectives, and selection rationale for each piece
4. Content Production System Design: Modular filming schedule + AI knowledge base architecture + Team role definitions
5. Benchmark Account Reference: 3 content role-type benchmarks (not specific accounts, but style directions) + Style boundaries (what the content is NOT)
6. AI Knowledge Base: Topic library / Case library / Quote library / Script library / Template library

### Layer 5: Growth Engine

**Core question answered**: "How to turn traffic into money? How to sustain growth?"

**Deliverables**:
1. Hook Product Design: Low-barrier, high-value experience (not cheap goods — complete experience of core methodology)
2. Private Domain Conversion Path: Content → DM → WeChat → Trial → First Order → Repeat
3. Comment Section Strategy: Free, public consultation site and trust display zone
4. **Data Review Loop** (NEW — not in v6.2): Win signals (when to invest more) + Adjustment triggers (when to pivot) + Feedback loop design (data validates or corrects diagnosis)

### Closing Sections

- Team setup recommendations
- Modular filming method
- First-month checklist (weekly action items with capability indicators)
- Report meta: "Based on HeiQiang IP team internal workshop, combined with consensus meeting interpretation and client feedback iterations, AI Agent assisted formatting"

## Report Writing Principles

1. **Client-facing, not methodology-teaching**: The report helps the client make decisions, not shows off how impressive the methodology is. Client should finish thinking "I know what to do now," not "you're so professional."
2. **Diagnosis before prescription**: Never jump to positioning or content before the business diagnosis is complete.
3. **Every table has a purpose**: Don't include tables just to list data. Each table must serve a strategic insight.
4. **The causal chain is the persuasion engine**: The client should feel pulled through the report by an irreversible logic, not presented with five independent toolboxes.
5. **No AI flavor in delivery**: The docx output should look like a human wrote it — no excessive bold, no formulaic structure, proper typography. Emphasis comes from layout hierarchy and natural wording, not full-page bolding.
6. **Include the feedback loop**: Every report must end with win signals and adjustment triggers — this transforms the report from a one-time deliverable into an iterable system and plants the seed for ongoing consulting relationships.
