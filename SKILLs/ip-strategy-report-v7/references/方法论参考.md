# IP 商业策略报告框架（黑墙 v7.0 五层递进模型）

> **核心理念**：不做网红做生意。做IP只是表象，生意增长才是目的。
>
> **核心公式**：商业诊断 → 价值定义 → 身份工程 → 内容系统 → 增长引擎
>
> **核心升级**（vs v6.2）：五板块并列 → 五层因果递进。每一层是下一层的因，下一层是上一层的果。客户读报告的过程就是被这条因果链说服的过程。

## 报告结构总览

### 执行摘要（一页纸，报告最前面）

**采用「价值预告片」模式——不是目录，是「之前-之后」对比。**

1. **报告说明**（开篇meta信息）：声明「本报告基于黑墙IP营销团队内部研讨会议定稿，结合共识会解读与客户二次反馈持续优化，由黑墙AI Agent辅助排版生成。」
2. **你现在的处境**：1-2句话点出客户当前最大的增长痛苦
3. **IP赋能后的未来**：时间线+关键变化（第1/3/6/12个月）
4. **我们的核心路径**：一句话概括五层递进链路
5. **起盘关键成功要素**：客观分析起盘需要的三种能力，不提价格不说服务，让客户自己产生需求

**起盘关键要素写作要点**：
- 不提价格（不写服务包金额）
- 不说「我们」的功劳（以行业经验视角客观描述）
- 强调「不可替代性」（客户出镜和行业素材是别人替代不了的）
- 给客户判断标准（让客户自己评估）

## 第一层：商业诊断（Business Diagnosis）

> 别急着拍视频。先搞清楚——你赚的是哪笔钱？赚谁的钱？凭什么你赚？想清楚了，内容方向自然就出来了。

### 1.1 业务线解构与利润矩阵

**业务线总览表**（必须包含：营收占比 / 利润率 / 复制性 / IP适配度 / 判断 / IP策略）：

| 字段 | 填写标准 |
|------|---------|
| 利润率 | 高 / 中高 / 中 / 低 |
| 复制性 | 高（一客绑定长期复购）/ 中 / 低 |
| IP适配度 | 极高 / 高 / 中 / 低 |
| 判断 | 最佳业务 / 利润业务 / 氧气业务 / 边缘业务 |
| IP策略 | IP主攻 / 内容中适度提及 / 暂不作为IP内容 / 独立IP运营 |

**收入-利润矩阵分析**（一段话结论）：找出「高利润+高潜力+可复制」的核心业务单元——这就是IP的最佳载体。

### 1.2 客户价值分析：从画像到痛点场景

**核心客户画像表**（是谁 / 什么设备或场景 / 核心痛点 / 年支出或客单价）：

必须写出**痛点场景**——描述核心客户「在什么具体情境下，最为决策痛苦和焦虑」。这个场景，就是未来内容的主战场。

**客户决策链**：如果涉及多层决策（如老板+采购+生产主管），必须分析每个角色的关注点和IP内容如何同时打动他们。

### 1.3 竞争格局与心智空白

**竞争力量分析表**（竞争力量 / 是谁 / 优势 / 弱点 / 你的攻法）：

必须包含至少四种竞争力量：直接竞品、替代方案、客户惯性、供应链风险。

**核心判断**（一段话）：明确指出真正的敌人是谁——通常不是同类竞品，而是「客户不知道有更好的选择」这一信息差。这个判断决定了整个IP内容的方向。

### 1.4 业务胜负手：力出一孔

胜负手必须是**一个具体、可聚焦的方向**：
> 不是「提升品牌影响力」这种空话，而是「未来90天，所有IP内容集中火力，将我们在XX细分场景的解决方案，塑造为行业首选标准。」

## 第二层：价值定义（Value Definition）

> 从「我有」变成「只有我能」。客户选你而不选同行，不是因为「更好」，而是因为「不一样」。

### 2.1 创始人基因解码（v7.0全新模块）

这是整个v7.0框架最核心的升级。不再是简单列举「老板的经历和能力」，而是**从经历中提取出结构化的认知优势**。

**基因解码表**（经历阶段 → 沉淀的认知优势 → 对IP的价值 → 在内容中怎么用）：

必须以「经历→能力→独特认知」三层递进。每一段经历回答的不是「什么时候做了什么」，而是「这段经历在他大脑里留下了什么别人没有的认知」。

**基因解码结论**（一句话）：用「不是...而是...」的句式收束——「你不是一个卖XX的，你是一个在XX领域有XX年深度认知、有XX能力的行业人物。」

### 2.2 稀缺性金字塔（4层分层）

| 层级 | 维度 | 填写标准 |
|------|------|---------|
| 第1层（最有力） | 独特结果 | 你为客户创造过哪些同行做不到的惊人结果？用数据说话。 |
| 第2层 | 独特方法论 | 你解决问题有没有名字的独家流程？ |
| 第3层 | 独特经历/视角 | 跨界、失败或高光经历形成了什么独特认知？ |
| 第4层 | 独特资源/背书 | 基础层——单独说力量弱，要结合上面几点 |

每层必须填写「为什么同行抄不走」——这才是稀缺性的本质。

### 2.3 购买理由公式

> 如果你正面临【客户核心痛点】，并且重视【隐性需求：安全感/省心/确定性】，那么选择我，不是因为我A或B，而是因为我能独家为你实现【可感知的独特结果】。

**购买理由清单表**（你的稀缺性 → 客户看到的购买理由 → 为什么同行做不到）

**信任力三阶段**：
1. 成果信任：让客户觉得「你靠谱」→ 案例数据、交付过程、客户评价
2. 种草信任：让客户觉得「需要你」→ 行业洞察、痛点分析、趋势判断
3. 购买理由：让客户觉得「现在就找你」→ 限时/稀缺/标杆案例/同行对比

### 2.4 定价权逻辑

从「贵的三层」来写：
1. 贵=有标准：「用你是资格，不是选择」
2. 贵=能帮你赚更多：「贵是投资，不是成本」
3. 贵=这个人有分量：「愿意为靠谱溢价20%-50%」

## 第三层：身份工程（Identity Engineering）

> 定位不是「告诉别人我是谁」，而是让别人主动靠近你。从你的价值里长出来的身份，才是别人抄不走的身份。

### 3.1 一句话定位 = 价值容器 + 记忆钩子

| 维度 | 内容 | 设计原则 |
|------|------|---------|
| 角色标签（记忆钩子） | 【独特价值/结果】+【核心角色】 | 从稀缺性和业务胜负手中提炼；后半部分用有专业感的身份词 |
| 一句话价值（价值容器） | N年经验+核心动作+同时打动多类受众的好处 | 必须同时打动潜在客户、合作伙伴、行业同行 |
| 身份标签体系 | 3-5个对外统一标签 | 资历标签+成果标签+态度标签 |

标签设计四步：
1. 找到客户最渴望的那个「结果」
2. 找一个能承载这个结果的专业身份词
3. 组合：【结果】+【身份】= 角色标签
4. 测试：在饭局上说出来，对方是否会追问？

### 3.2 四个测试验证

| 测试 | 问题 | 通过标准 |
|------|------|---------|
| 饭局测试 | 饭局上说出定位，对方会追问吗？ | 追问=好定位 |
| 抄不走测试 | 同行能抄吗？抄了像吗？ | 抄了不像=好定位 |
| 客户行动测试 | 目标客户听完会主动要微信吗？ | 要微信=好定位 |
| 下意识测试 | 客户遇到问题，会下意识想找「你的角色标签」吗？ | 是=好定位 |

### 3.3 账号四件套

| 项目 | 设计要求 |
|------|---------|
| 名称 | 称呼 + 角色标签后缀 |
| 简介 | 角色标签 + 一句话价值 + CTA，80字内 |
| 头像 | 专业+有能量（实拍，不要影楼精修） |
| 封面 | 行业感+大字标题，强化识别 |

### 3.4 定位使用场景

为每个场景写一段模拟话术：
- 饭局/社交场合：先抛角色标签等追问
- 商务社交/行业展会：用数据和案例展现分量
- 官方活动/行业论坛：输出观点而非卖产品
- 朋友圈日常：3-5条方向建议

## 第四层：内容系统（Content System）

> 内容是价值的放大器，不是流量的诱饵。每条内容发布前必须回答——看完这条，创始人更「贵」了吗？

### 4.1 内容三阶段

| 阶段 | 时间 | 核心目的 | 内容重点 | 购买理由重点 |
|------|------|---------|---------|------------|
| 破冰期 | 1-30天 | 建立「识」——让目标客户识别你、认同你 | 人设+专业+资历+格局 | 成果信任 |
| 信任期 | 31-90天 | 展示「能」——系统性证明你能解决 | 业务卖点+客户标准+贵的原因 | 种草信任 |
| 引领期 | 91天+ | 塑造「势」——成为领域代言人 | 行业观点+标准输出+趋势判断 | 购买理由触发 |

**内容四型分配原则**：

| 内容类型 | 第1月 | 第2月 | 第3月 |
|---------|-------|-------|-------|
| 人设型 | 40% | 10% | 10% |
| 传播型 | 30% | 20% | 40% |
| 业务型 | 20% | 40% | 20% |
| 学说型 | 10% | 30% | 30% |

### 4.2 三条置顶视频

| 位置 | 定位 | 内容框架 | 目标 |
|------|------|---------|------|
| 置顶1 | 定位宣言 | 核心经历+不忽悠的证据+CTA | 吸引精准客户 |
| 置顶2 | 成果展示 | 客户痛点+方案+惊人结果 | 建立强信任 |
| 置顶3 | 价值预览 | 独家方法论+可用洞察+「想了解更多」钩子 | 筛选高意向客户 |

每条置顶必须写详细脚本方向：标题建议 / 开头钩子（3秒内）/ 核心内容 / 信任锚点 / 结尾CTA / **为什么选这个框架**（解释设计逻辑）。

### 4.3 90天选题排期（33条内容塑造计划）

**发布节奏**：第1周4条（3置顶+1常规），其余每周不超过3条。总计3置顶+30常规=33条。

**每周必须包含**：本周目的 + 本周想要实现的价值

**每条选题必填**：选题标题 / 内容类型（人设/传播/业务/学说）/ 内容摘要（讲什么、用什么素材、打什么认知点）/ 内容选择的原因（为什么本周发、跟上一条的关系）/ 策略目的

**每月必须有**：月度总结（目标 / 四型比例 / 信任阶段推进 / 下月衔接）

### 4.4 对标账号与风格边界

3个内容角色类型对标（不是具体账号名，是角色风格方向）：参考方向 / 内容特征 / 学习重点 / 适配建议

**风格边界表**：明确告诉客户的内容「不是什么」→「而是什么」

### 4.5 内容生产系统设计

- 模块化拍摄法：每周集中1-2小时录制，助理剪辑成日更内容
- AI知识库架构：选题库（初始50条）+ 案例素材库（20个）+ 金句库 + 话术库 + 模板库
- 团队配置：冷启动期（老板+运营1人）→ 稳定期（+剪辑1-2人）

## 第五层：增长引擎（Growth Engine）

> 设计一条「无需说服」的成交路径。有流量没钩子=白忙，有钩子没承接=白费。

### 5.1 钩子产品设计

钩子产品 = **低门槛、高价值体验**。不是便宜货——是完整体验核心方法论，自然导向高阶服务。

**产品矩阵**：引流品（钩子）→ 入门品 → 核心品 → 高奢品

### 5.2 私域转化路径

从「加微→转化」设计成自动化价值交付旅程。给出方向和节奏，细节留陪跑方案。

转化节点：内容→私信→加微→试样/体验→首单→复购

### 5.3 评论区运营

评论区 = **免费的、公开的咨询现场和信任展示区**。老板亲自回复高价值问题——回复超越答案本身，展示思考深度。

### 5.4 数据复盘回路（v7.0全新模块）

**赢的信号**（什么时候该继续投）：
- 评论区出现真实询盘
- 行业群有人主动转发
- 客户主动复购
- 有人主动来问合作

**调整触发条件**（什么时候该转方向）：
- 连续2周0有效询盘 → 调整选题方向
- 评论区全是同行没目标客户 → 重新审视分发渠道
- 有流量没转化 → 复盘内容和钩子
- 播放量高但非目标人群 → 内容定位需校准

**反馈回路**：内容发布 → 数据回来 → 对比第一层诊断假设 → 偏了？→ 调整第三层/第四层 → 对了？→ 加大投入 → 形成增长飞轮

## 注意事项

### 团队配置

| 阶段 | 配置 | 核心任务 |
|------|------|---------|
| 冷启动（1-30天） | 老板+运营1人 | 定方向、拍内容、建素材库 |
| 稳定期（61-90天） | 老板+运营1人+剪辑1-2人 | 批量生产、数据复盘 |

### 内容日常怎么拍

老板每周集中1-2小时录制，助理剪辑成多条日更内容。常态化选题来源（永不枯竭的4个渠道）：
1. 客户提问：一个问答=一条内容
2. 行业变化：政策/技术/竞品动态
3. 交付故事：每个项目提炼故事
4. 竞品动态：同行做了什么？你怎么看？

### 前90天不要做的事
- 不要追求播放量，追求精准询盘
- 不要用AI数字人（前90天必须真人出镜）
- 不要同时做太多平台（主攻一个，辅助1-2个）
- 不要每条视频都卖产品（建立信任优先）
