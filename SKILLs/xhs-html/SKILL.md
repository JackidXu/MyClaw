# 小红书图文排版（xhs-html）

你把长内容拆成多页 3:4 图文，输出单文件 HTML（浏览器逐页截图即得图片）。与 `xhs-cover`（首图）、`xhs-image`（信息图）分工：**本技能做可编辑多页图文**。

## 一、输入

文章内容 / 教程 / SOP / 清单 +（品牌）视觉规范（若有）。

## 二、页数方案

开始前给方案：6 / 7 / 8 / 9 张，按内容密度选。教程类偏多页，清单类可少页。

## 三、风格候选

提供 2-3 个风格方向（如：清新留白 / 高饱和撞色 / 高级灰 / 科技感 / 杂志感），让用户选，不默认。

## 四、关键产出：品牌视觉规范（交付中台）

```
【品牌视觉规范 · 图文】
- 主色 / 辅助色 / 强调色（ hex ）
- 字体：标题 / 正文（中文，跨页一致）
- 版式：标题页 + 内容页 + 结尾页 的固定结构
- 安全区：每页关键信息避开顶部被裁切区
- 图标/插画语言：线性 / 扁平 / 实物 …
- 禁用元素
```

## 五、关键产出：可放大性标注

```
【可放大性 · 图文】
- 绑定人设不可剥离：___（如真人出镜页、特定口吻页）
- 可模板化复制：___（版式/配色/字体/页码结构）
- 适合渠道：种草图文 / 口播配套图文 / 达人派发
```

## 六、交付

输出 HTML 文件，逐页截图即可发布；同时交回视觉规范与可放大性标注，供中台批量套用。

### 交付必附用户操作指引（解决90%用户疑问）
每次交付HTML时，必须附带以下3个常见问题的操作说明，避免用户不知如何使用：

#### 1. 如何拿到完整的3:4小红书图片？
> ① 双击打开HTML文件，自动用浏览器打开
> ② 按 `Command + 减号(-)`（Mac）/ `Ctrl + 减号(-)`（Windows）把页面缩放到60%-70%，整页就会完整显示
> ③ 按 `Command+Shift+4`（Mac）/ `Win+Shift+S`（Windows）框选整页截图即可
> ✅ 专业版无水印精准截图步骤（完全标准3:4尺寸，无多余边框）：
> 1. 在当前页面按 `F12` 打开开发者工具（如果F12没反应，Mac按 `Command+Option+I`，Windows按 `Ctrl+Shift+I`）
> 2. 点击开发者工具左上角的「箭头选择按钮」（元素选择器）
> 3. 鼠标移动到页面上你要截的这页圆角卡片上，点击一下，开发者工具的Elements面板会自动选中对应代码行
> 4. 在Elements面板里右键刚才选中的那行蓝色高亮代码 → 选择「Capture node screenshot」
> 5. 浏览器会自动下载当前页的高清无水印截图，完全是标准3:4小红书尺寸，没有任何多余边框
> 6. 下滑到下一页，重复步骤2-5即可完成6页截图

#### 2. 如何修改页面里的文字？
> ① 右键HTML文件 → 选「打开方式」→ 用VS Code/记事本/文本编辑打开（Mac文本编辑需先在偏好设置里勾选「将HTML显示为代码」）
> ② 代码里的文字和页面显示内容一一对应，找到要改的文字直接替换就行，比如把「惠州XX路」改成实际地址
> ③ 保存后刷新浏览器就能看到修改后的效果
> ✅ 嫌改代码麻烦：先截图，用醒图/美图秀秀直接在图上改字更简单

#### 3. 如何替换成自己的实拍图？
> ① 打开HTML代码，找到对应占位描述，比如`<div class="grid-item">拉丝特写图</div>`
> ② 替换成：`<img src="你的实拍图绝对路径（如/Users/xxx/Downloads/拉丝.jpg）" style="width:100%;height:100%;border-radius:16px;object-fit:cover;">`
> ③ 保存后刷新浏览器就会显示你的实拍图
> ✅ 嫌改代码麻烦：截图后用修图APP直接插入实拍图即可

## 七、不做的事

- 不自动发布。
- 不替代封面首图（首图交 `xhs-cover`）。
- 不依赖本套件以外的私有技能或仓库。
