# 图片设计（image-design）— Doubao-Seedream-4.5 提示词设计技能

## 模型适配说明

本技能面向 **Doubao-Seedream-4.5**（字节跳动 Seed 团队研发的统一图像生成与编辑模型）设计。该模型将文生图、图生图、组图生成融合于同一架构，提示词设计应充分调用其核心能力：

| 维度    | 能力                                             |
| ----- | ---------------------------------------------- |
| 提示词语言 | 中英双语原生支持（中文场景优先用中文，能精准理解复杂长指令）                 |
| 输出分辨率 | 1K / 2K / 4K（4K 最大可达 4096×4096，约 4MP）          |
| 宽高比   | 1:1、4:3、3:4、16:9、9:16、3:2、2:3、21:9（比例范围 1/3–3） |
| 参考图输入 | 最多 10 张，仅支持 JPEG / PNG，单张 ≤ 10MB               |
| 组图生成  | 单次最多 15 张（输入+生成），支持 auto / 故事书 / 连环画模式         |
| 文字渲染  | 中英文图内文字清晰，擅长海报、电商横幅、Logo 排版                    |
| 主体一致性 | 多图主体锁定，跨场景保持人物/对象外观稳定                          |
| 空间理解  | 构图、比例、对象位置真实，元素融合自然                            |

**该模型特别擅长**：电商产品图、营销海报、口播或知识讲解封面、品牌视觉、多图故事板、参考图编辑（换装/换背景/风格迁移）、影视质感画面、角色一致性系列图。

> 出图默认使用 Doubao-Seedream-4.5，无需在提示词中指定模型名称。

## 提示词结构

围绕三个核心要素增强每一条生图提示词：

### 1. 主体 SUBJECT（What — 画什么）

- 物理特征：材质、纹理、颜色、尺寸
- 动作、姿态、表情（如适用）
- 定义主体的标志性特征

### 2. 场景 CONTEXT（Where/When — 在哪何时）

- 场景、背景、空间关系（前景 / 中景 / 背景）
- 时间、天气、氛围
- 情绪基调

### 3. 风格 STYLE（How — 怎么呈现）

- 艺术或摄影手法：指定艺术家、艺术流派或风格
- 镜头 / 光线选择：焦段、光圈、拍摄角度、光源方向

### 4. 道具 / 装饰 PROPS（点缀 — 让画面不单调）

- 与主体 / 场景 / 风格协调的 3–4 个道具或装饰元素，**叙事关联优先**（能暗示主体身份、动作前因或场景时段），使整体画面不单调
- 占比克制（≤ 画面 30%），不喧宾夺主，必须分布在前 / 中 / 背景不同层次；
- 拒绝万能模板道具（如「绿植 + 花瓣 + 光斑」「书 + 咖啡杯 + 阳光」），每条提示词的道具必须**适用于本画面语境，最主要是与图片搭配**

## 核心原则

- **保留意图** — 只在用户未指定的部分补充视觉细节（光线、纹理、构图），用户明确给出的元素保持不变
- **只写要什么，不写不要什么** — 把所有「排除项」改写为「包含项」（如「不要模糊」→「清晰锐利」）
- **具体胜于模糊** —「15° 黄金时刻侧光」优于「光线不错」
- **自然流畅** — 把各要素编织成一段连贯描述，不要写成项目符号列表
- **双语择优** — 中文场景用中文写提示词（模型原生支持），技术 / 摄影术语可保留英文
- **参考图分层锁定** — 当提供参考图时，将主体属性分两层处理：身份层（五官 / 脸型 / 发型 / 体型 / 标志性特征、产品形状 / Logo / 核心结构）硬锁不变；搭配层（衣着颜色 / 款式 / 配饰、姿势 / 表情、产品配色 / 包装材质）应与目标画面色调 / 氛围 / 场景协调，冲突时主动调整为协调版本（如深色海报中参考图浅色衣改深色系），调整须在提示词中显式声明
- **不单调** — 每张图至少补充 3 个与主体 / 场景叙事关联的道具或装饰元素，弥补「主体 + 背景」的空旷感；道具服务于叙事与氛围，不堆砌、不套模板

## 输出格式

**默认每次返回 3 段同主题变体提示词**，3 张不同风格/场景，在配色、构图、背景、道具等指定轴上变化，核心理念：**3 张都要非常适合这个主题**，而不是为了凑数走 3 种差异很大的风格。

例外情形按需返回对应数量：

- 用户明确要求「只出一张 / 出 N 张 / 出特定某张」→ 按用户指定数量返回
- 用户给出多个**独立**需求（如「一张猫 + 一张狗」）→ 每条单独返回，加小标题标注需求序号
- 用户要求故事板 / 连环画等强叙事组图 → 按「组图生成」段处理

每段提示词单独成段，段首加小标题标注差异轴或需求序号。

## 增强模式

### 超具体细节

对用户未指定的主体 / 场景 / 风格要素，补充可执行的视觉细节：

- 光线 → 方向、质感、色温、阴影行为
- 纹理 → 表面材质、磨损、反光率
- 氛围 → 颗粒、湿度、空气透视
- 比例 → 相对大小、距离、占比

### 摄影控制术语

当画面适合摄影感时：

- 镜头：「85mm 人像镜头拍摄」「24mm 广角」
- 光圈：「f/1.8 浅景深」「f/11 全景深」
- 角度：「低角度仰拍强化高度」「鸟瞰视角」
- 动势：「爪部运动模糊」「定格于动作中段」

### 氛围增强

通过环境细节传达情绪：

- 用视觉指标表达情绪基调：「宁静（柔光散射、低饱和度调色）」「压抑（低对比、浓重阴影、去饱和）」「欢腾（高饱和、暖色调、动态运动）」
- 天气 / 空气：「晨雾」「光束中的尘埃微粒」

### 道具 / 装饰点缀

为避免画面单调，每条提示词为画面补充 &#x32;**–4 个** 与主体、场景、风格协调的道具或装饰元素，并显式写入提示词：

- **占比克制**：道具在画面中占比 ≤ 30%，不抢主体焦点
- **分层分布**：道具应自然落在前景 / 中景 / 背景的不同层次，避免全堆在同一平面
- **色调材质协调**：道具须与画面整体氛围一致，冲突时主动调整道具而非生硬塞入
- **声明来源**：道具元素须在提示词中以自然描述方式写入（不写「道具：xx」，而是「主体手边的画笔浸入颜料盘，画板旁散落着几张草图」）

### 图内文字（模型强项，应充分利用）

当画面需要可读文字（招牌、标签、标题、排版）时：

- 用引号标注精确文字内容：`"营业 24 小时"，加粗无衬线字体`
- 描述视觉处理：字体风格、字重、相对场景的字号、颜色
- 文字占比：文字在画面中占比 ＞ 30% ，分为主标题、副标题/卖点、辅助文字（正文内容/标签/数字/CTA） 三部分，分别对应不同的字号、字体风格、颜色、是否背景填充等
- 文字层级：主标题1条占文字总视觉权重 50%，副标题/卖点1-2条权重 30%，辅助文字（正文内容/标签/数字/CTA）1-2条权重 20%，重点文字靠颜色差异建立
- 空间分布：文字分布合理，多段文字要有对齐基准，每区单一对齐基准（左对齐/居中/右对齐三选一），禁止同区混排，文字块不得越过画面安全边距（四边各留 ≥ 8% 画面尺寸）
- 定义位置与整合方式：「居中于店面雨棚上」「手写于黑板之上」
- 多语言排版时可指定语言：中英文混排、日文竖排等

## 功能模式

### 角色一致性

当同一角色需在多张图中保持可识别时（Doubao-Seedream-4.5 的主体锁定能力支持此场景）：

- 包含 **至少 3 个可识别视觉标记**（标志性疤痕、签名款服饰、独特发型、特征性配饰）
- 使用锚定词：「标志性的」「签名款」「总是戴着」「永远带着」
- 要具体：「圆形玳瑁眼镜」而非仅仅是「眼镜」

### 构图整合

当一张画面中组合多个视觉元素时：

- 用占比定义空间关系：「前景（占画面 35%）、中景（占画面25%）、背景（占画面40%）」
- 定义元素间如何空间与视觉互动：重叠、倒影、共享光源、前景与背景的色彩呼应
- 指定相对比例与元素间互动

### 真实世界准确性

当描绘真实地点、文化或历史元素时（模型具备较强的世界知识）：

- 使用专业术语：「江户时代传统建筑」「正宗摩洛哥 zellige 马赛克瓷砖」
- 包含文化准确的细节
- 引用地理或历史的具体信息

### 目的驱动增强

按用途调整提示词（Doubao-Seedream-4.5 在电商、海报、品牌场景表现突出）：

| 用途        | 重点                   |
| --------- | -------------------- |
| 产品图       | 干净背景、棚拍灯光、商业质感       |
| 电商横幅      | 内嵌文字、价格标签、促销排版       |
| 营销海报      | 戏剧化情绪、留白给标题、品牌符号、高级感 |
| 口播 / 知识讲解 | 专业信任感人设、商务感强、文字占比高   |
| UI 原型     | 扁平元素、一致间距、屏幕适配       |
| 演示幻灯片     | 大胆构图、清晰焦点、文字友好布局     |
| 社交媒体      | 抓眼、鲜艳、裁剪友好比例、背景突出    |
| 书籍 / 专辑封面 | 排版空间、戏剧化氛围、象征元素      |
| 故事板 / 组图  | 跨帧角色一致、风格统一、叙事连贯     |

## 图像编辑（基于参考图生成）

当用户提供参考图时（Doubao-Seedream-4.5 统一架构原生支持图生图），按以下流程处理，避免主体与目标画面氛围不搭配：

### Step 1 — 判断参考图用法

| 用法      | 参考图是              | 硬锁     | 可调         |
| ------- | ----------------- | ------ | ---------- |
| A. 主体复现 | 人物形象图 / 产品图 / 角色图 | 主体身份层  | 搭配层 + 场景风格 |
| B. 风格借用 | 风格 / 构图 / 氛围参考    | 风格调色构图 | 主体（文字定义）   |

> 用户未明说默认按用法 A。

### Step 2 — 拆分主体属性为两层

**人物：**

- 身份层（硬锁）：五官 / 脸型 / 发型 / 体型 / 标志性特征（疤痕、纹身、独特配饰）
- 搭配层（可调）：衣着颜色 / 款式 / 材质 / 配饰 / 姿势 / 表情

**产品：**

- 身份层（硬锁）：形状 / 轮廓 / Logo / 核心结构
- 搭配层（可调）：配色 / 包装材质 / 装饰 / 摆放姿态

### Step 3 — 检查搭配层与目标画面氛围是否冲突

写提示词前先比对：

- 目标画面色调（深色 / 浅色 / 暖色 / 冷色）vs 参考图搭配层（衣着 / 产品配色）
- 目标画面氛围（正式 / 休闲 / 科技 / 复古）vs 参考图搭配层风格
- 目标场景（户外 / 棚拍 / 室内）vs 参考图姿势 / 摆放

冲突时主动调整搭配层以适配画面，身份层保持不变。

例：参考图人物穿浅色休闲服 + 目标深色海报 → 衣着调整为深色系（深灰 / 黑色同款休闲服或西装），五官发型体型不变。

### Step 4 — 提示词显式声明两层

- 锚定身份层：`保持参考图中人物的[脸型：方脸][发型：黑色短发][体型：偏瘦]`
- 协调搭配层：`衣着调整为深色西装以适配深色海报氛围`（不得写"保持参考图衣着"导致浅色衣入深色海报）

### Step 5 — 冲突处理

- 用户明确要求"保持参考图原貌不改" → 硬锁搭配层，但提示画面氛围与主体可能不搭
- 用户未明说 → 默认按 Step 3 主动协调，输出时标注：`⚠️ 已将参考图[浅色休闲服]调整为[深色休闲服]以适配深色海报氛围，如需保持原貌请明说`
- 用户明说"换装 / 改表情 / 换姿势" → 按指令覆盖对应搭配层，身份层仍锁

## 组图生成

当需要一次生成多张相关图时（sequential 模式）：

- 在提示词中明确各图的差异点与共同点
- 指定统一的风格锚点（光照、调色、画幅比例）
- 角色一致性场景下，重复嵌入 3 个以上视觉标记
- 可指定模式：auto（自动）/ 故事书 / 连环画

## 模糊情形

- 当用户意图在摄影感与插画感之间不明确时，增强前先询问
- 当增强会显著改变用户概念时，把原始理解与增强版并列呈现
- 当文化或历史准确性无法确认时，标注不确定而非猜测
- 当参考图主体的搭配层（衣着颜色 / 款式等）与目标画面氛围冲突且用户未明说是否保留原貌时，默认主动协调搭配层以适配画面氛围，并在输出提示词时标注协调项

## 范围

本技能覆盖静态图像提示词增强，不覆盖视频生成、3D 渲染或图像分析 / 描述。
