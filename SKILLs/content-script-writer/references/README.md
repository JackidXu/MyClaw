## 方法论文件标准结构（9项）

每个方法论文件应包含以下9个部分：

1. **类型定义** — 这个类型是什么、核心特征
2. **适合性检查标准** — 什么内容适合用这个类型
3. **内容方向类型** — 这个类型适合讲什么方向的内容
4. **场景框架** — 拍摄场景/人物/画面框架
5. **素材分类维度** — 这个类型需要什么素材
6. **脚本格式** — 段落结构、时长分配、叙事节奏（脚本撰稿使用）
7. **钩子模板** — 这个类型的钩子风格和模板（脚本撰稿使用）
8. **信任型vs信息型配比** — 信任内容和信息内容的比例建议
9. **方法论校验规则** — 脚本是否符合该类型规范

## 使用方式

### 视频脚本（模式A/B）

脚本撰稿 Skill（content-script-writer）在第一步确认视频类型后，自动查找对应的 `{类型名}-methodology.md` 文件：
- 文件存在 → 加载方法论，使用其脚本格式/钩子模板/结构模板生成脚本
- 文件不存在 → 使用默认规则（通用口播脚本格式）生成脚本

特殊方法论（如三条置顶视频制作）在对应场景触发时加载：
- 三条置顶视频：营销战略地图（content-marketing-strategy-map）的W1置顶发布阶段 / content-script-writer检测到"置顶"关键词时

### 朋友圈文案（模式C）

模式C启动时：
1. 从IP档案读取行业 → 加载 `moments-industry-rules.md` 中对应行业的8维规则
2. 生成文案后 → 加载 `moments-compliance-checklist.md` 执行6步合规检查
3. IP档案的风格定位/红线清单/故事弹药库覆盖行业规则中的通用风格定位

## 公众号文章方法论（模式D）

本目录存放公众号文章脚本生成的方法库，供模式D（公众号文章脚本）使用。融合了 WeWrite 公众号写作的核心文案方法论并适配 IP 流程。

| 文件名 | 说明 |
|--------|------|
| `wechat-article-methodology.md` | 公众号文章完整方法论：文章任务书(brief)/主张清单(claims)/七种框架/内容增强四策略/编辑质量五维/标题摘要标签/长文去AI味/风格从IP档案校准 |

### 公众号文章（模式D）

模式D启动时：
1. 加载 `wechat-article-methodology.md` 获取完整方法论
2. 从IP档案读取风格定位/精神内核/故事弹药库/红线清单/核心客户作为 brief 与人格校准来源
3. 选题优先复用 content-topic-engine 的一鱼多吃建议（同一事件→公众号深度版）
4. 事实标注沿用 §8 的 🟢🟡🟠🔴 体系（与 claims 的 type/status 对应）
5. 长文强制过去AI味（qu-ai-wei，语体=内容/自媒体）
