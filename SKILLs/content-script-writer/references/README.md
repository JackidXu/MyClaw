## 方法论文件标准结构（9项）

每个方法论文件应包含以下9个部分：

1. **类型定义** — 这个类型是什么、核心特征
2. **适合性检查标准** — 什么内容适合用这个类型
3. **内容方向类型** — 这个类型适合讲什么方向的内容
4. **场景框架** — 拍摄场景/人物/画面框架
5. **素材分类维度** — 这个类型需要什么素材
6. **脚本格式** — 段落结构、时长分配、叙事节奏（脚本撰稿使用）
7. **钩子模板** — 这个类型的钩子风格和模板（脚本撰稿使用）
8. **信任型vs信息型配比** — 信任内容和信息内容的比例建议
9. **方法论校验规则** — 脚本是否符合该类型规范

## 使用方式

脚本撰稿 Skill（content-script-writer）在第一步确认视频类型后，自动查找对应的 `{类型名}-methodology.md` 文件：
- 文件存在 → 加载方法论，使用其脚本格式/钩子模板/结构模板生成脚本
- 文件不存在 → 使用默认规则（通用口播脚本格式）生成脚本

特殊方法论（如三条置顶视频制作）在对应场景触发时加载：
- 三条置顶视频：content-ip-operator的W1置顶发布阶段 / content-script-writer检测到"置顶"关键词时
