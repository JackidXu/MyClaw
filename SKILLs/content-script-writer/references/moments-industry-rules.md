# 朋友圈文案生成完整规则库

> 本文件是《18个行业朋友圈文案适配规则手册》的完整提取版，供 Skill 在生成文案时加载匹配。
> 每个行业包含全部8个维度，不做任何缩减。

## 概述：朋友圈好文案的通用法则

朋友圈的本质是**熟人社交场**，不是广告投放渠道。每一条内容都在回答朋友心里那个问题："这跟我有什么关系？"

### 六条铁律（生成时必须全部遵循）

1. **真实感优先**：像跟朋友聊天，不像在念广告词。口语化、有细节、有温度。"今天店里来了个客人"比"热烈欢迎各位顾客莅临"强一万倍。
2. **价值感驱动**：每条文案至少提供一种价值——有用（干货/攻略）、有趣（段子/反差）、有共鸣（情绪/故事）、有福利（优惠/稀缺）。纯广告 = 屏蔽催化剂。
3. **场景化表达**：别讲抽象概念，讲具体画面。不是"护肤很重要"，而是"加班到凌晨一点，卸完妆看到镜子里的脸，法令纹深得能夹蚊子"。
4. **互动钩子前置**：用提问、悬念、选择题等方式，在文案前两行埋下让人想评论的冲动。评论互动是朋友圈算法加权的重要信号。
5. **简洁有力**：3-5行是黄金长度，最多不超过8行。超过的用配图承载，文字负责"钩住"，图片负责"说服"。
6. **软性CTA**：给路径，不给命令。"需要的私信我"比"赶紧下单！"高级；"评论区聊聊"比"请转发"自然。

### 通用文案公式

```
痛点/场景钩子（1-2行） → 解决方案/价值点（1-2行） → 软性CTA（1行）
```

### 数据驱动原则

- 形容词不如数据可信："376位宝妈回购3次以上" > "很多客户好评"
- 第三方证言比自夸管用10倍：客户反馈截图 > 自己夸自己
- 含精准标签词的文案点击率增强70%
- 刷屏式推销（日发10条商品图）屏蔽率↑82%

## 一、情感行业

### 行业特点与受众画像
情感行业覆盖情感咨询、婚恋服务、心理疗愈、情感内容创作等。核心受众25-40岁女性为主，也有相当比例的男性。痛点：失恋后情绪崩溃、长期单身焦虑、婚姻沟通困境、原生家庭创伤、自我价值感低下。朋友圈行为特征：深夜活跃度高、容易共鸣转发、对"懂我"的内容极度敏感。他们不需要说教，需要的是**被看见、被理解、被接住**。

### 文案风格定位
**人设定位：深夜电台主播 / 比你大几岁的知心姐姐（哥哥）**
调性关键词：温暖、克制、共情、不说教。语气像一个经历过类似困境、已经走出来的人在分享。偶尔脆弱，时常坚定。用"我"和"你"，不用"大家"和"各位"。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 情感故事/案例 | 30% | 真实或改编的情感故事，引发共鸣 |
| 情绪共鸣金句 | 25% | 一句话戳中痛点，配一张氛围图 |
| 干货/认知 | 20% | 情绪管理方法、关系经营技巧 |
| 互动讨论 | 15% | 抛出情感话题，引导评论区分享 |
| 软性种草 | 10% | 课程/咨询/书籍的自然推荐 |

### 文案样式/模板
**模板一：场景共鸣型**
```
{深夜场景描述}，{一个戳心的细节}。
{一句反常识或共情的话}。
{一个温柔的收尾，不给答案，给陪伴感}。
```
**模板二：认知刷新型**
```
很多人以为{常见误区}，
其实{真相/反常识观点}。
{一句话解释为什么}。
觉得有用的，转给那个{特定身份}看看。
```
**模板三：故事型**
```
{人物身份}跟我聊了一个小时，说了一句让我沉默很久的话——
"{一句扎心的台词}"
{两三句背景交代}
{你的感受/启发}
{开放式收尾，留给读者自己想}
```

### 配图建议
- 首选：氛围感实拍图（雨天的窗、深夜的路灯、咖啡馆角落）
- 张数：1张最佳，多了分散注意力
- 风格：低饱和度、暖色调或冷色调统一，带胶片质感
- 避免：网图、表情包堆砌、花哨滤镜

### 发布频率与时间
- 频率：每天1-2条，不超过3条
- 黄金时段：21:30-23:30（深夜情绪高峰期）、7:30-8:30（早起通勤期）
- 周末：适当降低频率，发轻松治愈类内容

### 避坑指南
- 鸡汤说教："你要学会放下""一切都会好的"——空话没人爱听
- 过度负能量：天天发丧，会让人想屏蔽
- 暴露客户隐私：咨询案例必须脱敏
- 强行卖课："点击链接领取课程"——朋友圈不是落地页
- 价值观站队：别在男女对立话题上选边

### 示例文案
> 昨晚三点接到一个电话，那头哭得说不成句。她说："我删了他所有照片，但删不掉他给我设的闹钟。"我没说话，就听着。有些伤口不是要治好，是要先有人愿意看见它。

> 好的关系是什么样的？不是从来不吵架，是吵完了还愿意一起吃饭。不是什么都说，是不说的话对方也懂。你们觉得呢，评论区聊聊。

> 今天一个来访者说："我用了三年才明白，他不是不爱我，是不会爱。"区别在哪？不爱是选择，不会是能力。选择可以变，能力要学。

### 合规要求
🟢低危 — 注意脱敏案例，不暴露客户隐私。

## 二、美食行业

### 行业特点与受众画像
美食行业涵盖餐饮门店、私房烘焙、食品电商、美食内容创作等。受众极广，核心活跃人群18-45岁，男女皆宜。痛点：选择困难症（不知道吃什么）、踩雷恐惧（怕花了钱还难吃）、社交分享需求（好吃的东西要发朋友圈才有仪式感）、性价比敏感。美食是朋友圈天然的流量密码——**每个人都吃东西，每个人都是潜在受众**。关键是"好吃"这件事要说得让人流口水。

### 文案风格定位
**人设定位：懂吃的美食探险家 / 用心做食物的手艺人**
调性关键词：烟火气、馋人、真诚、有细节。不是美食评委在打分，是一个真的爱吃的人在分享发现。允许夸张的馋，但不允许虚假的夸。用感官描写代替形容词堆砌。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 新品/招牌种草 | 30% | 让人流口水的食物描写 |
| 幕后故事 | 20% | 食材来源、制作过程、开店故事 |
| 福利/优惠 | 20% | 限时活动、到店福利 |
| 互动/科普 | 15% | "你知道XX的正确吃法吗"类内容 |
| 客户证言 | 15% | 真实好评截图+故事 |

### 文案样式/模板
**模板一：感官诱惑型**
```
{食物名称}出锅的时候，{嗅觉描写}。
{口感描写，用比喻}。
{一个让人想马上吃的收尾}。
{限时/限量信息，制造紧迫感}。
```
**模板二：场景代入型**
```
{天气/场景}就该吃{食物}。
{一个具体的吃法描述}。
{价格或福利信息，自然带出}。
```
**模板三：幕后故事型**
```
凌晨4点去市场挑{食材}，老板说："又是你啊。"
{一个关于食材选择的细节}。
好食材不需要花里胡哨的做法，{简单做法描述}就够了。
今天{数量}份，卖完为止。
```

### 配图建议
- 首选：实物特写图，突出食物质感和色泽
- 张数：1-3张，1张特写+1张场景+1张细节
- 风格：自然光拍摄，暖色调，不要过度修图
- 技巧：拍食物的"动"——拉丝的芝士、冒热气的汤、流心的蛋黄
- 避免：菜单图直接发、过度滤镜、构图杂乱

### 发布频率与时间
- 频率：每天2-3条（饭点前1小时发效果最佳）
- 黄金时段：11:00-11:30（午餐前）、17:00-17:30（晚餐前）、21:00-22:00（夜宵档）
- 周末：可增加1条，大家更有时间探店

### 避坑指南
- 只发菜单图：没有文字描述的菜单图=广告，屏蔽率极高
- 过度PS：实物和图差太远，到店必差评
- 天天发优惠：优惠贬值，失去吸引力
- 忽略卫生细节：厨房脏乱的照片绝对不能发
- 抄袭文案：大众点评上的文案别直接搬

### 示例文案
> 试了17次才定下来的配方。牛肉选的是每天早上市场送来的黄牛腱子，炖足4小时，筷子一戳就散。汤底是牛骨熬的，不加一滴水。今天限量30碗，来晚了的明天请早。

> 下雨天就该吃火锅啊。毛肚七上八下，蘸碟里滚一圈，辣得鼻尖冒汗但还是停不下筷子。到店提我名字，送一份鲜鸭肠。（限今晚，就10份哈）

> 顾客发来的消息："你家那个提拉米苏，我男朋友不吃甜食的人吃了三块。"做甜品最开心的就是这种时刻。Mascarpone是进口的，手指饼干自己烤的，可可粉撒了三层。明天有6个名额，要的滴滴我。

### 合规要求
🟡一般 — 相对宽松，避免夸大食品安全宣称；禁用"最好吃""第一"等绝对词。

## 三、宠物行业

### 行业特点与受众画像
宠物行业覆盖宠物食品、用品、医疗、美容、摄影、寄养、训练、宠物内容创作等。核心受众20-35岁年轻人，女性占比约70%。把宠物当家人，消费意愿强，对宠物健康极度关注。痛点：挑食、皮肤病、分离焦虑、行为问题、医疗费用焦虑、外出无人照看。天然优势：**情感浓度高**——毛孩子本身就是最好的内容素材。竞争激烈，必须在"真实感"和"专业度"之间找到平衡。

### 文案风格定位
**人设定位：把宠物当孩子的铲屎官 / 懂宠物的暖心专业人士**
调性关键词：可爱、温暖、专业不端着、偶尔搞笑。可以用宠物"第一人称"口吻发圈，也可用铲屎官视角记录日常。涉及健康/医疗时切换到专业模式，但不丢温度。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 萌宠日常 | 30% | 可爱瞬间、搞笑行为，天然吸睛 |
| 干货科普 | 25% | 养宠知识、健康提醒、行为解读 |
| 产品种草 | 20% | 粮、零食、用品的真实使用体验 |
| 情感故事 | 15% | 宠物与主人的羁绊故事 |
| 互动/福利 | 10% | 征集粉丝宠物照片、抽奖 |

### 文案样式/模板
**模板一：第一人称卖萌型**
```
{宠物名字}今天{一个可爱/搞笑的行为}。
{铲屎官的反应}。
{自然带出产品/服务}。
{互动收尾，引发评论}。
```
**模板二：干货科普型**
```
{一个常见的养宠误区或问题}？
其实{真相}。
{简短解释}。
{一个可操作的建议}。
觉得有用，转给养{宠物种类}的朋友看看。
```
**模板三：情感故事型**
```
{一个具体的场景，宠物和主人的互动}。
{一句关于陪伴的感悟}。
{自然关联到服务/产品}。
它的一生很短，{一个行动号召}。
```

### 配图建议
- 首选：宠物实拍图，抓拍自然瞬间优于摆拍
- 张数：1-3张，1张萌照+1张细节+1张使用场景
- 风格：自然光、抓拍、不要过度滤镜
- 技巧：拍宠物的"眼神"——眼神最有感染力
- 避免：网图、过度修图把宠物修得不像它自己

### 发布频率与时间
- 频率：每天1-2条
- 黄金时段：12:00-13:00（午休刷手机）、20:00-22:00（晚上放松时段）
- 周末：适合发户外遛宠/宠物社交类内容

### 避坑指南
- 过度拟人化：偶尔可以，天天用宠物口吻发广告会腻
- 医疗信息不严谨：涉及用药/疾病，必须有专业背书
- 卖惨营销：用流浪动物悲惨画面卖产品，会引起反感
- 忽视品种差异：不同品种养护重点不同
- 发血腥图片：手术过程、伤口等需打码

### 示例文案
> 它用一生做你的跟屁虫，你用什么记住它的眼神？上周给一只15岁的金毛拍了组照片，主人全程在哭。狗子不太懂，一直在舔她的手。镜头能定格的瞬间，比记忆可靠。想给毛孩子留点什么的，私信我聊聊。

> 养猫的注意了！你家主子突然频繁舔毛、掉毛增多，别以为是换毛季。有可能是压力过大的表现。换了新环境、来了陌生人、甚至换了猫粮品牌都可能触发。试试给它一个安静的角落，放一件有你气味的旧衣服。

> 今天店里来了一只剃完毛觉得自己变丑了不肯出门的柯基。给它戴了条小领巾，瞬间昂首挺胸了。看来理发对狗子来说也很重要啊。预约美容的排到下周三了，急的可以私信加个塞。

### 合规要求
🟡一般 — 医疗信息须有专业背书，不要用卖惨营销。

## 四、职场行业

### 行业特点与受众画像
职场行业覆盖职业规划、求职辅导、职场技能培训、HR服务、企业管理咨询、职场内容创作等。核心受众22-35岁职场人，男女比例较均衡。痛点高度集中：升职加薪无门、跳槽纠结、领导关系处理、同事摩擦、职业倦怠、35岁焦虑、副业探索。传播逻辑是**替人说出不敢说的话**——打工人在公司里不能发的牢骚、不敢提的要求，你帮他说出来，他就转发。

### 文案风格定位
**人设定位：过来人前辈 / 毒舌但真心的职场导师**
调性关键词：犀利、真实、接地气、有分寸。不是成功学大师在灌鸡汤，是一个踩过坑、爬上来的前辈在掏心窝子。可以犀利但要有建设性；可以吐槽但别只有负能量。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 职场干货/方法论 | 30% | 可复用的技巧、框架、工具 |
| 真实案例/故事 | 25% | 身边人的职场故事，有启发 |
| 认知/观点 | 20% | 打破常见职场误区 |
| 互动讨论 | 15% | 抛出职场两难选择 |
| 软性种草 | 10% | 课程/咨询服务/书籍推荐 |

### 文案样式/模板
**模板一：反常识观点型**
```
{一个职场常见做法/观念}，可能是你{某个困境}的根源。
{一句话解释为什么}。
{一个替代方案}。
{互动收尾}。
```
**模板二：故事启发型**
```
{人物身份}跟我聊了聊，说了一个让我愣住的事——
{一个具体的职场场景/对话}
{你的分析/洞察}
{一句话总结，可以扎心但要准}
```
**模板三：清单型**
```
{某个场景}，记住这{数字}件事：
1. {要点一}
2. {要点二}
3. {要点三}
{一句话收尾}。觉得有用，收藏起来。
```

### 配图建议
- 首选：金句卡片（简洁排版+一句话）、思维导图、数据图表
- 张数：1张，职场内容不宜多图分散注意力
- 风格：简洁、专业、留白多
- 避免：成功学风格的花哨海报、网图、表情包

### 发布频率与时间
- 频率：每天1-2条
- 黄金时段：7:30-8:30（通勤路上）、12:00-13:00（午休）、20:00-21:00（下班后复盘期）
- 周末：降低频率，适合轻松类职场内容

### 避坑指南
- 成功学腔调："只要你足够努力，全世界都会为你让路"——假且空
- 制造焦虑："30岁还没做到管理层你就完了"——焦虑营销容易引反感
- 点名批评具体公司：法律风险+掉粉
- 只吐槽不给方案：负能量堆砌，没有建设性
- 泄露公司机密：即使脱敏也可能被识别

### 示例文案
> 一个做了8年HR的朋友说了句话，我记了很久："面试时问'你有什么缺点'，不是真的想知道你的缺点，是看你会不会真诚地审视自己。"说"太追求完美"的，基本凉了。说一个真实缺点+你怎么在改的，反而加分。

> 离职前的最后一个工作日，交接文档我写了40页。同事说我太较真了。但职场这东西，你的口碑不是在职时建立的，是离开后别人怎么提你。好聚好散，比撕破脸值钱多了。

调性关键词：自由、浪漫、有画面感、实用。不是导游在背解说词，是一个真的热爱旅行的人在分享路上的发现。可以感性，但关键信息（路线/价格/注意事项）要清晰。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 目的地种草 | 30% | 小众/热门目的地的画面感描述 |
| 攻略/干货 | 25% | 路线规划、省钱技巧、避坑指南 |
| 旅行故事 | 20% | 路上的人和事，有温度 |
| 优惠/套餐 | 15% | 限时优惠、定制路线 |
| 互动/讨论 | 10% | "你最想去哪""投票选目的地" |

### 文案样式/模板
**模板一：画面种草型**
```
{目的地}的{季节/时间}，{一个画面感描述}。
{一个独特的体验细节}。
{实用信息：最佳时间/交通/预算}。
{软性CTA}。
```
**模板二：攻略干货型**
```
{目的地}{天数}天攻略，预算{金额}。
Day1：{行程简述}
Day2：{行程简述}
Day3：{行程简述}
{一个省钱/避坑小贴士}。
收藏起来，{季节}去刚好。
```
**模板三：旅行故事型**
```
在{地点}遇到{人物/事件}。
{一段简短的对话或场景}。
{你的感受/感悟}。
{自然关联到目的地推荐/服务}。
```

### 配图建议
- 首选：风景实拍图、人文抓拍、氛围感照片
- 张数：3-6张，1张标志性风景+2-3张细节/人文+1张美食
- 风格：自然光、有构图意识、色彩统一
- 技巧：拍"人景结合"——有人物的风景照比纯风景更有代入感
- 避免：过度滤镜、网图、游客照式构图

### 发布频率与时间
- 频率：每天1-2条
- 黄金时段：12:00-13:00（午休escape时段）、21:00-22:00（睡前规划期）
- 节假日前：提前2-3周开始种草目的地

### 避坑指南
- 只发风景无信息：好看但没用，看完就划走
- 照搬官方宣传语：毫无个人视角
- 过度修图：实地差距大=差评
- 忽视安全提示：涉及户外/探险，必须提醒风险
- 发布未确认的航班/价格信息：变动频繁，误导客户

### 示例文案
> 三月的大理，风里带着苍山的雪味。租辆小电驴环洱海，路过喜洲吃个粑粑，在双廊发呆到日落。不用赶行程，大理教会你的就是慢。3天2晚自由行套餐1680起，含住宿+租车。清明假期还有少量名额。

> 分享一个被问最多的路线——川西小环线5天。Day1成都-四姑娘山 Day2四姑娘山-丹巴藏寨 Day3丹巴-塔公草原-新都桥 Day4新都桥-康定-成都。高反严重的别硬撑，提前一周吃红景天。想去的私信我发详细路书。

> 在京都遇到一家开了40年的亲子丼小店。老板娘82岁了，一个人又做饭又端盘子。我用蹩脚日语问她累不累，她笑着说："做了一辈子，停不下来。"旅行最珍贵的不是景点，是这些不期而遇的人和故事。

### 合规要求
🟢低危 — 注意安全提示和价格信息准确性。

## 十、母婴行业

### 行业特点与受众画像
母婴行业覆盖婴幼儿食品、用品、早教、孕产服务、母婴内容创作等。核心受众25-35岁宝妈（及部分宝爸），消费力强，对安全性和品质极度敏感。痛点集中在：选品焦虑（怕不安全/不合适）、育儿知识焦虑（信息过载不知信谁）、时间精力不足、情绪波动大（产后抑郁等）。朋友圈营销核心是**信任前置**——宝妈只信两种人：有经验的过来人、有专业背书的内行人。

### 文案风格定位
**人设定位：经验丰富的过来人宝妈 / 懂儿科的专业育儿顾问**
调性关键词：温暖、靠谱、共情、不说教。不是专家在高台上讲课，是一个刚经历过同样阶段的人在分享经验。允许脆弱，允许吐槽，但始终传递"我懂你，我能帮你"。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 育儿干货/科普 | 30% | 按月龄分段的内容最有用 |
| 产品种草/测评 | 25% | 真实使用体验，FABE法则 |
| 育儿日常/故事 | 20% | 引发共鸣的日常碎片 |
| 互动/答疑 | 15% | 宝妈互助、问题征集 |
| 福利/活动 | 10% | 团购、试用、福利 |

### 文案样式/模板
**模板一：FABE法则种草型**
```
特点：{产品特点}
优势：{比其他产品好在哪}
利益：{对宝宝/妈妈有什么好处}
证据：{数据/认证/客户反馈}
{软性CTA}。
```
**模板二：场景痛点型**
```
{宝宝月龄/阶段}的{常见问题}。
{一个具体的场景描述}。
{产品/方法如何解决}。
{客户反馈/数据}。
需要的宝妈滴滴我。
```
**模板三：经验分享型**
```
{育儿场景}，我踩过的坑你们别踩了。
{错误做法}。
{正确做法+原因}。
{一个实用小贴士}。

```

### 配图建议
- 首选：宝宝使用产品实拍、真实生活场景
- 张数：2-3张
- 风格：温馨、自然、真实
- 技巧：拍"使用中的状态"——宝宝用产品的真实反应
- 避免：宝宝隐私部位露出、过度摆拍、网图

### 发布频率与时间
- 频率：每天1-2条
- 黄金时段：9:00-11:00（宝宝睡后宝妈刷手机）、20:00-22:00（晚间育儿话题高峰）
- 按月龄分组：6-12个月推辅食相关，3岁+推入园/绘本相关

### 避坑指南
- 制造育儿焦虑："不做早教孩子就落后了"——焦虑营销失灵
- 推荐三无产品：母婴产品的安全性是底线
- 晒宝宝隐私部位：即使是无意也不行
- 医疗建议不严谨：涉及用药/疾病必须加"遵医嘱"声明
- 按月龄推错内容：给6个月宝妈推3岁内容，精准度差

### 示例文案
> 春雨一来，我家娃的湿疹又犯了。还好备了那瓶霜，涂了两次就消红了。不含激素，新生儿也能用，我家从出生用到现在。上次团了200多瓶，回购率最高的单品之一。需要的宝妈滴滴我。

> 6个月开始加辅食，记住一个原则：由稀到稠，由少到多，一种吃3天不过敏再加新的。第一口辅食选强化铁米粉，不是自己磨的米糊。很多妈妈觉得自己磨的更健康，其实铁含量根本不够。6~12个月的辅食食谱我整理了一份，需要的评论区扣1。

> 昨天带娃去打疫苗，排队的时候旁边妈妈说："我都不知道该给娃买什么绘本。"3岁前的宝宝不用买太多，这5套就够了——《蹦》《点点点》《好饿的毛毛虫》《小熊宝宝》《我爸爸》。亲测每套都被翻烂了，闭眼入不踩雷。

### 合规要求
🟠中危 — 需遵医嘱声明；禁用"让宝宝更聪明/提高智力"。

## 十一、三农行业

### 行业特点与受众画像
三农行业覆盖农产品种植/销售、乡村特产、农资农技、乡村内容创作等。核心受众28-50岁城市消费者（买方）+ 农村生产者（卖方/合作方）。城市消费者痛点：食品安全焦虑、想买正宗土货但怕假货、对田园生活的向往。天然优势是**真实感和溯源感**——从田间到餐桌，过程本身就是最好的内容。

### 文案风格定位
**人设定位：守着土地的老实农人 / 懂农业的新农人**
调性关键词：朴实、真诚、有泥土味、不端着。不是品牌方在做营销，是一个真的种地/养山/做特产的人在跟你分享劳动成果。用大白话，讲真实的故事。偶尔笨拙的文笔反而更有信任感。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 田间/生产实拍 | 30% | 种植/采摘/制作过程，溯源感 |
| 产品种草 | 25% | 季节性农产品推荐 |
| 乡村生活/故事 | 20% | 乡村日常，治愈感 |
| 科普/干货 | 15% | 怎么挑选/保存/烹饪 |
| 预售/福利 | 10% | 时令产品预售、老客福利 |

### 文案样式/模板
**模板一：时令预售型**
```
{节气}一到，我家的{产品}就开始{生长状态}。
去年的老客都知道，这口鲜一年就等这一遭。
{一个关于品质的细节}。
预售已开，先定先发货。
```
**模板二：溯源故事型**
```
{地点}的{海拔/土壤/气候}，种{产品}再合适不过。
{一个种植/采摘的细节}。
不打{农药/催熟剂}，就等它自然熟。
今年{产量}斤，卖完等明年。
```
**模板三：场景种草型**
```
{产品}刚从地里拔出来，{新鲜度描述}。
{一个烹饪/食用建议}。
{价格+物流信息}。
{软性CTA}。
```

### 配图建议
- 首选：田间实拍、采摘过程、产品新鲜度特写
- 张数：3-6张，1张产地全景+2张过程+1张产品特写
- 风格：自然光、不修图、真实感第一
- 技巧：拍"新鲜证据"——带泥的根、挂露水的叶、掰开的截面
- 避免：精修商品图、假背景、过度包装

### 发布频率与时间
- 频率：每天1-2条
- 黄金时段：6:00-7:00（早起田间实拍）、12:00-13:00（午休下单时段）、20:00-21:00
- 时令节点：采摘前1-2周开始预热预售

### 避坑指南
- 过度包装文案：朴实是三农内容的灵魂，写太文艺反而假
- 产品与图片不符：收到货发现品质差，口碑崩塌
- 忽视物流时效：生鲜产品物流慢=烂果=退款
- 夸大功效："吃了治百病"——违规且不可信
- 只发卖货不讲故事：没有过程内容，信任感不足

### 示例文案
> 雨水一到，我家的春茶就开始冒芽了。海拔800米，云雾多，日照短，茶树长得慢但味道足。早上5点上山采的，下午就炒好。去年的老客都知道，这口鲜一年就等这一遭。预售已开，先定先发货。

> 今天在地里挖红薯，一锄头下去挖出个4斤的。掰开里面金黄金黄的，冒着热气。今年种的西瓜薯，甜得很，蒸着吃烤着吃都行。10斤装39.9包邮，今天发顺丰。

> 朋友圈被问爆的土鸡蛋，补货了。我妈养的50只走地鸡，吃的是玉米和菜叶子。每天就产30来个，攒三天发一次。收到坏蛋包赔，放心买。老规矩，老客优先。

### 合规要求
🟡一般 — 禁用"包治百病/神效/野生抗癌"。

## 十二、文化行业

### 行业特点与受众画像
文化行业覆盖书店/图书馆、博物馆/美术馆、文化活动/展览、出版/作家、文化内容创作等。核心受众25-45岁城市知识群体，消费力中高，对精神文化需求强。痛点：信息碎片化带来的知识焦虑、文化消费选择困难、想提升但没时间/没方向、孤独感（想找到同频的人）。朋友圈营销核心是**提供精神价值**——内容本身就是产品，好看/有深度/有启发的文案自带传播力。

### 文案风格定位
**人设定位：有品位的读书人 / 温暖的文化策展人**
调性关键词：文雅但不掉书袋、有温度、有见识、克制。不是学术报告，是文化爱好者在分享发现。可以引用、可以感悟，但不能掉书袋到让人读不下去。始终站在"普通读者"视角。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 书籍/展览推荐 | 30% | 有个人视角的推荐，不是简介搬运 |
| 文化观点/思考 | 25% | 对热点/现象的文化视角解读 |
| 文化故事/人物 | 20% | 作家/艺术家/历史人物的故事 |
| 活动预告 | 15% | 讲座/读书会/展览信息 |
| 互动/讨论 | 10% | 读书话题、观点投票 |

### 文案样式/模板
**模板一：书籍推荐型**
```
最近读完《{书名}》，{一句最打动你的话}。
{为什么推荐，2-3句你的感受}。
适合{什么人}读。
{一句金句摘录}。
```
**模板二：展览/活动种草型**
```
{展览/活动名称}，{一个让你心动的细节}。
{2-3句背景/亮点介绍}。
{实用信息：时间/地点/票价}。
{一个私人建议}。
```
**模板三：文化思考型**
```
{一个文化现象/热点}。
{你的思考，1-2句}。
{一个历史/文学参照}。
{开放式收尾}。
```

### 配图建议
- 首选：书籍实拍、展览现场实拍、金句卡片
- 张数：1-3张
- 风格：文艺、简洁、有留白
- 技巧：拍"阅读中的状态"——翻开的书页、标注的笔记
- 避免：网图、过度设计、花哨排版

### 发布频率与时间
- 频率：每天1条，不超过2条
- 黄金时段：7:30-8:30（晨间阅读时段）、21:00-23:00（深夜阅读/思考时段）
- 周末：适合发展览/活动类内容

### 避坑指南
- 掉书袋：大段引用、生僻词汇，读者直接划走
- 无个人观点：只搬运书籍简介/展览介绍，没有自己的感受
- 故作高深：用复杂的方式说简单的事
- 蹭热点牵强：硬把文化跟不相关的热点扯上关系
- 活动信息不全：时间地点票价漏一个都影响转化

### 示例文案
> 今天读完《秋园》，最后一段看哭了。一个普通女人的一生，被她女儿用最朴素的文字写出来，比任何宏大叙事都震撼。"她活过，她挣扎过，她不被人记得。"适合每一个想了解母亲的人读。

> 周末去看了个展，被一幅画钉在原地站了十分钟。那是一幅画窗外的雨，技法不算复杂，但雨打在玻璃上的那个瞬间，让人想起小时候趴在窗台看雨的下午。展期到月底，XX美术馆，门票30。建议工作日去，人少能多站一会儿。

> 朋友说他最近读不进去书了。我说那就别读了，去看一部好电影，听一张老专辑，去公园坐一下午。文化不只是书本，是所有让精神喘口气的东西。你们最近在"读"什么？评论区推一个。

### 合规要求
🟢低危 — 基本不踩广告法，重点防限流行为。

## 十三、汽车行业

### 行业特点与受众画像
汽车行业覆盖汽车销售（4S店/二手车）、汽车维修保养、汽车用品、汽车内容创作等。核心受众25-50岁男性为主（新能源/城市代步车女性比例上升）。痛点高度集中：怕被坑（价格不透明/维修猫腻）、选车纠结、养车成本焦虑、保值率担忧、售后服务质量。高客单价、低频次消费，朋友圈营销核心不是"卖车"，而是**持续建立专业信任**，让客户在需要时第一个想到你。

### 文案风格定位
**人设定位：懂车的实在人 / 不忽悠的汽修老炮**
调性关键词：专业、实在、不忽悠、有温度。不是销售在背话术，是一个真的懂车的人在帮你避坑。可以聊技术参数，但要用车主听得懂的话。用"帮你省钱"的心态而不是"赚你钱"的心态写文案。

### 推荐内容类型
| 内容类型 | 占比 | 说明 |
|---------|------|------|
| 选车/用车干货 | 30% | 对比评测、用车技巧、保养知识 |
| 车型推荐/种草 | 20% | 真实试驾体验、适合人群分析 |
| 保养/维修科普 | 20% | 常见误区、避坑指南 |
| 客户案例/故事 | 15% | 帮客户选车/解决问题的真实故事 |
| 优惠/活动 | 15% | 保养套餐、购车福利 |

### 文案样式/模板
**模板一：选车对比型**
```
{车型A} vs {车型B}，预算{金额}怎么选？
{一个核心区别}。
{适合A的人群} / {适合B的人群}。
{一个私人建议}。
纠结的把需求发给我，帮你分析。
```
**模板二：保养干货型**
```
{里程数/时间}该做{保养项目}了。
{一个常见误区}。
{正确做法+为什么}。
{费用参考}。
```

> "年化收益率"和"年收益率"差一个字，差很多钱。年收益率就是一年赚多少，简单直接。年化收益率是把任意期限的收益折算成一年的——7天赚1%年化就是52%，但你实际只赚了1%。看产品先看是"年化"还是"年"，再看期限。转给买理财的朋友看看。

> 降息了，很多人问房贷要不要提前还。说句实在话——如果你的房贷利率高于4%，手里有闲钱且没有更好的投资渠道，可以还。如果利率低于3.5%，不如把钱留着做稳健理财。具体情况因人而异，把你的贷款余额和利率发我，帮你算算。以上不构成投资建议哈。

> 一个32岁程序员来找我做规划。年薪40万，存款80万，全放银行活期。我说你这不是理财，是让通胀帮你花钱。给他做了个方案——3万应急金放货基，50万配置稳健理财，27万配置保障型保险。一年后他跟我说："终于不用每天盯着余额焦虑了。"理财不是让你暴富，是让你睡得着觉。

## 十八、法律行业

### 行业特点与受众画像
法律行业覆盖律师事务所、法律咨询、企业法务服务、法律内容创作等。核心受众28-55岁，分两类：企业客户（老板/高管，关注合同/劳动/知识产权）和个人客户（关注婚姻/继承/债务/维权）。痛点：怕请律师花冤枉钱、不知道什么时候该找律师、法律术语看不懂、对律师信任度低、怕信息泄露。朋友圈营销核心是**用案例建立专业形象+用科普降低咨询门槛**——让潜在客户觉得"这个律师靠谱，而且我能跟他正常沟通"。

### 文案风格定位
**人设定位：说人话的好律师 / 懂商业的法律顾问**
调性关键词：专业、严谨、通俗、有温度。不是法官在写判决书，是一个靠谱的律师在跟你聊天。可以聊法条、聊案例，但必须翻译成大白话。不煽动诉讼，而是帮人理性维权。

### 推荐内容类型

### 避坑指南
- 线上给具体法律意见：朋友圈只能做普法，不能做具体案件咨询

- 贬低同行："别的律师都不行"——格局小
- 对未决案件下结论：司法未定性的事件不能妄下定论

### 示例文案
> 借钱给朋友，没有借条怎么办？先别慌。微信聊天记录、转账记录、通话录音都能当证据。但注意三点——1.聊天记录要能看出双方身份和借款金额 2.转账备注写"借款" 3.录音要自然，不能诱导。当然，最好还是写个借条。借出去的是钱，收不回来的是关系。

> 今天开庭，一个劳动纠纷。员工被辞退，公司说"绩效不达标"。但拿不出考核标准和签字记录。结果：公司败诉，赔偿N+1。给老板们提个醒——辞退员工不能拍脑袋，程序和证据一个都不能少。有劳动合规问题的，可以聊聊。

> 离婚时对方转移财产怎么办？法律给了你一把武器——财产保全。如果你有证据证明对方在转移存款/卖房/转股权，可以在起诉同时申请财产保全，冻结对方的财产。但动作要快，等钱转走了再追就难了。具体情况建议尽早找律师面谈。（以上为普法内容，不构成具体法律意见）
