# 公域短视频 & 直播 时段指南（public-video-timing）

本文件给「公域短视频发布时段」与「直播时段/时长」提供**按行业 / 目标受众**的建议。由 `content-marketing-strategy-map`（营销战略地图）在生成周计划与「整周时间规划图」时引用；`content-script-writer` 在脚本层按账号数据做最终微调。

四柱分类（立人/立信/立言/立势）与本文无关，见 `content-marketing-strategy-map/references/four-pillars.md`。

---

## 通用原则

- **时段优先级**：目标客户活跃时间 > 平台算法推荐 > 主播个人状态。
- **视频/直播 ≠ 朋友圈**：短视频与直播需要完整注意力，优先选「晚间完整时段」，次选午休；朋友圈可碎片化穿插。
- **直播时长**：B2B / 专业服务 60–90 分钟；C端 / 泛流量可 90–120 分钟。太短讲不透，太长掉人。
- **频率纪律**：每天公域短视频 ≤ 3 条、直播 ≤ 1 场；与朋友圈合计仍遵守各 skill 的发布纪律（间隔、合规声明等）。
- **直播预告**：直播前 1 周起，每天 1 条不同角度预告（见 content-moments-planner Phase 3）。

## 行业适配

### B端专业服务 / 财经投资
目标受众：企业决策者、专业人士、有资产 / 招聘需求的人。活跃：通勤 7:30–8:30、午休 12:00–13:00、下班后 20:00–21:30。
- 公域短视频黄金时段：主 **20:00–21:00**（下班后复盘 / 放松，深度内容易被看完）、次 **12:00–13:00**（午休学习）。
- 直播时段与时长：工作日 **20:00–21:30**，时长 **60–90 分钟**；招人 / 业务专场建议 60–90 分钟。
- 注：财经类每条加合规声明（见 content-quality-guard）。

### B端制造业 / 供应链
目标受众：企业采购 / 厂长 / 工程师。活跃：开工前 8:00–9:00、午休 12:00–13:00、下班后 19:00–21:00。
- 公域短视频黄金时段：主 19:00–21:00、次 12:00–13:00。
- 直播时段与时长：工作日 19:30–21:00，时长 60–90 分钟（工厂探访 / 实测类可做更长）。

### C端高客单服务
目标受众：高净值个人 / 家庭决策者。活跃：午休 12:00–13:00、晚间 20:00–22:00、周末白天。
- 公域短视频黄金时段：主 20:00–22:00、次 12:00–13:00。
- 直播时段与时长：晚间 20:00–21:30 或 周末 15:00–16:30，时长 60–90 分钟。

### 职场 / 教育
