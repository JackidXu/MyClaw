# Compliance Check Checklist

After generating copy, run through this 6-step check before delivering to user.

## Step 1: Length Check (Anti-folding)

- Pure text MUST NOT exceed 5 lines; put overflow in image captions
- Images: 1-3 best; 9-grid gets flagged as marketing

## Step 2: Frequency Check (Anti-shadowban)

- Max 5 posts/day total
- Max 3 posts per 30 minutes
- Space posts at least 15 minutes apart

## Step 3: Duplicate Check (Anti-dedup)

- Body text must differ >30% from previous post
- Don't reuse same image consecutively
- Don't use same template structure 3 posts in a row

## Step 4: Universal Banned Words

| Category | Banned | Safe Alternative |
|----------|--------|-----------------|
| Absolute claims | 最好、第一、唯一、顶级、首选、全网最低 | 更推荐、很多客户选、口碑款 |
| National-level | 国家级、世界级、全国首发 | 通过XX认证(需真实) |
| Extreme promises | 100%、绝对、永不、永久、零风险 | 大多数客户反馈、实测有效 |
| Induced interaction | 转发、集赞、截图发我、不转不是XX | 评论区聊聊、收藏起来 |
| Traffic diversion | 加微信、加好友、扫码加我、立刻下单 | 私信我、想了解的聊聊 |

## Step 5: Industry-specific Banned Words

| Industry | Banned | Safe Alternative |
|----------|--------|-----------------|
| 医疗健康 | 治愈、根治、包好、一次见效 | 帮助改善、配合调理、定期复查 |
| 美业/医美 | 永久脱毛、一次祛斑、永不反弹 | 视觉改善、持续护理、建议按疗程 |
| 教育 | 保过、保提分、包录取 | 往期通过率高、学员反馈有效 |
| 财经 | 保本、稳赚不赔、年化XX%、零风险 | 历史业绩、仅供参考、不构成投资建议 |
| 保健品 | 治疗、预防疾病、增强免疫力 | 补充营养、辅助调理(需蓝帽子) |
| 母婴 | 让宝宝更聪明、提高智力 | 助力成长、陪伴探索 |
| 法律 | 包赢、一定胜诉、保证结果 | 全力争取、依法维权、建议面谈 |
| 房地产 | 必涨、绝不贬值 | 位置优越、配套完善、欢迎实地考察 |
| 三农 | 包治百病、神效、野生抗癌 | 地道风味、传统种植、自然生长 |

## Step 6: Behavior Check (Hidden shadowban triggers)

| Behavior | Risk | Fix |
|----------|------|-----|
| Image with lots of text + logo + price | Flagged as ad by image recognition | Use lifestyle photos, minimize text stickers |
| External links in post | Traffic diversion detection | No links; guide to DM |
| WeChat ID / QR code in post | Same as above | Say "私信我" not "加我微信" |
| @ many friends | Marketing bot behavior | Max 3 @s |
| Same content from multiple accounts simultaneously | Matrix marketing detection | Stagger timing, differentiate copy |

## Required Disclaimers (by industry)

| Industry | Required Disclaimer |
|----------|-------------------|
| 医疗健康 | "牙齿/身体不适请及时就医" or "以上为健康科普" |
| 财经 | "以上仅为个人观点，不构成投资建议" |
| 法律 | "以上为普法内容，不构成具体法律意见" |
| 教育 | Avoid "保过/包录取" entirely |

## Quick Self-check Mantra

> 六行以内不折叠，五条封顶不刷屏。
> 复制粘贴别偷懒，最好第一不能写。
> 根治保过是大坑，导流链接别乱放。
> 配图要像真人发，写完先查再发送。
