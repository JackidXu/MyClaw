# 旁白视频方法论

> 来源：曾定《把选择理由拍出来》课程资料
> 文档状态：✅ 已完成
> 适用业务：B2B / 高客单专业服务 / 抽象购买理由型内容

---

## 1. 类型定义

**旁白视频**：以旁白文案为核心、画面为证据的视频形式。

### 核心公式

```
旁白视频 = 选择结论 + 理由链 + 证据画面
```

- **选择结论**：看完这条视频，客户应该相信的"一个"结论
- **理由链**：5-7个按次第顺序排列的理由，全部服务于同一个结论
- **证据画面**：每一句旁白都有对应的画面作证

### 本质定位

> **不是句句卖货，而是句句都为选择服务。**
> 旁白提出理由，画面交付证据。

### 5个核心优势

| # | 优势 | 说明 |
|---|------|------|
| 1 | 不要求老板全程面对镜头 | 适合不愿意出镜的老板 |
| 2 | 可以使用大量真实工作和产品画面 | 拍摄成本低、素材复用高 |
| 3 | 文案逻辑容易提前设计 | 脚本可一次成型 |
| 4 | 能同时承载人物、产品、场景和案例 | 信息密度大 |
| 5 | 适合把抽象购买理由变成可感知的内容 | 把"专业""可靠"等抽象词落地 |

## 2. 适合性检查标准

### 适合使用旁白视频的场景

✅ **B2B业务** —— 人本身就是购买理由，先建立人物信任
✅ **高客单专业服务** —— 决策成本高，需要完整理由链
✅ **抽象购买理由型产品** —— 价值难以直接展示（如咨询、法律、财税）
✅ **需要承载人物+产品+案例+场景的复合内容**
✅ **客户决策周期长** —— 一次视频需要讲透多个理由

### 不适合的场景

❌ 强情绪驱动的快消品（如饮料、食品）—— 用场景切片或剧情演绎
❌ 强悬念/反转的叙事 —— 用剧情演绎
❌ 强真实感的日常分享 —— 用VLOG
❌ 需要即兴互动的访谈 —— 用嘉宾访谈/人物对谈

## 3. 内容方向类型

旁白视频分为两类子方向，底层方法相同，对象不同：

### 类型A：购买理由型（让客户相信产品）

> 适合消费产品、门店、标准化服务

| 维度 | 内容 |
|------|------|
| 客户要相信 | 产品或服务 |
| 主要内容 | 收益、差异、品质、场景 |
| 主要证据 | 产品、现场、数据、客户体验 |

### 类型B：信任理由型（让客户相信人）

> 适合B2B、高客单、专业服务

| 维度 | 内容 |
|------|------|
| 客户要相信 | 人 |
| 主要内容 | 经历、结果、方法、标准 |
| 主要证据 | 项目、行动、结果、第三方评价 |

### 底层统一

> 两类视频最终都在回答同一个问题：**客户为什么应该选择你？**

## 4. 场景框架

### 声音层 × 画面层

```
声音层（旁白文案）：希望客户相信什么
画面层（视频画面）：凭什么证明这是真的
```

两层必须**严丝合缝**——旁白提出一个理由，画面立刻提供证据。

### 三步工作流

#### 第一步：确定一个选择结论

先不写文案，先填一句话：

> **"看完这条视频，我希望客户相信：______________"**

示例：
- "这家游泳馆虽然投入高，但体验和品质值得"
- "这个老板真正重视产品安全"
- "这个顾问有实战经验和完整方法"
- "家企业的交付能力比同行更稳定"

#### 第二步：把理由排列成链（5-7个）

**筛选标准**（5项必过）：

| # | 标准 | 说明 |
|---|------|------|
| 1 | 对客户重要 | 客户真正在意的点 |
| 2 | 与核心结论有关 | 服务于同一个选择结论 |
| 3 | 有一定差异 | 不是同行都在说的套话 |
| 4 | 能够被证明 | 有事实/数据/画面可作证 |
| 5 | 可以通过画面呈现 | 不只是抽象描述 |

#### 第三步：句画合一

每写一句旁白，都问：

> **"这句话出现时，观众应该看到什么？"**

| 旁白 | 画面 |
|------|------|
| 负责提出理由 | 负责证明理由 |

**如果一句话没有画面**，三个处理方案：
1. 补拍证据
2. 换一个能够呈现的理由
3. 降低表达强度（去掉过度夸大）

## 5. 素材分类维度

### 购买理由型（产品信任）—— 5种理由来源

| # | 理由类型 | 说明 | 典型问法 |
|---|---------|------|---------|
| 1 | 客户收益 | 客户能获得什么 | "客户买单后能得到什么？" |
| 2 | 产品差异 | 为什么不是普通同行 | "跟同行最大的区别在哪？" |
| 3 | 品质与风险 | 为什么更安心 | "凭什么说品质更好？" |
| 4 | 真实证据 | 凭什么相信 | "有什么第三方可核实的证据？" |
| 5 | 人群与场景 | 谁适合、什么时候需要 | "谁适合？什么场景下需要？" |

> **不是每条视频都要写满五种，只选择最能证明核心结论的理由。**

### 信任理由型（人物信任）—— 6种理由来源

| # | 理由类型 | 说明 |
|---|---------|------|
| 1 | 长期经历 | 做了多久、经历过什么 |
| 2 | 代表项目 | 做过哪些相关的事 |
| 3 | 结果证据 | 具体做成过什么 |
| 4 | 方法判断 | 如何理解和解决问题 |
| 5 | 做事标准 | 如何交付、坚持什么 |
| 6 | 第三方评价 | 客户和行业如何评价 |

> **只有与能力、方法、标准和可靠性相关的人设，才会成为选择理由。** 不是所有生活故事都能促进B2B购买。

### 人物信任链 —— 7步顺序

```
身份反差 → 经历密度 → 代表项目 → 能力来源 → 方法与标准 → 第三方背书 → 人物记忆
```

**关键洞察**：
- **人设信任视频不是让客户觉得你"很有故事"，而是让客户判断你是否值得托付**
- 经历不是履历清单，要说明这些经历最终形成了什么能力
- 客户不只关心你做过什么，还会判断这些结果是否与你今天提供的服务有关
- 方法论是B2B信任的重要组成
- 标准让客户感受到交付确定性
- 第三方评价补上最后一层信任

## 6. 脚本格式

### 选择结论模板

**产品型**：
> "我的 ______ 值得选择，因为 ______ 。"

**人物型**：
> "我是一个 ______ 的人，拥有 ______ 能力，值得把 ______ 交给我。"

> 注：这句话是写给自己看的策略句，不一定直接出现在最终旁白中。

### 证据画面表格（生成阶段使用）

| 旁白句子 | 这句话提供什么理由 | 用什么画面证明 |
|---------|-------------------|---------------|
| （一句旁白） | （理由类型+具体指向） | （具体画面/证据） |

> **不要求现在完成详细分镜，只需要判断这句话是否能被真实呈现。**

### 段落组织规则

1. **开头先放最有吸引力的理由** —— 5-7个理由中第一个最有钩子价值的
2. **多用数字、动作、场景、结果和选择** —— 避免抽象形容词
3. **让理由之间形成自然推进** —— 不要跳跃
4. **每句话只承担一个主要任务** —— 不堆砌
5. **结尾留下行动入口或人物记忆** —— 不是单纯升华
6. **少用"专业、领先、优质、靠谱"等抽象形容词** —— 必须有证据

## 7. 钩子模板

### 旁白视频的钩子特征

旁白视频的钩子**不是悬念式钩子**，而是**最有冲击力的理由句**——因为观众需要在前3秒判断"这条视频值不值得看"，而理由链中"反差最大、最具体"的点最有钩子价值。

### 钩子选择策略

从5-7个理由中选出**最满足钩子标准的1个**作为开头：

| 钩子标准 | 说明 |
|---------|------|
| 数字冲击 | 用了具体数字（800万/3年/0投诉） |
| 反差对比 | 行业都在做A，你做B |
| 反直觉 | 看似不利的条件，反而是优势 |
| 场景画面感 | 观众能立刻"看到"画面 |

### 钩子案例（来自两个案例）

**案例一（游泳馆）**：
> "我在广州珠江新城，花一套房子的钱，开了家能游泳，还能学潜水的游泳馆！"

这一句同时完成四件事：锁定目标城市、制造高投入预期、展示复合体验差异、留下悬念。

**案例二（曾定）**：
> "好多老板第一次见我，都以为是个实习生。但我已经在新媒体营销这个领域，实打实干7年了。"

钩子是"身份反差"——年轻外表 + 7年实战经历。

### 不建议的开头

❌ "今天我们来聊聊..."
❌ "大家好，我是XX..."
❌ "你有没有遇到过这样的问题..."
❌ 抽象概念起手（"在这个时代..."）

## 8. 信任/信息配比

### 产品型视频（购买理由型）

| 维度 | 配比建议 |
|------|---------|
| 理由数量 | 5-7个（不少于5个，否则理由链单薄） |
| 客户收益类理由 | 1-2个 |
| 产品差异类理由 | 1-2个 |
| 真实证据类理由 | 1-2个（必须有，否则变成自夸） |
| 人群场景类理由 | 0-1个（放结尾作为行动指引） |
| 钩子占比 | 前5秒（约前2句）必须有冲击力 |
| 证据画面占比 | 每句旁白必须有画面配对，比例为1:1 |

### 人物型视频（信任理由型）

| 维度 | 配比建议 |
|------|---------|
| 理由数量 | 5-7个 |
| 长期经历类 | 0-1个（多变成履历清单） |
| 代表项目类 | 1-2个 |
| 结果证据类 | 1-2个 |
| 方法判断类 | 1-2个（B2B信任核心） |
| 做事标准类 | 0-1个 |
| 第三方评价类 | 1个（必放在靠后位置作为压轴） |
| 身份反差 | 0-1个（作为钩子） |

### 核心原则

> **不是每条视频都要写满五种/六种理由来源。只选择最能证明核心结论的理由。**
> 理由之间不能重复——如果两个理由本质相同，合并为一个。

## 9. 方法论校验规则

### 8个问题自检清单

完成脚本后，逐项检查：

| # | 检查问题 | 通过标准 |
|---|---------|---------|
| 1 | 这条视频最终只在证明一个结论吗？ | 所有理由都服务于同一个结论 |
| 2 | 我是在让客户相信产品，还是相信人？ | 明确选择路径，不混搭 |
| 3 | 每一个理由都与客户选择有关吗？ | 砍掉与选择无关的理由 |
| 4 | 理由之间有没有重复？ | 两个理由本质不同时才保留 |
| 5 | 有没有真实经历、数字、结果或证据？ | 至少3个理由配有具体证据 |
| 6 | 每一句旁白能否找到对应画面？ | 1:1配对，没有"无画面句" |
| 7 | 有没有无法证明或过度夸大的表达？ | 高冲击表达必须有可核实证据 |
| 8 | 结尾有没有形成记忆或行动？ | 留下一个记忆点或行动入口 |

### 红线规则（讲师备注）

> **高冲击表达必须有检测、标准、现场或其他可核实证据。不要把传播性建立在无法证明的夸张上。**

触发红线的高风险表达：
- "最好""第一""唯一""绝对"
- 没有数据来源的数字
- 没有客户授权的"客户证言"
- 没有出处的"行业标准"
- 没有案例的"我们做过"

### 理由筛选的5项硬标准（第二步使用）

| 标准 | 检查方法 |
|------|---------|
| 对客户重要 | 这个理由客户买单前会关心吗？ |
| 与核心结论有关 | 删掉它，结论还能成立吗？ |
| 有一定差异 | 同行也会这样说吗？ |
| 能够被证明 | 能提供具体事实/数据/画面吗？ |
| 可以通过画面呈现 | 这句话有视觉化对应的画面吗？ |
