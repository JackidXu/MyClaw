# 非素材画面：按语义自己设计，不套模板

这份文档只管一类镜头：**没有真素材、得靠这一句口播的意思把画面画出来**的那一屏。

带真素材的镜头（口播真人、官网原文截图、产品实拍、界面截图、新闻页）跟这里无关，一律用原技能的场景和动效，见 `references/footage-effects.md`。成片里那些放大、荧光笔刷黄、推近、挂墙、圆窗，全是原技能做的。

---

## 先说清楚这里不给你什么

不给固定构图，不给「关键词 → 版式」映射表，不给图标顺序，不给英文卡眉，不给占位文案，也不在运行时替你自动选一种画法。

以前这里有一套六种构图、`pickKind()` 自动选型、`ONE ENTRY` / `YOUR RULES` / `FAQ` 这类固定卡眉，还有 `['book','rocket','clock']` 按第几张卡自动发图标。结果每条片子、每个 AI 工具做出来的非素材画面都长一个样。**那不是「会按语义画」，那是把某一次画出来的东西固化了。**

现在给的是一套思考方法、一组没有内容的绘图零件、一个可以自己写的 `art.js` 骨架。换一条口播、换一个 AI 工具，本来就应该画出不一样的东西——这是验收标准，不是副作用。

事实基准见 `references/mid-film-breakdown.md`：用户认可的那条成片里，第 3/6/7/8 镜是当时读着口播现画的，当时没有任何模板。

---

## 四步思考：写每一镜的画面之前过一遍

### 第一步：这一镜的信息结构是什么

看的不是场景名，是**这句口播到底在讲什么关系**。把 `says` 和这一镜的口播原话念一遍，判断它属于哪种：

- 否定 / 更正（「不是 A，是 B」「问题不在 X」）
- 并列（几样东西、几种身份、三个步骤）
- 因果或流程（先给出什么，才长成什么；从提问到回答）
- 一问一答、对照
- 一个数量、一个量级
- 一个身份、一个片名或章节

判断不出来，多半是这一镜 `says` 没写清楚，回去重写 `says`，别急着画。

**这里没有「哪种结构对应哪种版式」的表。** 同样是并列，可以是一排东西、可以是一个中心分出几条线、可以是几张卡叠着进来，取决于这一句的重音落在哪。

### 第二步：想清楚呈现形式，先定主焦点

问自己一句：**观众第一眼该看到什么？** 一个字或一样东西答得出来，才是主焦点。答不出来就是这一屏还没想清楚。

主焦点只能有一个。它可以是那句最要紧的话、一个数字、一个被划掉的旧说法、一个要成形的东西。其余元素都是给它让路、解释它、或者把视线引过去。

### 第三步：只放重点信息

上屏的字全部来自这一镜的口播原话，或者已核实的官网 / 新闻原文。不编数字，不编出处，不写「第一样」「STEP 01」这种没信息的占位词。

- 每屏 34–55 个汉字，2–6 秒里读得完。
- 少到只剩图标，或堆到读不完，都不合格。
- **取不到内容就少画一个元素，绝不拿废话把空白填上。** 空白是设计，废话是噪音。

### 第四步：区域越大，内容越多

这是唯一的硬原则。

- 占画面最大的那块区域，承载主焦点和相对多一点的信息；小贴片只放一个图标或一个短词，别往里塞句子。
- 卡片内部的内容**垂直居中成簇**，不要用 `space-between` 把一行小字顶到顶、一行大字压到底，中间空一大块。
- 一屏里 1 个主焦点 + 1 张短句卡 + 少量贴片（纯图标贴片不超过 4 枚），留白 30% 以上。
- 元素分层：背景（底色、网格、柔光）／中景（主焦点、连接线）／前景（短句卡、贴片）。别把所有东西铺在一个平面上。

配色沿用画布的深蓝 + 琥珀金 + 米白，图标用单色线稿，不用彩色 emoji。这是画风，不是内容。

## 零件在哪、怎么用

`kit/semantic_scenes.js` 现在只是工具箱（`window.KIT_ART`），不会自动改任何画面。里面是：

- 画布：`BG()`、`TOP({left,right})`、`BEAM()`、`RULE()`
- 文字：`TITLE()`、`H2()`、`TXT()`、`LAB()`、`KICK()`、`CAP()`
- 容器：`GLASS(x,y,w,h,inner)`、`CARD(x,y,w,h,inner)`、`STICK(x,y,d,inner)`
- 图形：`ICO(name,size,color)`（`ICON` 是一组线稿零件，自己按语义挑名字）、`FACE(size,mood,color)`
- 时间：`A(t,at,d,i)` 淡入、`fx(a)`、`esc()`、`cut()`、`FIT()`
- 安全区：`SAFE`，`setMode(p)` 按 `host:'window'` / `'pip'` 切换字号

**所有零件的文字都由你传进去，工具箱一个默认文案都不给。** 图标库也只是一堆可选项，没有「第 i 个用第 i 个」的分配逻辑。

`new_film.mjs` 会把它拷进片子的 `lib/`；`starter/index.html` 默认已加载，直接 `window.KIT_ART` 就能取。

## 怎么把自己画的画面挂进片子

骨架在 `starter/art.js`，`new_film.mjs` 建片时会拷到片子目录。它导出 `ART.make(i, c, p)`，返回该时刻的 HTML 字符串（`t` 由渲染器逐帧传进来）：

```js
// art.js（骨架，内容自己写；这里只是示范零件怎么调）
(()=>{
const A=window.KIT_ART;
window.ART={
 make(i,c,p){
  // 只接管你要重画的那一镜；其它镜返回空字符串交回原模板
  if(i!==2)return ()=> '';
  // 内容从这一镜的镜头表参数取，不写死在画层里
  const title=p.title||p.brow||'';
  const line=(p.lines||[])[0]||'';
  return t=>{
   A.setMode(p);                       // 每帧都要设，别让最后一镜的字号盖过来
   const a=A.A(t,c.t0,.42);           // 淡入，落点自己按口播定
   return A.BG()+
    `<div style="position:absolute;left:110px;top:260px;${A.fx(a)}">${A.TITLE(title)}</div>`+
    (line?`<div style="position:absolute;left:110px;top:430px;${A.fx(a)}">${A.TXT(line)}</div>`:'');
  };
 }
};
})();
```

片子目录的 `index.html` 里把 `art.js` 放在 `film.js` 之前加载，然后在 `film.js` 里挂到要重画的场景上：

```js
for(const name of ['flow','statement']){
 const def=KIT.SCENES[name];
 def.make=(p,c)=>window.ART.make(c.i,c,p);
}
```

**只挂纯语义的场景。** `host` / `footage` / `article` / `frames` / `desk` / `device` / `popup` / `montage` 这些带真素材的场景连 `make` 都不要碰——它们身上就是原技能的动效。当初那条成片也只挂了 `flow` / `statement` / `discs` 三个。

如果不想覆盖场景，也可以直接写 `scene:'custom'` 自己出整屏 HTML，见 `kit/README.md` 的 custom 一节。

## 落点和时长

- 时刻一律写 `'@句id:词'`，别写死秒数。每个元素的出现落在它对应的那个词上；词找不到要能退回镜头起点，不能抛错。
- 信息画面 ≥2.6 秒，元素多、字多或自己画的一屏 ≥3.0 秒；带推近刷黄动作的素材镜 ≥3.4 秒（`--check` 硬错误）。
- 最后一个落点到切镜留 ≥0.7 秒（带动作 ≥1.2 秒）静止可读；短镜就少画点，别硬塞，也别靠 `short:true` 绕开检查。
- 元素必须在镜头前 2/3 全部出现，别把落点排到下一镜去。
- 全屏字幕在 `top=936`；`pip` 镜 y>880 不放元素；`window` 镜的图形板有缩放，板内底部反而安全。

## 交片前自检

1. 这一屏的主焦点，能不能用一个短句说清？
2. 上屏的每一个字，是不是都能在口播原话或核实过的原文里找到？
3. 有没有「第一样」「STEP 01」「ONE ENTRY」这种不承载信息的占位文字？有就删掉，宁可少画一个元素。
4. 卡片内部是不是垂直居中成簇，中间没有大片空白？
5. 区域大小和内容多少是否匹配？有没有把一整句话塞进小贴片？
6. 时长够不够读完？落点是不是都夹在这一镜里？
7. 带真素材的镜头有没有被动过？逐像素比一遍。
8. **换一条口播文案、换一个 AI 工具，做出来的这一屏是不是不一样？** 如果还是那套固定三卡加固定图标，说明又套模板了。

---

## 两个容易踩的坑

**把「丰富」理解成「元素多」。** 丰富的是信息层次，不是贴片数量。当初从中版往回改时，字太多读不完、字太少只剩贴片，最后落在「每屏 34–55 字、1 个主焦点 + 1 张短句卡 + 少量贴片」，靠的是配比，不是加装饰。

**用兜底把空白填上。** 写「不足三张自动补齐」「取不到就填某某」这类分支最危险，它会让每条片子都出现同一句废话，而且往往正好违反「不编内容」这条。取不到就少画，让版面自己留白。
