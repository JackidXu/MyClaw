开片必执行：动效要写进镜头表，而且不能只用一种

渲染代码一直在，靠镜头表里的参数触发。参数不写，成片里就看不到荧光笔刷黄和放大推近——这不是代码被删。

① 先给每个带真素材的镜头写一句 says：这句要让观众看懂什么；② 按语义给每镜定一个主动作（见「动效配比」），把它的参数写齐；③ --check 会拦「一处刷黄 / 推近都没有」「连续三镜同一种动作」「5 镜以上少于 3 种动作」「镜太短」「末尾没留静止」；④ 每镜停够 2.6 / 3.0 / 3.4 秒，见「停留多久」；⑤ --sheet 亲眼看动作走完没有。

别把荧光笔当默认动作。上一版把 article 放在必执行第 1 条、前三张卡都叫「荧光笔」、检查只查「全片有没有至少一处 hl」，结果每镜都写 article + hl + zoom 就能一次过检，整条片一直在刷黄。现在按镜统计主动效族，重复直接报错。

已验收的真实成片：mid 片 10 镜里只有第 5、9 镜刷黄，第 4 镜是 footage 慢推，第 1、10 镜是 host 景别跳，第 2、10 镜还挂了证据上墙——动作是换着用的。这 6 镜全是原技能原样，逐镜拆解见 references/mid-film-breakdown.md。

v3.8.0：画面别抖、别死。host.zoom 相邻档位 ≥0.9 秒、方向来回 ≥1.2 秒（景别是硬切，挤在一起像抖）； popup 底层默认跟着时间走、人还在动，back 写在看完那一刻（撑开完→缩回前 ≤1.8 秒、缩回完→切镜 ≤0.9 秒）； 只有一张静态图的镜超过 3.2 秒要写 push 或落点。详见 references/footage-effects.md 第七节。

--check 报「动效重复」时，改法是把其中一镜换成表里另一族并写齐它的参数，不是把 hl 删掉让它变成静态截图。这是配比，不是镜头顺序模板：哪一族用在哪一镜，全看这条口播在讲什么。

停留多久：别让内容一闪而过

量化基准是用户认可的 demo_720_host_mid.mp4：10 镜分别 4.4 / 6.0 / 6.2 / 4.1 / 5.3 / 5.5 / 2.6 / 3.9 / 5.1 / 4.7 秒，最短也有 2.6 秒。旧版只给纯图形场景设 1.5 秒，带真素材的 article / footage 一秒下限都没有，于是刷黄刚落笔就切走。

这一镜是什么至少停为什么
一般信息画面（卡片、大字、图表、实拍展示）2.6 s34–55 汉字要读完 / 要认得出是什么
元素多、信息量大、或按语义自己画的一屏3.0 s视线要扫过不止一个焦点
带推近 + 刷黄动作（article、device、desk、frames）3.4 s起手 0.3 + 推近 1.05 + 刷 0.45 + 稳定停 1.0 + 余量
popup 窗口撑开2.6 s撑开 0.35 + 缩回 0.3 秒；硬凑 3.4 秒会多出一段静止，静止段见 #rules 第 3 条
最后一个落点 → 切镜0.7 s（带动作 1.2 s）动作走完要留一段静止可读的时间

--check 把这些做成硬错误。改法只有两种：把 until 往后挪，或并进相邻镜。short:true 一条片最多一处，写多了也会被拦——别拿它当绕开检查的开关。

① 给出处：原文整页 → 推近 → 刷黄

用在「这个数可能被质疑，先给出处」。原文斜摊在深蓝织物上，先看整页认出是哪一家哪一天，镜头推向那一句，正片叠底的黄色从左往右刷过。

怎么运作：渲染时先 loadImg 量原图宽高，页面按 1560 宽排进 1920×1080 世界坐标并斜放 tilt 度（默认 -1.2）。hl 框乘 k=1560/(cssW 或 1600 或原图宽) 换算，多个框 unionBox 后取中心当推近目标。zoom 的时刻起用 1.05 秒推到该中心（倍率按刷黄句宽度算 1.2–1.8 倍），hlAt 的时刻起用 0.45 秒把 #ffd84a 正片叠底的矩形从左往右刷开。刷完到切镜不足 1 秒会告警。三个参数 zoom / hlAt / until 一起写，动作才完整。

⑤ 就是这个东西：全屏实拍 + 慢推

用在「实拍就是在讲的东西」。全屏、干净、不压字，镜头朝一个点慢慢推近。

怎么运作：每帧算 k=(t-镜起点)/镜长，s=lerp(s0,s1,k)：push:[1,1.06] 就是整镜线性从 1 倍推到 1.06 倍。transform-origin 取 focus（默认 960,540），scale(s) 作用在整个实拍层上。clip 帧序列按 from+(t-t0)*rate 取帧；settle:true 会额外在开头 0.35 秒从 1.08 收回 1，用来接 frames.fill 推满屏。

硬规矩 & 怎么验证

1. 带真素材的镜头一个像素都不改。 上面所有场景都由原技能渲染。不要在 art.js 里覆盖 host / footage / article / frames / desk / device / popup / montage 的 make，也不要拿文字卡、网格、贴片去盖真素材。

2. 这些是词汇，不是镜头顺序；一镜一个主动作。 每镜先写 says，再按这句话在讲什么挑一个特效并把参数写进镜头表。 同族不连着用三镜、带素材 ≥5 镜至少分散到 3 族、每镜停够 2.6 / 3.0 / 3.4 秒（见 #mix、#hold）。 不要照抄片段里的文案和数字；semantic 字段已废弃，技能不会自动替你画非素材画面， 那一类镜头按 references/semantic-thinking.md 的四步自己在 art.js 里设计。

3. 画面别抖、别死。 host.zoom 是硬切档位：相邻 ≥0.9 秒、方向来回 ≥1.2 秒， 一缩一放挤在一起观众看到的是抖。popup 底层默认跟时间走（freeze:true 才回旧行为）， back 提前到看完那一刻，别让窗口撑开后两秒多一动不动、缩回后露出一张不动的照片。 一张静态图别撑过 3.2 秒。25fps 源片抽 30fps 会有周期重复帧，觉得顿才用 footage.py host --interp 重抽。

4. 交片前逐镜验。
