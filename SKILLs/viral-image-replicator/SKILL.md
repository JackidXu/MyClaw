# 爆款图复刻技能

## 核心功能

用户提供一张参考图片，自动完成「反向拆解 → 主题适配 → 图片生成」全流程，输出三份可直接复用的成果：

1. **风格总结**：精准定位原图的视觉风格、使用场景、构图特征、配色体系，提炼可复用的风格标签
2. **正向生成 Prompt**：1:1 还原图所有元素、细节描述、排版结构，直接复制即可在任意 AI 生图工具生成高度相似的图片
3. **Negative Prompt**：完整列出所有排除项，避免生成崩坏、不符合原图要求的低质量结果

最终根据用户指定的新主题，适配改写提示词并生成全新图片，同时返回：生成的图片文件 + 正向完整提示词 + 反向排除提示词。

## 完整工作流程

### Phase 1：图片反向拆解

用户上传任意生成图/实拍图后，严格按照以下规范完成拆解，不可遗漏任何步骤。

#### 1.1 元素识别（100% 覆盖）

对原图进行全量元素拆解，以下每个维度必须逐一分析，不可跳过：

- **背景**：背景类型（纯色/渐变/场景/图案）、背景色调、背景与主体的层次关系
- **人物/主体**：主体类型（人物/产品/IP形象/文字海报等）、姿态/角度/朝向、表情/情绪、服饰/造型、数量与位置关系
- **装饰元素**：图标、贴纸、边框、分割线、纹理、光影特效、手绘元素等所有辅助视觉元素
- **文字内容**：标题文案、副标题、正文、标签/标签文字、水印、所有可见文字的准确内容
- **排版布局**：整体构图方式（居中/对称/三分法/满版等）、信息层级排列、留白比例、元素间距与对齐方式
- **色彩调性**：主色调、辅助色、点缀色、整体明度/饱和度/色温倾向、色彩情绪（温暖/冷峻/活泼/高级等）

#### 1.2 风格总结输出

基于元素识别结果，输出完整的风格总结：

- **视觉风格定位**：用精准关键词描述原图的整体视觉风格（如「扁平插画风+大字报排版」「极简实拍+柔光氛围」等）
- **使用场景判断**：判断原图适用于什么场景（小红书封面/抖音封面/公众号头图/电商主图等）
- **构图特征提炼**：总结可复用的构图模式（如「上文字下产品三等分」「中心人物+环绕式标签布局」等）
- **配色体系提取**：列出完整配色方案，包括色值（尽量用 HEX 或色彩描述）和配色逻辑（主色占比/辅助色占比/点缀色位置）
- **可复用风格标签**：提炼 5-8 个风格标签，便于后续主题适配时快速定位风格方向

#### 1.3 正向生成 Prompt 输出

输出 1:1 还原图的正向生成提示词，要求：

- 完整覆盖 Phase 1.1 中识别的所有元素，按「背景 → 主体 → 装饰元素 → 文字内容 → 排版布局 → 色彩调性」的顺序组织
- 每个元素的描述精准无歧义，语句通顺逻辑清晰，AI 生图工具可完全识别不会乱生成
- 包含具体的构图指令（如「centered composition」「rule of thirds」「symmetrical layout」等）
- 包含具体的风格指令（如「flat illustration style」「minimalist photography」「hand-drawn aesthetic」等）
- 包含画质与细节增强指令（如「high detail」「sharp focus」「4K」「professional quality」等）
- 兼容 Stable Diffusion、Midjourney、豆包 Seedream 等所有主流生图平台
- 适配小红书/抖音等社交平台内容场景，优先识别爆款封面类图片的专属特征

#### 1.4 Negative Prompt 输出

输出完整的反向排除提示词，要求：

- 列出所有可能导致生成崩坏的排除项（如「blurry, distorted, low quality, watermark, extra fingers, deformed text」等）
- 列出不符合原图调性的排除项（如原图是温暖治愈风则排除「dark, gloomy, horror」等）
- 列出可能导致排版错乱的排除项（如「misaligned text, overlapping elements, cropped layout」等）

#### 1.5 读取原图宽高比例

分析原图的宽高比例信息，记录比例数值（如 3:4、1:1、16:9、9:16 等），用于 Phase 3 生成时保持比例一致。

---

### Phase 2：主题适配改写

接收用户指定的新主题（如美妆、穿搭、美食、求职、健身、旅行等），对 Phase 1 拆解出的原提示词做适配改写。

#### 2.1 主题元素替换

逐一完成以下替换，每项不可遗漏：

1. **替换背景**：将原背景替换为新主题的适配场景
   - 示例：原背景为「简约白色桌面」→ 美妆主题适配为「大理石台面+柔光氛围+化妆品点缀背景」
2. **替换人物/主体形象**：将原主体替换为新主题的符合设定
   - 示例：原主体为「手持书本文案卡」→ 美妆主题适配为「手持口红产品的优雅女性，自然妆容，自信微笑」
3. **适配主题专属配色体系**：将原配色调整为新主题的专属调性
   - 示例：原配色为「蓝白清新」→ 美妆主题适配为「玫瑰金+裸粉+白色高级感配色」
4. **替换装饰元素**：将原装饰元素替换为新主题风格的匹配元素
   - 示例：原装饰为「几何线条分割」→ 美妆主题适配为「花瓣轮廓装饰+光泽粒子+柔光晕染」
5. **替换标题文字内容**：将原文字替换为新主题的爆款风格文案
   - 示例：原标题为「3个读书方法」→ 美妆主题适配为「这支口红太绝了」或对应主题的爆款标题

#### 2.2 爆款特质保留

在主题替换的同时，严格保留原图的以下爆款特质，确保改写后是同等质感的同类型内容：

- **整体构图**：保持原图的构图方式不变（如原图是三分法构图，改写后仍为三分法）
- **排版比例**：保持原图的信息层级排列方式和留白比例
- **信息密度**：保持原图的元素密集程度，不过多添加也不过度精简
- **视觉节奏**：保持原图的视觉引导路径和焦点分布

#### 2.3 输出适配后的完整提示词

输出最终适配完成的完整新提示词，包含：

- **正向 Prompt**：整合所有主题替换后的元素描述，保持 Phase 1.3 的格式规范
- **Negative Prompt**：更新排除项以匹配新主题调性，保持 Phase 1.4 的格式规范

---

### Phase 3：图片生成

使用 Doubao-Seedream-5.0-lite模型 生成最终图片。

#### 3.1 调用图片生成

- 使用 Phase 2.3 输出的正向 Prompt 作为生成提示词
- 将 Negative Prompt 中的排除项整合进提示词描述中
- 确保生成的图片与原图宽高比例完全一致（参考 Phase 1.5 记录的比例信息）
- 如原图比例为竖版（如 3:4、9:16），生成竖版图片；如原图比例为横版（如 16:9），生成横版图片；如为正方形（1:1），生成正方形图片

#### 3.2 最终成果返回

向用户返回三份可直接复制使用的成果：

1. **生成的图片文件**：高清分辨率，与原图宽高比例一致
2. **正向完整提示词**：Phase 2.3 输出的适配后正向 Prompt，可直接复制粘贴到任意生图工具
3. **反向排除提示词**：Phase 2.3 输出的适配后 Negative Prompt

## 规范要求

- 元素识别 100% 覆盖：背景、人物/主体、装饰元素、文字内容、排版布局、色彩调性全部拆解到位，没有遗漏
- 描述精准无歧义：所有提示词语句通顺逻辑清晰，AI 生图工具可以完全识别不会乱生成
- 适配主流生图工具：输出的提示词兼容 Stable Diffusion、Midjourney、豆包 Seedream 等所有主流生图平台
- 适配小红书/抖音等社交平台内容场景，优先识别爆款封面类图片的专属特征
- 输出的提示词必须无文字乱码、描述清晰，可直接复制粘贴到任意生图工具生成符合预期的图片
- 自动适配原图比例生成对应高清分辨率，完全对齐原图尺寸比例，不强行拉伸裁剪
- 禁止生成不符合主题调性的违和元素，保证整体风格统一协调，爆款属性拉满

## 使用示例

**用户输入**：上传一张小红书风格的读书分享封面图 + "帮我复刻这张图，主题换成美妆"

**执行流程**：
1. Phase 1：拆解原图 → 输出风格总结（扁平插画风+大字报排版）、正向 Prompt（完整还原）、Negative Prompt、宽高比例（3:4）
2. Phase 2：主题适配 → 将读书元素替换为美妆元素，保留原构图和爆款特质，输出新提示词
3. Phase 3：调用 Doubao-Seedream-5.0-lite模型 生成 3:4 竖版美妆主题图片
4. 返回：生成的图片 + 正向 Prompt + Negative Prompt
