# 爆款图复刻（viral-image-replicator）— 主题锚定 + 爆款版式拆解与主体替换技能

## 核心功能

用户提供一张爆款参考图与作图需求，自动完成「**主题提炼 → 反向拆解 → 主题适配 → 图片生成**」全流程。

**主题先行是本技能的第一原则**：所有改写必须对着 Phase 0 产出的「主题卡」做，改完还要回归核对。没有主题卡就动手改，是「复刻出来不贴题」的根本原因——执行层会默认把原图的职业装束、道具、装饰当成必须保留的视觉资产照抄下来。

四份可直接复用的成果：

1. **主题卡**：从用户需求提炼的主题一句话、主体身份、场景、调性、配色、必含 / 排除项，是全程唯一判定基准
2. **风格总结**：精准定位原图的视觉风格、使用场景、构图特征、配色体系，并标出「版式骨架（硬保留）」与「主题表达（整组替换）」
3. **正向生成 Prompt**：1:1 还原图的元素、细节描述、排版结构，作为拆解存档；进入 Phase 2 后按主题卡整组改写
4. **Negative Prompt**：完整列出所有排除项，含原图造型残留、主体图背景残留等

**双参考图输入**：除爆款原图外，用户可额外传入一张**主体图**（人物或产品）。爆款原图只负责版式骨架，主体图只负责身份特征，两者职责不得混用（见 1.0）。启用主体锁定后额外输出「主体锁定清单」，并在生成后做五检（见 3.2）。

最终返回：生成的图片文件 + 主题卡 + 正向完整提示词 + Negative Prompt + 适配核对表 / 主体锁定清单。

## 完整工作流程

### Phase 0：主题提炼与锚定（所有复刻必做，最先执行）

**先定主题，再拆图，再改写。** 主题卡没产出、没回述，不得进入 Phase 1。

#### 0.1 从用户需求提炼主题卡

把用户那句话（可能很短，如「我是厨师」「做个美妆封面」）展开成下表，**每一格都要填**，填不出就走 0.2：

| 字段        | 内容                                   | 供后续哪一步使用                    |
| --------- | ------------------------------------ | --------------------------- |
| 主题一句话     | 这张图到底要表达什么（含卖点 / 观点 / 情绪）            | 全程总纲                        |
| 主体身份 / 职业 | 画面里的人是谁、是什么产品                        | 2.0 造型推导、2.2 主体替换           |
| 使用场景 / 场合 | 在哪、正在做什么、什么时段                        | 2.0 造型与背景、2.1 Step 3① 动作合理性 |
| 目标人群 / 平台 | 给谁看、发在小红书 / 抖音 / 公众号 / 电商            | 调性、信息密度、画幅                  |
| 调性关键词     | 3–5 个（专业 / 烟火气 / 高级 / 治愈 / 科技 / 复古…） | 2.0 配色与装饰、2.2 字体气质          |
| 主色与配色倾向   | 具体色系与明暗关系                            | 2.2 第 3 项                   |
| 必须出现      | 用户明确点名要有的元素                          | 2.2、Negative 反向校验           |
| 明确排除      | 用户明说不要的元素                            | Negative Prompt             |
| 不变项       | 用户要求保留原图的哪些（如「文字别动」「姿势别改」）           | 2.3、2.1 Step 5              |
| ⚠️ 推断项    | 需求里没给、按最小必要补齐的内容                     | 0.3 回述时重点报备                 |

#### 0.2 信息不足时的处理

用户只给一句短语是常态，按**最小必要推断**补齐，不反复追问、不凭空大改：

- 从用户身份、产品、平台、原图使用场景里就地推断，推断要有依据（如「厨师」→ 后厨 / 餐厅、白色厨师服、烟火气或专业感）
- 所有推断项打上 ⚠️ 标记，写进主题卡，0.3 一并回述
- 推断只补「让画面能成立」的必要项，不替用户决定卖点、文案主张、品牌名；这类缺失且影响成图时才单独问一句

#### 0.3 回述确认（进入下一步前必做）

用 2–3 句话把主题卡讲给用户，重点报备推断项，等一句确认再进 Phase 1：

> 「我理解这张图要表达的是 [主题一句话]，主体是 [身份]，场景 [场景]，调性走 [调性]，配色 [主色]。其中 [X / Y] 是按常见情况补的，如果跟你想的不一样我先改。」

- 用户明确说「别问了直接出 / 按你理解来」→ 跳过等待，**但主题卡仍必须产出、推断项仍要标注，并随成果附上**
- 用户中途改需求或补充信息 → **先更新主题卡并重述，再从 2.0 重跑改写**，不要在旧卡上打补丁，避免前后几处改动各自跑偏

#### 0.4 主题卡是唯一判定基准

- Phase 2 的每一处改动，都要能回答「对应主题卡的哪一格」；答不上来的改动一律不做
- 2.4 输出前做「主题回归核对」，3.2 成图后再做一次，两次都以主题卡为准
- 主题卡与用户新指令冲突时，以用户新指令为准并同步更新主题卡

### Phase 1：图片反向拆解

用户上传任意生成图/实拍图后，严格按照以下规范完成拆解，不可遗漏任何步骤。

#### 1.0 输入判定与参考图分流（拆解前必做）

先清点本次输入，再开始拆解：

| 输入         | 角色                 | 代号  | 必需性 |
| ---------- | ------------------ | --- | --- |
| 作图需求（文字）   | 主题来源 → Phase 0 主题卡 | —   | 必需  |
| 爆款原图       | 版式骨架蓝本             | 图 A | 必需  |
| 主体图（人物或产品） | 身份锚点               | 图 B | 可选  |

- **双图（A + B）**：启用全流程（Phase 0 → 2.0 → 2.1 → 2.2 → 2.3 → 2.4 → 3.1 → 3.2）
- **单图（仅 A）**：仍必做 Phase 0 主题卡与 2.0 造型与主题对齐（这是「复刻成厨师却穿西装」这类问题的解药），只是主体用文字定义，不做身份锁定
- **只有主体图、没有爆款原图**：不属于本技能范围，向用户说明需补一张要复刻的爆款图

双图时，严格按下表划分两张参考图的职责：

| 参考图      | 提供（必须继承）                                                                                  | 不提供（必须排除）                                                |
| -------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 图 A 爆款原图 | 构图骨架、主体占画幅比例与位置、信息层级、文字块位置与字号层级、留白比例、装饰元素的数量 / 密度 / 分布层级、配色的明暗关系与主辅点缀占比、视觉引导路径、光位与画质、画幅比例 | **原图主体的职业、装束、配饰、手持道具、具体装饰元素、具体色值、文字内容、背景内容**，以及主体图里的任何信息 |
| 图 B 主体图  | 人物五官 / 脸型 / 发型 / 体型 / 标志性特征；产品形状 / 轮廓 / Logo / 核心结构                                       | 姿势、表情、衣着、配饰、背景、光线、色调、画幅、原图自带文字与水印                        |

> **两个最容易出问题的地方**：  
> ① 把图 B 整个人（连衣服、连背景、连光线）搬进新画面——图 B 只交身份。  
> ② **把图 A 的造型当成「爆款特质」照抄**——原图人物穿西装、拿公文包、旁边是几何线条，那是原主题的表达，不是可复用的版式资产。版式要留，造型整组换。

同时判定图 B 的主体类型，**人物 / 产品二选一**，后续身份层清单、适配维度、生成后校验项都按该类型执行。

#### 1.1 元素识别（100% 覆盖 + 元素归类）

对原图（图 A）全量拆解，每个维度逐一分析，并对**每个识别出的元素标注归类**：

| 归类             | 含义                | 包含                                                                                  |
| -------------- | ----------------- | ----------------------------------------------------------------------------------- |
| **A 类 · 版式骨架** | 硬保留，与主题无关         | 构图方式、主体占画幅比例与位置、信息层级与字号层级、文字块位置、留白比例、对齐基准、装饰元素的数量与分布层级、配色的明暗关系与占比、视觉引导路径、光位与画质、画幅比例 |
| **B 类 · 主题表达** | 随主题整组替换，**一律不继承** | **主体的职业 / 装束 / 配饰 / 手持道具**、背景内容、装饰元素的具体内容、文字内容、具体色值、字体气质、表情与情绪基调                    |
| **C 类 · 身份锚点** | 仅双图时从图 B 硬锁       | 人物五官 / 脸型 / 发型 / 体型 / 标志性特征；产品形状 / 轮廓 / Logo / 核心结构                                 |

逐一识别以下维度（不可跳过）：

- **背景**：背景类型（纯色/渐变/场景/图案）、背景色调、背景与主体的层次关系 →「类型与层次」归 A，「具体内容」归 B
- **人物/主体**：主体类型、姿态/角度/朝向、表情/情绪、服饰/造型、数量与位置关系 →「位置与占画幅」归 A，**「服饰/造型/职业/道具」归 B**
- **主体构图角色**（后续动作适配的依据，必填）：占画幅比例、画面位置、身体朝向、视线落点、手部动作、与文字 / 道具的互动关系、裁切范围（全身 / 半身 / 胸像 / 特写）、光位与阴影方向 → 归 A，用新身份重演（见 2.0 / 2.1 Step 3①）
- **装饰元素**：图标、贴纸、边框、分割线、纹理、光影特效、手绘元素 →「数量 / 密度 / 分布层级」归 A，「具体元素」归 B
- **文字内容**：标题、副标题、正文、标签、水印、字体样式、所有可见文字的准确内容 →「位置 / 字号层级 / 对齐」归 A，「文案内容 / 字体气质」归 B
- **排版布局**：构图方式、信息层级排列、留白比例、元素间距与对齐 → 归 A
- **色彩调性**：主色、辅助色、点缀色、明度 / 饱和度 / 色温、色彩情绪 →「明暗关系与占比」归 A，「具体色值」归 B

#### 1.2 风格总结输出

基于元素识别结果输出完整风格总结，并额外产出两份清单：

- **视觉风格定位**：用精准关键词描述（如「扁平插画风+大字报排版」「极简实拍+柔光氛围」）
- **使用场景判断**：小红书封面 / 抖音封面 / 公众号头图 / 电商主图等
- **构图特征提炼**：可复用的构图模式（如「上文字下产品三等分」「中心人物+环绕式标签布局」）
- **主体构图角色**：一句话写出主体「在做什么、站在哪、看向哪、被裁到哪里」（如「居中偏左胸像，右手举物贴近脸侧，视线投向右上标题区」），供 2.0 / 2.1 Step 3① 重演
- **配色体系提取**：色值 + 配色逻辑（主色 / 辅助色 / 点缀色占比与明暗关系）
- **可复用风格标签**：5–8 个
- **A 类保留清单**：明确列出本次硬保留的版式骨架项
- **B 类不继承清单（重点）**：把原图的职业装束、配饰、手持道具、装饰元素、背景、文案逐项写明，并标注「不继承，由主题卡重新推导」。例：`原图[深色西装、领带、公文包、几何线条装饰、冷蓝背景] → 全部不继承`

#### 1.3 正向生成 Prompt 输出

输出 1:1 还原图的正向生成提示词，要求：

- 完整覆盖 1.1 识别的所有元素，按「背景 → 主体 → 装饰元素 → 文字内容 → 排版布局 → 色彩调性」组织
- 每个元素描述精准无歧义，AI 生图工具可完全识别不会乱生成
- 包含具体的构图指令（「centered composition」「rule of thirds」「symmetrical layout」等）
- 包含具体的风格指令（「flat illustration style」「minimalist photography」「hand-drawn aesthetic」等）
- 包含画质与细节增强指令（「high detail」「sharp focus」「4K」「professional quality」等）
- **这份 1:1 还原 Prompt 只作拆解存档**。进入 Phase 2 时，1.2 的 B 类不继承清单里的元素必须整组替换，禁止只换主体身份而保留原造型、原道具、原装饰
- 兼容 Stable Diffusion、Midjourney、豆包 Seedream 等主流生图平台；双参考图的角色声明仅适用于支持多图输入的模型（如 Doubao-Seedream-4.5），单图平台按 3.1 降级处理
- 适配小红书 / 抖音等社交平台内容场景，优先识别爆款封面类图片的专属特征

#### 1.4 Negative Prompt 输出

输出完整的反向排除提示词，要求：

- 所有可能导致生成崩坏的排除项（「blurry, distorted, low quality, watermark, extra fingers, deformed text」等）
- 不符合原图调性的排除项（原图温暖治愈风则排除「dark, gloomy, horror」等）
- 可能导致排版错乱的排除项（「misaligned text, overlapping elements, cropped layout」等）
- **主题适配阶段必补**：把 1.2 的 B 类不继承清单逐项写成排除项，如「原图西装、领带、公文包、原图装饰元素、原图背景、原图色值残留」；再补「与新主题身份不符的装束 / 道具 / 场景、主题外元素」
- **启用主体锁定时额外补充**：换脸 / 五官漂移 / 长相改变、面部变形、产品 Logo 变形 / 结构错乱 / 配件增减、主体图背景残留、主体图原衣着串入、主体与背景光线不一致、边缘生硬像贴上去、双重主体 / 多出一个人

#### 1.5 读取原图宽高比例

分析原图（图 A）的宽高比例，记录比例数值（3:4、1:1、16:9、9:16 等），用于 Phase 3 生成时保持一致。

### Phase 2：主题适配改写

拿 Phase 0 的主题卡、Phase 1 的 A 类保留清单与 B 类不继承清单，对原提示词做适配改写。

> **执行顺序不可颠倒**：2.0 造型与主题对齐（所有复刻必做）→ 2.1 主体锁定与替换（有主体图 B 时必做）→ 2.2 主题元素替换 → 2.3 爆款特质保留 → 2.4 输出与回归核对。  
> 有主体图时，2.0 推导出的主题造型就是 2.1 Step 3② 的「调整后」目标值，两处必须一致，不得一个写厨师服、一个写西装。

#### 2.0 造型与主题对齐（所有复刻必做，无论是否传主体图）

**核心规则：原图主体的职业、装束、配饰、手持道具、装饰元素属于「原主题的表达」，不是爆款版式资产，一律整组替换。** 复刻保留的是「怎么摆、怎么排、明暗怎么分」，不是「穿什么、拿什么、摆什么」。

##### Step 1 — 从主题卡推导主题造型

按三步推导，不许跳到「照抄原图」：

1. 从主题卡取出 **主体身份 / 职业 + 使用场景 + 调性关键词**
2. 推导该身份**在该场景下真实合理的装束与道具**：服装款式、材质、颜色、头部配饰、手持物、周围陈设、背景内容、装饰元素，每一项都要能对应主题卡某一格
3. 套回图 A 的 **A 类版式骨架**：保持占画幅比例、位置、朝向、视线落点、手部动作结构、裁切范围、装饰的数量与分布层级、明暗关系；**只把内容换成主题版本**

Step 2 — 装饰元素与配色同步对齐

- 装饰元素保留图 A 的**数量、密度、分布层级**，内容换成与主题叙事关联的元素（例如厨师主题用蒸汽、香料、锅具轮廓、食材色块，而不是原图的几何线条）
- 配色保留图 A 的**明暗关系与主辅点缀占比**，具体色值换成主题卡的主色 / 调性
- 字体保留图 A 的**位置与字号层级**，字体气质按主题卡调性微调，文案内容整组替换

##### Step 3 — 提示词显式声明「整组替换」

把下面这段原样写进正向 Prompt，缺一不可：

> `原图[深色西装、领带、公文包、几何线条装饰、冷蓝背景]属原主题造型，全部不继承；按[厨师]主题调整为[白色双排扣厨师服、厨师帽、围裙，手持锅铲，背景为后厨操作台，装饰为蒸汽与香料色块]，保留原图[居中偏左胸像、右手举起贴近脸侧、视线投向右上标题]的构图角色、[装饰三层分布]的密度层级与[深色主调 + 暖色点缀]的明暗关系`

- 声明必须写清「原图是什么 → 换成什么 → 因为主题卡哪一格 → 保留哪些版式骨架」
- **禁止**写「保持原图服饰 / 沿用手持道具 / 保留原装饰元素」这类会把 B 类锁死的话
- Negative Prompt 同步补上 1.4 的 B 类排除项

##### Step 4 — 遮标题自查

写提示词前问一句：**把标题文字遮住，只看这身装束、手里的东西、周围陈设，能不能一眼看出新主题的身份？** 看不出、或者指向了原主题（还像商务人士），就是没换干净，回 Step 1 重推。

#### 2.1 主体锁定与替换（存在主体图 B 时必做）

目标：把图 A 里的主体换成图 B 的身份，同时做&#x5230;**「脸还是那张脸 / 产品还是那款产品，动作、衣着、光线都长在这张新画面上」**。按 Step 1–6 执行，不许跳步。

##### Step 1 — 观察并文字化图 B 的身份层（硬锁）

身份层必须来自对图 B 的**实际观察**，逐项写下来，禁止凭空编，也禁止只写「保持参考图人物不变」这类笼统话。

| 主体类型 | 身份层（硬锁，任何情况下不得改动）                                                            |
| ---- | ---------------------------------------------------------------------------- |
| 人物   | 五官比例与形状（眼型 / 眉形 / 鼻梁 / 唇形）、脸型轮廓、发际线与发型、肤色、体型、年龄感、标志性特征（痣 / 疤 / 眼镜 / 纹身 / 胎记） |
| 产品   | 外形轮廓、结构比例、Logo 位置与字形、按键 / 接口 / 拼接线、表面纹理与材质基底、型号特征                            |

写出 **≥ 3 个可识别视觉标记**，越具体越好（「圆形玳瑁眼镜」优于「眼镜」），并配锚定词：「标志性的」「始终佩戴的」「保持不变的」。

##### Step 2 — 拆分搭配层（可调）

| 主体类型 | 搭配层（按 Step 3 主动调整）                      |
| ---- | --------------------------------------- |
| 人物   | 衣着颜色 / 款式 / 材质 / 配饰、姿势 / 动作 / 表情、头发造型细节 |
| 产品   | 配色 / 包装材质 / 装饰 / 摆放角度                   |

##### Step 3 — 搭配层三重适配检查

逐项比对并给出结论，冲突就调整搭配层，**身份层始终不动**。

**① 动作 / 摆放 → 适配图片场景**

- 先取 1.2 的「主体构图角色」，让图 B 的身份**重演**这个角色：同样的占画幅比例、位置、朝向、视线落点、手部动作结构、裁切范围、与文字 / 道具的互动关系
- 再校验动作在**主题卡的场景**里是否物理合理（手持什么、手与道具是否接触、身体朝向是否与文字区呼应、遮挡关系是否成立）；产品则校验摆放角度、朝向、与道具 / 文字的互动、使用场景是否成立
- 手持道具必须换成 2.0 推导的主题道具。例：原图举公文包、图 B 是证件照站姿、主题是厨师 → 新画面里是 B 的脸在做「举锅铲贴近脸侧」的动作，既不是证件照站姿，也不是举公文包
- 禁止直接沿用图 B 里的原姿势
- 声明模板（人物）：`人物沿用图 A 的构图角色——[居中偏左胸像，右手举起贴近脸侧，视线投向右上标题区]，用图 B 的身份重演，手部的[主题道具]自然接触`
- 声明模板（产品）：`产品沿用图 A 的构图角色——[右下 45° 仰角摆放，占画幅 35%，瓶身倒影落在台面]，用图 B 的同一款产品重演，与[主题道具]自然接触`

**② 衣着 / 配色 → 以 2.0 的主题造型为目标**

三个比对维度，任一冲突即调整：

| 维度   | 比对                                | 冲突示例            |
| ---- | --------------------------------- | --------------- |
| 色调   | 主题卡主色 + 图 A 明暗关系 vs 图 B 衣着 / 产品配色 | 深色高级感海报里出现浅色花衬衫 |
| 风格调性 | 主题卡调性关键词 vs 图 B 衣着 / 包装风格         | 古风主题出现现代卫衣      |
| 场景   | 主题卡使用场景 vs 图 B 衣着与摆放              | 后厨场景出现西装领带      |

- **调整目标直接取 2.0 Step 1 推导出的主题造型**，与 2.0 Step 3 的声明保持一致；默认不沿用图 B 的衣着 / 配色
- 调整后与图 A 的明暗关系协调，不抢文字与主体焦点
- 声明模板：`衣着由图 B 的[浅色休闲卫衣]调整为 2.0 推导的[白色双排扣厨师服 + 厨师帽]，以适配[厨师 / 后厨 / 专业烟火气]主题；五官、脸型、发型、体型保持不变`（产品：`包装配色由图 B 的[亮银]调整为[哑光深灰]，以适配[新主题]；外形轮廓、Logo、结构保持不变`）

**③ 光线 / 影调 → 不继承图 B**

- 按图 A 的光位、色温、光质、景深、画质给主体重新打光；图 B 的光线、背景、阴影方向一律不继承
- 补融合细节：发丝边缘、接触阴影、皮肤 / 产品表面反射与环境色呼应，让主体真正「长在」画面里

##### Step 4 — 提示词显式声明两层

写进正向 Prompt，缺一不可：

- **锚定身份层**：人物 `保持主体参考图中的人物身份：[脸型：方脸][眼型：内双细长眼][发型：黑色短发][体型：偏瘦][标志性特征：左眼下小痣]，五官比例与面部识别特征完全一致，是同一个人`；产品 `保持主体参考图中产品的外形轮廓、结构比例、Logo 位置与字形、[具体结构特征]，是同一款产品`
- **协调搭配层**：把 Step 3 的三条声明模板原样写进去，明确写出「由 X 调整为 Y」及原因；再叠加 2.0 Step 3 的整组替换声明
- **禁止**写「保持参考图衣着 / 保持参考图姿势 / 保留原图道具」——这会把 B 类元素锁死，直接导致不协调
- 参考图角色也要点明：哪张是版式骨架来源、哪张是身份来源（见 3.1）

##### Step 5 — 冲突处理（用户指令优先级）

| 用户指令                        | 处理                                                                                              |
| --------------------------- | ----------------------------------------------------------------------------------------------- |
| 明确要求「保持主体图原貌 / 衣服不动 / 姿势别改」 | 硬锁对应搭配层，身份层不变；写进主题卡「不变项」，输出时标注该搭配可能与目标氛围不搭                                                      |
| 明确要求「换装 / 改表情 / 换姿势 / 换配色」  | 按指令覆盖对应搭配层，同步更新主题卡，身份层仍锁                                                                        |
| 未明说                         | 默认按 2.0 + Step 3 主动协调，输出时标注：`⚠️ 已将原图[西装]/主体图[浅色卫衣]调整为[白色厨师服]，原[公文包]调整为[锅铲]，以适配[厨师]主题；如需保持原貌请明说` |

> 主题卡「不变项」优先级最高；但它只锁用户点名的项，不能据此把整组原图造型都留下来。

##### Step 6 — 违和防线（写提示词前过一遍）

确认以下五项都已处理，任何一项没处理就回去补：

1. 主题卡已产出并回述，本处改动能对应到卡上某一格
2. 1.2 的 B 类不继承清单已整组替换，装束 / 道具 / 装饰 / 背景 / 色值无原图残留
3. 图 B 的身份层已逐项文字化、≥ 3 个具体视觉标记；图 B 的姿势、衣着、背景、光线、文字、水印均未被继承
4. 动作 / 摆放重演了图 A 的构图角色，且在主题卡场景中物理合理
5. 衣着 / 配色与主题卡调性、场景、图 A 明暗关系三者一致，且 2.0 与 Step 3② 的取值一致

#### 2.2 主题元素替换

对着主题卡逐一完成，每项不可遗漏：

1. **替换背景**：换成主题卡「使用场景」对应的场景，不沿用原图背景内容
2. **替换人物/主体形象**：
   - **有主体图 B**：按 2.1 锁定结果替换，正向 Prompt 完整保留身份锚定段与搭配层声明；禁止用「一位优雅女性」这类新文字设定覆盖或稀释身份锚点
   - **无主体图 B**：按主题卡「主体身份」文字生成
   - **两种情况都必须套用 2.0 推导的主题造型**，不得沿用图 A 的职业 / 装束 / 配饰 / 手持道具
   - 端到端示例：原图「穿深色西装、手持公文包的商务男性」+ 主题「厨师」→「穿白色双排扣厨师服、戴厨师帽、系围裙的厨师，手持锅铲，自然自信的神情」（有主体图时，脸换成图 B 的人，装束不变）
3. **适配主题专属配色**：具体色值换成主题卡主色，保留图 A 的明暗关系与占比
4. **替换装饰元素**：具体内容换成与主题叙事关联的元素，保留图 A 的数量 / 密度 / 分布层级
5. **替换标题文字内容**：按主题卡「主题一句话」提炼爆款文案，字体气质按调性微调，位置与字号层级不变
6. **核对必含 / 排除项**：主题卡「必须出现」逐项落地，「明确排除」写进 Negative Prompt

#### 2.3 爆款特质保留

严格保留原图的以下爆款特质，确保改写后是同等质感的同类型内容：

- **整体构图**：保持构图方式不变（原图三分法，改写后仍三分法）
- **排版比例**：保持信息层级排列方式和留白比例
- 字体风格：保持文字字体样式与比例
- **信息密度**：保持元素密集程度，不多添加也不过度精简
- **视觉节奏**：保持视觉引导路径和焦点分布
- **保留边界（重要）**：以上锁的是**数量、层级、位置、比例关系**，不是元素内容本身。原图的职业装束、配饰、道具、装饰元素、背景、具体色值、文案属于 B 类主题表达，**不属于爆款特质，不得借本条规则保留**。例：原图有 3 个装饰元素分三层分布 → 新图也要 3 个、分三层，但换成蒸汽、香料、食材色块，而不是原图的几何线条
- **构图与主体姿态的边界**：「整体构图」锁的是构图骨架、信息层级、主体占画幅比例与位置；主体具体姿势按 2.0 / 2.1 Step 3① 用新身份重演，不是硬抄原图姿势。若原图姿势与身份锁定冲突（强行照抄会让五官变形 / 识别度下降），**以身份锁定优先**，用同一构图角色下的等效动作替代

#### 2.4 输出适配后的完整提示词 + 主题回归核对

输出最终适配完成的完整新提示词，包含：

- **正向 Prompt**：整合所有替换后的元素描述，保持 1.3 的格式规范，且必须含 2.0 Step 3 的整组替换声明（有主体图时叠加 2.1 Step 4 的两层声明）
- **Negative Prompt**：更新排除项以匹配新主题调性，保持 1.4 的格式规范（含 B 类不继承清单与主体锁定补充项）
- **主题回归核对（所有复刻必做）**：逐格对照主题卡，确认没有偏离，任何一格对不上就回去改：

| 主题卡字段       | 核对问题                         |
| ----------- | ---------------------------- |
| 主题一句话       | 不看文字，画面能否读出这个表达？             |
| 主体身份 / 职业   | 装束、配饰、道具是否指向这个身份？有无原图造型残留？   |
| 使用场景        | 背景、动作、陈设是否属于这个场景？            |
| 目标人群 / 平台   | 调性、信息密度、画幅是否适配？              |
| 调性关键词       | 配色、光影、装饰、字体气质是否对得上？          |
| 主色与配色       | 色值换成主题主色了吗？图 A 明暗关系还在吗？      |
| 必须出现 / 明确排除 | 必含项齐了吗？排除项进 Negative 了吗？     |
| 不变项         | 用户点名保留的项保住了吗？有没有顺手多留了别的原图元素？ |

- **适配核对表**（所有复刻必出）+ **主体锁定清单**（有主体图 B 时并入同一张表）：

| 分类           | 原图 / 主体图                    | 调整后                                    | 依据                  |
| ------------ | --------------------------- | -------------------------------------- | ------------------- |
| 主题卡          | —                           | [主题一句话 / 身份 / 场景 / 调性 / 主色]，⚠️ 推断项：[…] | Phase 0             |
| 版式骨架（A 类）    | [构图 / 层级 / 密度 / 明暗 / 画幅]    | 原样保留                                   | 1.2 A 类清单           |
| 职业装束 / 配饰    | [深色西装、领带]                   | [白色厨师服、厨师帽、围裙]                         | 主题卡身份 + 2.0 Step 1  |
| 手持道具 / 陈设    | [公文包、办公桌]                   | [锅铲、后厨操作台]                             | 主题卡场景 + 2.0 Step 1  |
| 装饰元素         | [几何线条三层分布]                  | [蒸汽 / 香料 / 食材色块，同为三层]                  | 2.0 Step 2          |
| 背景 / 配色 / 文字 | [冷蓝背景、蓝白配色、原文案]             | [后厨暖光、主题主色、新文案]                        | 主题卡 + 2.2           |
| 动作 / 摆放      | [图 B 原姿势 / 图 A 举物]          | 重演图 A 构图角色，适配主题场景                      | 1.2 / 2.1 Step 3①   |
| 身份层硬锁（有图 B）  | [脸型 / 眼型 / 发型 / 体型 / ≥3 标记] | 逐项不变，是同一人 / 同一款                        | 2.1 Step 1 / Step 4 |
| 光线 / 融合      | 图 B 光线 / 背景                 | 按图 A 重打光，不继承，补接触阴影                     | 2.1 Step 3③         |
| ⚠️ 协调提示      | —                           | 已调整 X 项，如需保持原貌请明说                      | 2.1 Step 5          |

### Phase 3：图片生成

使用 Doubao-Seedream-4.5 模型 生成最终图片。

#### 3.1 调用图片生成

- 使用 Phase 2.4 输出的正向 Prompt 作为生成提示词
- 将 Negative Prompt 中的排除项整合进提示词描述中
- 确保生成的图片与原图宽高比例完全一致（参考 1.5 记录的比例）
- 竖版（3:4、9:16）生成竖版，横版（16:9）生成横版，正方形（1:1）生成正方形
- **参考图传入（有主体图 B 时）**：同时传入图 A 与图 B 两张参考图（Doubao-Seedream-4.5 最多 10 张，JPEG / PNG，单张 ≤ 10MB），并在提示词开头点明角色：`图 A 为版式骨架参考，只取构图、层级、留白、装饰密度、明暗关系、光位与画幅，不取其人物造型、服饰、道具、装饰元素、背景与色值；图 B 为主体身份参考，仅取[人物五官 / 产品结构]，不取其姿势、衣着、背景、光线`。只传一张或不点明角色，会让模型把两张图的信息混在一起，也容易把图 A 的西装一起带过来
- **单图模式（仅图 A）**：传入图 A 时同样要点明「只取版式骨架，造型按提示词的主题版本生成」，否则原图装束极易残留
- **降级**：若生成工具只支持单张参考图，优先传图 B（身份保真优先），把图 A 的构图、层级、明暗、排版、光位全部文字化写进提示词，并标注「单图降级，版式还原度可能下降」

#### 3.2 生成后五检

拿到成图后逐项核对，全部通过才算完成（**第 1、3 项所有复刻必做**；第 2、4、5 项有主体图 B 时必做，单图模式同样建议全过）：

| # | 检查项           | 不通过的表现                                                          |
| - | ------------- | --------------------------------------------------------------- |
| 1 | **主题一致性**     | 遮住标题看不出新主题身份；残留原图职业装束 / 道具 / 装饰 / 背景；冒出主题卡以外的元素；必含项缺失、排除项出现     |
| 2 | **识别度**       | 五官 / 脸型变了、不是同一个人；产品 Logo 变形、结构或比例不同款                            |
| 3 | **造型 / 衣着协调** | 原图西装或图 B 原衣服串进画面、装束与主题身份不符、与主题卡调性或图 A 明暗关系冲突、抢了文字焦点             |
| 4 | **动作适配**      | 沿用图 B 原姿势 / 摆放、没重演图 A 构图角色、手持的还是原图道具、手与道具没接触或手型崩坏、视线没落在文字 / 焦点区 |
| 5 | **融合度**       | 残留图 B 的背景 / 光线 / 水印、主体边缘生硬像贴上去、缺少接触阴影与环境色呼应                     |

任一不通过 → 带着具体问题重生成，**一次只改一个变量**（主题偏离先修主题卡在提示词里的表达，再补身份锚定，再修造型，再修动作），最多重试 2 次；2 次后仍不达标，如实说明是哪一项没过、建议用户补更清晰的主体图或确认主题卡推断项，不要交付明显跑题或违和的图。

#### 3.3 最终成果返回

向用户返回：

1. **生成的图片文件**：高清分辨率，与原图宽高比例一致
2. **主题卡**：含 ⚠️ 推断项，方便用户一眼看出理解有没有偏
3. **正向完整提示词 + Negative Prompt**
4. **适配核对表 / 主体锁定清单**（见 2.4）
5. 有单图降级或重试时，一并说明

**产物存放**：生成的图片一律保存为当前工作区（cwd）下的**绝对路径**，不写入本 skill 安装目录；若 cwd 恰好是本 skill 安装目录，回退到该目录父级下的 `复刻产出/` 子目录。提示词若落盘同样按此规则，路径一律写绝对路径，不用相对路径。

## 规范要求

- **主题先行**：所有复刻必先产出并回述主题卡；主题卡是全程唯一判定基准，每处改写都要能对应到卡上某一格，改完做主题回归核对，成图后再做主题一致性校验。需求中途变更先更新主题卡并重述，再从 2.0 重跑
- **造型整组替换**：原图主体的职业、装束、配饰、手持道具、装饰元素、背景、具体色值、文案属 B 类主题表达，不是爆款版式资产，一律不继承；按主题卡重新推导，并在提示词中显式声明「原图是什么 → 换成什么 → 保留哪些版式骨架」
- **保留的是骨架不是内容**：A 类锁数量、层级、位置、比例关系与明暗关系；不得借「爆款特质保留」把原图造型、道具、装饰留下来
- 元素识别 100% 覆盖并完成 A / B / C 归类，A 类保留清单与 B 类不继承清单都要输出
- 描述精准无歧义：所有提示词语句通顺逻辑清晰，AI 生图工具可以完全识别不会乱生成
- 适配小红书 / 抖音等社交平台内容场景，优先识别爆款封面类图片的专属特征
- 自动适配原图比例生成对应高清分辨率，完全对齐原图尺寸比例，不强行拉伸裁剪
- **主体锁定（有主体图时）**：身份层硬锁且逐项文字化、≥ 3 个具体视觉标记；图 B 的姿势 / 衣着 / 背景 / 光线 / 文字一律不继承；动作必须重演图 A 构图角色并适配主题场景；衣着以 2.0 推导的主题造型为目标，与 2.0 声明保持一致；搭配层每处调整都在提示词中显式声明
- **识别度优先**：构图照抄与身份锁定冲突时，身份锁定优先，用同一构图角色下的等效动作替代
- **五检闭环**：生成后按 3.2 的必做范围过检（主题一致性、造型衣着两项所有复刻必过），未过不交付，最多带具体问题重试 2 次
- **产物不落分发包**：所有成图与落盘提示词写入 cwd 绝对路径，禁止写入本 skill 安装目录（见 3.3）
