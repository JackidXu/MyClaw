# 比例适配（ratios）

本文件列出视频封面支持的画幅与就近解析规则。图文封面共用仓库级 `../../references/platform-ratios.md`，此处仅补充视频场景。

## 支持的生成比例（固定白名单）

| 比例 | 典型像素 | 常见用途 |
|------|----------|----------|
| `3:4` | 1080×1440 | 小红书视频封面、通用竖封（默认） |
| `9:16` | 1080×1920 | 视频号 / 抖音 / 快手 竖封面 |
| `16:9` | 1280×720 | B站 / 知乎视频 / 横版封面 |
| `4:3` | 1440×1080 | 近似方，部分平台推荐位 |

## 就近解析

- 用户要的比例不在白名单 → 取数值最接近的受支持比例，并用当前语言告知「只能生成最接近的比例 {生成比例}」，然后直接用，**不反问**。
- 常见就近：
  - 任意 `~9:16.5` / `9:17` → `9:16`
  - 任意 `4:5` / `3:5` 竖 → `3:4`
  - 任意 `2.35:1` / `21:9` 横 → `16:9`
  - 任意 `1:1` → `4:3`（偏竖则 `3:4`）
- 用户给了具体 宽×高 无比例 → 推导并保留该比例；若同时给比例且冲突 → 先问谁优先。

## 多比例套装

- 用户明确要一套多比例（如「抖音 + B站 各一张」），则每个比例单独编译一份独立构图的 prompt，至少 2 个目标才生效。
- 禁止用裁剪 / 拉伸 / 拼九宫格凑数；每版独立生成与保存。
- 数量不因风格数或比例数自动相乘；用户明确要多风格×多比例时才各自独立生成。
