# 多比例排版与同风格变体（layouts）

视频封面常用 3:4 / 16:9 / 4:3 / 9:16。本文件指导同一设计如何适配不同画幅、如何选择构图结构，以及同一风格如何做排版变体。

每次按主题、标题长度、人物动作、画幅与阅读顺序重新构图，不固定模板、不复制上一次坐标，也不随机轮转。下列结构仅作可组合的基础灵感，不是某个风格绑定的构图。真人以独立抠图层进入设计，具体位置、比例与层级在本期重新决定。

## 画幅与版式惯性

| 画幅 | 惯性版式 | 人物占比 | 标题处理 |
|------|----------|----------|----------|
| `3:4` | 竖构图，人物居中偏下或右侧，标题占上 1/3 | 50%–65% | 顶部 2–3 行，字较大 |
| `9:16` | 超竖构图，人物占满，标题压底部或侧边 | 70%–85% | 底部大标题 + 半透明底托 |
| `16:9` | 横构图，人物居左或居右，标题占另一侧 | 40%–55% | 对侧横排，字宽而扁 |
| `4:3` | 近似方，人物居中，标题环绕或压角 | 55%–70% | 角部或底部，避免顶天立地 |

## 适配规则

- 每换一个画幅，**重新决定**人物位置、景别、标题区、断行和文字路径；不拉伸、不裁切、不拼九宫格。
- 保持内容 / 隐喻 / 风格 / 配色一致，但构图、字号、留白、阅读方向按画幅重写。
- 标题断行随画幅调整：竖版可 2–3 行竖向节奏，横版尽量 1–2 行横向铺开。
- 人物保护区随画幅变化：竖版可近景大脸，横版宜中景留出标题空间。

## 基础构图结构（16 种可组合灵感）

| 结构 | 人物与文字的安排 | 适配要点 |
|---|---|---|
| 左右分栏 | 人物在一侧，另一侧为独立文字区 | 横版优先；人物视线朝文字时更顺畅 |
| 上字下人 | 标题在上部，人物在中下部 | 竖版常用；标题区大小由文字长度决定 |
| 上人下字 | 人物在上中部，标题置于下方独立区域 | 下方须留边距与实际平台遮挡空间 |
| 中轴布局 | 人物与标题围绕同一条中轴，上下形成主次 | 控制文字宽度与人物肩宽的关系，避免拥挤 |
| 顶端横题 | 标题横跨上沿，下方人物偏置，辅助字沿固定轴线排列 | 标题与头部之间保持明确间隔 |
| 两侧人物、中间文字 | 两个人物区域占两侧，中央放标题 | 适合已有双人素材；中央文字区要足够宽 |
| 对角线 | 人物与文字沿对角线错位，形成阅读动线 | 主要靠位置安排，不依赖大角度旋转文字 |
| 满版图、底部标题 | 图片铺满画幅，标题位于人物胸部以下或侧下方的可读区域 | 脸部保留完整，下方文字不贴边 |
| 侧边竖栏 | 人物占主要区域，标题沿一侧纵向排列 | 中文按词组组织，辅助英文保持自然阅读方向 |
| 图文穿插 | 标题与人物前后叠放，利用头发或肩部形成轻微遮挡 | 优先保护关键词完整与面部清楚 |
| 左右或上下对比 | 两个已有图片区域并列，各自配简短标题或标签 | 横版左右排、竖版上下排，双方信息层级一致 |
| 双人访谈 | 人物分别位于两侧，主题在上部或中央空白 | 两人视觉占比协调，标题不插进人脸之间的狭窄缝隙 |
| 主图与辅图 | 一张主人物图占大部分面积，已有辅图排列在侧边或下方 | 主标题有独立位置，辅图不能打碎阅读顺序 |
| 人物、物件、标题 | 已有的人物、主题物件和文字形成三角关系 | 确定主次，物件区域不挤占标题区 |
| 特写与留白 | 人物特写占主要画面，标题放在上方或边侧剩余空间 | 裁切优先保留眼睛与嘴，文字不压面部 |
| 框内图、框外字 | 人物图放入独立图像区域，标题在图像区之外 | 图像边界与文字轴线协调，框线不穿过脸部 |

## 断行与对齐

先确定语义单元，再确定行宽。例如"普通人如何建立个人品牌"可以按"普通人如何 / 建立个人品牌"组织；不能机械切成等字数而拆开"个人品牌"。实际行数与长度依据可用空间调整。

同一组文字共用对齐轴。左对齐利于阅读多行文字，中轴对齐适合短标题和上下关系，右对齐适合人物在左且右侧空间明确的布局。已有副标题与主标题建立清楚对应关系。

## 多比例重排

横版转竖版时，左右分栏可以变成上下分区或侧栏；竖版转横版时，上下关系可以转成左右关系。保留文字层级与人物焦点，重新决定断行、间距与占比，不机械复用同一套坐标。

## 同风格排版变体（多版本用同一风格时）

优先在以下维度拉开差异，不只换背景色：
- **断行与文字路径**：同一标题换不同断行点、换横排 / 斜排。
- **人物占比与景别**：近景 ↔ 中景，人物偏左 ↔ 偏右。
- **图文层次**：标题压人物 ↔ 标题与人物并置 ↔ 标题在独立色块。
- **装饰密度**：同一风格下装饰多 ↔ 装饰少。

每版标注为「排版变体」，不冒充其他风格。数量不因比例数量自动相乘（用户明确要多比例×多版本时才各自独立生成）。
