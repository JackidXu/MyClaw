# 人物动作、表情与手持物（person-remix）

用户已允许修改上传老板的动作与表情，适用于全部风格。本文件指导在不改变身份的前提下，按主题调整人物表现。

## 可改维度（身份保留 ≠ 锁死原姿态）

- **姿势**：站 / 坐 / 微侧身 / 双臂交叉 / 单手托腮，按主题氛围选。
- **手势**：指点、摊手、握拳、托腮、指向画外（CTA 感）、扶镜框。
- **朝向**：正面面对镜头（信任）/ 侧身 3/4（思考、权威）/ 看向画外（引导）。
- **视线**：直视镜头（对话感）/ 看向标题（引导阅读）/ 微垂（沉稳）。
- **情绪**：自信微笑 / 沉稳严肃 / 犀利 / 温暖亲和，匹配主题语气。

## 身份锁定红线（不可改）

- 脸型、五官比例、发型、肤色、眼镜等面部配饰必须与参考图一致。
- 五官不能变成另一人；肢体不能畸形、多指、断肢。
- 用户在某次任务明确要求原动作 / 原表情不变时，局部锁定。

## 服装适配分支（用户授权换装时启用）

默认服装与参考图一致；当用户明确授权"换装 / 服装适配背景"时启用本分支：

- **仍锁死**：脸型、五官、发型、肤色、眼镜（这些是身份识别核心，不因换装而变）。
- **允许改动**：服装款式与颜色，按所选风格的背景调性重新匹配。
- **匹配原则**：
  - 深色背景（墨蓝 / 深灰蓝 / 近黑）→ 深色西装（炭灰 / 海军蓝 / 深黑）+ 白衬衫，敞开领口或细领带按风格气质定；不穿休闲T恤。
  - 浅色背景（奶白 / 米白 / 浅灰）→ 深色西装（保证与浅底对比度）+ 白衬衫，避免浅色西装融进背景。
  - 暖调工作室背景 → 暖灰 / 燕麦色西装或针织衫，呼应暖调但不喧宾夺主。
  - 杂志 / 财经权威风 → 海军蓝或炭灰双排扣西装 + 白衬衫 + 可选深色细领带。
  - 新闻主播风 → 深色单排扣西装 + 白衬衫，敞开领口，现代专业感（不戴领带更当代）。
  - 大字主张风 → 深炭灰或深黑西装 + 白衬衫，强对比色块，主张者气场。
- **风险与兜底**：单图图生图改服装时脸型可能轻微漂移，prompt 须明确"严格保留脸型 / 五官 / 短发 / 黑框眼镜 / 肤色，仅替换服装"，input_fidelity 取 medium 让服装改更彻底；若漂移明显，升级到两步法（先自由出图控制服装+构图，再换脸）。
- **brief 必记**：在 brief.md 的"本期身份"段标注"用户授权换装：原照服装=XX，本期改=XX，理由=背景调性匹配"。

## 手持物与道具

- 仅在主题确实需要且用户提供的情形下加入（如产品、书、笔）；不虚构未授权道具。
- 手持物与手部接触要自然，检查手指数量与握持关系。
- 道具属于内容素材，明确其角色，不喧宾夺主。
