# 风格目录（style-catalog）

本仓库自带 **33 套原生风格**，全部面向「老板个人 IP · 中高端信任获客」调性，图文封面与视频封面共用同一套风格库。选风格前读本目录，选定后再读对应 `styles/{id}/META.md`、`styles/{id}/STYLE.md` 与 `styles/{id}/PROMPT.md`。

## 按场景路由（选风格启发）

- 讲**赚钱 / 战略 / 认知升级 / 行业洞察**且受众是老板、高管 → `trust-business-magazine`。
- 讲**AI / 数字化 / 工具 / 方法论**且要现代感 → `minimal-tech-authority`。
- 封面**以老板本人出镜**为主视觉、走专家人设 → `editorial-portrait`（配合真人参考图锁脸）。
- 要**小红书 / 短视频高点击**，标题即主张、视觉极简 → `bold-statement`。
- 做**咨询 / 教育 / 服务型**老板，想显得像在自家工作室聊透一个问题 → `warm-studio`。
- 做**知乎 / B站专业干货**，靠观点密度而非视觉炫技 → `clean-minimal-whitespace`。
- 做**金融 / 硬核决策 / 高端权威**，要黑金或黑红电影感 → `dark-cinematic`。
- 做**本土 / 传统行业 / 国货 / 文化**老板，要东方气韵不老气 → `guochao-newchinese`。
- 做**咨询报告 / 方法论 / 数据分析**类内容 → `data-blueprint`。
- 做**年轻化 / 创意 / 内容行业**，要编辑态度与手作温度 → `editorial-collage`。
- 做**硬核科技产品 / 元宇宙 / AI 基建**，要 3D 通透未来感 → `3d-futurism`。
- 做**教育 / 育儿 / 生活方式 / 情感**，要亲近叙事温度 → `handdrawn-warmth`。
- 做**高净值私域 / 高端品牌 / 奢侈调性**，要极致克制高级 → `luxury-monochrome`。
- 做**消费 / 美业 / 年轻消费品牌**，要活力种草感 → `vibrant-gradient`。
- 做**严肃财经分析 / 宏观研判 / 行业报告**，要头版刊例的权威 → `financial-newspaper`。
- 做**高端人物专访 / 品牌故事 / 生活方式大刊**封面 → `classic-magazine`。
- 做**年轻科技 / 潮流 / 二次元向**，要赛博朋克高能 → `cyber-neon`。
- 做**现代 App / SaaS / 数字产品**，要通透界面感 → `glassmorphism`。
- 做**设计师 / 建筑 / 极简主义**，要理性排版美学 → `swiss-grid`。
- 做**真实创业者故事 / 纪实访谈 / 草根逆袭**，要人文纪实 → `bw-documentary`。
- 做**年轻消费 / 创意 / 活泼品牌**，要玩趣张扬 → `memphis-pop`。
- 做**知识科普 / 教育 / 方法论**，要易懂不死板 → `flat-illustration`。
- 做**盘点 / 干货清单 / 数据对比**，要强信息传达 → `infographic-list`。

- 做**文化 / 国货 / 非遗 / 高端中式**，要敦煌美学 → `dunhuang-guochao`。

## 备注

- 全部 33 套的 `outputs` 均含 `cover` 或 `poster`，图文封面与视频封面菜单共用。
- 不选则推荐 3 套并给理由；用户说 `自动` 才代选。
- 不混搭风格，不加第二个自定义风格段。
- 接入新风格见视频封面技能 `references/add-style.md`（图文封面同理）。
