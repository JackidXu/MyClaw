# 四色提取与搭配（photo-palette）

每期视频封面的四个代表色必须取自本期老板照片，而不是风格文件的固定色值。本文件定义提取与分配流程。

## 提取步骤

1. 查看本期老板照片，识别四个有代表性的颜色区域：
   - **C1 肤色 / 面部光**：通常来自脸部受光面或服装主色，最稳的重色。
   - **C2 服装主色**：西装、衬衫、外套等大面积色块。
   - **C3 背景或环境色**：原照片背景、道具、场景里的中性或有彩色。
   - **C4 点缀色**：领带、配饰、眼镜框、手表、口红等小面积高饱和色。
2. 记录每个颜色的**来源部位**与**近似色值**（用肉眼或取色工具估算 HEX）。
3. 若照片本身偏单调（如纯色背景 + 黑西装），从 C1–C3 派生同色族深浅，补足四个角色，不强行虚构与人物无关的颜色。

## 分配规则（每期重新决定，不照搬）

| 角色 | 常规用途 | 注意 |
|------|----------|------|
| C1 | 背景主色 或 人物保护区底 | 取稳重、不刺眼的值 |
| C2 | 标题 / 大字 主色 | 与背景对比够，保证可读 |
| C3 | 强调 / 点缀（关键词、线条） | 小面积使用，提神不抢戏 |
| C4 | 辅助 / 描边底托 | 用在标题牌、边框、装饰线 |

- 同色族派生：例如 C1 墨蓝可派生 `#0E1B2C`（深）/ `#1C2E45`（中）/ `#2E4A6B`（浅），按需求取。
- 对比校验：标题色与背景色明度差 ≥ 40%，避免「标题融进背景」。

## 与风格的边界

- 四色提取是**全部风格共用**的核心规则，优先级高于风格文件的参考色盘。
- 风格的 `STYLE.md` 里若出现固定色值，仅作「同类气质」参考，执行时以本期四色为准。
- 用户当次明确要求原场景色盘或指定色时，按当次要求执行，并在 brief 中标注。
