# 平台与画幅映射（platform-ratios）

本文件给「老板 IP 封面」工作流提供平台 → 画幅的本地化菜单，以及不支持比例时的就近解析规则。

## 支持的生成比例（固定白名单）

生成模型只吃这几档比例，其余一律就近解析：

| 比例 | 典型像素 | 常见用途 |
|------|----------|----------|
| `1:1` | 1080×1080 | 公众号方图、微博方图、头像区 |
| `3:4` | 1080×1440 | 小红书竖封面、通用海报 |
| `4:5` | 1080×1350 | 小红书竖封面备选、横版笔记 |
| `9:16` | 1080×1920 | 视频号 / 抖音 / 快手 竖封面 |
| `16:9` | 1280×720 / 1146×717 | B站视频封面、知乎、微博头条 |
| `21:9` | 2560×1080 | 公众号横首图、超宽 banner |

## 平台菜单（中文模式）

| 平台 | 默认比例 | 说明 |
|------|----------|------|
| 小红书 竖封面 | `3:4` | 主战场；备选 `4:5` |
| 小红书 横版笔记 | `4:5` 或 `16:9` | 横构图笔记 |
| 微信公众号 首图（横） | `21:9` | 用户常要 2.35:1，就近取 21:9 |
| 微信公众号 方形封面 | `1:1` | 转发小图 |
| 视频号 封面 | `9:16` | 竖屏 |
| 抖音 / 快手 竖封面 | `9:16` | 信息流竖封 |
| 知乎 文章 / 想法 | `16:9` 或 `1:1` | 取决于版面 |
| B站 视频封面 | `16:9` | 1146×717 |

## 就近解析规则

- 用户要的比例不在白名单 → 取数值最接近的受支持比例，并用当前语言告知「只能生成最接近的比例 {生成比例}」，然后直接用，**不反问**。
- 常见就近示例：
  - 公众号 `2.35:1` → `21:9`
  - X / 推特 `5:2` → `21:9`
  - 任意 `4:3` 类 → `1:1`（若偏竖）或 `3:4`
  - 任意 `~9:16.5` → `9:16`
- 用户给了具体 宽×高 无比例 → 推导并保留该比例；若同时给比例且冲突 → 先问谁优先。
- 用户给了明确比例且匹配白名单 → 原样保留，不做转换。
- 多尺寸套装：每个目标单独解析、单独构图，互不裁切。

## 语言模式

- 中文模式：上表平台名与提示语用中文。
- 英文模式：对应 `X / WeChat / YouTube / Bilibili / Weibo / Xiaohongshu / Douyin / Zhihu` 等。
- 双语模式：中英文并列展示。
