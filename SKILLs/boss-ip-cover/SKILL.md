# 老板 IP 封面套件（boss-ip-cover）

一套专为老板个人 IP 打造的中高端「信任获客」视觉封面系统，**完全自有原创代码、MIT 协议可商用**。
套件内聚两大核心工作流，共用一套 **14 套精选风格视觉库**：
1. **图文封面 / 社媒海报**：覆盖公众号、小红书、视频号、抖音、知乎、B站等图文与海报；
2. **人物视频封面 / 口播短视频**：口播视频与短视频封面，自带照片锁脸与四色提取。

---

## 快速路由：工作流选择

当用户发起需求时，依据输入特征自动分流：
- **若用户需求为短视频、口播、视频号/抖音视频封面、提取照片四色** → 进入 **【工作流 B：人物视频封面】**
- **若用户需求为文章、公众号、小红书图文、个人 IP 海报、宣传物料** → 进入 **【工作流 A：图文封面与海报】**
- **若用户未指明且未提供线索** → 简明询问用户期望制作的是「社媒图文/文章封面」还是「口播/短视频人物封面」。

---

## 核心机制：老板真人 IP 锁定（换封面不换脸）

这是本套件区别于通用封面工具的核心：同一张老板真人脸在跨版本、跨画幅、跨平台时保持 100% 身份一致性。

1. **图文封面两步法（架构原则：设计自由与身份锁定解耦）**：
   - **第一步（自由出图，文生图）**：不传老板照，只描述场景、姿态、服装、光影与风格。让模型在最自然的空间构图下生成底图（底图人物脸为陌生人）。
   - **第二步（精准换脸，多图图生图）**：`image1` 传入底图（场景锚点，高保留度），`image2` 传入老板真人照。指令明确要求：「严格保留 image1 的场景、服装、姿态、光照、背景；仅将人物面部特征替换为 image2 的脸部（五官/脸型/发型），不得采用 image2 的服装与背景」。
2. **视频封面锁脸法**：
   - 上传的老板真人照片作为图生图参考图传入，锁定脸型、五官比例、发型、肤色；风格只改变光影/版式/背景/字体，不改变人物身份。
3. **表情与多照选择**：
   - 建议用户提供 2–3 张不同表情（严肃/亲和/微笑）的同角度照片；根据封面情绪挑选最匹配的照片作为参考图，严禁靠 prompt 硬改表情避免五官漂移。
4. **无参考图时**：
   - 按文字描述生成人物，并主动提示「补充一张老板真人照片可确保跨平台人设统一与锁脸」。
5. **隐私与安全**：
   - 用户照片仅供当次生成使用，绝不外泄、绝不拼入公开文档。

## 工作流 A：图文封面与海报

### 1. 参考资源
- 画幅与平台比例：读 `references/platform-ratios.md`
- 封面 Prompt 骨架蓝图：读 `references/cover-blueprint.md`
- 风格选型：读 `references/style-catalog.md` 与对应 `styles/{id}/`

### 2. 标准步骤
1. **解析素材**：提取标题、主题、副标题、视觉主体、受众与情绪基调。长文提取核心摘要，不把整篇原文塞进 prompt。
2. **确认平台与画幅**：依据 `references/platform-ratios.md` 确定比例（缺平台时先问；已指明或说自动时跳过）。
3. **确认风格**：若未指定，依据内容推荐 **恰好 3 套** 风格并给出简明理由供用户选择。
4. **确认门**：平台/画幅或风格缺失时问完即停，齐全后方可编译出图。
5. **编译 Prompt**：
   - 遵守蓝图「参数-文案隔离规则」：十六进制色值改用自然语言，要展示的文字一律用 `「」` 包裹；
   - 开头加 `Render ONLY the text enclosed in 「」 as visible text.`，收尾加 `Do NOT render any color codes, percentages, font names, or technical parameters as visible text.`；
   - 融合唯一选定风格在 `styles/{id}/` 中的视觉原子。
6. **保存与交付**：
   - Prompt 保存至 `boss-ip-cover-output/{slug}/prompts/cover.md`；
   - 多尺寸套装独立编译并在文件名标注比例；
   - 调用图像生成工具出图，保存为 `boss-ip-cover-output/{slug}/cover.png`。

## 工作流 B：人物视频封面

### 1. 参考资源
- 视频封面蓝图：读 `references/video-cover-blueprint.md`
- 四色提取与搭配：读 `references/photo-palette.md`
- 排版与比例变体：读 `references/layouts.md` 与 `references/ratios.md`
- 字体/材质/装饰设计系统：读 `references/design-system.md`
- 动作与表情重设：读 `references/person-remix.md`

### 2. 标准步骤
1. **提取四色**：查看上传的照片，提取四个代表色 C1–C4（背景/文字/强调/辅助），不照搬固定色板。
2. **真人抠图与构图**：将人物从原背景抠出作为独立主体，按主题决定景别、标题区、断行与文字路径。
3. **比例支持**：默认 `3:4`，支持 `16:9`、`4:3`、`9:16`。
4. **多版本制作**：用户要求多版本时（默认 3 版），在构图、断行、字形、图文层次上拉开明显差异。
5. **保存与出图**：
   - 任务简报保存至 `boss-ip-cover-output/{slug}/brief.md`；
   - 各版本 Prompt 保存至 `prompts/{version}-{style-id}-{ratio}.md`；
   - 渲染各版本成品图，并检查缩略图尺寸下的观感。

## 输出纪律

1. **唯一风格融合**：Prompt 必须是任务字段与**唯一**选定风格原子的融为一体制作单，不把多套风格硬拼，不把 `STYLE.md` 机械粘贴在尾部。
2. **文字白名单**：画面要渲染的文字必须严格用 `「」` 标明，严禁将技术参数、色值或注释渲染在图上。
3. **产物严谨取证**：仅使用工具明确返回的图片结果进行存储与展示，严禁凭空瞎猜目录中的无关图。
