# 暖调工作室（Warm Studio）视觉原子

为咨询 / 教育 / 服务型老板设计的「像在自家工作室聊透一个问题」的封面语言。目标是亲切、可信、有人味，不端着。

## 材质（Materials）
- 暖纸张、原木桌面、柔窗光（window light），可点缀少量绿植或书本。
- 不用反光金属、玻璃冷感材质。

## 空间逻辑（Spatial Logic）
- 人物在桌前或自然姿态（托腮、翻资料、看向一侧），居中或偏置。
- 标题像手写便签般「放」在画面，不强行对齐成版式。
- 整体像一张生活化工作照 + 一句开场白。

## 标题处理（Title Treatment）
- 友好无衬线（如思源黑体 Medium）或人文衬线（如思源宋体），中等字重。
- 标题像一句聊天开场（如「很多老板卡在这一步」），不喊口号。

## 字体行为（Typography）
- 温暖舒展的字体，行距放松；中文保持自然。
- 可偶尔用稍大首字营造亲和力。

## 肌理（Texture）
- 暖颗粒，柔和投影，窗光在桌面形成自然渐变。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：暖米 `#EDE4D3`
- 强调：陶土橙 `#B5733A`
- 字：墨棕 `#2E2620`
- 点缀：叶绿 `#6B7A4F`（少量）

## 风格特有负向约束（Negative Constraints）
- 不要冷蓝、科技感、霓虹、企业蓝。
- 不要过度正式、商务模板感、PPT 排版。
- 不要人物过度摆拍或僵硬。
- 不要杂乱背景抢了人物与开场白。
