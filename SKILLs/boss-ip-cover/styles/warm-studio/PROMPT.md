# 暖调工作室：视觉原子

> 执行优先级：先从上传照片提取四个代表色并搭配、抠出真人、按本期主题自由构图，再应用本风格字形与材质。下文的参考色值、原背景处理和固定位置只作例子，不覆盖共用核心；见 [照片四色](../../references/photo-palette.md) 和 [基础构图](../../references/layouts.md)。

把以下规则编译为本期完整封面说明，不直接把此文件当成已经填写的生成提示词。只使用用户人物与本期文字；不需要参考案例图片，不输出目录名称、编号或规则说明。

## 构图与文字路径

- 人物在桌前或自然姿态（托腮、翻资料、看向一侧），居中或偏置。
- 标题像手写便签般「放」在画面，不强行对齐成版式。
- 整体像一张生活化工作照 + 一句开场白。

封面形态适配：主题变成一句像朋友聊天的开场，人物自然居中或偏置

## 字形、字高与效果

- 友好无衬线（如思源黑体 Medium）或人文衬线（如思源宋体），中等字重。
- 标题像一句聊天开场（如「很多老板卡在这一步」），不喊口号。

- 温暖舒展的字体，行距放松；中文保持自然。
- 可偶尔用稍大首字营造亲和力。

主字身参考区间见 [设计系统](../../references/design-system.md) 尺寸口径表；按字数、字宽与净区调整，不是字体软件字号。字身尺寸与字组占区、外边和底托分开计算。保留完整中文结构，主句先按语义排清楚再做弯曲或倾斜。

## 颜色逻辑

- 底：暖米 
- 强调：陶土橙 
- 字：墨棕 
- 点缀：叶绿 （少量）

这里的颜色是设计角色，不把人物肤色、衣服和原环境强制限色。用户指定配色优先，仍保持本风格的明暗、材料和重点分工。四色取自本期照片，风格固定色值仅作参考。

## 人物与主题物

- 人物在桌前或自然姿态（托腮、翻资料、看向一侧），居中或偏置。

按 [人物动作与表情](../../references/person-remix.md) 调整姿势 / 手势 / 朝向 / 视线 / 情绪，身份不变。

## 装饰

- 暖颗粒，柔和投影，窗光在桌面形成自然渐变。

- 暖纸张、原木桌面、柔窗光（window light），可点缀少量绿植或书本。
- 不用反光金属、玻璃冷感材质。

只选有识别、引导、情绪或材料作用的元素；每项在提示词里有明确位置。文字长或场景复杂时减装饰。去掉后不损失主题、读序、情绪或材料质感的装饰，优先删。

## 迁移与边界

不可妥协锚点：
- 暖米底色与陶土强调不可换成冷色系
- 自然柔光与亲切氛围

封面场景禁用：
- 冷蓝、科技感、霓虹、企业蓝、过度正式

- 不要冷蓝、科技感、霓虹、企业蓝。
- 不要过度正式、商务模板感、PPT 排版。
- 不要人物过度摆拍或僵硬。
- 不要杂乱背景抢了人物与开场白。
