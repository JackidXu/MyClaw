# 节日大促（Festival Promo）视觉原子

一套为「节日营销 / 品牌大促 / 节点活动」老板设计的喜庆语言。目标：喜庆、热闹、仪式感，像一张节日主视觉。

## 材质（Materials）
- 节日元素（灯笼/雪花/礼盒/烟花），烫金，红金。
- 拒绝冷灰与极简。

## 空间逻辑（Spatial Logic）
- 居中主视觉（产品/人物/礼盒）+ 节日装饰环绕。
- 装饰均匀但有主次。

## 标题处理（Title Treatment）
- 书法或粗体节日字，烫金处理。
- 节点名（双11/春节/店庆）醒目。

## 字体行为（Typography）
- 书法 / 粗体，端正喜庆。

## 肌理（Texture）
- 烫金、光点、轻微光晕。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 红：`#C8102E` / 金：`#D4AF37` / 节日色（如绿 `#1A7A3C` / 蓝 `#1E5BB8` 按节选）

## 风格特有负向约束（Negative Constraints）
- 不要冷灰、极简、暗黑。
- 不要霓虹、赛博。
- 烫金红金的喜庆感不可弱。
