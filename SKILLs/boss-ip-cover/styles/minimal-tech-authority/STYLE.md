# 轻科技权威（Minimal Tech Authority）视觉原子

为科技 / AI / SaaS 类老板设计的「轻科技」封面语言。核心是：少即是多，用留白和一道冷色渐变撑起未来感与专业度。

## 材质（Materials）
- 近白磨砂底，轻微玻璃透光感。
- 极细发丝线（hairline）作结构分割，不用粗边。
- 柔和投影（soft shadow）让焦点视觉轻轻浮起。

## 空间逻辑（Spatial Logic）
- 留白占画面 55%-70%，焦点视觉（抽象 3D 形体 / 数据节点 / 干净设备剪影）居中或偏上。
- 标题偏下或偏左，单行或两行，不与焦点争抢。
- 可加一行极小的无衬线说明（如「AI 内容中台 · 第 03 期」）。

## 标题处理（Title Treatment）
- 几何无衬线（如思源黑体 Heavy / Inter / Söhne 类），bold 但不过粗。
- 字距略收紧，靠留白和字号层级制造力量感，不靠描边。

## 字体行为（Typography）
- 纯无衬线体系，标题与标签同一族，仅权重区分。
- 中文用现代黑体，保持清爽。

## 肌理（Texture）
- 极淡渐变网格 / 光晕作为背景锚点，不用颗粒、不用噪点。
- 渐变方向统一（左上→右下）。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：近白 `#FAFBFC`
- 字：墨 `#11161D`
- 渐变锚点：冷蓝→青 `#2E6BFF → #18C8C8`（或靛 `#4338CA`）
- 辅助线：浅灰 `#E3E8EF`

## 风格特有负向约束（Negative Constraints）
- 不要拟物、金属拉丝、木纹、暖纸、金色。
- 不要霓虹、过饱和、混乱信息图。
- 不要过多色块拼贴。
- 不要标题被视觉主体遮挡到难读。
