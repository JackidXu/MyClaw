## 构图与文字路径

- 栅格分区：标题区、数据区、图注区各居其位，像一页分析稿。
- 主体（人物 / 模型）可嵌入栅格，但不破坏结构感。
- 留白也是栅格的一部分，克制对齐。

封面形态适配：把主题压成一个可拆解的命题，用栅格与标注承载方法论气场

## 字形、字高与效果

- 等宽或几何无衬线，配小号维度标签（如「PART 01 / 03」「N=1,200」）。
- 主标题重体，副标题用维度标签收口。

- 标题 / 正文：几何无衬线。数据 / 维度：等宽字体（如 JetBrains Mono 类）凸显理性。
- 中文清晰，等宽体不糊。

主字身参考区间见 [设计系统](../../references/design-system.md) 尺寸口径表；按字数、字宽与净区调整，不是字体软件字号。字身尺寸与字组占区、外边和底托分开计算。保留完整中文结构，主句先按语义排清楚再做弯曲或倾斜。

## 颜色逻辑

- 底：蓝图蓝 或浅格 
- 线：白 / 浅灰 
- 高亮：橙 或青 （单一，用于关键数据）

这里的颜色是设计角色，不把人物肤色、衣服和原环境强制限色。用户指定配色优先，仍保持本风格的明暗、材料和重点分工。四色取自本期照片，风格固定色值仅作参考。

## 装饰

- 全幅细网格、轻微扫描线、坐标感刻度。

- 蓝图底：深蓝 或浅格 ，细网格线贯穿。
- 标注感：细线引出、角标、尺寸刻度，强化「图纸」气质。
- 拒绝手写、卡通、情绪化渲染。

只选有识别、引导、情绪或材料作用的元素；每项在提示词里有明确位置。文字长或场景复杂时减装饰。去掉后不损失主题、读序、情绪或材料质感的装饰，优先删。
