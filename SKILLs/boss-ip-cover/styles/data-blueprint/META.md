name_en: Data Blueprint
outputs: [cover, poster]
best_for: 咨询报告 / 方法论 / 分析类老板内容，要把逻辑与数据感做出来
mood: 理性、专业、结构感
style_anchors:
  - 材质：技术蓝图底（深蓝或浅格），细网格线，标注感
  - 空间：栅格分区，标题 / 数据 / 图注各居其位，像一页分析稿
  - 标题处理：等宽或几何无衬线，配小号维度标签（如「P1 / 03」）
  - 字体：等宽 + 无衬线混排，数据用等宽凸显
  - 肌理：网格、轻微扫描线、坐标感
  - 配色：蓝图蓝 / 白线 / 单一高亮橙或青
cover_shape_adaptation: 把主题压成一个可拆解的命题，用栅格与标注承载方法论气场
must_preserve:
  - 栅格与标注的「分析稿」结构感
  - 数据 / 维度标签的等宽字体处理
avoid_when_applying_to_cover:
  - 手写感、卡通、情绪化渲染、装饰花边
  - 无结构的随意排版
