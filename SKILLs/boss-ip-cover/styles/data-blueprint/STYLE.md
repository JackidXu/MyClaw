# 数据蓝图（Data Blueprint）视觉原子

一套为「咨询报告 / 方法论 / 分析」老板内容设计的技术稿版式。目标：像一页 MIT 公开课讲义或麦肯锡分析稿，理性、有结构、可信。

## 材质（Materials）
- 蓝图底：深蓝 `#0F2A47` 或浅格 `#F2F5F8`，细网格线贯穿。
- 标注感：细线引出、角标、尺寸刻度，强化「图纸」气质。
- 拒绝手写、卡通、情绪化渲染。

## 空间逻辑（Spatial Logic）
- 栅格分区：标题区、数据区、图注区各居其位，像一页分析稿。
- 主体（人物 / 模型）可嵌入栅格，但不破坏结构感。
- 留白也是栅格的一部分，克制对齐。

## 标题处理（Title Treatment）
- 等宽或几何无衬线，配小号维度标签（如「PART 01 / 03」「N=1,200」）。
- 主标题重体，副标题用维度标签收口。

## 字体行为（Typography）
- 标题 / 正文：几何无衬线。数据 / 维度：等宽字体（如 JetBrains Mono 类）凸显理性。
- 中文清晰，等宽体不糊。

## 肌理（Texture）
- 全幅细网格、轻微扫描线、坐标感刻度。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：蓝图蓝 `#0F2A47` 或浅格 `#F2F5F8`
- 线：白 `#FFFFFF` / 浅灰 `#C9D2DC`
- 高亮：橙 `#F2A03D` 或青 `#3DB8C9`（单一，用于关键数据）

## 风格特有负向约束（Negative Constraints）
- 不要手写感、卡通、情绪化渲染、装饰花边。
- 不要无结构的随意排版。
- 高亮色只标关键数据，不铺满。
- 标题不错字、不被裁切。
