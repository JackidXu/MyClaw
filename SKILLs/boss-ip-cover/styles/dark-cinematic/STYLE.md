# 深色电影感（Dark Cinematic）视觉原子

一套为「金融 / 硬核决策 / 高端权威」老板设计的好莱坞级暗调版式。目标：像一部金融惊悚片的海报，低光里藏着力量，而不是亮堂堂的企业宣传。

## 材质（Materials）
- 哑光近黑底（`#0B0B0D` / `#121214`），拒绝高光塑料感。
- 体积光 / 侧逆光勾勒人物轮廓，暗部承担情绪。
- 轻微胶片颗粒与暗角，营造电影质感。

## 空间逻辑（Spatial Logic）
- 人物占主导，低键光只打亮脸部与肩线，其余沉入暗部。
- 大面积暗部不是空，而是「留黑」，制造张力与高级。
- 标题置于亮区边缘或暗部发光，不与人物抢光。

## 标题处理（Title Treatment）
- 重体几何无衬线，字距收紧，可轻微发光（1–2px 柔光）但不浮夸。
- 关键词用暖金 `#C9A24B` 或正红 `#E23B3B` 点睛，小面积。
- 长标题压成 2 行短句，主词加重。

## 字体行为（Typography）
- 几何无衬线（Inter / 思源黑体），禁用衬线繁复装饰。
- 中文清晰，发光处理不糊字。

## 肌理（Texture）
- 全幅极轻胶片颗粒，四角暗角，可有微弱光晕。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：近黑 `#0B0B0D`
- 强调：暖金 `#C9A24B` 或正红 `#E23B3B`
- 中性：石墨灰 `#5A5A5E`（次级小字）
- 光：冷白体积光 `#E8ECF2`

## 风格特有负向约束（Negative Constraints）
- 不要高饱和满屏、糖果色、明亮平光。
- 不要卡通、 emoji、信息图、价格标签。
- 不要「证件照平光感」——必须有光影层次。
- 金 / 红强调不可大面积铺，只点睛。
