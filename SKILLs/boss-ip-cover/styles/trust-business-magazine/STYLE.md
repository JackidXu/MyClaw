# 信任商业杂志（Trust Business Magazine）视觉原子

一套为「老板 IP · 信任获客」设计的商业杂志头版语言。目标：一眼像《经济学人》《彭博》级别的严肃刊物，而不是课程封面或朋友圈海报。

## 材质（Materials）
- 哑光纸面为主，拒绝高光塑料感。
- 极细金线（1px）作分隔与报头装饰，不用粗框。
- 可选轻微压凹 / 击凸的标题处理，强化纸质体感。

## 空间逻辑（Spatial Logic）
- 顶部留报头区：一行小字栏目名（如「战略观察」「老板内参」）+ 细金线。
- 标题左对齐、占画面 30%-45%，下方用金线或留白收口。
- 主视觉只占一角或作单色剪影（人物侧影、灯塔、棋盘、天平），不与标题争夺焦点。
- 留白面积 ≥ 图形面积，整体克制。

## 标题处理（Title Treatment）
- 展示衬线（如思源宋体 / Playfair 类），重体，字距略收。
- 长标题拆成 2-3 行，主词加重，修饰词减小。
- 标题下可接一行无衬线小标（栏目 / 期数 / 作者署名）。

## 字体行为（Typography）
- 标题：衬线展示体。正文标签：干净无衬线（如思源黑体 / Inter）。
- 中文必须清晰，禁止艺术字变形导致难读。

## 肌理（Texture）
- 全幅极轻纸纹颗粒，边缘轻微暗角，像印刷品。
- 不叠加明显滤镜。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 主色：墨蓝 `#0E1B2C`（背景或主块）
- 纸色：奶白 `#F4EFE6`（标题区 / 留白）
- 强调：暖金 `#C9A24B`（金线、关键词、报头点）
- 辅助：石墨灰 `#3A3A3A`（正文小字）

## 风格特有负向约束（Negative Constraints）
- 不要渐变光斑、霓虹、荧光色。
- 不要卡通、扁平萌系、emoji 堆叠。
- 不要电商大促式满屏卖点 / 价格标签。
- 不要与主题无关的花卉、几何装饰乱入。
- 标题不错字、不被主视觉裁切、不挤到边缘。
