# 信任商业杂志：视觉原子

> 执行优先级：先从上传照片提取四个代表色并搭配、抠出真人、按本期主题自由构图，再应用本风格字形与材质。下文的参考色值、原背景处理和固定位置只作例子，不覆盖共用核心；见 [照片四色](../../references/photo-palette.md) 和 [基础构图](../../references/layouts.md)。

把以下规则编译为本期完整封面说明，不直接把此文件当成已经填写的生成提示词。只使用用户人物与本期文字；不需要参考案例图片，不输出目录名称、编号或规则说明。

## 构图与文字路径

- 顶部留报头区：一行小字栏目名（如「战略观察」「老板内参」）+ 细金线。
- 标题左对齐、占画面 30%-45%，下方用金线或留白收口。
- 主视觉只占一角或作单色剪影（人物侧影、灯塔、棋盘、天平），不与标题争夺焦点。
- 留白面积 ≥ 图形面积，整体克制。

封面形态适配：把主题压成一句报头式主张，主视觉只占一角或作剪影，留白大于图形

## 字形、字高与效果

- 展示衬线（如思源宋体 / Playfair 类），重体，字距略收。
- 长标题拆成 2-3 行，主词加重，修饰词减小。
- 标题下可接一行无衬线小标（栏目 / 期数 / 作者署名）。

- 标题：衬线展示体。正文标签：干净无衬线（如思源黑体 / Inter）。
- 中文必须清晰，禁止艺术字变形导致难读。

主字身参考区间见 [设计系统](../../references/design-system.md) 尺寸口径表；按字数、字宽与净区调整，不是字体软件字号。字身尺寸与字组占区、外边和底托分开计算。保留完整中文结构，主句先按语义排清楚再做弯曲或倾斜。

## 颜色逻辑

- 主色：墨蓝 （背景或主块）
- 纸色：奶白 （标题区 / 留白）
- 强调：暖金 （金线、关键词、报头点）
- 辅助：石墨灰 （正文小字）

这里的颜色是设计角色，不把人物肤色、衣服和原环境强制限色。用户指定配色优先，仍保持本风格的明暗、材料和重点分工。四色取自本期照片，风格固定色值仅作参考。

## 人物与主题物

- 顶部留报头区：一行小字栏目名（如「战略观察」「老板内参」）+ 细金线。
- 主视觉只占一角或作单色剪影（人物侧影、灯塔、棋盘、天平），不与标题争夺焦点。

按 [人物动作与表情](../../references/person-remix.md) 调整姿势 / 手势 / 朝向 / 视线 / 情绪，身份不变。

## 装饰

- 全幅极轻纸纹颗粒，边缘轻微暗角，像印刷品。
- 不叠加明显滤镜。

- 哑光纸面为主，拒绝高光塑料感。
- 极细金线（1px）作分隔与报头装饰，不用粗框。
- 可选轻微压凹 / 击凸的标题处理，强化纸质体感。

只选有识别、引导、情绪或材料作用的元素；每项在提示词里有明确位置。文字长或场景复杂时减装饰。去掉后不损失主题、读序、情绪或材料质感的装饰，优先删。

## 迁移与边界

不可妥协锚点：
- 墨蓝主色与暖金强调不可替换
- 衬线标题的编辑感与克制留白

封面场景禁用：
- 渐变光斑、霓虹、卡通、杂乱信息图
- 电商大促式满屏卖点

- 不要渐变光斑、霓虹、荧光色。
- 不要卡通、扁平萌系、emoji 堆叠。
- 不要电商大促式满屏卖点 / 价格标签。
- 不要与主题无关的花卉、几何装饰乱入。
- 标题不错字、不被主视觉裁切、不挤到边缘。
