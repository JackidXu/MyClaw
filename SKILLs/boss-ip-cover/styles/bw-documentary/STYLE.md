# 黑白纪实摄影（B&W Documentary）视觉原子

一套为「真实创业者故事 / 纪实访谈」老板设计的人文纪实语言。目标：像一篇《国家地理》式人物特写，真实、粗粝、有力量。

## 材质（Materials）
- 黑白银盐照片质感，高对比，硬光影。
- 拒绝彩色与柔焦。

## 空间逻辑（Spatial Logic）
- 人物特写占主，环境（办公室/车间/街头）交代故事。
- 大面积暗部或亮部承担情绪，不是空。
- 颗粒感是质感核心。

## 标题处理（Title Treatment）
- 简洁白字压暗部，或无衬线小标于边角。
- 不抢画面，克制。

## 字体行为（Typography）
- 无衬线，字重中性，清晰。

## 肌理（Texture）
- 银盐颗粒、四角暗角，强化胶片感。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 纯黑 `#000000` / 纯白 `#FFFFFF` / 灰阶过渡

## 风格特有负向约束（Negative Constraints）
- 不要彩色、霓虹、卡通、柔光。
- 不要高饱和、装饰花纹。
- 不要过度修图破坏真实感。
