# 图文穿插编辑（editorial-interleaved）

## 材质
真实摄影质感。人物处在一个有真实纵深的工作室/环境里（柔光、渐变墙面、浅景深、微噪点），不是纯色块。背景与人物共享同一套光照与影调，整体像一张棚拍杂志封面，而非合成图层。

## 空间
竖版构图。人物居中偏上、占画面约 55-65% 高度，自然站姿（手持麦克风/抱臂/前倾倾听）。超大标题从画面上部贯穿到下部，与人物身体形成真实的空间遮挡关系。

## 标题
超大粗体几何无衬线中文主标题（1 行 2-6 字），至少两次清晰换层：部分笔画在人物身后（被墙面或虚化前景遮挡），部分笔画压在人物肩臂前方。遮挡严格避开眼睛、鼻子、嘴巴。下方一行小一级完整标题，最底部一行极小辅助文字（品牌/栏目）。

## 字体
标题用重体字重（900）的几何无衬线（如思源黑体 Heavy / 站酷快乐体类），字距收紧、行距紧凑。辅助文字用同族细体，字号阶梯明确，不抢主标题。

## 肌理
极轻 film grain + 浅景深焦外光斑，营造电影感。禁止明显噪点、渐变光斑、网格、金属拉丝等"AI 装饰"。

## 配色
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
严格 2-4 色：深墨 #11161D 底、奶白 #F4EFE6 主标题、橙红 #E8552D 小范围强调（≤画面 8%）。可加一档石板灰 #3A4150 作中间过渡。

## 负向约束
禁止：金属雕塑人、机器人、PPT感、电商大促感、卡通、装饰性乱码、AI伪影（多余手指、扭曲文字、假logo）、把人物单纯缩小贴在平涂底色上、整行半透明字。中文字形必须准确、无错字、无乱码。
