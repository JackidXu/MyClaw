# 财经报纸刊例（Financial Newspaper）视觉原子

一套为「严肃财经 / 宏观研判」老板设计的头版刊例语言。目标：像《华尔街日报》《财新》的要闻版，信息密度高、权威、不花哨。

## 材质（Materials）
- 新闻纸灰白底（`#F2F0EA`），拒绝铜版高光。
- 多栏网格（3–4 栏）分隔，细黑分割线（1px）。
- 轻微套印错位与纸纹颗粒，像真实印刷。

## 空间逻辑（Spatial Logic）
- 顶部报头：刊名 + 巨幅日期/期数，下方一道粗黑线。
- 主标题压顶，占画面 25%-35%，下方多栏正文摘要。
- 一张主视觉（图表/人物/场景）置于某栏，不抢标题。
- 信息分层清晰，留白用于区隔而非装饰。

## 标题处理（Title Treatment）
- 粗黑无衬线大标题，副标题小字，关键词用红框/红线强调。
- 长标题压成 2 行，主词加重。

## 字体行为（Typography）
- 标题：粗黑无衬线（思源黑体 Heavy / 类似）。
- 正文摘要：报纸衬线小字，清晰可读。

## 肌理（Texture）
- 全幅极轻新闻纸颗粒，边缘轻微套印错位。
- 不叠加滤镜、光晕。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 新闻纸：`#F2F0EA`
- 墨黑：`#1A1A1A`（标题/分割线）
- 警示红：`#C8102E`（关键强调，小面积）
- 灰：`#6B6B6B`（摘要小字）

## 风格特有负向约束（Negative Constraints）
- 不要渐变光斑、卡通、糖果色、电影光晕。
- 不要电商大促式满屏卖点。
- 不要与财经无关的花卉、萌系装饰。
- 标题不错字、不挤到边缘。
