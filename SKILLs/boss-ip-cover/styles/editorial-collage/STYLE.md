# 杂志拼贴（Editorial Collage）视觉原子

一套为「年轻化 / 创意 / 内容行业」老板设计的编辑拼贴版式。目标：像一本独立杂志的封面，有态度、有手作温度，而不是精致却无聊的企业稿。

## 材质（Materials）
- 撕纸 / 拼贴层叠：不同纸质（哑光、牛皮、光面）错位叠放。
- 胶带痕迹、真实纸边、轻微卷角，强化手作感。
- 拒绝平涂极简与「设计稿感」。

## 空间逻辑（Spatial Logic）
- 多图层错位：照片块、色块、文字块互相穿插遮挡。
- 标题与图像咬合，不是上下分层。
- 留白也是撕纸留出的不规则边缘。

## 标题处理（Title Treatment）
- 手写感或粗黑体拼贴，字体混搭（一本正经 + 随性）。
- 标题像剪下来的字，错位贴纸，可有轻微旋转。
- 长标题拆短，主词用最大字号。

## 字体行为（Typography）
- 混排：粗黑展示体 + 手写感体，制造编辑冲突。
- 中文清晰，手写体不糊。

## 肌理（Texture）
- 全幅纸纹、网点、胶带、印章质感。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：暖白 `#F4EFE6` 或牛皮 `#D9C7A8`
- 拼块：2–3 个跳色（如墨蓝 `#0E1B2C`、朱 `#C8472F`、芥黄 `#D8B24A`）
- 线：近黑 `#1A1A1A`

## 风格特有负向约束（Negative Constraints）
- 不要平涂极简、商务蓝、信息图、价格标签。
- 不要过度干净的「设计稿感」——要手作痕迹。
- 跳色不过 3 个，避免杂乱。
- 标题不错字、不被裁切到难读。
