# 水彩（Watercolor）视觉原子

一套为「生活方式 / 情感 / 文艺」老板设计的手绘水彩语言。目标：柔和、治愈、文艺，像一本独立杂志插画。

## 材质（Materials）
- 水彩晕染，纸张纹理，湿边。
- 拒绝硬边缘与高饱和。

## 空间逻辑（Spatial Logic）
- 主体水彩渲染，留白透气，不堆满。
- 自然元素（植物/天空/器物）作背景衬托。

## 标题处理（Title Treatment）
- 手写感或细衬线字压水彩之上。
- 字重轻，不破坏晕染。

## 字体行为（Typography）
- 手写体 / 衬线，柔和。

## 肌理（Texture）
- 水彩纸纹、晕染边缘、轻微水痕。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 低饱和粉彩：蓝 `#A7C7E7` / 绿 `#B5D8B0` / 粉 `#F3C4C4` / 米底 `#FBF7F0`

## 风格特有负向约束（Negative Constraints）
- 不要硬边缘、霓虹、高饱和。
- 不要暗黑、金属质感。
- 晕染要自然，不糊成一片。
