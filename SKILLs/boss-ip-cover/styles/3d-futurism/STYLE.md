# 3D 未来（3D Futurism）视觉原子

一套为「硬核科技 / 产品 / 元宇宙 / AI 基建」老板设计的 3D 渲染版式。目标：像一支 Apple / NVIDIA 产品片的静帧，体积、通透、高完成度。

## 材质（Materials）
- 3D 渲染主体：体积光、折射、玻璃 / 金属质感，拒绝扁平。
- 环境光通透，有空气感与景深虚化。
- 柔焦光斑克制使用，不廉价满天飞。

## 空间逻辑（Spatial Logic）
- 主体（人物 / 产品 / 抽象意象）悬浮于通透空间。
- 景深虚化背景，突出主体完成度。
- 标题嵌入 3D 空间，与主体有前后层次。

## 标题处理（Title Treatment）
- 立体字或发光字，可轻微挤出于画面。
- 几何无衬线，字距收紧，未来感。
- 关键词用荧光点缀，小面积。

## 字体行为（Typography）
- 几何无衬线，可立体挤出或霓虹发光。
- 中文清晰，发光不糊。

## 肌理（Texture）
- 折射、反射、柔焦光斑（克制）、微噪点。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：冷调蓝紫 `#1B1F3B` / 透白 `#EEF2FF`
- 荧光点缀：青 `#39E6E0` 或品红 `#E64BD0`（单一）
- 金属：拉丝银 `#C8CCD4`

## 风格特有负向约束（Negative Constraints）
- 不要扁平插画、纸感、手绘、复古。
- 不要廉价光斑满天飞、过度滤镜。
- 荧光色只点缀，不铺满。
- 标题不错字、不被裁切。
