# 知识付费课程（Course Promo）视觉原子

一套为「课程发售 / 训练营 / 知识星球」老板设计的转化语言。目标：专业、清晰、有获得感。

## 材质（Materials）
- 干净底 + 课程模块卡 / 讲师照，图标。
- 拒绝暗黑与霓虹。

## 空间逻辑（Spatial Logic）
- 主题利益标题在上，卖点清单/模块卡在中，讲师与权益在下。
- 层级分明，扫读即懂。

## 标题处理（Title Treatment）
- 利益导向大标题（如「30 天学会 X」）+ 副标题。
- 模块卡用编号或图标区隔。

## 字体行为（Typography）
- 无衬线，清晰，数字/价格可强调。

## 肌理（Texture）
- 卡片、图标，轻微投影。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 品牌蓝：`#2D6CDF` / 橙强调：`#F5A623` / 白底：`#FFFFFF` / 灰：`#8A8A8A`

## 风格特有负向约束（Negative Constraints）
- 不要过于艺术化、信息混乱。
- 不要暗黑、霓虹。
- 利益点与模块结构必须清晰。
