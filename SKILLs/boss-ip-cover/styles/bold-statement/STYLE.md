# 大字主张（Bold Statement）视觉原子

为「高点击率」而生的封面语言。核心不是设计感，是**一秒看懂、一秒想点**。适合小红书两列信息流、短视频封面缩略图。

## 材质（Materials）
- 平涂色块为主，可双色对撞，不用复杂渐变。
- 文字本身即主视觉，不需要额外图形装饰。

## 空间逻辑（Spatial Logic）
- 超大标题占画面 50% 以上，1-3 行，行距收紧。
- 人物 / 产品缩到一角（常右下），作为「证据」而非主角。
- 关键词（一个数字、一个痛点词）单独换色高亮。

## 标题处理（Title Treatment）
- 字重 900 的重体无衬线，越短越狠越好（如「别再裸奔做IP」「3个信号」）。
- 关键词用强调色（橙 / 红 / 金）区别于正文标题。
- 可加一行极小副标补充语境。

## 字体行为（Typography）
- 纯重体无衬线，中文用思源黑体 Heavy / 站酷快乐体类。
- 白字配黑描边或黑字配白光，确保在缩略图尺寸可读。

## 肌理（Texture）
- 平涂，无颗粒、无噪点；可极轻投影增加层次。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底色：奶白 `#F4EFE6` 或 深墨 `#11161D`（二选一做主调）
- 强调：橙红 `#E8552D` 或 暖金 `#C9A24B`（关键词）
- 字：与底色对撞的墨 / 奶白

## 风格特有负向约束（Negative Constraints）
- 不要含蓄、弱对比、低信息密度。
- 不要花哨装饰、渐变光斑、过度留白。
- 标题在缩略图下必须清晰，禁止细小字。
- 不要把人物放太大抢了标题主张。
