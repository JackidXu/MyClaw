# 扁平插画（Flat Illustration）视觉原子

一套为「知识科普 / 教育 / 方法论」老板设计的扁平矢量语言。目标：易懂、不死板，像优质知识类动画封面。

## 材质（Materials）
- 扁平矢量插画，无渐变或微渐变，粗描边。
- 拒绝写实照片与真实光影。

## 空间逻辑（Spatial Logic）
- 场景化插画叙事，人物简化，图标化元素辅助。
- 主体清晰，一眼读懂在讲什么。

## 标题处理（Title Treatment）
- 插画上方或卡内无衬线字，字重中等。
- 不与插画抢焦点。

## 字体行为（Typography）
- 圆润无衬线，亲和。

## 肌理（Texture）
- 平面矢量，无真实肌理，可微渐变。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 明亮多色但柔和（蓝 `#4A90D9` / 橙 `#F5A623` / 绿 `#7ED321` / 底白）

## 风格特有负向约束（Negative Constraints）
- 不要写实照片、暗黑、霓虹。
- 不要过度装饰、信息图堆叠。
- 人物可简化但不丑化。
