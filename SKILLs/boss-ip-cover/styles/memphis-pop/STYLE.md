# 孟菲斯波普（Memphis Pop）视觉原子

一套为「年轻消费 / 创意 / 活泼品牌」老板设计的孟菲斯语言。目标：玩趣、张扬、有态度，像 80 年代米兰设计。

## 材质（Materials）
- 亮色块拼接，几何图形（圆点/锯齿/波浪/三角），粗黑描边。
- 拒绝写实照片与柔焦。

## 空间逻辑（Spatial Logic）
- 不规则拼贴，图形跳跃，留白故意不均。
- 元素看似随意但有节奏，不堆满。

## 标题处理（Title Treatment）
- 粗体彩色字，黑色描边，随图形倾斜排布。
- 关键词可换对比色。

## 字体行为（Typography）
- 圆体无衬线，字重夸张，活泼。

## 肌理（Texture）
- 平面色块、图形拼贴，无真实肌理。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 黄：`#FFD23F` / 青：`#1BC0C9` / 粉：`#FF6B9D` / 黑：`#1A1A1A`

## 风格特有负向约束（Negative Constraints）
- 不要极简留白、暗调、严肃衬线。
- 不要柔焦、写实照片。
- 孟菲斯几何不可少。
