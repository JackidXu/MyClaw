# 经典杂志封面（Classic Magazine）视觉原子

一套为「高端人物专访 / 品牌故事」老板设计的大刊封面语言。目标：像《GQ》《三联》的封面，经典、优雅、有格调。

## 材质（Materials）
- 哑光铜版纸，柔光，轻微暗角。
- 拒绝高光塑料感与过度磨皮。

## 空间逻辑（Spatial Logic）
- 人物居中大图占主（占画面 55%-70%），气质优先。
- 刊名 logo 压顶（左上或中上）。
- 封面线条（封面故事/独家/专访）小字于边角排布。
- 留白克制，但人物与刊名之间要有呼吸。

## 标题处理（Title Treatment）
- 刊名标准字 + 大标题（封面故事名）。
- 引线小字（一句话卖点）于人物旁或底部。

## 字体行为（Typography）
- 刊名：高对比衬线（如 Didot 类）或定制标准字。
- 标题/引线：现代无衬线，干净。

## 肌理（Texture）
- 纸张微光泽、柔焦，四角轻微暗角。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 米白：`#F5F1E8`（留白/刊名区）
- 墨黑：`#1C1C1C`（刊名/标题）
- 低饱和强调：`#8A6D3B`（一抹暖棕，可选）

## 风格特有负向约束（Negative Constraints）
- 不要渐变光斑、霓虹、信息图堆叠。
- 不要电商促销满屏卖点。
- 不要卡通、emoji、过度滤镜。
