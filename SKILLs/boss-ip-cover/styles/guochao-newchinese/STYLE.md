# 新中式（New Chinese）视觉原子

一套为「本土老板 / 传统行业 / 国货 / 文化」设计的东方气韵版式。目标：像一幅当代水墨海报，有文化自信却不老气、不艳俗。

## 材质（Materials）
- 宣纸 / 绢丝肌理底，自然纤维颗粒，拒绝高光塑料。
- 细墨线作分隔与边框，不用粗黑框。
- 可选淡墨晕染、金箔细线点缀。

## 空间逻辑（Spatial Logic）
- 远近虚实：主体（人物 / 意象）如画中人也，周边大量留白如卷轴。
- 边角钤印（朱砂小印）点睛，不喧宾夺主。
- 竖排标题可选，留白如诗句节奏。

## 标题处理（Title Treatment）
- 书法感展示体或宋体重笔，字距通透。
- 长标题拆 2 行，主词加重，修饰词收小。
- 可用竖排，从右向左，呼应传统阅读。

## 字体行为（Typography）
- 标题：宋体 / 书法展示体。小字注解：现代无衬线（思源黑体）。
- 中文清晰为要，书法体不糊。

## 肌理（Texture）
- 全幅宣纸纹、淡墨晕染、边缘轻微做旧。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：宣白 `#F3EEE3` / 绢色 `#EDE6D6`
- 墨：墨黑 `#1C1C1C`
- 强调：黛青 `#2F4F4F` 或朱砂 `#B5402F`
- 点缀：金箔 `#C9A24B`（细线）

## 风格特有负向约束（Negative Constraints）
- 不要大红大绿艳俗、龙凤卡通、描金满铺。
- 不要西方衬线堆砌、信息图、价格标签。
- 不要「年画感」——保持当代克制。
- 标题不错字、不被裁切。
