name_en: Hand-drawn Warmth
outputs: [cover, poster]
best_for: 教育 / 育儿 / 生活方式 / 情感类老板，要亲近感与叙事温度
mood: 温暖、真诚、像朋友
style_anchors:
  - 材质：纸本手绘，铅笔 / 水彩边缘，柔软笔触
  - 空间：随性留白，人物与插画元素自然共处
  - 标题处理：手写感字体，像随手写下的标题
  - 字体：手写感 / 圆体，禁用冷硬几何
  - 肌理：纸纹、笔触、水彩晕染
  - 配色：奶油暖底 / 柔彩（藕粉、雾蓝、暖橙）
cover_shape_adaptation: 把主题压成一句像朋友说的话，用手绘人物与暖色营造安全感
must_preserve:
  - 手绘笔触与纸本温度
  - 柔和暖调，不刺眼
avoid_when_applying_to_cover:
  - 冷硬几何、金属感、商务蓝、信息图
  - 过度精致的「广告插画感」
