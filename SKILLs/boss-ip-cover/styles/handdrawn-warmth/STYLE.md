# 手绘温暖（Hand-drawn Warmth）视觉原子

一套为「教育 / 育儿 / 生活方式 / 情感」老板设计的纸本手绘版式。目标：像一个值得信任的朋友在笔记本上写给你看，温暖、真诚、有安全感。

## 材质（Materials）
- 纸本手绘：铅笔 / 水彩边缘，柔软笔触，拒绝冷硬。
- 轻微纸纹与水彩晕染，强化手作温度。
- 拒绝金属感、商务蓝、信息图。

## 空间逻辑（Spatial Logic）
- 随性留白，人物与插画元素（小图标、箭头、圈注）自然共处。
- 不是严格栅格，而是「手写笔记」的松弛感。
- 标题可穿插在插画之间，像随手标注。

## 标题处理（Title Treatment）
- 手写感字体，像随手写下的标题，可有轻微倾斜。
- 长标题拆短，语气像朋友说话。
- 可用圈注、下划线、箭头增强笔记感。

## 字体行为（Typography）
- 手写感 / 圆体，禁用冷硬几何无衬线。
- 中文清晰，手写不糊。

## 肌理（Texture）
- 全幅纸纹、铅笔笔触、水彩晕染。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：奶油暖 `#FBF3E7`
- 柔彩：藕粉 `#E8B7B0`、雾蓝 `#A9C4D4`、暖橙 `#E8A866`
- 线：暖褐 `#6B4F3A`

## 风格特有负向约束（Negative Constraints）
- 不要冷硬几何、金属感、商务蓝、信息图。
- 不要过度精致的「广告插画感」——要手作松弛。
- 柔彩不刺眼，整体低饱和。
- 标题不错字、不被裁切。
