# 编辑式人物大片（Editorial Portrait）视觉原子

以「老板本人」为绝对主视觉的封面语言。目标是人物气场与专业度，像杂志人物专访跨页或高端品牌代言，而非自拍或合照。

## 材质（Materials）
- 摄影级真实光影，单主光 + 轮廓光（rim light），浅景深（shallow DOF）。
- 背景柔焦，可虚化出几何块面或渐变，不抢人物。
- 保留皮肤质感与布料织理，拒绝塑料磨皮。

## 空间逻辑（Spatial Logic）
- 人物占画面 60%-70%，3/4 侧身偏置（左或右），留出标题呼吸区。
- 目光方向朝向标题或画面开口处，引导阅读。
- 微表情自然，不做作；可托腮、看镜头或看向某处。

## 标题处理（Title Treatment）
- 高对比单行人名 / 一句主张，置于人物留白侧或顶部。
- 字体：极简无衬线（重体）或精致衬线，字数少、字号大。
- 标题不压住五官，不破坏人物识别度。

## 字体行为（Typography）
- 一族到底，仅权重区分；中文用现代黑体或雅致宋体。
- 避免艺术字变形导致人名难认。

## 肌理（Texture）
- 皮肤细节、织物经纬、柔光斑（bokeh）。
- 整体偏胶片质感，轻微颗粒可选。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 中性影棚调：暖灰 / 深炭 / 米褐背景。
- 单一轮廓光：暖金或冷白，依品牌定。
- 人物服装颜色作为画面第二主色。

## 风格特有负向约束（Negative Constraints）
- 不要卡通化、多人同框、背景杂乱。
- 不要过度磨皮 / 网红滤镜 / 表情僵硬。
- 不要把人脸缩成角落小图当装饰。
- 真人参考图必须传入图生图以锁定身份，禁止「换封面换张脸」。
