# 森系自然（Organic Nature）视觉原子

一套为「健康 / 有机 / 可持续 / 农文旅」老板设计的自然质朴语言。目标：自然、质朴、安心，像一本植物图鉴。

## 材质（Materials）
- 自然肌理（木纹/麻布/叶脉），暖白底，手作感。
- 拒绝塑料高光与霓虹。

## 空间逻辑（Spatial Logic）
- 自然元素（枝叶/麦穗/山形）环绕主体。
- 人物可融入场景，不作孤立摆拍。

## 标题处理（Title Treatment）
- 衬线或手写，质朴，字重轻。
- 不抢自然元素。

## 字体行为（Typography）
- 衬线 / 手写，温和。

## 肌理（Texture）
- 纸张、植物肌理，轻微手作不规则。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 大地色：`#A6824C` / 草绿：`#7A9B6E` / 米白：`#F4EFE6` / 赭：`#8C5E3C`

## 风格特有负向约束（Negative Constraints）
- 不要霓虹、硬塑料、高饱和。
- 不要冷灰极简、金属。
- 自然肌理要真实，不卡通化。
