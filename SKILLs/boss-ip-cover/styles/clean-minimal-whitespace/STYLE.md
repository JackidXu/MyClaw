# 极简留白（Clean Minimal Whitespace）视觉原子

一套为「专业干货 / 观点输出」老板内容设计的安静版式。目标：像一本好书的扉页，靠留白和一句话的重量取胜，而不是靠视觉轰炸。

## 材质（Materials）
- 纯白或近白底（`#FAFAFA` / `#FFFFFF`），拒绝纹理、噪点、投影。
- 不叠加任何装饰材质；高级感来自「什么都没有」的克制。

## 空间逻辑（Spatial Logic）
- 主体（人物 / 产品 / 隐喻）只占画面 25%–30%，退到一角或一侧。
- 留白面积明显大于图形面积，形成呼吸感。
- 标题区与主体区互不重叠，靠间距而非框线分割。

## 标题处理（Title Treatment）
- 单一字重无衬线，字距宽松（letter-spacing 略放开）。
- 左对齐或居中，最多 2 行，长标题压短。
- 不加重金属、不描边、不加底托——字本身就是全部。

## 字体行为（Typography）
- 几何无衬线（Inter / 思源黑体 / 系统黑体）。
- 中文清晰为第一优先级，禁止艺术变形。

## 肌理（Texture）
- 无肌理，平涂到底。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 底：白 `#FFFFFF` 或近白 `#FAFAFA`
- 字：近黑 `#1A1A1A`
- 强调：单一灰阶 `#8A8A8A`（用于次级小字，不抢标题）

## 风格特有负向约束（Negative Constraints）
- 不要渐变、光斑、阴影、倒影。
- 不要卡通、 emoji、信息图堆叠、色块撞色。
- 不要框线包围、角标、价格标签。
- 标题不错字、不被裁切、不挤边。
