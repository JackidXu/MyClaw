# 极简黑白（Luxury Monochrome）视觉原子

一套为「高净值私域 / 高端品牌 / 奢侈调性」老板设计的极致黑白版式。目标：像一本时装屋的画册，冷峻、稀缺、不解释。

## 材质（Materials）
- 纯黑白，细腻灰阶过渡，哑光。
- 无纹理、无装饰材质，高级感来自光影与灰阶本身。
- 拒绝任何彩色与渐变光斑。

## 空间逻辑（Spatial Logic）
- 两种极端：极致留白（主体孤悬）或极致满版（单点聚焦）。
- 不居中讨好，而是用不对称制造张力。
- 留白是刻意的高级，不是空。

## 标题处理（Title Treatment）
- 高对比衬线（Didot 类）或极简无衬线，字距极宽（像时装屋 logo）。
- 长标题压短，主词加重，全大写可选。
- 不描边、不加底托——字与灰阶即全部。

## 字体行为（Typography）
- 标题：高对比衬线或极简无衬线。小字：同族细体。
- 中文清晰，衬线不糊。

## 肌理（Texture）
- 无肌理，靠灰阶过渡与微光影。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 纯黑 `#000000` / 纯白 `#FFFFFF` / 灰阶 `#6E6E6E` 等
- 零彩色，零强调色

## 风格特有负向约束（Negative Constraints）
- 不要任何彩色、渐变光斑、装饰花边、信息图。
- 不要热闹、满屏卖点、价格标签、电商感。
- 标题不错字、不被裁切。
- 灰阶过渡要细腻，不要硬边色块（除非满版单点聚焦）。
