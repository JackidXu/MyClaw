# 活力渐变（Vibrant Gradient）视觉原子

一套为「消费 / 美业 / 年轻消费品牌」老板设计的潮流渐变版式。目标：像一支种草短视频的封面帧，年轻、活力、让人想点。

## 材质（Materials）
- 流畅渐变流体，光感通透，轻玻璃质感（磨砂 / 折射）。
- 微光斑、柔焦，营造潮流空气感。
- 拒绝沉闷、纸质感、复古。

## 空间逻辑（Spatial Logic）
- 主体（人物 / 产品）居中或对角，渐变铺满画面。
- 留白少而精致，不空旷，但也不拥挤。
- 标题与渐变咬合，浮于色彩之上。

## 标题处理（Title Treatment）
- 圆润粗体，白色或深色，可选轻微立体 / 描边。
- 字距宽松，年轻化，长标题压短。
- 关键词可换色或放大。

## 字体行为（Typography）
- 圆润无衬线（如圆体 / 苹方圆），年轻化。
- 中文清晰，立体不糊。

## 肌理（Texture）
- 流体渐变、微光斑、柔焦、轻玻璃折射。

## 配色（Color System）
> ⚠️ 色值参考：以下 hex 仅为风格定义参考值，编译进最终图像 prompt 时一律转自然语言颜色名（如 #4FC3F7 → bright cyan），hex 不得出现在 prompt 主体；如需保留色值精度，集中放到 prompt 末尾「PALETTE (reference only)」段。详见 references/cover-blueprint.md「参数-文案隔离规则」。
- 渐变 2–3 色：珊瑚 `#FF6B6B`、紫 `#8B5CF6`、青 `#22D3EE`（高饱和但不脏）
- 字：白 `#FFFFFF` 或深 `#1A1A1A`
- 底：渐变铺满

## 风格特有负向约束（Negative Constraints）
- 不要沉闷商务、黑白、纸质感、复古。
- 不要渐变脏污、过度滤镜、信息图。
- 高饱和但不刺眼，保持通透。
- 标题不错字、不被裁切。
