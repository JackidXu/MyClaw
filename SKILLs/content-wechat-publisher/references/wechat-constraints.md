# 微信公众号平台硬约束与排版细则

> 维护转换器时参考。写作 / 排版时只需看「发布前检查清单」与各容器块语法。

## 1. 核心技术限制（转换器已自动处理）

| 限制 | 微信行为 | 本 skill 的处理 |
|---|---|---|
| 不支持外部 CSS | `<link>`、`<style>` 被剥离 | 所有样式写入元素 `style` 内联属性 |
| 不支持 JS | `<script>` 禁用 | 纯静态 HTML，无脚本、无动画、无交互 |
| 不支持 `position:fixed/sticky`、`transform`、`animation`、`filter` | 渲染异常 | 只用语义化 `section` + `flex` 布局 |
| 不支持本地图片路径 | `file://` / 相对路径不显示 | 用图床 URL，或后台手动上传 |
| 原生 `ul/ol` 渲染不稳定 | 缩进/符号错位 | 列表转 `<section>` + 自定义圆点/编号 |
| 暗黑模式颜色反转错 | 设计色被破坏 | 注入 `data-darkmode-color/bgcolor` 属性 |

## 2. 排版限制

- **最大宽度**：约 750px（移动端），正文区按 720px 设计，居中。
- **字体**：仅系统字体栈（PingFang SC / Microsoft YaHei / Roboto…），不用 `@font-face`。
- **表格**：列数 ≤ 4，移动端才友好；复杂表格建议拆图。
- **标题层级**：H1→H2→H3 合理递进（H1 作为文章主标题，正文用 H2/H3 分节）。

## 3. 内容限制

- 单篇正文 **200–20000 字**；图片 **≤ 10 张**（视频算 1 张）。
- 标题 **≤ 64 字**；摘要（digest）**≤ 120 字节**（UTF-8）。
- 外链：微信屏蔽外部链接，读者看到的是死文本 → 转换器自动转成上标脚注 `[n]` + 文末「参考链接」列表。
- 未认证公众号不支持外链；认证号外链也需审核。视频/音频只支持腾讯系，需后台手动插入。

## 4. 图片处理

- 微信不支持本地路径，`src` 必须是图床 URL 或上传后微信给的 URL。
- **转换器自动替换（推荐）**：排版阶段用 `wechat_convert.py` 的两个参数，本地相对路径直接变成图床 URL，省去手动改 `src`：
  - `--img-base https://你的图床域名/目录`：自动拼接图片文件名，如 `./01-封面.png` → `https://你的图床域名/目录/01-封面.png`；
  - `--img-map 图床映射.json`：`{"本地src或文件名": "完整URL"}` 精确替换（真实图床返回的 URL 最准，优先级高于 `--img-base`）；
  - 已是 `http(s)` 绝对地址则原样保留。两者都不给则保留原路径，仅供本地预览。
- 发布 API 路径：内文图用 `material/add_material` 或 `media/uploadimg` 换 URL；封面用 `material/add_material` 拿 `thumb_media_id`（草稿必填）。
- 本地预览（复制粘贴）路径：若没走上面替换、粘贴后图片显示异常，在后台「插入图片」重新上传，或把 `src` 换成图床链接。
- 建议图片 < 1MB、宽度 720–1080px、JPG/PNG。

## 5. 容器块语法（增强排版，可选）

在 Markdown 里用 `:::类型 ... :::` 包裹，转换器会渲染成微信兼容样式块（颜色取当前主题）：

```
:::callout tip
小标题（可选）
这里是提示内容。
:::

:::callout warning / info / danger   同上四种类型，图标不同

:::quote
一句值得引用的话，会自动加左侧竖条与浅底。
:::

:::pullquote
居中金句，大字号，自带装饰短横。
:::

:::label
小节标签（左竖条式）
:::
:::label pill
实色药丸标签
:::

:::steps
第一步要点
第二步要点
第三步要点
:::

:::dialogue
左边的问
> 右边的答
:::

:::timeline
时间线节点一
时间线节点二
:::

:::highlight
高亮框标题
高亮框正文说明。
:::

:::summary
总结标题
总结正文。
:::
```

行内仍支持 `**加粗**`、`*斜体*`、`` `代码` ``、`[链接](url)`、`![图](url)`。

## 6. 发布前检查清单

- [ ] 所有样式均为内联 `style`（无外部 CSS / JS）
- [ ] 标题 ≤ 64 字；摘要 ≤ 120 字节；正文 200–20000 字
- [ ] 图片 ≤ 10 张，且为图床 URL 或准备后台上传
- [ ] 表格列数 ≤ 4
- [ ] 外链已转脚注（文末有「参考链接」）
- [ ] 颜色用十六进制；无 `position/fixed/sticky/transform/animation/filter`
- [ ] 手机端可读（字号 ≥ 15px，图片自适应，表格可滚动，代码块不超屏）
- [ ] 草稿必须有封面（`thumb_media_id`）

## 7. 推送草稿（API）注意事项

- 凭据来自环境变量 `WECHAT_APPID`/`WECHAT_SECRET` 或 `--config` 本地 JSON，**绝不入库 / 不进分享包**。
- `access_token` 有效期约 2 小时，脚本带 5 分钟缓冲缓存。
- 失败不自动重试；保留本地 HTML，改走后台手动粘贴。
- 草稿创建后需人工在 mp.weixin.qq.com 核对封面 / 摘要 / 正文再发布。
