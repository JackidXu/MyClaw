## 4.5 观点引擎（取观点 · 锐度门槛 · 燃料分级 · 采集优先与自主推导）

> **观点定位：脊梁，不是桥梁。** 一条好内容能不能立住、被客户记住、自然接上卖点，全看观点。观点不是"把热点和业务连起来的桥"，而是整条内容的脊梁——热点和卖点都挂在它上面。本引擎解决三件事：**观点从哪抽、什么算好观点、建档素材不够时怎么办**。本引擎同时适用于 §5 事件选题与 §7 热点选题。

### 一、观点的本质：给客户一个"风险/机会"判断

观点不是立场声明（"我反对XX""我支持XX"），而是IP基于亲身经历和立场，对客户说的一句**判断**：

- **风险预警型**：这件事/这个趋势，对客户有什么潜在坑、代价、盲区？（例："金税四期上线，你的钱在税务局面前是透明的——你该给自己留条后路了"）
- **机会主张型**：客户该抓住什么、投入什么、能换回什么回报？（例："高才通收紧不是坏事，乱来的路被堵了，真想干的人反而被保护"）
- **反共识型**：反直觉的判断，打破客户固有认知（例："教育焦虑的本质不是升学焦虑，是身份焦虑"）

> **为什么必须落风险/机会**：老板出镜的视频，客户要的不是"听你讲道理"，而是"你帮我看清，这事对我有什么利弊、我该避开什么、该抓住什么"。观点若只停在"我怎么看"的层面、不落到客户钱包/人生的具体影响，就会变成讲道理——记不住，也接不上卖点。

### 二、燃料分级：建档素材决定了观点的"硬度"

观点不是凭空编的，它依赖IP档案提供的"燃料"。按燃料充足度分三级：

| 级别 | 建档素材状态 | 能产出什么观点 | 处理 |
|------|------------|--------------|------|
| **T0 理想燃料** | IP档案含 精神张力 / 好恶立场 / 独立观点 / 故事弹药 | IP独门判断（最锐利，别人抄不走） | 直接抽观点，过锐度门槛即可 |
| **T1 业务资料燃料** | 只有**业务资料库**（产品/服务/流程/踩坑点/客户画像/购买理由），缺立场与独立观点 | "业务推导观点"——优先尝试向老板采集真实态度；采不到时，从业务资料库真实事实自主推导的风险/机会判断 | **采集优先、推导兜底**：先轻量尝试采集一次（非阻塞），采到升T0；采不到→自主推导，且**必须标注"[AI自主推演·来源有风险]"**（详见第五节） |
| **T2 稀薄燃料** | 连业务资料都很少 | 仅有行业通用认知 | 自主推导"通用专业观点"，标注"[AI自主推演·来源有风险·建议建档后强化]" |

> **核心纪律（采集优先 · 推导兜底 · 必标风险 · 永不阻塞）**：① 建档已有真实立场 → 直接用（T0），最锐。② 缺真实立场时，**先尽力采集**——取观点环节轻量问老板一句真实判断（只问一次、非阻塞、不等），老板回应即升T0。③ **真的采集不到**（老板说"你定"/不回应/无档可查）→ 才自主推导"业务推导观点"（T1/T2），流程照常出选题。④ 凡自主推导的观点，**必须标注来源为"AI自主推演"并提示风险**：资料库中无该主题相关真实立场/案例，此判断由AI基于业务资料/通识推演，可能与IP真实立场有偏差，仅供草稿参考；若客户使用时觉得不对，应说明"因资料库缺相关数据才自主推演"，可补采资料后重推为T0。T0与T1标注须区分：T0=IP独门观点（真实立场），T1=AI自主推演观点（来源有风险）。⑤ **范围边界（铁律）**：自主推演**只作用于"观点/判断/立场"这一层**，且仅在**选题环节**因采不到观点时才触发——它不是通用机制，不用于脚本、文案等其他内容。业务资料库里的客户痛点、踩坑点、客户案例、产品事实等均为**真实素材**，AI 不得推演、改写、补全；推演出的观点**绝不写回 IP 档案**冒充已采集数据——它只是本次选题的临时产出，标 [AI自主推演]；若老板后来补了真实立场，仅用于本次/后续选题重推，不把推演内容塞进档案。

### 三、取观点五步（继承 ip-manager / strategy-map 的 DNA）

1. **取原料**：读IP档案——精神内核（张力）/ 好恶立场 / 独立观点 / 故事弹药库 / 业务资料库。
2. **找碰撞**：热点或事件 × IP立场 → 哪里有矛盾、反差、印证，哪里就是张力点。
3. **定三型**：风险预警 / 机会主张 / 反共识（见第一节）。
4. **写成一句判断**：是"IP的判断"（我判断XX会怎样 / 这事对你的风险是…），不是"你应该XX"的准则式说教。
5. **过锐度门槛**（下一节）。

### 四、观点锐度门槛（生成前预筛，对齐 script-writer & quality-guard 标尺）

每条候选观点用以下 5 问做**质量评级**（不是开关）：过越多条越锐。评级只决定观点标注为"T0独门"还是"T1业务推导"、以及是否建议在建档后强化——**任何情况下都输出选题，流程不阻塞**：

1. **是判断不是道理？** 是IP的独门判断/独门准则，而非泛泛的"行业常识"。（允许IP的独门准则式表达，如"我不招人"——那是立场，不是空道理）
2. **有信息差/反直觉？** 基于IP实操经验、外行不知道的东西；或打破客户固有认知。
3. **落到客户的风险或机会？** 对客户的钱包/人生有具体影响，而非自说自话。
4. **能展开60-90秒不水？** 有≥1个证据/故事/数据/客户案例支撑，老板能讲满不空。
5. **能溯源到精神张力或好恶立场？** 不是拍脑袋，能回溯到IP档案的某个锚点（T1状态可溯源到业务资料库的客户痛点/踩坑点）。

> 概念与下游统一：本门槛的"核心判断 / 新增价值(novelty) / 反方与边界"对应 script-writer 编辑五维的观点项与 quality-guard §520 观点检查三件套——**本引擎是生成前预筛，quality-guard 是发布前核验**，同一套标尺，不另造术语。

### 五、采集优先与自主推导（推导兜底 · 必标风险 · 引导补采）

**总原则**：能采集尽量采集（采集到的观点最准、最锐）；只有**真的采集不了**才自主推导。自主推导的部分**不是IP真实立场、可能有坑**，必须标注清楚来源与风险，并引导客户补采。

> **范围边界（铁律）**：① 自主推演**只针对"观点"这一层**——业务事实（客户痛点/踩坑点/案例/产品资料）是真实素材，不可推演、不可改写；② 触发条件**仅限选题环节的取观点步骤**且采不到真实观点时，不是全局自动机制；③ 推演结果**只作为本次选题卡里的临时标注**（[AI自主推演]），**绝不写回 IP 档案**、不把档案变成"都是推演内容"。

**第一步·先尝试采集（非阻塞、只问一次）：** 在事件 / 热点 / 业务三种模式的取观点环节（常青选题同此），若档案缺真实立场，AI 应先做**一次轻量采集**——只问老板一句真实判断（如"你对这个热点怎么看？用你自己的话给客户一句判断"）。规则：
- 只问一次，**不等、不卡**流程；
- 老板回应了 → 该观点升为 T0，按正常流程过锐度门槛；
- 老板说"你定"/不回应/无档可查 → 立即转第二步自主推导，不重试、不阻塞。

**第二步·自主推导（采集失败的兜底，T1/T2）：**
1. 热点抓取与评分照常进行（不依赖观点）。
2. 进入公式第三步，以**业务资料库的真实事实为底座**，仅对其做"风险/机会"判断的自主推导（注意：**事实本身不可推演，只推导"判断"**）：
   - 在资料库里找与热点同频的**客户痛点 / 行业通病 / 踩坑点 / 客户案例**（这些是**真实业务事实，原样引用，AI 不得编造或改写**）；
   - 仅对"这个热点，对客户意味着什么**风险或机会**"做 AI 判断推导，用上面的真实事实做支撑；
   - 写成一句判断，呈现为"从我们服务[X类客户 / X年]的经验看，这个热点最该警惕/抓住的是…"。
3. **必标风险来源（强制）**：该观点在选题卡中必须标注：
   - 标签：`[AI自主推演]` 或 `[AI自主推演·来源有风险]`
   - 说明：资料库中无该热点/事件相关的真实立场或案例数据，此观点由AI基于业务资料/行业通识推演得出，**可能与IP真实立场有偏差，仅供草稿参考，拍摄前建议老板确认**。
   - 引导补采：如客户使用时觉得不对，应说明"因资料库缺少相关真实资料，观点由AI自主推演"，并请老板补充真实态度/案例/立场，AI 将据此重推为 T0。
4. 过锐度门槛评级：业务推导观点通常能稳过"落到客户风险/机会"+"能展开（有材料事实支撑）"两条；若"独门/反直觉"偏弱，仍正常输出，但风险标注不变。
5. 若客户在后续对话中补充了真实立场，把T1升级为T0即可，无需重跑流程。

> **为什么必须标注风险**：业务资料库是IP生意经验的沉淀（帮客户规避什么坑、解决什么难题），从中推导"对客户的风险/机会"是**领域专家的正常推理框架**；但"判断/立场"本身是AI推演的，不是IP亲口说的，可能漏掉IP独有的视角或踩过的坑——所以必须标"AI自主推演·来源有风险"，让使用者在无真实资料时保持警惕、并知道如何补正。

**事件模式（T1 状态）：**
- 若事件是**老板真实口述的经历** → 走正常六感流程，观点从用户口述态度里取（§5第一步追问已覆盖），不触发推导。
- 若没有真实经历、只有产品资料 → **禁止伪造六感体验**，但可把资料里的真实客户案例/踩坑点作为事件素材，按"先采集→采不到再推导+风险标注"处理，产出**业务素材驱动型选题**。
- 即：事件模式优先用真实经历；没有真实经历也能从业务素材产出，但必须走采集优先+推导兜底+风险标注。

**T2 稀薄燃料（连业务资料都少）：**
- 用行业通识 + 热点做"通用专业观点"推导，标注"[AI自主推演·来源有风险·建议建档后强化锐度]"。
- 绝不因"素材少"就放弃输出或卡住流程。
