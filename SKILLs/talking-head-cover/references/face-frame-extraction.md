# 人物脸部特征图抽取（face-frame-extraction）

> 对应工作流 Step 1。目标：从视频里拿到**一张清晰、正面、无遮挡**的人物脸部特征图，用作出图时「身份层」硬锁参考，保证封面人物与视频是同一个人。

## 为什么要「抽多张直到拿到合适的」

单张随机帧常被字幕、手势、麦克风、咖啡杯遮挡，或逆光/模糊。口播视频尤甚——字幕往往压在下半脸。所以必须**批量抽帧 + 人工逐张筛选**，不能抽一张就用。

## 操作流程

### 1. 按固定间隔批量抽帧（覆盖整段）

```bash
mkdir -p face_frames && ffmpeg -v error -i "<视频路径>" -vf "fps=1/2" -q:v 2 face_frames/f_%03d.jpg
```

- `fps=1/2` = 每 2 秒 1 张；52 秒视频约 26 张，足够筛选。
- 视频很长（数分钟）可改 `fps=1/4`（每 4 秒 1 张）控制数量。

### 2. 逐张查看，按标准筛选

合格图需同时满足：

| 标准 | 说明 |
| --- | --- |
| 角度 | 正面或微侧脸（≤ 30°），五官清晰可辨 |
| 无遮挡 | 手、麦克风、大字幕、水杯、前景物体不挡脸 |
| 光线 | 均匀，不欠曝（黑脸）也不过曝（死白），分辨率高 |
| 表情 | 自然；说话微张嘴可接受，闭眼/怪表情不要 |

> 用 ViewImage 逐张看，重点检查脸部。数字人视频同理，抽一帧清晰数字人正脸。

### 3. 没合适的就继续抽

首批都不理想时，二选一加码：

- **加密采样**：`ffmpeg -vf "fps=1" ...`（每 1 秒 1 张，帧数翻倍）
- **只抽中段**：`ffmpeg -ss 5 -to 25 -i "<视频>" -vf "fps=1/2" -q:v 2 face_frames/f_%03d.jpg`（避开片头片尾字幕/黑场）

直到选出 **1 张**合格图，记录其路径。

## 4. 用作出图参考图

将该图作为图像模型的 `image1`（参考图用法 A：主体复现），并在提示词中**逐条锚定身份层**：

```
保持参考图人物的[脸型：方脸][发型：黑色短发][黑框眼镜][体型：偏瘦][标志性特征：XX]
```

`input_fidelity` 设高，确保人物不变。搭配层（衣着颜色/款式）若与目标画面氛围冲突可协调，但身份层不动。

## 备注

- 若视频全程无清晰正脸（如只拍手部/背影），则无法硬锁身份层，需在交付时说明，改用「风格借用」（用法 B）或纯文生图。
- 抽帧图仅作参考输入，不直接当封面（清晰度/构图通常不达封面标准）。
