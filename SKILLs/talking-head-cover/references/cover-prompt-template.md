# 口播封面提示词模板（cover-prompt-template）

> 把方括号内容替换为真实信息，保留「主体-场景-风格-道具」四要素结构。身份层来自脸部特征图（Step 1），三层文字来自 `transcription-and-copy.md`（Step 2）。构图的空间关系按「构图整合」段定义。文字默认按「图内文字」增强模式由模型直出。

---

## 模板（直接填空）

```
【主体 SUBJECT — 身份层硬锁】
保持参考图人物[脸型：方脸][发型：黑色短发][黑框眼镜][体型：偏瘦][标志性特征：XX]；
动作姿态[双臂自然交叉/身体前倾]，表情[专业而亲和，微笑]，正在对镜头讲解。

【场景 CONTEXT — 按构图与文字安全区填写】
示例：暖光咖啡店室内，浅景深；主体置于画面下半部、占下 60%，
上方 40% 为标题区（放主标题+卖点）；整体明亮温暖、商务休闲。

【风格 STYLE】
85mm 人像镜头、f/2.0 浅景深、暖色调电影感柔光、清晰锐利、商业人像质感、高完成度。

【道具 PROPS — 3 到 4 个，叙事关联、分层、占比≤30%】
1) 手边中景一杯带拉花拿铁咖啡；
2) 中景平板显示口播分镜草稿；
3) 背景虚化处一盆绿植与暖光吊灯；
4) 领口一枚小巧品牌金属徽章（信任符号）。

【文字 — 按「图内文字」增强模式由模型直出】
主标题 "XXX"，加粗无衬线大字、白色，占文字视觉权重 50%；
副标题/卖点 "XXX"，中号、暖金色，权重 30%；
辅助/CTA "XXX"，小号白字配深色底条，权重 20%。
文字区对应构图空间关系与文字安全区，每区单一对齐基准，不越四边各 ≥ 8% 安全边距。

【搭配层协调声明 — 如有冲突才写】
⚠️ 已将参考图[浅色休闲服]调整为[深色西装]以适配[深色海报]氛围，如需保持原貌请明说。
```

---

## 映射到图像模型参数

| 参数 | 建议值 | 说明 |
| --- | --- | --- |
| `image1` | Step 1 选中的脸部特征图 | 参考图用法 A，主体复现 |
| `input_fidelity` | `high` | 硬锁身份层，人物不变 |
| `size` | `1080x1920`（或 `1072x1920`） | 竖屏 9:16 封面 |
| `quality` | `high` | 商业质感 |
| `prompt` | 上方填空后的完整提示词 | 中文为主，摄影术语可英文 |
