# 视频文案转录与封面文字总结（transcription-and-copy）

> 对应工作流 Step 2。封面文字必须来自视频真实内容，不杜撰。流程：转写配音 → 总结三层文字。

## 1. 转录配音文案

本机 `/usr/bin/python3` 自带 whisper（base 模型，已缓存）：

```bash
# 抽音频
ffmpeg -v error -i "<视频路径>" -vn -acodec pcm_s16le -ar 16000 -ac 1 audio.wav

# 转写
/usr/bin/python3 - <<'PY'
import whisper
m = whisper.load_model("base")
r = m.transcribe("audio.wav", language="zh")
print(r["text"].strip())
# 如需带时间戳分段：
# for s in r["segments"]: print(f"[{s['start']:.1f}] {s['text'].strip()}")
PY
```

> 若 `/usr/bin/python3` 无 whisper，回退到 `python3 -m whisper` 或任意可用 ASR；重点是把中文配音变成可读文本。

## 2. 把文案总结为三层封面文字

按「文字层级规范」拆成三层（权重：主标题 50% / 副标题·卖点 30% / 辅助·CTA 20%）：

### 主标题（1 条，~50% 权重）
- 抓**痛点**或**核心卖点**，口语化、有冲突感（例：「老板最头疼的内容」「内容跟不上？」）。
- 竖屏可读，建议 **≤ 12 字**；可断 2 行放大。
- 不必把全片信息塞进去，留钩子即可。

### 副标题 / 卖点（1–2 条，~30% 权重）
- 承接主标题，给方案或利益点（例：「超会AI 几十分钟出一条口播」「抖音·视频号·小红书 一键分发」）。
- 每条 ≤ 18 字，信息密度高、不啰嗦。

### 辅助文字 / CTA（1–2 条，~20% 权重）
- 引导动作：评论区扣关键词、关注、领资料、私信等（例：「评论区扣『超会』领演示」）。
- 可带品牌名/关键词高亮（暖金/橙）。

## 3. 总结原则

- **忠于原片**：标题卖点必须能在转写文案里找到依据，不编造数据/头衔。
- **具体胜于模糊**：用原片里的真实词（如品牌名、具体平台名、具体时长）。
- **口语化自然**：沿用用户/账号语气，避免书面长句与诊断腔。
- **重点词高亮**：品牌名、关键数字、核心动词用颜色差异建立层级。
- **安全边距**：所有文字不越过画面四边各 ≥ 8% 区域；每区单一对齐基准（左/居中/右）。

## 4. 文字去向：优先写进提示词（模型直出）

三层文字**默认按「图内文字」增强模式写进生图提示词**，由模型直出（引号标注精确文字 + 字体/字重/字号/颜色 + 位置）。整理成如下结构便于填入提示词：

```
brand   = "超会AI"
brand_tag = "老板口播 · AI内容工厂"
title_lines = ["老板最头疼的内容", "超会AI 几十分钟搞定"]   # 可含需高亮子串
title_accent = ["超会AI", "几十分钟"]
subtitle_lines = [
    "你讲卖点 → 自动出脚本+数字人口播",
    "抖音·视频号·小红书 一键矩阵分发",
    "矩阵号同跑 · 多语种出海也行",
]
cta = "评论区扣「超会」领演示"
cta_accent = ["超会"]
```
