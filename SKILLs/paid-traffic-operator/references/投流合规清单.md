# 投流合规清单（投流操盘手 · Step6 支撑文件 · 自包含）

> 用途：投流视频发布前的合规自检。投流是「广告」，合规比普通内容更严——广告法 + 平台审核 + 引流风险三层都要过。
> 来源：从 content-quality-guard（IP包）蒸馏的「投流专用」子集，本 Skill 自带，不依赖 quality-guard 是否安装。
> 配套使用：SKILL.md §5 Step6、§7 脚本模板的「合规自检」表。
> 使用纪律：每条脚本交付前逐行过一遍；任一 ❌ 未消除 → 不交付。

---

## 一、广告法禁用词（绝对化 / 虚假宣传）

以下词在广告语境中**禁止或极高危**，必须替换：

### 1.1 国家级 / 最高级 / 最佳类（广告法第九条明令禁止）
- ❌ 国家级、最高级、最佳、最、第一、唯一、首个、首选、顶级、极品、极致、绝无仅有、空前绝后、万能
- ❌ 第一品牌、领导品牌、领先品牌、销量第一、排名第一、市场占有率第一
- ✅ 替换：用「可验证的具体事实」代替，如"服务过 320 家企业"而非"服务第一"

### 1.2 绝对化承诺 / 保证类
- ❌ 100%、绝对、 guaranteed、保证、确保、必定、一定、永久、终身（用于效果承诺）
- ❌ 根治、治愈、包好、药到病除、永不复发（医疗健康尤其高危）
- ✅ 替换：说「帮助」「支持」「多数客户反馈」，不替客户结果打包票

### 1.3 诱导 / 虚假对比类
- ❌ 国家级机构认证（无凭证）、假一赔十（无机制）、全网最低价（无法证伪）
- ❌ 贬低同行："别家都是坑""只有我们靠谱"
- ✅ 替换：讲自己的差异事实，不踩同行

### 1.4 限时 / 限量制造焦虑类（需真实）
- ⚠️ "仅限今天""最后 3 个"——若不实属虚假宣传，必须真有限时/限量机制

## 二、平台引流雷区（抖音 / 视频号 / 小红书）

> 投流结尾要「接流量」，但硬导流会被限流/拒审。按平台差异化表达。

| 平台 | 高危雷区 | 合规表达建议 |
|------|----------|--------------|
| 抖音 | 口播/字幕直接说"加微信""私信我微信号"、展示二维码、留联系方式 | 引导「主页/评论区/私信组件」；用平台允许的留资组件；不说完整微信号 |
| 视频号 | 直接留个人微信、外部跳转链接 | 用视频号助手/企业微信组件；引导"点主页加" |
| 小红书 | 站外导流（微信/淘宝）、二维码、"私我"过直白 | 用小红书专业号组件/私信自动回复；不说"加微信" |

**通用红线**：
- ❌ 口播念出完整手机号/微信号/QQ
- ❌ 画面长时间展示二维码（部分平台直接拒审）
- ❌ 用"私我领取"但实为站外导流话术诱导
- ✅ 钩子商品用平台允许的组件承接（如抖音留资、企业微信）

## 三、行业特殊禁词（高危行业加严）

借 content-script-writer 风险分级（🔴高危行业合规是第一红线）：

| 行业 | 风险级 | 额外禁区 |
|------|--------|----------|
| 医疗健康 | 🔴高危 | 疗效承诺、疾病治疗用词、处方药推广、资质未明示 |
| 财经 / 理财 | 🔴高危 | 收益承诺、稳赚不赔、荐股、无资质金融建议 |
| 法律 | 🔴高危 | 包赢、保证胜诉、个案替代法律意见 |
| 教育 | 🟠中危 | 保过、提分承诺、升学保证 |
| 美业 | 🟠中危 | 制造容貌焦虑、医美疗效绝对化、无资质医美宣传 |
| 保健食品 | 🟠中危 | 治疗功效暗示、疾病预防宣称 |

> 投流涉及以上行业 → 结尾与方案段额外过「行业禁词」，且建议提示客户确认资质。

## 四、风险审查（通用）

1. **虚假承诺 / 绝对化保证**：任何"保证结果"的表达 → 改可验证事实或删。
2. **未核实数据**：标 🔴需验证 的，发布前必须核实；核实前不出。
3. **诱导分享 / 诱导下载**："转发得XX""下载领XX"需符合平台规则。
4. **知识产权**：用了客户/第三方案例、头像、数据 → 需授权，否则模糊/替换。
5. **未成年人 / 敏感群体**：不针对未成年人营销高危品类。
