# 解决方案方法论库模板（投流操盘手 · Step4 支撑文件）

> 用途：捕获并持久化「客户独有」的解决方法论——这是投流视频方案段的核心弹药，也是转化力的来源。通用套路没有差异化，投出去不打动人。
> 借用关系：挖法借 content-ip-manager 的「挖独门方法逻辑」；方案文案落点借 content-script-writer 的「转化三刀」（卖点→买点）。
> 配套使用：SKILL.md §5 Step4；产出 `references/解决方案方法论库_{客户}.md`。
> 红线：本库只记录客户真实有的方法论，**不得编造、不得从通用模板套**。挖不到 → 如实追问客户，不补写。

---

## 1. 为什么要单独建这个库

IP 流程里「方法论」是人物的能力构成（信任理由型）。投流里「方法论」是**产品/服务怎么真正解决客户问题**——它是方案段的骨架。

客户的方法论往往藏在话术里，不挖就只是"我们服务好、我们专业"这种废话。本库负责把它挖成「可口播、可验证、有差异化」的结构化资产，per-client 持久保存，下次同类投流直接复用。

---

## 2. 一条方法论的字段结构（必填）

```markdown
## 方法论：{名称}
- 解决什么问题：{客户的具体痛点场景}
- 步骤（A→B→C→…）：{客户实际操作的先后次序，越具体越好}
- 独门心法：{客户跟别家最大的不同在哪，那句"只有他懂"的话}
- 差异化（对比别家）：{别家怎么做 / 客户怎么做 / 差异带来的结果}
- 适用条件：{什么客户、什么阶段用了有效}
- 不适用条件：{什么情况用不了 / 用了没用}
- 关键那一下：{客户操作时最见功力的一个动作/判断，决定成败的那一下}
- 证据/结果：{做过的案例、数据、客户原话}
- 来源：{本次对话·客户口述 / IP档案·业务资料库}
- 事实状态：{🟢事实 / 🟡判断 / 🟠推测 / 🔴需验证}
```

> 一个客户可以有 1-3 条方法论（针对不同核心痛点）。每条独立成块。

---

## 3. 挖法（多轮追问，不一次性抛 20 问）

借 content-ip-manager「拆问题+给选项」的减负逻辑，每轮 1-3 个具体问题，3 轮内挖清。

### 第 1 轮：摸步骤
- 「你给客户解决『{核心痛点}』的时候，第一步一般做什么？」
- 「然后呢？中间最关键的那一步是什么？」
- （给选项辅助）「是按 A 诊断→B 方案→C 落地，还是别的次序？」

### 第 2 轮：挖差异化与心法
- 「同样的问题，别家一般怎么解？你跟他们最大的不同在哪？」
- 「你自己有没有一句总结这个方法的话？（你的独门心法）」
- 「客户在你这和别家体验的最大不同是什么？」

### 第 3 轮：抠关键那一下 + 适用边界
- 「整套做下来，最见功力、最决定成败的是哪一下？」
- 「什么客户用这个最有效？什么情况其实用不上？」
- 「有没有一个客户用了之后特别明显的例子？（数据/原话）」

> 不挖清楚不写方案。客户说"就是服务好"→ 追问到具体动作；客户说"我们有独家技术"→ 追问技术到底独特在哪、有无证据。

---

## 4. 方案文案落点：转化三刀（借 content-script-writer）

挖到方法论后，写方案口播时过「转化三刀」，把卖点思维转成买点思维：

| 刀 | 做法 | 反例→正例 |
|----|------|-----------|
| ① 追问"所以呢" | 把方法追到客户能感知的损失/收益 | "我们用 X 方法" → "所以用 X 方法，你不用再{痛点}，每月省{数字}" |
| ② 换主语"我→你" | 从"我们"转到"你"的视角 | "我们提供诊断" → "你点一下，马上知道问题出在哪" |
| ③ 配可感知结果 | 给一个客户能想象的具体结果 | "提升效率" → "原来 3 天的活，半天搞定" |

**自检**：方案段落主语是不是全是"我们/我"？是 → 还没过转化三刀，退回重写。

## 5. per-client 库文件结构

文件名：`references/解决方案方法论库_{客户}.md`

```markdown
# 解决方案方法论库：{客户}

> 创建：{日期} | 最近更新：{日期}
> 关联产品：{产品1}（痛点A）、{产品2}（痛点B）
> 来源：本次对话挖掘 / IP档案业务资料库

## 方法论1：{名称}
（按 §2 字段结构填写）

## 方法论2：{名称}
（同上）

## 使用备忘
- 哪条方法对接哪个投流脚本的 Step4（理由链③~⑤）
- 客户确认状态：{已确认 / 待确认}
```

---

## 6. 红线（必守）

1. **不编方法论**：客户没说、没证据的一律不写；标 🔴需验证，发布前核实。
2. **不套通用模板**：避免"我们专业、我们用心、我们一对一"——这些不是方法论，是废话。
3. **Step4 必须客户确认**：方法论理解对不对、步骤缺不缺、关键那一下漏没漏，客户明确拍板后才定稿。
4. **差异化要真**：对比别家的差异必须客户能说清，不能编"别家都不做"这种无法证伪的话。
