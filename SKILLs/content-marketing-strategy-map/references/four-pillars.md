# 四柱通用分类（短视频 + 朋友圈 共用）

四柱（立人 / 立信 / 立言 / 立势）来自 IP 档案（content-ip-manager 信任审计），是 IP 的**底层人格维度**。本文件把它定义为**短视频与朋友圈共用的内容分类框架**——每条内容不论公域还是私域，都按四柱分类，从而能在周 / 月层面检视"人格维度配比"是否均衡。

> 朋友圈原本只在 content-moments-planner 内部用了四柱；本文件将其提升为**通用定义**，两个 skill 共用同一份，避免各写一份。

---

## 四柱定义

| 四柱 | 含义 | 典型内容 |
|------|------|---------|
| 立人 | 三观人品、真实经历、人设 | 价值观、初心、日常真实面、人设故事 |
| 立信 | 积累信任 | 案例、客户反馈、工作过程、凭证 |
| 立言 | 方法论、专业输出 | 干货、观点、行业认知、拆解 |
| 立势 | 涨势能、被认可 | 互动、认可、里程碑、福利、破圈曝光 |

---

## 内容目的 → 四柱 映射（短视频 / 朋友圈通用）

规划层用"内容目的"定方向，落内容时再标四柱（每条 1 个主四柱，可选 1 个次四柱）。

| 内容目的 | 主四柱 | 次四柱 |
|---------|-------|-------|
| 破圈（破壁 / 势能） | 立势 | 立人 |
| 种草（打磨认知） | 立言 | 立信 |
| 升维（拔高认知） | 立言 | 立势 |
| 感召（招人 / 招代理） | 立人 | 立信 |
| 圈层（社交证明） | 立信 | 立人 |
| 凭证（案例证明） | 立信 | 立言 |
| 信任（建设信任） | 立信 | 立言 |

---

## 配比检视

- 每条内容标 **1 个主四柱**（可选 1 个次四柱）。
- 周 / 月层面统计四柱出现次数，对照 IP 档案四柱配比基线：**弱柱多补内容、强柱适当减**。
- **短视频与朋友圈合并统计**——同一人格维度，两条渠道合力（如周一短视频=立人、同日朋友圈早间=立人，算 2 次立人）。
- 配比建议基线：立人 30% + 立信 25% + 立言 30% + 立势 15%；弱柱 +10%、强柱 -10%（按信任审计微调）。
