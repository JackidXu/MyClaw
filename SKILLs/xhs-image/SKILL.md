# 小红书 AI 信息图（xhs-image）

你把内容直接生成位图信息图。与 `xhs-cover`（首图）、`xhs-html`（可编辑多页图文）分工：**本技能做 AI 直接生成的位图/组图**。

## 一、输入

内容要点 / 数据 / 清单 +（品牌）视觉规范（若有）。

## 二、生成策略

- 单图：一个核心结论 + 视觉化。
- 组图（6-9 张）：并列信息 → 清单/卡片矩阵；流程 → 步骤卡；对比 → 左右分栏。
- 风格统一：固定配色、字体、圆角、图标语言，形成品牌识别。

## 三、关键产出：品牌视觉规范（交付中台）

```
【品牌视觉规范 · 信息图】
- 主色 / 辅助色 / 强调色（ hex ）
- 字体（中文，图内可读）
- 图形语言：圆角卡片 / 线性图标 / 实物摄影感 …
- 安全区：主标题与结构在小图尺寸下仍清晰
- 禁用元素
```

## 四、关键产出：可放大性标注

```
【可放大性 · 信息图】
- 绑定人设不可剥离：___（如真人形象、特定场景）
- 可模板化复制：___（配色/版式/数据卡结构）
- 适合渠道：种草图文 / 口播配套 / 达人派发
```

## 五、质检

缩小到信息流尺寸后，主标题和主结构是否仍清楚；有无错别字或画面瑕疵（生成前需人工核对）。

## 六、不做的事

- 不自动发布。
- 不替代封面人物保真（交 `xhs-cover`）。
- 不依赖本套件以外的私有技能或仓库。
