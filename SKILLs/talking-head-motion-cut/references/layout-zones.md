# 三层布局分区规范（layout-zones）

## 3 种布局模式

一段口播视频可选 3 种布局之一，也可在一段视频里混用（比如前几段上下结构，中间一段切画中画全屏分析，结尾总结卡全屏）。

### 模式 1：上下结构（竖屏 9:16 默认）

适用：竖屏口播原片，人物居中。

```
┌──────────────┐
│  动效卡       │  ← 顶部约 25% 高度（如竖屏 1920 高→约 460-480px）
│  (top:30)    │     只遮额头不遮五官，人脸全程可见
├──────────────┤
│              │
│   视频原片    │  ← 视频满屏，人物全程可见
│   (满屏)     │
│              │
├──────────────┤
│  字幕 rail   │  ← 底部（如 top:1300 height:200）
└──────────────┘
```

动效卡 CSS：`left:40px; top:30px; width:1000px; height:460-480px;`（竖屏 1080×1920）

### 模式 2：左右结构（横屏 16:9）

适用：横屏口播原片。

```
┌──────────────────────────┐
│              │           │
│   视频原片    │ 动效卡    │  ← 动效卡在右侧约 25% 宽度
│   (满屏)     │ (right)   │     （如横屏 1920 宽→约 480 宽）
│              │           │     height 接近画高，top:30
│              │           │
├──────────────────────────┤
│       字幕 rail          │  ← 底部
└──────────────────────────┘
```

动效卡 CSS（右侧）：`left:1432px; top:30px; width:480px; height:1020px;`（横屏 1920×1080）  
动效卡 CSS（左侧）：`left:40px; top:30px; width:480px; height:1020px;`

视频保持满屏不动，动效卡浮在侧边。和上下结构同思路，只是从"顶部 25% 高度"改成"侧边 25% 宽度"。

### 模式 3：画中画（人物缩角落圆角小窗）

适用：内容为主、人物为辅的段落（如全屏分析流程图时）。

```
┌──────────────────────────┐
│  动效卡(满屏)    ┌──────┐ │  ← 动效卡占满屏
│                  │人物  │ │     人物缩成右上角圆角小窗
│                  │小窗  │ │     （pip-pill 样式：圆角+阴影+白边）
│                  └──────┘ │
├──────────────────────────┤
│       字幕 rail          │  ← 底部，最顶层
└──────────────────────────┘
```

实现：

1. 动效卡 `left:0; top:0; width:画宽; height:画高;`（满屏）
2. 用 GSAP 把 `#video-wrap` 缩成角落小窗 + 加 `.pip-pill` 类：
   ```javascript
   tl.set('#video-wrap', { className:'+=pip-pill' }, START_SEC);
   tl.to('#video-wrap',
     { left:738, top:28, width:312, height:555, duration:0.6, ease:'power2.inOut' }, START_SEC);
   ```
3. 切回满屏人物时反向 tween + 去掉 pip-pill 类

### 模式 4：信箱居中式（横屏源 → 竖屏成片）

适用：客户给的是横屏 16:9 原片，但要求产出竖屏 9:16 成片。

做法：横屏原片居中放置、保持 16:9 不变形，画布上下用黑边补齐到 9:16；上方黑边区域当作动效区，下方黑边区域当作字幕区。人物（视频主体）在正中，上下黑边都不遮人物，只承载动效卡和字幕。

```
┌──────────────┐
│  动效区(黑边)  │  ← 上方黑边，当作动效卡 zone（如 top:30 height:560）
│              │
├──────────────┤
│              │
│   横屏原片    │  ← 居中、16:9 不裁切（1080×608，top:656）
│   (居中)     │     上下黑边由 stage 黑底补齐
│              │
├──────────────┤
│  字幕区(黑边)  │  ← 下方黑边，当作字幕 rail zone（如 top:1300 height:200）
└──────────────┘
```

几何（竖屏画布 1080×1920，16:9 源）：

- 视频宽 1080，高 = 1080 × 9 / 16 = 607.5 ≈ 608，垂直居中 → top = (1920-608)/2 = 656
- 上方黑边：0–656px（动效区）
- 下方黑边：1264–1920px（字幕区）

CSS 与 HTML 声明（与默认满屏写法只差在 #stage 声明 `data-fit-mode="contain"` 及 video-wrapper 样式）：

```html
<!-- 在 #stage 声明 contain 模式，底座渲染器 render.js 将自动应用等比居中无裁切贴合 -->
<div id="stage" ... data-fit-mode="contain">
```

```css
/* 模式 4：video-wrapper 不再满屏，改成居中信箱 */
.video-wrapper { position:absolute; left:0; top:656px; width:1080px; height:608px; overflow:hidden; }
.video-wrapper video { width:100%; height:100%; object-fit:contain; }  /* 不裁切，黑边交给 stage 黑底 */
```

动效卡 CSS（复用竖屏顶区坐标，黑边更高可放更多元素）：`left:40px; top:30px; width:1000px; height:560px;`  
字幕 rail CSS（落在下方黑边内）：`left:0; top:1300px; width:1080px; height:200px;`

要点：

- 视频绝不裁切（`data-fit-mode="contain"` + `object-fit:contain`），保持客户原片完整画面；黑边是设计区不是浪费。
- 上方黑边比上下结构默认的"顶部 25%"更高（约 656px vs 480px），按"区域越大内容越多"原则，动效卡可承载 4–8+ 个元素。
- 字幕仍走最顶层（track-index=10），落在下方黑边内，不压人物。
- 标题卡、全屏总结卡坐标与竖屏上下结构一致（标题在上方黑边、总结满屏），无需改。
- 此模式与模式 2（左右结构）区分：左右结构是横屏源→横屏成片、视频满屏；本模式是横屏源→竖屏成片、视频居中黑边。

## 字幕永远在最顶层（关键规范）

**字幕 rail 和 标题卡 的 track-index 永远最大，任何动效卡（含全屏分析卡/总结卡）都不能盖住字幕。**

正确做法：

- 字幕 rail：`data-track-index="10"`（或任何大于所有动效卡的值）
- 标题卡：`data-track-index="5"`
- 动效卡：`data-track-index="3"` 到 `"4"`
- 全屏总结卡：`data-track-index="4"`（小于字幕的 10，所以字幕会盖在它之上）

track-index 机制：数值大的层在数值小的层之上（后绘制覆盖前绘制）。所以字幕要盖住动效卡，字幕的 track-index 必须更大。

## 布局混用

一段视频可以混用布局。比如竖屏口播视频：

- 前 5 段用上下结构（动效卡顶部约 25%）
- 中间一段要画流程图，切画中画（动效卡满屏 + 人物缩角落）
- 结尾总结卡全屏（满屏总结，字幕照常在底部）

混用时，动效卡和画中画的切换用 GSAP tween 平滑过渡，不要硬切。
