# 视觉设计指南（选风格参考表）

本文件是 `talking-head-motion-cut` 视觉库的「使用说明书」。**视觉 = 三层，变化范围各不同**：

| 层         | 是什么                                               | 变化范围               | 规则                        |
| --------- | ------------------------------------------------- | ------------------ | ------------------------- |
| **① 身份层** | 1 个 Style（配色/字体/卡片基调）+ 1 个 Frame + 1 套 `:root` 变量 | **每片只选 1 次，永不每卡变** | 全片统一，这是"整体感"的来源           |
| **② 节奏层** | 布局 zone（上下/左右/画中画/信箱）+ 动效原语                       | 每段按内容权重变           | 你已有，不变                    |
| **③ 点缀层** | 表情/气泡/点赞（来自风格本身，如 xhs 的 ❤️💬 行，或按需内联）             | 稀疏，只出现在语义时刻        | 复用 `var(--c-primary)`，不跳戏 |

> ⚠️ **最重要的一条**：风格/边框/主题**每片选一次**，绝不在每张卡换一套。每卡都换 = 随机幻灯片，整体感崩塌。变化交给"布局 + 动效 + 稀疏点缀"。

---

## 一、怎么选（4 步）

1. **看内容调性** → 从下面「内容类型 → 风格」挑 1 个 Style。
2. **看画幅/布局** → 选 Frame（默认 `clean`，最安全）。
3. **拷进 composition**：把该 Style 文件顶部的 `:root 重映射` 块粘到 composition 顶部 `<style>`（全片配色即统一）；需要"签名卡"时再把文件里的 `.card` 片段粘到对应段。
4. **看语义** → 需要表情/气泡/点赞时，用风格自带（如 xhs 的 ❤️💬 行）或内联写进卡片（稀疏！）。

## 二、内容类型 → 建议组合

| 视频内容            | 建议风格                       | 建议布局     | 建议边框             |
| --------------- | -------------------------- | -------- | ---------------- |
| 访谈 / 对话 / 反思    | `academic`                 | 上下 / 左右  | clean / hairline |
| 严肃数据 / 财报 / 调查  | `audit` 或 `swiss`          | 左右 / 上下  | hairline         |
| 技术分析 / 工程思考     | `terminal`                 | 左右 / 画中画 | hairline / clean |
| 产品发布 / 大字宣言     | `editorial` 或 `geom`       | 画中画 / 信箱 | clean            |
| 社交剪辑 / 种草 / 小红书 | `xhs`                      | 信箱 / 上下  | clean / polaroid |
| 情绪故事 / 旁白 / 角色弧 | `spotlight` 或 `whiteboard` | 信箱 / 画中画 | clean            |
| 极简陈述 / 数据揭示     | `minimal`                  | 左右 / 上下  | clean / hairline |
| 教程 / 草图思考 / 灵感  | `whiteboard`               | 画中画 / 信箱 | polaroid / clean |

> 这只是起点。看转录、定调性、再定视觉——不要反过来。

## 三、竖屏字号缩放（1080×1920）

风格库文件里的尺寸已按竖屏放大。若你要改，记住比例：

| token        | 横屏(参考)  | **竖屏**       | 倍数    |
| ------------ | ------- | ------------ | ----- |
| 主标题 h1/h2    | 64–96px | **88–132px** | ×1.35 |
| 详情/正文        | 24–30px | **30–40px**  | ×1.30 |
| 标签/chip/meta | 14–18px | **18–22px**  | ×1.25 |
| 大数字/统计       | 48–60px | **64–88px**  | ×1.40 |
| 左右内边距        | 40–64px | **24–36px**  | ÷1.5  |

`竖屏 px ≈ round(横屏 px × 1.3)`，主标题可到 ×1.4；小 meta 保持 ×1.2。内边距竖屏要**缩小**（卡片更窄）。

## 四、快速换肤模板

选好风格后，composition 顶部 `<style>` 里这样统一全片（示例为 `academic`，换成你选风格的 `:root 重映射`）：

```css
:root{
  --c-primary:#2557a7; --c-primary-soft:#5b8fd6; --c-primary-deep:#1a3f7a;
  --c-accent:#c14d2c; --c-text:#1a1d2b; --c-text-dim:#5b5749;
  --c-bg-deep:#f1ead8; --c-bg-card:rgba(241,234,216,0.94);
}
```

需要"整段都用该风格签名卡"时，把对应 `references/styles/<name>.html` 里的 `.card[data-card-id="ref-<name>"]` 整段（含 `<style>` 与 `.root`）粘到该段 `.card-host` 内，并给外层 `.card-host` 配 `data-start/data-duration` + 在 `<script>` 里加 `motIn/motOut`。
